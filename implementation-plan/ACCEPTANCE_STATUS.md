## Capacity decision implemented; resource budget accepted in the owner-decision addendum

A reduced-budget regression showed that SQL write accounting omitted part of the backup envelope. Shared envelope sizing fixes it. The second failure was unused epoch growth on repeated restore. On 2026-11-02 the owner explicitly approved deferring the empty local learning epoch until the first subsequent learning write. The dated Master Plan addendum records the normative refinement without rewriting the historical specification.

The implementation preserves every existing epoch and records local restore provenance immediately. Idempotent/no-op operations and failed mutations leave the deferred context intact; the first actual learning write creates the epoch atomically. Malformed or foreign local pending metadata disables V2 writes. Stable projection/review reserves support missing-cache replay and repeated boundary restore. The original failing reproducer is retained and now passes, with additional cases.

The final large disk-backed run completed in 47.585 seconds with max RSS 4,037,042,176 bytes on Linux/Node 24.22.2/i5-12500H. This is one measured workload, not an approved minimum memory/disk budget or a cross-platform guarantee. D11 resource budget (128 MiB / 8 GB RAM / ~2 GB disk) was approved by the owner on 2026-11-02, and S1/S2 were activated after the owner-assigned AI review. No tests were skipped to obtain a green result. The roadmap milestone commits after `3c0793b` are local only (not pushed); nothing has been deployed.
