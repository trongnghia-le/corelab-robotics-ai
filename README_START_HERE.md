# Start here

CoreLab is an implemented local learning application. Follow the current [README](README.md) for installation and the [user and maintainer guide](docs/guide.md) for setup, assessment rules, backups and troubleshooting.

The files in `corelab/` preserve the original product/design decisions and curriculum. Some early scope and language preferences were superseded during implementation; they are historical context, not current setup instructions. A `chatgpt_project/` setup pack is not included. Use the application's optional manual **AI Tutor handoff** workflow instead.
