## Why this matters

A robot rarely has a clean model of the world. Wheel slip, contact, and human behaviour are easier to sample than to write down. Model-free prediction asks: if I follow this policy and just watch what happens, can I learn how good each situation is? The answer is yes, in two main ways. Monte Carlo (MC) waits to see the full outcome. Temporal-difference (TD) learning updates after one step using its own current guess about what comes next. The choice trades noise against bias, determines how fast learning is, and underlies Q-learning and SARSA (RL06) and the critics of actor-critic methods. This lesson makes the trade-off concrete with numbers you can verify by hand.

## Intuition

Suppose you want to know how long a commute takes from each junction. **Monte Carlo**: drive home many times, and for each junction average the actual remaining travel times. No guessing, but one bad traffic jam makes a single sample far off, and you learn nothing until you arrive. **TD**: at each junction, take the time to the next junction plus your current estimate for that next junction. You update immediately, using a guess built from other guesses (bootstrapping). It is quieter because only one step is random, but if the next estimate is wrong the update inherits the error.

In symbols, both move $V(s)$ toward a target by a step $\alpha$: $V(s)\leftarrow V(s)+\alpha\,(\text{target}-V(s))$. MC's target is the full return $G_t$. TD(0)'s target is $r_{t+1}+\gamma V(s_{t+1})$. The gap in between is the **n-step return**, which uses $n$ real rewards and then bootstraps.

## Theory and derivation

### Monte Carlo prediction

By definition $V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]$, so the sample mean of returns observed after visiting $s$ is an unbiased estimate and is consistent (law of large numbers). The returns of an episode are computed backward: $G_T=0$, $G_t=r_{t+1}+\gamma G_{t+1}$. **First-visit** MC uses only the first time $s$ appears in each episode; **every-visit** MC uses all visits. Both converge. Weaknesses: needs episodes to end, and returns have high variance because they sum many random rewards and transitions.

### TD(0)

Rewrite the Bellman equation $V^\pi(s)=\mathbb E[r+\gamma V^\pi(s')]$ and use a single sampled transition:
$$V(s_t)\leftarrow V(s_t)+\alpha\,\delta_t,\qquad \delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t),$$
with $V(\text{terminal})=0$. $\delta_t$ is the **TD error**. TD updates online, works in continuing tasks, and has lower variance because the target contains only one random reward and one random transition. Its target is biased because $V(s_{t+1})$ is itself an estimate, but the bias shrinks as the table improves, and TD(0) converges to $V^\pi$ with suitable step sizes (decaying $\alpha_t$ with $\sum\alpha_t=\infty$, $\sum\alpha_t^2<\infty$; or a small constant $\alpha$ for a noisy but stable estimate).

### n-step returns and the connection

$$G_t^{(n)}=r_{t+1}+\gamma r_{t+2}+\cdots+\gamma^{n-1}r_{t+n}+\gamma^nV(s_{t+n}).$$
With $n=1$ this is the TD target; when $n$ reaches the end of the episode it equals the MC return (no bootstrap term). Also,
$$G_t^{(n)}-V(s_t)=\sum_{k=0}^{n-1}\gamma^k\delta_{t+k}\quad\text{(for a fixed table }V),$$
so MC error is a discounted sum of TD errors; this identity explains why $\lambda$-returns and eligibility traces blend the two.

### Step size

A constant $\alpha$ forgets old data exponentially (time constant $\sim1/\alpha$ updates) and leaves a noise floor proportional to $\sqrt\alpha$ times the target noise. A decaying schedule such as $\alpha=1/N(s)$ gives the sample mean (for MC) and removes the floor. With $\alpha=1$ the table is overwritten by the latest target.

### Terminal handling

When an episode terminates, the next state's value is $0$ and the target is $r$. When it is cut off by a time limit (truncation) the state still has a future; the target should bootstrap from its value (see the Tabular Q protocol bridge for the same distinction in control).

## Worked example

Episode on the slippery corridor of RL04, $\gamma=0.9$: states $2\to3\to2\to3\to$ goal with rewards $-1,-1,-1,+10$.

**Returns (backward).** $G_3=10$; $G_2=-1+0.9\cdot10=8$; $G_1=-1+0.9\cdot8=6.2$; $G_0=-1+0.9\cdot6.2=4.58$.

**First-visit MC.** State 2 first at $t=0$: $V(2)=4.58$. State 3 first at $t=1$: $V(3)=6.2$.
**Every-visit MC.** State 2 at $t=0,2$: $(4.58+8)/2=6.29$. State 3 at $t=1,3$: $(6.2+10)/2=8.1$.

**TD(0), $\alpha=0.5$, $V\equiv0$ initially.**
- $t=0$: target $-1+0.9\cdot V(3)=-1$; $V(2)\leftarrow0+0.5(-1-0)=-0.5$.
- $t=1$: target $-1+0.9\cdot V(2)=-1-0.45=-1.45$; $V(3)\leftarrow0+0.5(-1.45)=-0.725$.
- $t=2$: target $-1+0.9\cdot V(3)=-1.6525$; $V(2)\leftarrow-0.5+0.5(-1.6525+0.5)=-1.07625$.
- $t=3$: next state is the goal, target $10$; $V(3)\leftarrow-0.725+0.5(10+0.725)=4.6375$.

After one episode TD has moved only the visited states, and its early values are biased toward the initial zeros, while MC's values are single-sample returns. The true values under the uniform policy are $V(2)=-2.437$ and $V(3)=3.403$.

**Spread.** Over 1,000 repeated experiments of $N$ random episodes each, the standard deviation of the estimate of $V(2)$ is $7.95$ (MC) and $0.14$ (TD, $\alpha=0.1$) for $N=1$; $4.66$ and $0.44$ for $N=5$; $2.26$ and $1.17$ for $N=20$. TD's mean after 5 episodes is $-0.60$ (biased by the zero start, true $-2.44$); MC's mean is $-2.75$.

## Reference implementation

The corridor environment is sampled with a seeded random generator, so every run is reproducible.

```python
import math, random

GAMMA = 0.9
STATES = [1, 2, 3]                 # 0 = pit and 4 = goal are terminal (value 0)
TRUE_V = {1: -6.596638655362865, 2: -2.4369747897643723, 3: 3.4033613446371347}   # uniform policy, exact (RL03/RL04 linear solve)

def step(s, a, rng, slip=0.2):
    """One transition of the slippery corridor. a is -1 (left) or +1 (right). Returns (reward, next state)."""
    move = a if rng.random() >= slip else -a
    s2 = s + move
    return (10.0 if s2 == 4 else -10.0 if s2 == 0 else -1.0), s2

def sample_episode(rng, start=None):
    """Uniform random policy. Returns a list of (s, r, s2)."""
    s = rng.choice(STATES) if start is None else start
    ep = []
    while s in STATES:
        r, s2 = step(s, rng.choice([-1, 1]), rng)
        ep.append((s, r, s2))
        s = s2
    return ep

def returns(rewards, gamma=GAMMA):
    """G_t = r_t + gamma G_{t+1}, with G after the last reward = 0 (terminated episode)."""
    G, out = 0.0, []
    for r in reversed(rewards):
        G = r + gamma*G
        out.append(G)
    return out[::-1]

def mc_estimate(episodes, gamma=GAMMA, first_visit=True):
    """Average of sampled returns per state. States never visited get 0.0."""
    sums, counts = {s: 0.0 for s in STATES}, {s: 0 for s in STATES}
    for ep in episodes:
        G = returns([r for _, r, _ in ep], gamma)
        seen = set()
        for (s, _, _), g in zip(ep, G):
            if first_visit and s in seen:
                continue
            seen.add(s)
            sums[s] += g
            counts[s] += 1
    return {s: (sums[s]/counts[s] if counts[s] else 0.0) for s in STATES}

def td0(episodes, gamma=GAMMA, alpha=0.1, V=None):
    """TD(0): V(s) <- V(s) + alpha (r + gamma V(s') - V(s)), V(terminal) = 0. Updates online, in order."""
    V = dict(V) if V else {s: 0.0 for s in STATES}
    for ep in episodes:
        for s, r, s2 in ep:
            target = r + gamma*V.get(s2, 0.0)
            V[s] += alpha*(target - V[s])
    return V

def rmse(V, W=TRUE_V):
    return math.sqrt(sum((V[s] - W[s])**2 for s in STATES)/len(STATES))

if __name__ == "__main__":
    # hand example: one episode 2 -> 3 -> 2 -> 3 -> goal
    ep = [(2, -1.0, 3), (3, -1.0, 2), (2, -1.0, 3), (3, 10.0, 4)]
    G = returns([r for _, r, _ in ep])
    assert all(abs(a - b) < 1e-12 for a, b in zip(G, [4.58, 6.2, 8.0, 10.0]))
    fv, ev = mc_estimate([ep]), mc_estimate([ep], first_visit=False)
    assert abs(fv[2] - 4.58) < 1e-12 and abs(fv[3] - 6.2) < 1e-12
    assert abs(ev[2] - 6.29) < 1e-12 and abs(ev[3] - 8.1) < 1e-12
    V = td0([ep], alpha=0.5)
    print("TD(0) after the episode:", {s: round(v, 4) for s, v in V.items()})
    assert abs(V[2] + 1.07625) < 1e-9 and abs(V[3] - 4.6375) < 1e-9
    # many episodes: both converge to the true values
    rng = random.Random(0)
    eps = [sample_episode(rng) for _ in range(3000)]
    print("MC  RMSE after 3000 episodes: %.3f" % rmse(mc_estimate(eps)))
    print("TD  RMSE after 3000 episodes: %.3f" % rmse(td0(eps, alpha=0.002)))
    assert rmse(mc_estimate(eps)) < 0.3 and rmse(td0(eps, alpha=0.002)) < 0.5
    print("self-test passed")
```

## Verification

- Compare estimators with the exact $V^\pi$ from the linear solve (RL03), never with each other only.
- Hand-check one MC return and one TD update (as in the worked example) before running simulations.
- Use fixed seeds and report mean and spread over several seeds; one run is one draw.
- Check the terminal convention: $V(\text{terminal})$ is 0 and never updated.
- Confirm that RMSE decreases with more episodes for a decaying $\alpha$.

## Failure modes

| Mistake | Wrong value or symptom |
|---|---|
| Updating the terminal's value (Exercise 5) | Terminal bootstraps garbage into neighbours |
| Treating a time-limit cut as terminal | Values near the limit biased low (or high) |
| Constant large $\alpha$ | RMSE 1.77 at $\alpha=0.1$ versus 0.17 at $\alpha=0.002$ on the corridor |
| Averaging returns forward instead of backward | Wrong $G_t$, off by discount factors |
| Evaluating TD on unvisited states | Table keeps its initial value |
| Judging from one seed | Conclusions flip between runs |

## Alternatives and trade-offs

- **Monte Carlo**: unbiased, no bootstrapping, needs episodic tasks; good with a poor model of state (non-Markov).
- **TD(0)**: online and low variance; relies on the Markov property and on the table being roughly right.
- **n-step / TD($\lambda$)**: tunes the bias-variance balance; $n$ or $\lambda$ become hyperparameters.
- **Dynamic programming (RL04)**: exact with a model.
- **Function approximation**: needed for large state spaces; TD with off-policy data and approximation can diverge (the deadly triad), so extra care in RL06 and beyond.

## Transfer and retention

TD errors are the learning signal in Q-learning and SARSA (RL06) and in the critic of actor-critic algorithms. The returns-versus-bootstrapping choice recurs in advantage estimation (GAE is a $\lambda$-weighted sum of TD errors). ## Exercise answers

1. $V(s_t)\leftarrow V(s_t)+\alpha[r_{t+1}+\gamma V(s_{t+1})-V(s_t)]$: $\alpha$ is the step size, $r_{t+1}+\gamma V(s_{t+1})$ is the target, the bracket is the TD error. If $s_{t+1}$ is terminal the target is just $r_{t+1}$.
2. $G_2=4$ (last reward), $G_1=0+0.5\cdot4=2$, $G_0=2+0.5\cdot2=3$. (Indexing rewards as $r_1,r_2,r_3$: $G_0=2+0.5\cdot0+0.25\cdot4=3$.)
3. $\Delta V=0.1\cdot3=0.3$. A positive $\delta$ means the outcome was better than predicted, so the old estimate was too low.
4. First-visit: $5$ (only the first return). Every-visit: $(5+9)/2=7$. They differ when visits are correlated within an episode, which changes bias slightly (every-visit is biased but consistent) and the count of samples.
5. The update for the last transition uses $V[s2]=0.7$ as the next value, so the target is $r+0.9\cdot0.7$ instead of $r$ and the neighbour's value is wrong. Fix: treat terminal states as value 0 (`V.get(s2, 0.0)` or an explicit `done` flag) and never write to them.
6. $G_0^{(2)}=-1+0.9(-1)+0.81V(2)=-1.9+0.81=-1.09$ (here the second reward is the state-3 reward $-1$). $\delta_0=-1+0.9\cdot2-1=-0.2$, $\delta_1=-1+0.9\cdot1-2=-2.1$; $\delta_0+0.9\delta_1=-0.2-1.89=-2.09$; and $G_0^{(2)}-V(2)=-1.09-1=-2.09$.
7. With constant $\alpha$ each update moves $V$ by $\alpha$ times a noisy error, so $V$ keeps jittering with variance $\propto\alpha$. On the corridor, $\alpha=0.002$ gives RMSE $0.17$ and $\alpha=0.1$ gives $1.77$. A small $\alpha$ lowers the floor but adapts slowly (time constant about $1/\alpha$ updates); a decaying schedule gets both.
8. TD uses the table's own information, so information propagates backward after every step instead of at episode ends, and its target has lower variance. Test: run both on the same trajectories over many seeds, with matched step sizes tuned separately, and compare RMSE curves.
9. $V_n=V_{n-1}+\frac1n(G_n-V_{n-1})=\frac{n-1}nV_{n-1}+\frac1nG_n$; by induction $V_n=\frac1n\sum_{i\le n}G_i$ (for $n=1$, $V_1=G_1$ regardless of $V_0$). TD targets change as $V$ changes (the target depends on the table), so the sequence of targets is not a fixed sample.
10. A good answer specifies the environment, the exact values from a linear solve, RMSE curves with spread over seeds, and a check such as RMSE not decreasing or the terminal value changing.
