## Why this matters

Almost every robot needs a sequence of discrete choices that gets it from here to there: which doors to pass, which waypoints to visit, which sub-steps to execute. When a model of the world exists, search finds the cheapest such sequence reliably and explains itself. It is also the base of later modules: task planning (E05) searches over symbolic states, and task-and-motion planning (E06) searches over those searches.

This lesson builds on E01 (states, actions, transitions, costs and horizon) and on PY02 (Python data structures: dictionaries, tuples, a heap). The optional bridge "Grid search, heuristics and exact shortcut checks" covers 8-connected grids, the octile distance, corner cutting and exact segment collision tests; here we concentrate on the general search algorithm and the proofs that make heuristics trustworthy.

## Intuition

Searching is exploring a tree of possibilities, always expanding the most promising partial plan. Dijkstra expands by cost so far, $g$, spreading out evenly like a circle of water. A* adds a guess of the remaining cost, $h$, and expands the lowest $f=g+h$, so the circle stretches toward the goal. If the guess is never too optimistic about *difficulty* (it never over-estimates), the first time the goal is popped its $g$ is optimal.

## Theory and derivation

### Problem formulation

A search problem is a tuple (state space $S$, start $s_0$, goal test, successor function $\mathrm{succ}(s)=\{(s',c)\}$ with step costs $c\ge0$). A **plan** is a path $s_0\to s_1\to\cdots\to s_n$ with the goal at the end; its cost is the sum of step costs. Planning here is *offline* and *open loop*: it assumes the model is right and the world deterministic (E03 relaxes that).

### Uniform-cost search (Dijkstra) and A*

Maintain a priority queue (the *open set*) keyed by a score. For each discovered state keep the best known cost $g(s)$ and a parent pointer. Repeat: pop the state with the smallest score, stop if it is the goal, otherwise relax each successor: if $g(s)+c<g(s')$, update $g(s')$, the parent, and push. The score is $g(s)$ for Dijkstra and $f(s)=g(s)+h(s)$ for A*.

**Stopping rule.** Stop when the goal is *popped*. When the goal is merely generated, a cheaper route may still be in the queue.

**Unreachable versus out of budget.** If the open set becomes empty without popping the goal, every reachable state was tried, so the goal is unreachable. If you stop early on a budget, report "budget exhausted", not "no plan".

### Admissible and consistent heuristics

Let $h^*(s)$ be the true cost-to-go from $s$.

- $h$ is **admissible** if $h(s)\le h^*(s)$ for all $s$ (never over-estimates) and $h(\text{goal})=0$.
- $h$ is **consistent** if $h(a)\le c(a,b)+h(b)$ for every edge $(a,b)$: the estimate cannot drop by more than the step cost.

**Consistent $\Rightarrow$ admissible.** Take any state $s$ and an optimal path $s=x_0,\dots,x_k=\text{goal}$. Summing the consistency inequality along the path gives $h(x_0)\le\sum_i c(x_i,x_{i+1})+h(x_k)=h^*(s)+0$.

**Optimality of A*.** If $h$ is admissible, A* with re-expansion returns an optimal path. Sketch: suppose the goal is popped with cost $g(G)>C^*$. At that moment the open set contains some state $n$ on an optimal path with $g(n)=g^*(n)$, whose $f(n)=g^*(n)+h(n)\le g^*(n)+h^*(n)=C^*<g(G)=f(G)$. So $n$ would have been popped before $G$, a contradiction. If $h$ is also consistent, $f$ never decreases along a path, and each state needs expanding only once.

If $h$ is admissible but *not* consistent, a state can be popped with a non-optimal $g$ and a cheaper route may appear later; you must allow re-expansion (do not keep a permanent closed set).

### Heuristics from relaxations

Good heuristics are exact costs of a *relaxed* problem: remove a constraint, solve exactly, use that as $h$. Manhattan distance is the cost of a grid problem without walls. For uniform costs $\ge c_{\min}$, $c_{\min}\cdot$Manhattan stays admissible. A heuristic $h_2$ **dominates** $h_1$ if $h_2\ge h_1$ everywhere and both are admissible; A* with $h_2$ never expands more states (up to tie-breaking).

Weighted A* ($f=g+wh$, $w>1$) trades optimality for speed: with admissible $h$ the returned cost is at most $w\,C^*$.

## Worked example

Grid, digits are the cost of *entering* a cell, `#` is a wall, 4-connected; start $(0,0)$, goal $(0,3)$:
```
1 1 2 1
1 # 9 1
1 1 1 1
```
Manhattan heuristic $h(r,c)=|r|+|c-3|$.

**Step 1.** Pop $(0,0)$: $g=0,h=3,f=3$. Successors $(0,1)$: $g=1,h=2,f=3$; $(1,0)$: $g=1,h=4,f=5$.

**Step 2.** Pop $(0,1)$ (f=3): successor $(0,2)$: $g=1+2=3,h=1,f=4$. $(1,1)$ is a wall.

**Step 3.** Pop $(0,2)$ (f=4): successors $(0,3)$: $g=3+1=4,h=0,f=4$; $(1,2)$: $g=3+9=12,h=2,f=14$.

**Step 4.** The open set now has $(0,3)$ with $f=4$ (the smallest). Pop it: it is the goal. Cost 4, path $(0,0),(0,1),(0,2),(0,3)$, three expansions.

**Admissibility check.** The true cost-to-go from $(0,0)$ is 4 and $h=3\le4$. Because costs are at least 1 per step, Manhattan can never exceed the true cost.

**Inadmissible heuristic.** On the grid `1191 / 1213 / 9122` the optimal path from $(0,0)$ to $(0,3)$ costs 8 via $(0,1),(1,1),(1,2),(1,3)$. With $h=10\cdot$Manhattan the search is almost greedy, pops the straight path along the top row and returns cost 11.

**Re-expansion.** Graph $S\to B$ (3), $S\to A$ (1), $A\to B$ (1), $B\to G$ (3), heuristic $h(A)=4$, others 0. $h$ is admissible ($h^*(A)=4$) but inconsistent: $h(A)=4>c(A,B)+h(B)=1$. A* pops $S$, then $B$ ($f=3$) with $g=3$, then $A$ ($f=5$) which improves $g(B)$ to 2, then pops $B$ again and reaches $G$ with $g=5$. A closed set that forbids re-expansion would return 6.

## Reference implementation

A* with re-expansion over a generic successor function, grid and graph examples, admissibility and consistency checkers.

```python
import heapq

def grid_successors(grid):
    """4-connected moves. Digits are terrain costs paid when ENTERING a cell; '#' is a wall."""
    R, C = len(grid), len(grid[0])
    def succ(s):
        r, c = s
        out = []
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            r2, c2 = r + dr, c + dc
            if 0 <= r2 < R and 0 <= c2 < C and grid[r2][c2] != "#":
                out.append(((r2, c2), int(grid[r2][c2])))
        return out
    return succ

def manhattan(goal):
    return lambda s: abs(s[0] - goal[0]) + abs(s[1] - goal[1])

def astar(start, goal, successors, h):
    """A* with a lazy-deletion priority queue. A state is RE-expanded if a cheaper route to it is
    found later, which keeps the result optimal for admissible but inconsistent heuristics. Returns (cost, path, expansions); cost and path are
    None if the open set empties (goal unreachable). Stops when the goal is POPPED, not generated."""
    g = {start: 0}; parent = {start: None}; expansions = 0
    pq = [(h(start), 0, start)]
    while pq:
        f, gs, s = heapq.heappop(pq)
        if gs > g[s]:
            continue                              # stale entry: a cheaper route to s was found
        if s == goal:
            path = []
            while s is not None:
                path.append(s); s = parent[s]
            return gs, path[::-1], expansions
        expansions += 1
        for s2, cost in successors(s):
            ng = gs + cost
            if ng < g.get(s2, float("inf")):
                g[s2] = ng; parent[s2] = s
                heapq.heappush(pq, (ng + h(s2), ng, s2))
    return None, None, expansions

def true_cost_to_goal(s, goal, successors):
    return astar(s, goal, successors, lambda _: 0)[0]          # Dijkstra: h = 0

def inadmissible_states(states, goal, successors, h):
    """States where h(s) exceeds the true cost to the goal."""
    bad = []
    for s in states:
        t = true_cost_to_goal(s, goal, successors)
        if t is not None and h(s) > t + 1e-12:
            bad.append(s)
    return bad

def inconsistent_edges(states, successors, h):
    """Edges (a, b) with h(a) > cost(a, b) + h(b)."""
    return [(a, b) for a in states for b, c in successors(a) if h(a) > c + h(b) + 1e-12]

if __name__ == "__main__":
    grid = ["1121",
            "1#91",
            "1111"]
    succ = grid_successors(grid); goal = (0, 3); states = [(r, c) for r in range(3) for c in range(4) if grid[r][c] != "#"]
    cost, path, n = astar((0, 0), goal, succ, manhattan(goal))
    print("A*:", cost, path, "expansions", n)
    print("Dijkstra:", astar((0, 0), goal, succ, lambda _: 0)[::2])
    print("inadmissible with Manhattan:", inadmissible_states(states, goal, succ, manhattan(goal)))
    print("inconsistent edges:", inconsistent_edges(states, succ, manhattan(goal)))
    open_grid = ["1" * 5] * 5
    s2 = grid_successors(open_grid)
    G = {"S": [("B", 3), ("A", 1)], "A": [("B", 1)], "B": [("G", 3)], "G": []}
    H = {"S": 0, "A": 4, "B": 0, "G": 0}
    print("admissible but inconsistent heuristic:", astar("S", "G", lambda s: G[s], H.get)[::2])
    print("open 5x5 expansions A*/Dijkstra:", astar((0, 0), (0, 4), s2, manhattan((0, 4)))[2], astar((0, 0), (0, 4), s2, lambda _: 0)[2])
    assert astar("S", "G", lambda s: G[s], H.get)[0] == 5
    assert cost == 4 and inadmissible_states(states, goal, succ, manhattan(goal)) == []
    print("self-test passed")
```

Expected: cost 4 with 3 expansions on the lesson grid; Dijkstra 6 expansions; empty inadmissible list; A* 4 versus Dijkstra 10 expansions on the open grid; cost 5 on the re-expansion graph.

## Verification

- Compare A* cost with Dijkstra ($h=0$) on many random instances; they must be identical for admissible $h$.
- Check the path: starts at the start, ends at the goal, every consecutive pair is a legal successor, summed costs equal the reported cost.
- Test $h$: for small state spaces compute true costs-to-go and check $h\le h^*$ on every state and the consistency inequality on every edge.
- Include an unreachable instance and check that the result is "no plan", not an exception or an infinite loop.

## Failure modes

- **Stopping when the goal is generated**: returns the first route found, e.g. cost 10 instead of 2 in the exercise 5 graph.
- **Inadmissible heuristic**: $10\cdot$Manhattan returned 11 instead of 8.
- **Permanent closed set with an inconsistent heuristic**: 6 instead of 5.
- **Equating empty open set with a budget limit**: reporting "no path" after a cut-off.
- **Heuristic ignoring cheap terrain**: Manhattan with cells costing 0.5 over-estimates.
- **State too small**: leaving out the collected-items flag in a multi-goal task makes the search loop or return wrong answers.

## Alternatives and trade-offs

| Method | Guarantee | Cost |
| --- | --- | --- |
| BFS | Fewest steps | Memory $O(b^d)$ |
| Dijkstra | Cheapest path | Expands in all directions |
| A* (admissible $h$) | Cheapest path | Needs a good $h$; memory |

Choose A* when a good admissible heuristic exists and optimality matters; weighted A* when time is limited and a bounded sub-optimality is acceptable.
