## Vì sao học bài này?

Derive endpoint coordinates from joint geometry and test the result. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

Forward kinematics asks where the robot goes for a known configuration. Begin by drawing links and naming angles. The second joint angle is normally relative to the first link, so the second link’s world orientation is the sum of joint angles.

## Định nghĩa và suy luận · Theory & derivation

For link lengths $l_1,l_2>0$ and relative angles $q_1,q_2$,
$$x=l_1\cos q_1+l_2\cos(q_1+q_2),\quad y=l_1\sin q_1+l_2\sin(q_1+q_2).$$
Derive this by adding two displacement vectors: the first has direction $q_1$, while the second has direction $q_1+q_2$. Endpoint orientation is $q_1+q_2$. Equivalently compose a rotation and translation for each joint/link pair using homogeneous transforms.

Squaring and adding yields $r^2=x^2+y^2=l_1^2+l_2^2+2l_1l_2\cos q_2$. Therefore $|l_1-l_2|\le r\le l_1+l_2$ without additional joint limits. This invariant independently checks the implementation and reveals why a target may be unreachable.

The same endpoint can come from different configurations; forward kinematics is well-defined even when its inverse is ambiguous. Singularities describe lost instantaneous task directions, not an inability to calculate the forward map.

## Ví dụ có lời giải · Worked example

With l₁=l₂=1, q₁=0, q₂=π/2, the first link ends at (1,0), the second contributes (0,1), and the endpoint is (1,1). With q₂=0 and q₁=π/2, both links point up and the endpoint is (0,2).

## Triển khai tham khảo · Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
from math import sin,cos,pi
def fk(q1,q2,l1=1.,l2=1.):
    return (l1*cos(q1)+l2*cos(q1+q2),
            l1*sin(q1)+l2*sin(q1+q2))
x,y=fk(0,pi/2)
assert abs(x-1)<1e-12 and abs(y-1)<1e-12
```

## Hiểu lầm thường gặp · Failure modes

Using cos(q₂) instead of cos(q₁+q₂) treats the second angle as absolute. Degree/radian confusion often gives plausible but wrong coordinates. Floating-point sin(π) is approximately zero, not exactly zero.

## So sánh và lựa chọn · Alternatives

Geometric derivations are transparent for small planar arms. Transform chains scale to many joints and sensors. Product-of-exponentials formulations offer a systematic spatial representation with different bookkeeping.
