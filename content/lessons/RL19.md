## Why this matters

A robot arm or a mobile base cannot afford millions of real trials. Model-based RL spends real interaction on learning a predictive model $\hat f(s,a)\approx s'$ and then reuses that model many times: to plan actions, to imagine extra training data, or to evaluate a policy before running it. When it works it is far more sample-efficient than model-free RL. When it fails it fails quietly: the model looks accurate on a one-step test while a plan built on it drives the real robot somewhere the model never saw.

This lesson builds on the MDP vocabulary of RL02 (transitions, rewards, returns), on state-space models from S01 and on supervised regression from ML06. The new content is how a learned model is *used*, and how to measure whether it can be trusted for that use.

## Intuition

Think of the model as a flight simulator you built from a few test flights. Predicting the next second from a state you really visited is easy. Flying the simulator for a minute is different: each prediction feeds the next one, so any small error is carried forward and amplified. And if you then ask an optimiser to find the best route *inside the simulator*, it will happily choose the corner where the simulator is wrong in your favour.

![Left: one-step error stays small while open-loop rollout error grows with the horizon. Right: the data region where the model was trained versus a planned state far outside it.](/lesson-figures/RL19.svg)

*Figure: one-step error (blue) versus open-loop rollout error (orange), and the training region versus the region a planner may wander into.*

Two uses of a model are worth separating:

- **Planning at decision time** (model predictive control, MPC): at every step, search over action sequences using the model, execute only the first action, observe the real state, and replan. Replanning from the real state resets the compounding error each step.
- **Planning in the background** (Dyna-style): use the model to generate extra simulated transitions that a model-free learner trains on. Errors here do not self-correct, so rollouts are kept short.

## Theory and derivation

### Learning the model

Collect transitions $(s_t,a_t,s_{t+1})$ and minimise a regression loss, for example $\sum_t \lVert \hat f_\theta(s_t,a_t)-s_{t+1}\rVert^2$. For a linear model $\hat s'=\alpha s+\beta a$ this is ordinary least squares with normal equations
$$\begin{pmatrix}\sum s^2&\sum sa\\ \sum sa&\sum a^2\end{pmatrix}\begin{pmatrix}\alpha\\ \beta\end{pmatrix}=\begin{pmatrix}\sum s s'\\ \sum a s'\end{pmatrix}.$$
Predicting the *change* $s'-s$ rather than $s'$ often conditions the regression better. Stochastic dynamics call for a probabilistic output (a Gaussian mean and variance), so that irreducible noise is not confused with model ignorance. Ignorance, the uncertainty that shrinks with more data, is called *epistemic* uncertainty; noise in the world is *aleatoric*. An ensemble of models trained on resampled data estimates epistemic uncertainty by their disagreement.

### Two different errors

- **One-step error** $\varepsilon_1(s,a)=\lVert\hat f(s,a)-f(s,a)\rVert$, evaluated on states that the real system actually visits (teacher forcing: every prediction starts from the true state).
- **$k$-step open-loop error** $e_k=\lVert\hat s_k-s_k\rVert$ where $\hat s_{j+1}=\hat f(\hat s_j,a_j)$ starts from $\hat s_0=s_0$ and feeds its own predictions back.

If $\hat f$ is $L$-Lipschitz in the state and $\varepsilon_1\le\varepsilon$ everywhere on the visited region, then
$$e_{k+1}=\lVert\hat f(\hat s_k,a_k)-f(s_k,a_k)\rVert\le\lVert\hat f(\hat s_k,a_k)-\hat f(s_k,a_k)\rVert+\lVert\hat f(s_k,a_k)-f(s_k,a_k)\rVert\le L\,e_k+\varepsilon .$$
With $e_0=0$ this unrolls to
$$e_k\le\varepsilon\,\frac{L^k-1}{L-1}\quad(L\ne1),\qquad e_k\le k\varepsilon\quad(L=1).$$
Even for $L=1$ the error grows linearly; for $L>1$ (unstable or chaotic dynamics) it grows geometrically. This is the reason one-step accuracy alone does not certify a model for long-horizon planning.

### From model error to value error (simulation lemma)

Suppose rewards lie in $[0,R_{\max}]$ and the model's transition distributions satisfy $\max_{s,a}\lVert P(\cdot|s,a)-\hat P(\cdot|s,a)\rVert_1\le\varepsilon$ with the same reward function. For a fixed policy, the value vectors satisfy $V=r+\gamma PV$ and $\hat V=r+\gamma\hat P\hat V$. Subtracting,
$$V-\hat V=\gamma P(V-\hat V)+\gamma(P-\hat P)\hat V\ \Rightarrow\ V-\hat V=\gamma(I-\gamma P)^{-1}(P-\hat P)\hat V .$$
Since $\lVert(I-\gamma P)^{-1}\rVert_\infty\le\frac1{1-\gamma}$, $\lVert(P-\hat P)\hat V\rVert_\infty\le\varepsilon\lVert\hat V\rVert_\infty$ and $\lVert\hat V\rVert_\infty\le\frac{R_{\max}}{1-\gamma}$,
$$\lVert V-\hat V\rVert_\infty\le\frac{\gamma\,\varepsilon\,R_{\max}}{(1-\gamma)^2}.$$
The error is amplified by the *effective horizon* $1/(1-\gamma)$ twice. The bound is loose but its message is right: long effective horizons demand much more accurate models, or short model rollouts.

### Model exploitation

A planner maximises *predicted* return. Where $\hat f$ is wrong in a direction that raises predicted reward, the maximiser is drawn to exactly that region, so the optimisation selects for model error ("optimiser's curse"). Standard mitigations: replan from real states (MPC), keep model rollouts short (MBPO), penalise or avoid actions where an ensemble disagrees (PETS-style uncertainty), and keep adding real data from where the planner goes.

## Worked example

### Open-loop model error versus one-step error on an integrator

**Problem.** The plant is a pure integrator $s_{t+1}=s_t+0.5\,a_t$. A slightly wrong learned model is $\hat s_{t+1}=1.02\,s_t+0.5\,a_t$. Apply $a_t=1$ for $H=10$ steps from $s_0=0$. Find (1) the true trajectory; (2) the model trajectory; (3) the open-loop error at $k=10$ and $k=5$; (4) the one-step RMSE measured on the true states; (5) the comparison, including the bound $e_H\le\varepsilon\,(L^H-1)/(L-1)$ with $L=1.02$ and $\varepsilon$ the largest one-step error.

**Solution.**

1. **True trajectory.** Each step adds $0.5$, so $s_k=0.5k$ and $s_{10}=5.0$.
2. **Model trajectory.** The recursion $\hat s_{k+1}=1.02\hat s_k+0.5$ with $\hat s_0=0$ is a geometric sum: $\hat s_k=0.5\,(1+1.02+\dots+1.02^{k-1})=0.5\,\dfrac{1.02^k-1}{0.02}$. For $k=10$: $1.02^{10}=1.21899$, so $\hat s_{10}=0.5\cdot0.21899/0.02=5.4749$.
3. **Open-loop error.** $e_{10}=5.4749-5.0=0.4749$. At $k=5$: $1.02^5=1.10408$, $\hat s_5=0.5\cdot(1.10408-1)/0.02=2.6020$ and the true value is $2.5$, so $e_5=0.1020$.
4. **One-step error on true states.** From the true state $s_k$ the model predicts $1.02s_k+0.5a$ while the plant gives $s_k+0.5a$, so the error is exactly $0.02\,s_k$. The true states before the ten actions are $0,0.5,\dots,4.5$, so the errors are $0,0.01,\dots,0.09$. The mean square of the states is $\tfrac1{10}\sum s_k^2=\tfrac{1}{10}\cdot0.25\,(0+1+4+\dots+81)=\tfrac{1}{10}\cdot0.25\cdot285=7.125$, and the RMSE is $0.02\sqrt{7.125}=0.02\cdot2.669=0.0534$.
5. **Compare.** The one-step RMSE is $0.053$ and the 10-step error is $0.475$; the ratio is $0.4749/0.0534=8.9$, about nine times larger. The bound uses $L=1.02$ and the worst one-step error $\varepsilon=0.09$: $e_{10}\le0.09\,(1.02^{10}-1)/0.02=0.09\cdot10.95=0.985$.

**Check.** The bound holds ($0.475\le0.985$) and is loose because most steps have smaller error than the worst one. A second check: $e_{10}=\sum_{k=0}^{9}1.02^{9-k}\cdot0.01k$ (each one-step error $0.01k$ is amplified by the remaining steps) reproduces $0.4749$.

**Takeaway.** A small one-step error compounds through the horizon; a model judged by one-step accuracy can be about ten times worse when rolled out.

## Reference implementation

The code fits a linear model to a mildly nonlinear plant, measures the two kinds of error, and runs random-shooting MPC with the model.

```python
import math, random

def true_step(s, a):          # unknown to the learner: mildly nonlinear scalar plant
    return 1.05 * s + 0.5 * a - 0.15 * s ** 3

def fit_linear(S, A, S2):
    """Least squares for s' ~ alpha*s + beta*a via the 2x2 normal equations."""
    saa = sum(s * s for s in S); sab = sum(s * a for s, a in zip(S, A)); sbb = sum(a * a for a in A)
    ty = sum(s * y for s, y in zip(S, S2)); tz = sum(a * y for a, y in zip(A, S2))
    d = saa * sbb - sab * sab
    return ((ty * sbb - tz * sab) / d, (saa * tz - sab * ty) / d)

def predict(th, s, a):
    return th[0] * s + th[1] * a

def rmse(xs):
    return math.sqrt(sum(x * x for x in xs) / len(xs))

def one_step_rmse(th, S, A):
    return rmse([predict(th, s, a) - true_step(s, a) for s, a in zip(S, A)])

def multi_step_rmse(th, s0s, action_seqs):
    """RMSE of an open-loop model rollout against the true rollout, per horizon step."""
    H = len(action_seqs[0]); st = list(s0s); sm = list(s0s); out = []
    for k in range(H):
        st = [true_step(s, seq[k]) for s, seq in zip(st, action_seqs)]
        sm = [predict(th, s, seq[k]) for s, seq in zip(sm, action_seqs)]
        out.append(rmse([x - y for x, y in zip(st, sm)]))
    return out

def plan_random_shooting(th, s, rng, H=5, n=200):
    """Pick the first action of the best random action sequence under the MODEL (goal: s -> 0)."""
    best, best_a = None, 0.0
    for _ in range(n):
        seq = [rng.uniform(-1, 1) for _ in range(H)]
        x, cost = s, 0.0
        for a in seq:
            x = predict(th, x, a); cost += x * x
        if best is None or cost < best:
            best, best_a = cost, seq[0]
    return best_a

def run_mpc(th, s0, steps=15, seed=1):
    rng = random.Random(seed); s = s0
    for _ in range(steps):
        s = true_step(s, plan_random_shooting(th, s, rng))   # replan every step on the REAL state
    return s

if __name__ == "__main__":
    rng = random.Random(0)
    S = [rng.uniform(-1, 1) for _ in range(500)]; A = [rng.uniform(-1, 1) for _ in range(500)]
    th = fit_linear(S, A, [true_step(s, a) for s, a in zip(S, A)])
    print("alpha, beta = %.4f, %.4f" % th)
    print("one-step RMSE (in distribution): %.4f" % one_step_rmse(th, S, A))
    print("one-step RMSE (states in [1.5,2.5]): %.4f" % one_step_rmse(th, [rng.uniform(1.5, 2.5) for _ in range(500)], A))
    s0s = [rng.uniform(-1, 1) for _ in range(200)]
    seqs = [[rng.uniform(-1, 1) for _ in range(10)] for _ in range(200)]
    errs = multi_step_rmse(th, s0s, seqs)
    print("multi-step RMSE, k=1,5,10: %.4f %.4f %.4f" % (errs[0], errs[4], errs[9]))
    assert errs[9] > 5 * errs[0] and errs[0] < 0.05
    print("MPC final |s| from s0=2.0:", round(abs(run_mpc(th, 2.0)), 4))
    print("self-test passed")
```

Expected: one-step RMSE about 0.023 in distribution but 1.23 outside the training states; multi-step RMSE rising from 0.023 at $k=1$ to 0.29 at $k=10$; and MPC still reaching $|s|<0.1$ because it replans from the real state.

```python
import numpy as np
from lab19 import true_step, fit_linear, rollout, one_step_rmse, horizon_rmse   # your stdlib solution

rng = np.random.default_rng(0)
S = rng.uniform(-1, 1, 200); A = rng.uniform(-1, 1, 200)
S2 = np.array([true_step(s, a) for s, a in zip(S, A)])

# 1. least squares with NumPy instead of the hand-written normal equations
X = np.column_stack([S, A])
th_np, *_ = np.linalg.lstsq(X, S2, rcond=None)
th = fit_linear(S.tolist(), A.tolist(), S2.tolist())
assert np.allclose(th_np, th, atol=1e-9)

# 2. vectorised open-loop rollout for many start states and action sequences at once
def rollout_np(th, s0, acts):                     # s0: (N,), acts: (N, H) -> (N, H)
    out, s = [], s0
    for k in range(acts.shape[1]):
        s = th[0] * s + th[1] * acts[:, k]
        out.append(s)
    return np.stack(out, axis=1)

bad = (1.02, 0.5)
acts = np.ones((1, 10))
assert abs(rollout_np(bad, np.zeros(1), acts)[0, -1] - rollout(bad, 0.0, [1.0] * 10)[-1]) < 1e-12

# 3. per-horizon RMSE over 500 random starts, compared with the stdlib horizon_rmse for one of them
s0 = rng.uniform(-1, 1, 500); acts = rng.uniform(-1, 1, (500, 10))
true_traj = np.cumsum(0.5 * acts, axis=1) + s0[:, None]          # integrator truth
mdl_traj = rollout_np(bad, s0, acts)
rmse_k = np.sqrt(np.mean((mdl_traj - true_traj) ** 2, axis=0))
print("RMSE at k=1,5,10:", rmse_k[[0, 4, 9]].round(4))
assert rmse_k[9] > 3 * rmse_k[0]
i = 7
ref = horizon_rmse(bad, true_step, float(s0[i]), acts[i].tolist())
assert np.allclose(ref, np.abs(mdl_traj[i] - true_traj[i]), atol=1e-9)

# 4. baseline s' = s: the model must beat it, otherwise it has learned nothing
base = np.sqrt(np.mean((s0[:, None] - true_traj) ** 2, axis=0))
print("persistence baseline at k=10: %.3f vs model %.3f" % (base[9], rmse_k[9]))
```

## Verification

- Evaluate one-step error on *held-out real transitions* and multi-step error on *held-out real trajectories*; never on training data alone.
- Compare predicted return of the chosen plan with the return actually obtained: a large gap (predicted much better than real) is the signature of model exploitation.
- Compare against a trivial baseline such as "$\hat s'=s$" (no motion). A model that does not beat it has learned nothing.
- Rerun with a second seed; report the spread, not a single run.

## Failure modes

- **Measuring only one-step error.** A 0.02 one-step RMSE hid a 0.29 ten-step error here (12 times larger).
- **Teacher-forcing bug.** Resetting to the true state at every step (exercise 5) silently turns multi-step error into one-step error.
- **Training-range extrapolation.** The same model had 0.023 RMSE inside $[-1,1]$ and 1.23 on $[1.5,2.5]$.
- **Optimiser's curse.** Planning on a model with no uncertainty penalty finds spurious high-reward regions.
- **Confusing noise with ignorance.** A deterministic regressor on stochastic dynamics gives a mean prediction that is wrong in every individual sample.
- **Reward model forgotten.** If the reward is learned too, its error enters the value bound separately.

## Alternatives and trade-offs

| Approach | Strength | Weakness |
| --- | --- | --- |
| Model-free (PPO, SAC) | No model bias | Needs far more real samples |
| MPC on a learned model | Very sample-efficient, replans from real state | Online compute; exploits model errors in long horizons |
| Dyna / MBPO short rollouts | Combines model-free asymptotics with model-based speed | Needs a rollout-length schedule; errors persist in the buffer |

Use a known physics model plus a learned residual when the structure is well understood; use a learned black box when contacts or perception make the physics too hard to write.
