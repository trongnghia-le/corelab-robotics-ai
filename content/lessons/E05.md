## Why this matters

"Put the cup on the shelf" is not one motion but a sequence of steps whose order matters: clear the shelf slot, go to the cup, grasp it, move, place. Task planning writes the world as a set of symbolic facts and chooses operators such as pick and place whose preconditions are logical conditions. It scales to many objects, explains why a plan is impossible, and gives later geometric planners (E06) a skeleton to check.

It builds on E02: the state space is searched exactly as before, but states are sets of facts and the successor function is generated from operators.

## Intuition

A state is a snapshot written as a list of true facts: `at_robot(A)`, `at(cup,A)`, `handempty`. An operator says "if these facts are all true, you may do this, and afterwards remove these facts and add those". With a one-gripper robot, `pick(box,B)` needs `handempty`; picking the box removes `handempty`, so nothing else can be picked until a `place` restores it. Constraints are not extra rules; they come from preconditions and delete lists.

*Figure: the box occupies B, so it must be moved to C first; the plan has 8 steps, found by breadth-first search over 36 reachable symbolic states.*

## Theory and derivation

### STRIPS representation

A **state** is a set of ground facts (closed-world assumption: a fact not in the set is false). An **operator** $o$ has a precondition set $\mathrm{pre}(o)$, an add list $\mathrm{add}(o)$ and a delete list $\mathrm{del}(o)$. It is **applicable** in $s$ iff $\mathrm{pre}(o)\subseteq s$. Applying it gives
$$s'=(s\setminus\mathrm{del}(o))\cup\mathrm{add}(o).$$
Delete first, then add: a fact in both lists ends up true. A **planning problem** is (initial state, goal set, operators); a **plan** is a sequence of operators $o_1,\dots,o_n$ with each applicable in turn and the goal set contained in the final state. PDDL is the standard text syntax for this model, with parameterised operators grounded over objects.

Domain used here (one gripper, locations $A,B,C$, objects `cup`, `box`):

| Operator | Preconditions | Add | Delete |
| --- | --- | --- | --- |
| `move(x,y)` | `at_robot(x)` | `at_robot(y)` | `at_robot(x)` |
| `pick(o,l)` | `at_robot(l)`, `at(o,l)`, `handempty` | `holding(o)`, `free(l)` | `at(o,l)`, `handempty` |
| `place(o,l)` | `at_robot(l)`, `holding(o)`, `free(l)` | `at(o,l)`, `handempty` | `holding(o)`, `free(l)` |

The fact `free(l)` is a capacity constraint: a location holds one object.

### Search

Breadth-first search over states returns a shortest plan: the number of states is finite, each action has unit cost. The state space grows exponentially with the number of objects, which is why heuristics matter. E02's A* applies unchanged with a heuristic computed from the symbolic model.

### Delete relaxation

Ignore all delete lists: facts, once true, stay true. Then reachability is monotone and a simple fixed-point iteration computes the set $R$ of facts that can ever be made true: start with $s_0$, repeatedly add $\mathrm{add}(o)$ for every $o$ with $\mathrm{pre}(o)\subseteq R$. Key properties:

- **Sound for impossibility.** Every real state is a subset of $R$: by induction, if the real plan reaches facts $F_k\subseteq R$ and $o_{k+1}$ is applicable then $\mathrm{pre}\subseteq F_k\subseteq R$, so the relaxation applies it too and $F_{k+1}\subseteq F_k\cup\mathrm{add}\subseteq R$. So a goal fact not in $R$ is **unreachable in reality**.
- **Not complete.** A goal fact in $R$ may still be unreachable because of deletes. Example: `holding(cup)` and `holding(box)` are both relaxed-reachable but one gripper cannot hold both.
- **Heuristic.** The length of the shortest relaxed plan never exceeds the real optimum, so it is admissible (this is the idea of the FF heuristic family and of Fast Downward's $h^+$ approximations).

### Impossible preconditions

For an unreachable goal fact $g\notin R$, look at the operators that add $g$ and list their preconditions that are also outside $R$: those are the *blocking facts*. Chasing them back finds the root cause (a missing move link, a never-established `free` fact) and gives an explanation a human can act on.

## Worked example

Initial state: `at_robot(A)`, `at(cup,A)`, `at(box,B)`, `free(C)`, `handempty`. Goal: `at(cup,B)`, `at(box,C)`.

**Step 1.** The goal needs `place(cup,B)` which needs `free(B)`. Currently the box sits at B and `free(B)` is false. `free(B)` is only added by `pick(·,B)`, which needs `at_robot(B)`, `at(·,B)` and `handempty`.

**Step 2, plan found by BFS (8 steps).** `move(A,B)`, `pick(box,B)` (now `holding(box)`, `free(B)`), `move(B,C)`, `place(box,C)` (needs `free(C)`: true), `move(C,A)`, `pick(cup,A)`, `move(A,B)`, `place(cup,B)` (needs `free(B)`: true after the pick).

**Step 3, check one transition by hand.** After `move(A,B)` then `pick(box,B)` the state is `{at(cup,A), at_robot(B), free(B), free(C), holding(box)}`: `at(box,B)` and `handempty` were deleted, `holding(box)` and `free(B)` added.

**Step 4, number of states.** Breadth-first search from the initial state reaches 36 distinct states.

**Step 5, an unreachable location.** Add a location D with no `move` into it and ask for `at(cup,D)`. Relaxed reachability never produces `at_robot(D)` or `free(D)`; `place(cup,D)` is the only way to add `at(cup,D)` and needs both. BFS exhausts the 36 states and returns no plan, and the blocking facts are `at_robot(D)` and `free(D)`.

**Step 6, a constraint the relaxation misses.** Goal `holding(cup)` and `holding(box)`. Relaxed reachability says both are reachable (each alone is), yet BFS returns no plan: after picking one, `handempty` is deleted and only a `place` restores it.

## Reference implementation

STRIPS operators for the pick-and-place domain, breadth-first planning, delete-relaxed reachability and blocking-fact analysis.

```python
from collections import deque

def ground_ops(locations, objects, links=None):
    """STRIPS operators for a one-gripper pick-and-place domain. links: allowed (from, to) robot moves
    (default: all pairs of distinct locations). Each operator is (name, pre, add, delete) with frozensets of facts."""
    ops = []
    for a in locations:
        for b in locations:
            if a != b and (links is None or (a, b) in links):
                ops.append((f"move({a},{b})", frozenset({f"at_robot({a})"}),
                            frozenset({f"at_robot({b})"}), frozenset({f"at_robot({a})"})))
    for o in objects:
        for l in locations:
            ops.append((f"pick({o},{l})", frozenset({f"at_robot({l})", f"at({o},{l})", "handempty"}),
                        frozenset({f"holding({o})", f"free({l})"}), frozenset({f"at({o},{l})", "handempty"})))
            ops.append((f"place({o},{l})", frozenset({f"at_robot({l})", f"holding({o})", f"free({l})"}),
                        frozenset({f"at({o},{l})", "handempty"}), frozenset({f"holding({o})", f"free({l})"})))
    return ops

def applicable(state, op):
    """An operator is applicable iff all its preconditions hold in the state."""
    return op[1] <= state

def apply_op(state, op):
    """Successor state: remove the delete list FIRST, then add the add list."""
    if not applicable(state, op):
        raise ValueError(f"{op[0]} not applicable: missing {sorted(op[1] - state)}")
    return frozenset((state - op[3]) | op[2])

def bfs_plan(init, goal, ops):
    """Shortest plan (list of operator names) or None if the goal is unreachable. goal: set of facts."""
    init = frozenset(init); goal = frozenset(goal)
    parent = {init: None}; q = deque([init])
    while q:
        s = q.popleft()
        if goal <= s:
            plan = []
            while parent[s] is not None:
                s, name = parent[s]; plan.append(name)
            return plan[::-1]
        for op in ops:
            if applicable(s, op):
                s2 = apply_op(s, op)
                if s2 not in parent:
                    parent[s2] = (s, op[0]); q.append(s2)
    return None

def relaxed_reachable(init, ops):
    """Facts reachable when delete lists are ignored (a fixed point). Optimistic: unreachable here means
    unreachable for real; reachable here does NOT mean achievable."""
    facts = set(init); changed = True
    while changed:
        changed = False
        for _, pre, add, _ in ops:
            if pre <= facts and not add <= facts:
                facts |= add; changed = True
    return facts

def blocking_facts(init, goal, ops):
    """Goal facts that are not relaxed-reachable, and for each the preconditions (of operators that
    would add it) that are themselves not relaxed-reachable. Empty dict if all goal facts are reachable."""
    reach = relaxed_reachable(init, ops); out = {}
    for g in goal:
        if g not in reach:
            missing = set()
            for _, pre, add, _ in ops:
                if g in add:
                    missing |= (pre - reach)
            out[g] = sorted(missing)
    return out

if __name__ == "__main__":
    locs, objs = ["A", "B", "C"], ["cup", "box"]
    ops = ground_ops(locs, objs)
    init = {"at_robot(A)", "at(cup,A)", "at(box,B)", "free(C)", "handempty"}
    plan = bfs_plan(init, {"at(cup,B)", "at(box,C)"}, ops)
    print(len(plan), plan)
    ops_d = ground_ops(locs + ["D"], objs, links={(a, b) for a in locs for b in locs if a != b})   # D has no move into it
    print("goal at(cup,D):", bfs_plan(init, {"at(cup,D)"}, ops_d), blocking_facts(init, {"at(cup,D)"}, ops_d))
    both = {"holding(cup)", "holding(box)"}
    print("hold both:", bfs_plan(init, both, ops), "| relaxed says reachable:", both <= relaxed_reachable(init, ops))
    assert len(plan) == 8
    print("self-test passed")
```

Expected: an 8-step plan; for the unreachable location `at(cup,D)`: no plan and blockers `at_robot(D)`, `free(D)`; for holding both objects: no plan although the relaxation says reachable.

### Library track

Check your planner against a real PDDL planner (`pip install pyperplan`, a small pure-Python planner). Save your stdlib solution as `lab_e05.py` (starter with stubs implemented, without tests). The script writes the lesson's domain as PDDL, with `loc` and `obj` type predicates because pyperplan supports plain STRIPS only, runs breadth-first search and A* with the FF heuristic, and compares plan lengths and the impossible goals with your `bfs_plan`.

```python
import os, tempfile
from pyperplan.planner import HEURISTICS, SEARCHES, search_plan
from lab_e05 import ground_ops, bfs_plan

DOMAIN = """(define (domain pickplace)
  (:requirements :strips)
  (:predicates (at_robot ?l) (at ?o ?l) (holding ?o) (free ?l) (handempty)
               (loc ?l) (obj ?o))
  (:action move :parameters (?x ?y)
    :precondition (and (loc ?x) (loc ?y) (at_robot ?x))
    :effect (and (at_robot ?y) (not (at_robot ?x))))
  (:action pick :parameters (?o ?l)
    :precondition (and (obj ?o) (loc ?l) (at_robot ?l) (at ?o ?l) (handempty))
    :effect (and (holding ?o) (free ?l) (not (at ?o ?l)) (not (handempty))))
  (:action place :parameters (?o ?l)
    :precondition (and (obj ?o) (loc ?l) (at_robot ?l) (holding ?o) (free ?l))
    :effect (and (at ?o ?l) (handempty) (not (holding ?o)) (not (free ?l)))))
"""

def problem(goal):
    return """(define (problem p1) (:domain pickplace)
  (:objects A B C cup box)
  (:init (loc A) (loc B) (loc C) (obj cup) (obj box)
         (at_robot A) (at cup A) (at box B) (free C) (handempty))
  (:goal (and %s)))
""" % " ".join(goal)

def plan_with(goal, search="bfs", heuristic=None):
    d = tempfile.mkdtemp()
    dom, prob = os.path.join(d, "domain.pddl"), os.path.join(d, "problem.pddl")
    open(dom, "w").write(DOMAIN); open(prob, "w").write(problem(goal))
    p = search_plan(dom, prob, SEARCHES[search], HEURISTICS[heuristic] if heuristic else None)
    return None if p is None else [a.name for a in p]

init = {"at_robot(A)", "at(cup,A)", "at(box,B)", "free(C)", "handempty"}
ops = ground_ops(["A", "B", "C"], ["cup", "box"])
goal_pddl = ["(at cup B)", "(at box C)"]
mine = bfs_plan(init, {"at(cup,B)", "at(box,C)"}, ops)
theirs = plan_with(goal_pddl)
print("pyperplan BFS:", len(theirs), theirs)
assert len(theirs) == len(mine) == 8

# an A* run with the (delete-relaxation) hFF heuristic finds an 8-step plan too, with a different search effort
astar = plan_with(goal_pddl, "astar", "hff")
print("pyperplan A* + hff plan length:", len(astar))
# the same two goals you tested by hand
assert len(plan_with(["(at box A)"])) == len(bfs_plan(init, {"at(box,A)"}, ops)) == 7
assert plan_with(["(holding cup)", "(holding box)"]) is None
print("library track ok")
```

Expected: both planners find an 8-step plan for the lesson goal and a 7-step plan for `at(box,A)`, pyperplan returns no plan for holding both objects, and the last line is `library track ok`. For realistic domains use Fast Downward instead (not run here); the PDDL files can be reused unchanged.

## Verification

- Execute the returned plan operator by operator with `apply_op`; the goal must hold at the end and every step must be applicable.
- Compare BFS plan length with a hand-derived plan for small cases.
- For an unreachable goal check the explanation: the blocking facts should really have no producer or an impossible producer.
- Check that the relaxed set contains every real reachable fact (property test over the 36 states).

## Failure modes

- **Add before delete** (exercise 5): facts present in both lists vanish.
- **Forgotten delete**: `pick` that fails to delete `handempty` lets the robot pick twice; plans are shorter than reality.
- **Missing capacity constraints**: without `free(l)` the plan puts two objects at one location.
- **Relaxation read as proof of feasibility**: `holding(cup)` and `holding(box)` pass the relaxed check but have no plan.
- **State blow-up**: facts for every object at every location; the 36 states of two objects explode with more objects.
- **Symbolic plans with no geometry**: `place(cup,B)` may be geometrically unreachable (the subject of E06).

## Alternatives and trade-offs

| Method | Strength | Weakness |
| --- | --- | --- |
| BFS / A* over STRIPS states | Simple, optimal | Exponential in objects |
| Heuristic planners (FF, Fast Downward) | Scale to thousands of facts | Heuristics not exact |
| SAT / constraint encodings | Good for parallel plans | Fixed horizon |

Use BFS to understand a domain, a heuristic planner such as Fast Downward for realistic sizes, and always validate plans symbolically before execution.

4. Closed-world assumption: facts not listed are false. Mistake: `pick` forgets to delete `at(o,l)`; then the object is both held and at the location because the fact is never removed, and a later `pick` of the same object seems legal.
5. It applies add before delete, so a fact that is in both lists is removed instead of kept. In this domain no operator lists the same fact in both, so the bug is invisible here; but for an operator such as "re-grasp" with `handempty` in both lists it would drop the fact. Correct: `(state - delete) | add`.
6. 7 steps: A holds the cup, and `place(box,A)` needs `free(A)`. So: `pick(cup,A)`, `move(A,C)`, `place(cup,C)`, `move(C,B)`, `pick(box,B)`, `move(B,A)`, `place(box,A)`.
7. `blocking_facts` returns `{'hanging(cup,H)': ['hook_free(H)']}` (the goal fact `hanging(cup,H)` is blocked by the missing precondition `hook_free(H)`): nothing produces it. Fix the model: add `hook_free(H)` to the initial state if the hook really is free, or add an operator that frees it; otherwise report that the task is impossible.
8. Let $F_k$ be the real state after $k$ operators and $R_k$ the relaxed-reachable set after the same sequence is replayed in the relaxation (never deleting). $F_0=R_0$. If $o_{k+1}$ is applicable in $F_k$ then $\mathrm{pre}\subseteq F_k\subseteq R_k$, so it is applicable in the relaxation, and $F_{k+1}=(F_k\setminus\mathrm{del})\cup\mathrm{add}\subseteq R_k\cup\mathrm{add}=R_{k+1}$. So every real plan maps to a relaxed plan of the same length: relaxed optimum $\le$ real optimum.
9. State: the robot holds the cup at C, `free(C)` true; goal: `at(cup,C)` and `handempty`. Both goal facts are false ($h=2$), but a single `place(cup,C)` achieves both: true cost 1, so $h$ over-estimates.
10. A good project reports expansions for A* and BFS, the plan lengths (equal if the heuristic is admissible), the unreachable-goal case (both exhaust, A* with the relaxation detects it immediately), and rejects "always reduces" if some instance expands as many states.
