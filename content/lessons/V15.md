## Why this matters

Many current perception stacks for robots (detectors, segmenters, vision-language-action policies) have a vision transformer, or ViT, at their core. A ViT replaces convolution's hard-wired local sliding window with a learned, global mixing of patches. That gives flexibility and strong scaling, but it also changes what the model can know, what it costs, and how it breaks. If you can count tokens, size the attention matrix and say where spatial information enters, you can predict whether a ViT will fit on your robot's compute budget and whether it can localise a grasp point.

## Intuition

Think of an image as a short "sentence". Cut it into non-overlapping $P\times P$ patches and read them in raster order. Each patch, flattened to $P^2C$ numbers, is turned into a vector of length $D$ by one shared linear layer. That vector is a **token**. Then a stack of transformer encoder blocks lets every token look at every other token and build a new representation.

Two things follow immediately.

- **Count.** An $H\times W$ image gives $N=\frac{H}{P}\cdot\frac{W}{P}$ patch tokens, plus one learned `[CLS]` token if the head reads a class summary from it.
- **Order blindness.** Attention treats its input as a set. If you shuffle the tokens, the outputs are shuffled the same way, so the network cannot tell the top-left patch from the bottom-right one. Position codes added to the tokens fix that.

## Theory and derivation

### Patch embedding

For patch $x_i\in\mathbb R^{P^2C}$ the token is $t_i=Ex_i+b+e_i$, where $E\in\mathbb R^{D\times P^2C}$ is shared and $e_i$ encodes position. For $H=W=224$, $P=16$, $C=3$: $14\times14=196$ patches of 768 numbers each. Implemented as a convolution with kernel and stride $P$, the patch embedding is exactly this linear map.

### Scaled dot-product attention

For tokens $X\in\mathbb R^{N\times D}$ and learned matrices $W_Q,W_K,W_V$:
$$Q=XW_Q,\quad K=XW_K,\quad V=XW_V,\qquad \mathrm{Attn}(X)=\mathrm{softmax}\!\Big(\frac{QK^{\top}}{\sqrt d}\Big)V .$$
The $\sqrt d$ keeps scores from growing with the key dimension $d$, which would otherwise push the softmax into saturation (tiny gradients). Each row of the softmax sums to 1, so each output is a convex combination of value vectors.

### Cost

$QK^{\top}$ has $N^2$ entries, each a length-$d$ dot product, and $AV$ needs another $N^2d$ multiply-accumulates: about $2N^2d$ per head, and $N^2$ numbers must be stored per head per layer. Because $N\propto (H/P)^2$, doubling the image side multiplies $N$ by 4 and attention cost by 16. Halving $P$ has the same effect. Convolutions scale linearly in pixels.

### Permutation equivariance and position

Let $\Pi$ be a permutation matrix. Then $\mathrm{Attn}(\Pi X)=\Pi\,\mathrm{Attn}(X)$ because $Q,K,V$ permute row-wise and the softmax acts row by row over a permuted set. Hence without position information a ViT cannot know *where* a patch is. Remedies:

| Encoding | Idea | Note |
|---|---|---|
| Learned 1D absolute | one vector per token index | the original ViT; must be interpolated for a new resolution |
| Sinusoidal | fixed sines and cosines of the index | no parameters; extrapolates in form |
| 2D / relative | encode row and column or the offset between tokens | closer to the image's geometry |

### Inductive bias

A convolution assumes locality and translation equivariance. A ViT assumes almost nothing, so it needs more data or strong augmentation to learn what a CNN gets for free, but it can model long-range relations (a gripper and a distant object) in one layer.

## Worked example

### Attention on two tokens

**Problem.** Two tokens $x_1=(1,0)$ and $x_2=(0,1)$ with $W_Q=W_K=W_V=I$ and key dimension $d=2$. Find the attention output of each token, check that swapping the inputs swaps the outputs, and count the tokens and attention entries of a ViT with $224\times224$ input, patch size $P=16$ and one CLS token.

**Solution.**

1. With identity matrices $Q=XW_Q=X$, so $Q=K=V=X=\begin{pmatrix}1&0\\0&1\end{pmatrix}$.
2. Scores $QK^{\top}=XX^{\top}=\begin{pmatrix}1&0\\0&1\end{pmatrix}$. Divide by $\sqrt d=\sqrt2=1.4142$: $\begin{pmatrix}0.7071&0\\0&0.7071\end{pmatrix}$.
3. Softmax of row 1 $(0.7071,\,0)$: $e^{0.7071}=2.0281$, $e^{0}=1$, sum $3.0281$, weights $(2.0281/3.0281,\ 1/3.0281)=(0.6698,\,0.3302)$.
4. Output 1 $=0.6698\,(1,0)+0.3302\,(0,1)=(0.6698,\,0.3302)$. Row 2 of the scores is $(0,\,0.7071)$, the mirror image, so its weights are $(0.3302,\,0.6698)$ and output 2 $=(0.3302,\,0.6698)$.
5. Swap the inputs: $X'=\Pi X$ with rows exchanged. Then $Q'K'^{\top}=\Pi(QK^{\top})\Pi^{\top}$ swaps rows and columns of the score matrix, the row-wise softmax gives the same weight rows in swapped places, and the outputs are the same two vectors in swapped order: $\mathrm{Attn}(\Pi X)=\Pi\,\mathrm{Attn}(X)$.
6. Size: $224/16=14$ patches per side, $14^2=196$ patches, plus CLS gives $N=197$ tokens, and one head stores $N^2=197^2=38{,}809$ attention entries.

**Check.** Each weight row sums to 1 ($0.6698+0.3302=1.0000$), and each output has coordinates summing to 1, as a convex combination of $(1,0)$ and $(0,1)$ must. Without the $1/\sqrt d$ scaling the weights would be $e/(e+1)=0.7311$ and $0.2689$, a sharper softmax, which shows what the scaling prevents as $d$ grows.

**Takeaway.** Token 1 keeps about two thirds of its own content, and attention treats tokens as a set: permuting the inputs only permutes the outputs, so position must be added explicitly.

## Reference implementation

Plain Python lists stand in for tensors, which is enough to check shapes, counts and symmetry.

```python
import math

def num_tokens(h, w, p, cls=True):
    if h % p or w % p:
        raise ValueError("image size must be divisible by the patch size")
    return (h//p)*(w//p) + (1 if cls else 0)

def patchify(img, p):
    """img: H x W x C nested lists. Returns row-major patches, each flattened to p*p*C numbers."""
    H, W = len(img), len(img[0])
    out = []
    for r in range(0, H, p):
        for c in range(0, W, p):
            out.append([v for i in range(p) for j in range(p) for v in img[r+i][c+j]])
    return out

def matmul(A, B):
    return [[sum(a*b for a, b in zip(row, col)) for col in zip(*B)] for row in A]

def softmax(row):
    m = max(row)
    e = [math.exp(v - m) for v in row]
    s = sum(e)
    return [v/s for v in e]

def attention(X, Wq, Wk, Wv):
    """Single-head self-attention. X: N x D. Returns (output N x d, weights N x N)."""
    Q, K, V = matmul(X, Wq), matmul(X, Wk), matmul(X, Wv)
    d = len(Q[0])
    scores = [[sum(q*k for q, k in zip(qi, kj))/math.sqrt(d) for kj in K] for qi in Q]
    A = [softmax(r) for r in scores]
    return matmul(A, V), A

def sinusoidal_pe(n, d):
    pe = []
    for pos in range(n):
        row = []
        for i in range(0, d, 2):
            ang = pos/(10000**(i/d))
            row += [math.sin(ang), math.cos(ang)]
        pe.append(row[:d])
    return pe

if __name__ == "__main__":
    assert num_tokens(224, 224, 16) == 197 and num_tokens(224, 224, 16, cls=False) == 196
    # 4x4 single-channel image, 2x2 patches
    img = [[[4*r + c] for c in range(4)] for r in range(4)]
    assert patchify(img, 2) == [[0, 1, 4, 5], [2, 3, 6, 7], [8, 9, 12, 13], [10, 11, 14, 15]]
    I = [[1, 0], [0, 1]]
    out, A = attention([[1, 0], [0, 1]], I, I, I)
    assert abs(A[0][0] - 0.6698) < 1e-4 and abs(out[0][1] - 0.3302) < 1e-4
    # without positional encoding, permuting tokens just permutes the outputs
    X = [[1, 0], [0, 1], [1, 1]]
    Wq = [[0.5, -1], [1, 0.3]]; Wk = [[1, 0.2], [-0.4, 1]]; Wv = [[0.3, 0.9], [0.6, -0.5]]
    o1, _ = attention(X, Wq, Wk, Wv)
    perm = [2, 0, 1]
    o2, _ = attention([X[i] for i in perm], Wq, Wk, Wv)
    assert all(abs(o2[k][j] - o1[perm[k]][j]) < 1e-12 for k in range(3) for j in range(2))
    # with position codes tied to the slot, shuffling the patches DOES change the result
    pe = sinusoidal_pe(3, 2)
    add = lambda T: [[a + b for a, b in zip(x, p)] for x, p in zip(T, pe)]
    o3, _ = attention(add(X), Wq, Wk, Wv)
    o4, _ = attention(add([X[i] for i in perm]), Wq, Wk, Wv)
    assert max(abs(o4[k][j] - o3[perm[k]][j]) for k in range(3) for j in range(2)) > 1e-3
    for side in (224, 384, 512):
        n = num_tokens(side, side, 16)
        print(side, "px ->", n, "tokens, attention entries per head:", n*n)
    print("self-test passed")
```

import math
import torch
import torch.nn.functional as F

torch.manual_seed(0)
# --- 1. patchify = Conv2d(kernel=stride=P): same numbers as the stdlib patchify ---
img = torch.arange(16.0).reshape(1, 1, 4, 4)                 # the 4x4 image from the self-test
patches = F.unfold(img, kernel_size=2, stride=2).transpose(1, 2)[0]   # (N, P*P*C), row-major
assert patches.tolist() == [[0, 1, 4, 5], [2, 3, 6, 7], [8, 9, 12, 13], [10, 11, 14, 15]]
x = torch.randn(1, 3, 224, 224)
conv = torch.nn.Conv2d(3, 32, kernel_size=16, stride=16)
tok_conv = conv(x).flatten(2).transpose(1, 2)[0]             # (196, 32)
flat = F.unfold(x, 16, stride=16).transpose(1, 2)[0]         # (196, 768), channel-major flatten
tok_lin = flat @ conv.weight.reshape(32, -1).T + conv.bias   # the same linear map E x + b
assert tok_conv.shape == (196, 32) and torch.allclose(tok_conv, tok_lin, atol=1e-4)

# --- 2. attention matches F.scaled_dot_product_attention and the stdlib `attention` ---
X = [[1, 0], [0, 1], [1, 1]]
Wq = [[0.5, -1], [1, 0.3]]; Wk = [[1, 0.2], [-0.4, 1]]; Wv = [[0.3, 0.9], [0.6, -0.5]]
Xt, Q, K, V = (torch.tensor(m, dtype=torch.float64) for m in (X, Wq, Wk, Wv))
out_t = F.scaled_dot_product_attention((Xt @ Q)[None], (Xt @ K)[None], (Xt @ V)[None])[0]
out_ref, _ = attention(X, Wq, Wk, Wv)
assert torch.allclose(out_t, torch.tensor(out_ref, dtype=torch.float64), atol=1e-12)

# --- 3. equivariance with nn.MultiheadAttention (no position codes) ---
mha = torch.nn.MultiheadAttention(embed_dim=8, num_heads=2, batch_first=True).eval()
T = torch.randn(1, 5, 8); perm = torch.tensor([3, 0, 4, 1, 2])
with torch.no_grad():
    o, w = mha(T, T, T)
    op, _ = mha(T[:, perm], T[:, perm], T[:, perm])
assert torch.allclose(op, o[:, perm], atol=1e-6)             # shuffled in, shuffled out
assert torch.allclose(w.sum(-1), torch.ones(1, 5), atol=1e-6)  # rows sum to 1

# --- 4. cost: attention matrix entries per head for N tokens, counted from the weights ---
for side in (224, 384):
    n = (side // 16) ** 2 + 1
    _, w = mha(torch.randn(1, n, 8), torch.randn(1, n, 8), torch.randn(1, n, 8), average_attn_weights=True)

## Verification

- Count tokens by hand first: $(H/P)(W/P)$, then add CLS. Compare with the code output.
- Rows of the attention matrix must sum to 1; entries must be non-negative.
- With identity weights and orthogonal unit tokens the weights should be $\frac{e^{1/\sqrt d}}{e^{1/\sqrt d}+(N-1)}$ on the diagonal; use it as a unit test.
- Equivariance test: shuffle tokens, run the layer, un-shuffle, and compare. It must pass without positions and fail with slot-tied positions.

## Failure modes

| Mistake | Effect |
|---|---|
| Forgetting CLS when counting tokens | Off by one in position-embedding shapes |
| Image size not divisible by $P$ | Crashes or silently crops border pixels |
| Omitting $\sqrt d$ | Saturated softmax, slow or unstable training |
| Reusing 224 px position embeddings at 384 px without interpolation | Shape error, or wrong geometry |
| Treating the attention map as an explanation | Attention weights are not a faithful saliency map |
| Ignoring the $N^2$ memory | Out-of-memory at modest resolution increases |

## Alternatives and trade-offs

- **CNN**: local, translation equivariant, linear cost; good with limited data; weak at long-range relations.
- **ViT (global attention)**: flexible and scalable with data; quadratic cost; needs position codes.
- **Windowed or hierarchical transformers (Swin-style)**: attention within local windows plus shifts; near-linear cost, multi-scale features suited to dense prediction.
- **Hybrid**: a small convolutional stem to produce tokens, which stabilises early training and cuts tokens.
- **Larger patches**: cheaper, coarser; small objects can vanish into a single patch.

## Exercise answers

1. $P=32$: $7\times7=49$ patches, each $32\cdot32\cdot3=3072$ numbers. $P=16$: 196 patches of 768 numbers. Same pixels in total ($49\cdot3072=196\cdot768=150{,}528$), but 4x fewer tokens, so 16x smaller attention matrix (2,401 vs 38,416 entries).
2. The head can instead average the patch tokens (global average pooling) or use attention pooling. CLS is a convention from language models.
3. $480/16=30$ and $640/16=40$: both divisible, so no resize is needed: $1200$ tokens (1201 with CLS), a $1201^2\approx1.44$M-entry matrix per head.
4. If $q_i,k_i$ are independent with variance 1, $q\cdot k$ is a sum of $d$ terms with variance 1 each, so variance $d=64$ (std 8). After dividing by $\sqrt d$ the variance is 1. Large scores would push the softmax toward one-hot with vanishing gradients.
5. Scores $/1.4142$: token 3 has $q=(0,1)$; against keys $(1,0),(1,0),(0,1)$ it scores $0,0,0.7071$. Softmax: $e^{0.7071}=2.0281$, sum $=1+1+2.0281=4.0281$; weights $(0.2483,0.2483,0.5035)$; token 3 attends most to itself.
6. For each row block $r=0,p,2p,\dots$ it returns only the first $p$ pixels of pixel row $r$ itself. So it yields $H/p$ short row fragments from the left edge of the image, not $(H/p)(W/p)$ square patches: it never offsets the column start, never reads the other $p-1$ pixel rows of a patch, and never visits patches to the right. A correct version loops over both row blocks and column blocks, collects all $p\times p$ pixels of each block, and flattens them in a fixed order.
7. The position-embedding table has 196 (+1) entries but $384/16=24$, $24^2=576$ patches are needed. Usual fix: reshape the 14x14 grid of embeddings to 2D and interpolate bicubically to 24x24. Cost: attention entries rise from $38{,}809$ to $577^2=332{,}929$ per head, about 8.6x.
8. Halving the input side from 224 to 112 at $P=16$ gives 49 tokens; doubling $P$ to 32 at 224 px gives 49 tokens too, so attention cost falls by the same 16x. The difference is what is lost: resizing keeps the pretrained patch embedding but changes object scale, while a larger $P$ needs a new embedding. A good answer also mentions windowed attention and measuring accuracy on the robot's own data at the target latency.
9. $Q'=\Pi XW_Q=\Pi Q$, similarly $K'=\Pi K$, $V'=\Pi V$. Scores $Q'K'^{\top}=\Pi QK^{\top}\Pi^{\top}$; the row-wise softmax commutes with the simultaneous row/column permutation, so $A'=\Pi A\Pi^{\top}$ and $A'V'=\Pi A\Pi^{\top}\Pi V=\Pi AV$. A bag of patches still carries which textures and parts are present, enough for many classes, but not their arrangement, so localisation fails.
10. A good table shows 38,809 / 332,929 / 1,050,625 entries per head (197 / 577 / 1025 tokens), notes the CNN's linear cost and built-in locality, and picks a CNN or windowed transformer for the embedded board unless global context is essential.
