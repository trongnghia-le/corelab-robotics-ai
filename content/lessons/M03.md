## Why this matters

Use shapes and basis vectors to reason about matrix multiplication. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A matrix is a machine that sends basis vectors somewhere. Its columns record those destinations. Multiplication by a vector builds the output as a weighted sum of the columns. This view explains the multiplication rule and why swapping matrices usually changes the answer.

## Theory and derivation

For $A\in\mathbb R^{m\times n}$ and $x\in\mathbb R^n$, $(Ax)_i=\sum_{j=1}^{n}A_{ij}x_j$. Equivalently $Ax=\sum_jx_jA_{:j}$. For $B\in\mathbb R^{n\times p}$, the product $AB$ has shape $m\times p$ and $(AB)_{ik}=\sum_jA_{ij}B_{jk}$.

Derive composition by substituting $y=Bx$ into $z=Ay$: $z=A(Bx)=(AB)x$. The rightmost operation happens first. Matrix multiplication distributes over addition and is associative, but is generally not commutative. The identity $I$ leaves every vector fixed. A square inverse satisfies both $A^{-1}A=AA^{-1}=I$; a matrix that collapses a nonzero direction cannot have an inverse.

The transpose exchanges indices: $(A^T)_{ji}=A_{ij}$. Expanding an entry shows $(AB)^T=B^TA^T$, with the order reversed. Dimensions are a fast error detector, though dimensionally valid calculations can still be semantically wrong.

## Worked example

For A=[[1,2],[0,1]] and x=(3,4), Ax=(11,4). The first coordinate uses a row-dot-vector product, 1×3+2×4. Let B=diag(2,1). Then AB=[[2,2],[0,1]], while BA=[[2,4],[0,1]]. Scale-then-shear differs from shear-then-scale.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
def matvec(A, x):
    if any(len(row) != len(x) for row in A):
        raise ValueError("shape mismatch")
    return [sum(a*b for a, b in zip(row, x)) for row in A]

assert matvec([[1, 2], [0, 1]], [3, 4]) == [11, 4]
```

## Failure modes

The product A*B in NumPy is elementwise, while A@B composes maps. An inverse exists only for nonsingular square maps. Avoid “dividing by a matrix” without stating the linear system being solved.

## Alternatives and trade-offs

A dense matrix is convenient for small transforms. Sparse representations avoid storing zero coefficients in large systems. Solving Ax=b is usually more stable and cheaper than explicitly computing A⁻¹ and multiplying.
