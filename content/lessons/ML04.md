## Why this matters

Build a small network from operations whose shapes you understand. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A neural network composes simple transformations. Each layer first mixes features with an affine map and then applies a nonlinearity. The power comes from learned compositions, not from replacing arithmetic with a mysterious black box.

## Theory and derivation

For column input $x\in\mathbb R^d$, a dense layer computes $z=Wx+b$ with $W\in\mathbb R^{h\times d}$ and $b\in\mathbb R^h$. An elementwise activation gives $a=\sigma(z)$. ReLU is $\max(0,z)$; sigmoid is $1/(1+e^{-z})$.

Without nonlinearities, two layers collapse: $W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$. Depth alone then does not add a new class of functions. A nonlinear hidden layer changes this limitation, while still requiring enough data and a valid optimization and evaluation procedure.

A dense layer has $hd+h$ parameters. Training adjusts these parameters to reduce a specified loss, while inference holds them fixed. Activations, losses, and data scales should fit the task: a scalar regression output need not use sigmoid, and a classification probability requires a consistent output and loss definition.

## Worked example

Let x=(1,2), W=[[1,−1],[2,0]], b=(0,1). Then z=(−1,3) and ReLU(z)=(0,3). With output weights (2,−1) and zero bias, the scalar output is −3. The first layer has 2×2+2=6 parameters, not four.

## Exercises

1. **(Easy)** Count the trainable parameters of a network with layer sizes $3\to4\to2$ (dense layers with biases) and of an image classifier $784\to128\to10$. Which layer dominates, and why is the first-layer count not $784\times128$? *(Adapted from: Stanford CS231n notes, Neural Networks Part 1, on network architecture and sizing)*
2. **(Easy)** Evaluate ReLU at $-2$ and $3$, and sigmoid at $0$, $2$, $-2$ (3 decimals). Verify $\sigma(z)+\sigma(-z)=1$ for $z=2$ and say what this means for a probability output.
3. **(Medium)** One hidden layer with ReLU: $x=(2,1)$, $W_1=\begin{pmatrix}1&2\\-1&0.5\end{pmatrix}$, $b_1=(0,0.5)$, output weights $w_2=(1,-1)$, $b_2=0.2$. Compute $z$, $a$ and the output. Which hidden unit is "off" for this input?
4. **(Medium)** **XOR.** Use $W=\begin{pmatrix}1&1\\1&1\end{pmatrix}$, hidden bias $c=(0,-1)$, output weights $w=(1,-2)$, ReLU hidden units, no output bias. Compute the output for the four inputs $(0,0),(0,1),(1,0),(1,1)$. Then argue that no single linear unit with a threshold can produce this table. *(Adapted from: Goodfellow, Bengio and Courville, Deep Learning, Ch. 6.1, the XOR example)*
5. **(Medium)** **Predict the output.**
   ```python
   W1, b1 = [[1, 2], [0, 1]], [1, 0]
   W2, b2 = [[1, 1]], [0.5]
   x = [2, 1]
   h = [sum(w * v for w, v in zip(r, x)) + b for r, b in zip(W1, b1)]
   y = [sum(w * v for w, v in zip(r, h)) + b for r, b in zip(W2, b2)]
   print(y)
   ```
   Then compute the single equivalent layer $(W_2W_1,\ W_2b_1+b_2)$ and confirm it gives the same output. What does this say about stacking linear layers?
6. **(Medium)** **Find the bug.** A regression network that must output battery temperature (values around 40 to 60) ends with a sigmoid output unit. What is the smallest possible squared error for a target of $50$? What two changes fix it? Also: a layer with $W$ stored as shape $(d,h)$ is multiplied as `W @ x`; when does this raise an error and when does it silently compute something wrong?
7. **(Hard)** **Backprop by hand.** A single ReLU neuron feeds a linear output: $a=\max(0,wx+b)$, $\hat y=va$, $L=\tfrac12(\hat y-y)^2$. For $x=2,\ w=1,\ b=-1,\ v=3,\ y=2$ compute $\partial L/\partial w$, $\partial L/\partial b$, $\partial L/\partial v$. What happens to all three if $b=-3$ instead? *(Adapted from: Nielsen, Neural Networks and Deep Learning, Ch. 2 on the backpropagation equations)*
8. **(Hard)** Show that a hidden layer of two ReLU units can represent $|x|$ exactly, and count its parameters. How would you represent a "tent" with a peak at $x=1$ from 0 to 2, and how does the number of hidden units relate to the number of linear pieces?
9. **(Hard)** **Design.** A controller needs a smooth torque prediction whose Jacobian with respect to joint angles is used by a downstream optimiser. Compare ReLU, softplus and tanh hidden activations: derivative at $z=0.5$, smoothness at $z=0$, and one failure mode of each. Which would you choose and what would you inspect during training?
10. **(Project)** Implement a 2-layer ReLU network with hand-written backprop, check every gradient with finite differences, and train on XOR with four hidden units from several seeds. Report the final loss per seed and explain any seed that fails.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
import numpy as np
x=np.array([1.,2.])
W=np.array([[1.,-1.],[2.,0.]])
b=np.array([0.,1.])
a=np.maximum(0,W@x+b)
assert np.allclose(a,[0,3])
assert np.array([2.,-1.])@a == -3
```

```python
import random
def close(a, b, t=1e-9): return abs(a - b) < t
assert relu(-2) == 0 and relu(3) == 3 and sigmoid(0) == 0.5 and close(sigmoid(2) + sigmoid(-2), 1.0)
assert param_count([3, 4, 2]) == 26 and param_count([784, 128, 10]) == 101770
# lesson worked example: z = (-1, 3), a = (0, 3), output -3
o, z, a = forward(([[1, -1], [2, 0]], [0, 1], [2, -1], 0.0), [1, 2])
assert z == [-1, 3] and a == [0, 3] and o == -3
# exercise 3 and the XOR network (hand weights)
o, z, a = forward(([[1, 2], [-1, 0.5]], [0, 0.5], [1, -1], 0.2), [2, 1]); assert close(o, 4.2) and a == [4, 0]
xor = ([[1, 1], [1, 1]], [0, -1], [1, -2], 0.0)
assert [forward(xor, [p, q])[0] for p in (0, 1) for q in (0, 1)] == [0, 1, 1, 0]
# two linear layers collapse into one
W, b = collapse([[1, 2], [0, 1]], [1, 0], [[1, 1]], [0.5]); assert W == [[1, 3]] and b == [1.5]
# hand backprop: single ReLU neuron, x=2, w=1, b=-1, v=3, y=2 -> (6, 3, 1); dead neuron -> 0
gW, gb, gv, g2 = backward(([[1.0]], [-1.0], [3.0], 0.0), [2.0], 2.0)
assert close(gW[0][0], 6) and close(gb[0], 3) and close(gv[0], 1)
gW, gb, gv, g2 = backward(([[1.0]], [-3.0], [3.0], 0.0), [2.0], 2.0)
assert gW[0][0] == 0 and gb[0] == 0 and gv[0] == 0
# finite-difference check of every gradient on a random network
random.seed(7)
P = ([[random.uniform(-1, 1) for _ in range(3)] for _ in range(4)], [0.5, 0.4, 0.6, 0.3], [random.uniform(-1, 1) for _ in range(4)], 0.1)
x, y = [0.9, -0.4, 0.7], 0.3
L = lambda Q: 0.5 * (forward(Q, x)[0] - y) ** 2
gW, gb, gv, g2 = backward(P, x, y); h = 1e-6
for j in range(4):
    for k in range(3):
        Wp = [r[:] for r in P[0]]; Wm = [r[:] for r in P[0]]; Wp[j][k] += h; Wm[j][k] -= h
        assert close(gW[j][k], (L((Wp,) + P[1:]) - L((Wm,) + P[1:])) / (2 * h), 1e-6)
    bp = P[1][:]; bm = P[1][:]; bp[j] += h; bm[j] -= h
    assert close(gb[j], (L((P[0], bp) + P[2:]) - L((P[0], bm) + P[2:])) / (2 * h), 1e-6)
# training: XOR from a fixed random init reaches near-zero loss
r = random.Random(0)
P0 = ([[r.uniform(-1, 1) for _ in range(2)] for _ in range(4)], [r.uniform(-.5, .5) for _ in range(4)], [r.uniform(-1, 1) for _ in range(4)], 0.0)
X = [[0, 0], [0, 1], [1, 0], [1, 1]]; Y = [0, 1, 1, 0]
Pt = train(P0, X, Y, 0.1, 3000)
loss = sum(0.5 * (forward(Pt, x)[0] - t) ** 2 for x, t in zip(X, Y)) / 4
assert loss < 1e-6 and [round(forward(Pt, x)[0]) for x in X] == Y
print("XOR outputs:", [round(forward(Pt, x)[0], 3) for x in X], "| final loss below 1e-6:", loss < 1e-6)
print("all tests passed")
```

```python
import torch
from torch import nn

torch.manual_seed(0)

# 1. Parameter counts
count = lambda m: sum(p.numel() for p in m.parameters())
assert count(nn.Sequential(nn.Linear(3, 4), nn.ReLU(), nn.Linear(4, 2))) == 26
assert count(nn.Sequential(nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10))) == 101770

# 2. The lesson's worked example, loading weights by hand
l1, l2 = nn.Linear(2, 2), nn.Linear(2, 1)
with torch.no_grad():
    l1.weight.copy_(torch.tensor([[1., -1.], [2., 0.]])); l1.bias.copy_(torch.tensor([0., 1.]))
    l2.weight.copy_(torch.tensor([[2., -1.]])); l2.bias.zero_()
assert torch.allclose(l2(torch.relu(l1(torch.tensor([1., 2.])))), torch.tensor([-3.]))

# 3. Hand backprop (exercise 7): x=2, w=1, b=-1, v=3, y=2 -> dL/dw=6, dL/db=3, dL/dv=1
w = torch.tensor(1., requires_grad=True); b = torch.tensor(-1., requires_grad=True); v = torch.tensor(3., requires_grad=True)
L = 0.5 * (v * torch.relu(w * 2 + b) - 2) ** 2
L.backward()
assert (w.grad.item(), b.grad.item(), v.grad.item()) == (6.0, 3.0, 1.0)

# 4. Two linear layers collapse into one affine layer
A, B = nn.Linear(2, 2), nn.Linear(2, 1)
x = torch.randn(5, 2)
W = B.weight @ A.weight; c = B.weight @ A.bias + B.bias
assert torch.allclose(B(A(x)), x @ W.T + c, atol=1e-6)

# 5. XOR with 4 hidden ReLU units
X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]]); Y = torch.tensor([[0.], [1.], [1.], [0.]])
for seed in range(10):                      # a few seeds may land on dead units; try until one works
    torch.manual_seed(seed)
    net = nn.Sequential(nn.Linear(2, 4), nn.ReLU(), nn.Linear(4, 1))
    opt = torch.optim.SGD(net.parameters(), lr=0.1)
    for _ in range(3000):
        opt.zero_grad(); loss = 0.5 * ((net(X) - Y) ** 2).mean(); loss.backward(); opt.step()
    if loss.item() < 1e-6: break
assert loss.item() < 1e-6 and net(X).round().flatten().tolist() == [0., 1., 1., 0.]
print("library track ok")
```

## Failure modes

More layers do not automatically mean more useful features. ReLU units with negative inputs have zero local gradient; output scaling and initialization can affect training. A forward pass alone does not demonstrate learning.

## Alternatives and trade-offs

Linear models are transparent baselines. ReLU networks provide piecewise-linear functions; smooth activations can help when derivatives of the output matter. Architecture should follow the task and evidence, not parameter count alone.

## Exercise answers

1. $3\to4\to2$: $(3\cdot4+4)+(4\cdot2+2)=16+10=26$. $784\to128\to10$: $(784\cdot128+128)+(128\cdot10+10)=100{,}480+1{,}290=101{,}770$. The first layer dominates (about 99%). Each of the 128 units has 784 weights plus a bias, so the layer has $128\times785=100{,}480$ parameters: the biases add 128.
2. ReLU$(-2)=0$, ReLU$(3)=3$; $\sigma(0)=0.5$, $\sigma(2)=0.881$, $\sigma(-2)=0.119$; $0.881+0.119=1$. The pair sums to 1 as probabilities of complementary outcomes should: the sigmoid gives a consistent two-class probability.
3. $W_1x=(1\cdot2+2\cdot1,\ -1\cdot2+0.5\cdot1)=(4,-1.5)$, so $z=W_1x+b_1=(4,-1)$; $a=(4,0)$; output $=1\cdot4-1\cdot0+0.2=4.2$. The second hidden unit is off (its $z<0$).
4. $(0,0)$: $z=(0,-1)\to h=(0,0)\to0$. $(0,1)$: $z=(1,0)\to h=(1,0)\to1$. $(1,0)$: same, 1. $(1,1)$: $z=(2,1)\to h=(2,1)\to2-2=0$. This is XOR. A linear threshold $w_1x_1+w_2x_2+b>0$ would need $b\le0$, $w_1+b>0$, $w_2+b>0$ and $w_1+w_2+b\le0$; adding the middle two gives $w_1+w_2+2b>0$, so $w_1+w_2+b>-b\ge0$, contradicting the last. Impossible.
5. $h=(2+2+1,\ 0+1+0)=(5,1)$, $y=5+1+0.5=6.5$: output `[6.5]`. Combined: $W_2W_1=(1,3)$, $W_2b_1+b_2=1+0.5=1.5$; $(1,3)\cdot(2,1)+1.5=6.5$. Stacked linear layers collapse into one, so depth without a nonlinearity adds nothing.
6. A sigmoid output is in $(0,1)$, so the error for target $50$ is at least $49^2\approx2401$ (and the loss gradient vanishes as it saturates). Fix: use a linear output and standardise targets (subtract mean, divide by std) or a scaled output. For $W$ of shape $(d,h)$ and `W @ x` with $x\in\mathbb R^d$: if $d\ne h$ it raises a shape error; if $d=h$ the shapes agree, so it silently computes $Wx$ where $W^Tx$ was intended: a wrong but valid product.
7. $z=1\cdot2-1=1>0$, $a=1$, $\hat y=3$, $e=\hat y-y=1$. $\partial L/\partial w=e\,v\,\mathbb 1[z>0]\,x=1\cdot3\cdot2=6$; $\partial L/\partial b=e\,v=3$; $\partial L/\partial v=e\,a=1$. For $b=-3$: $z=-1<0$, $a=0$, $\hat y=0$; $\partial L/\partial w=\partial L/\partial b=0$ (a "dead" unit gets no gradient), though $\partial L/\partial v=e\cdot a=0$ as well.
8. $|x|=\max(0,x)+\max(0,-x)$: hidden weights $(1,-1)$, biases $(0,0)$, output weights $(1,1)$. Parameters: first layer $2\cdot1+2=4$, output $2+1=3$, total 7. A tent: $\mathrm{relu}(x)-2\,\mathrm{relu}(x-1)+\mathrm{relu}(x-2)$ (3 hidden units, 3 kinks). A one-hidden-layer ReLU network with $k$ hidden units represents a continuous piecewise-linear function with up to $k+1$ pieces.
9. At $z=0.5$: ReLU derivative 1 (0 for $z<0$, undefined at 0), softplus derivative $\sigma(0.5)=0.622$, tanh derivative $1-\tanh^2(0.5)=0.786$. ReLU has a kink so the Jacobian is discontinuous and units can die; softplus is smooth but unbounded and more expensive; tanh is smooth and bounded but saturates (vanishing gradients). For a smooth Jacobian choose softplus or tanh; inspect activation histograms, saturation, gradient norms and Jacobian continuity along test trajectories.
10. A good answer shows finite-difference agreement (about $10^{-6}$), final loss near 0 for most seeds, and a failing seed explained by dead ReLU units (all hidden pre-activations negative on every input, so no gradient flows); remedies: other initialisation, smaller steps, or a leaky ReLU.
