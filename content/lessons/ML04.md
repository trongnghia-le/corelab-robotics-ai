## Why this matters

A neural network is the model class behind most learned parts of a robot: torque and dynamics models, perception heads, policies. Its core is two operations whose shapes can be checked by hand, an affine map and an elementwise nonlinearity. This lesson develops that calculation (shapes, parameter counts, what ReLU networks can represent, and how the scale of the initial weights decides whether a signal survives many layers) before ML05 differentiates it. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A neural network composes simple transformations. Each layer first mixes features with an affine map and then applies a nonlinearity. The power comes from learned compositions, not from replacing arithmetic with a mysterious black box.

Think of a sheet of paper with a pattern drawn on it. A single linear layer can only stretch, rotate and shift the sheet, so a pattern that two straight lines cannot separate stays unseparable. A ReLU unit does something new: it **folds** the sheet along a line, so that everything on one side is flattened onto the line. After one fold the points that lay on both sides of the crease are brought on top of each other; a second layer can then fold the folded sheet again. Training chooses where the creases go and how the layers combine the folded copies. This is why a network that is "just matrix multiplications" can draw curved decision boundaries: between the creases it is exactly linear, and the creases are where the nonlinearity lives.

![A ReLU layer folds the plane. Left: the input plane with the two crease lines z1 = 0 and z2 = 0 and four marked points A to D, one in each cell. Right: the images h = relu(Wx + b); the cell where both units are on is unchanged, the two cells where one unit is off are flattened onto the h2 axis and the h1 axis, and the cell where both are off collapses to the origin.](/lesson-figures/ML04.svg)

*Figure: each ReLU unit flattens the half-plane behind its crease onto the crease line; the points A to D are mapped with $W=[[1,\,0.5],[-0.5,\,1]]$, $b=0$ (illustrative numbers).*

A robot example makes this concrete. A motor's torque as a function of velocity has a dead zone near zero (static friction) and then a roughly linear rise. A linear model must choose one slope; a hidden layer with two ReLU units can represent "zero up to a threshold, then rising", which is exactly $\max(0,v-v_0)$. More hidden units add more thresholds and thus more slope changes, so you can read the capacity of a one-layer ReLU network as "number of kinks I can place".

**Predict before you compute.** Before the formulas below, guess: how many ReLU hidden units do you need to draw the letter V ($|x|$) exactly, and the shape of a tent that rises and falls? And if you are allowed to stack layers, how many linear pieces can $l$ layers of two units each create: $2l$, $l^2$ or $2^l$? Check your guesses against the theory section.

**The common wrong intuition** is that more layers are always "more nonlinear" and therefore better, or conversely that a deeper network "understands" the data. Depth multiplies the number of pieces only when the layers fold on top of each other in a useful way; with random weights and no nonlinearity, depth does nothing at all, and with a bad initialisation a deep network may not move during training. A second wrong intuition is that the biases are a detail: without the bias a ReLU unit can only fold along a line through the origin, which already rules out the XOR solution of the exercises.

## Theory and derivation

For column input $x\in\mathbb R^d$, a dense layer computes $z=Wx+b$ with $W\in\mathbb R^{h\times d}$ and $b\in\mathbb R^h$. An elementwise activation gives $a=\sigma(z)$. ReLU is $\max(0,z)$; sigmoid is $1/(1+e^{-z})$.

Without nonlinearities, two layers collapse: $W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$. Depth alone then does not add a new class of functions. A nonlinear hidden layer changes this limitation, while still requiring enough data and a valid optimization and evaluation procedure.

A dense layer has $hd+h$ parameters. Training adjusts these parameters to reduce a specified loss, while inference holds them fixed. Activations, losses, and data scales should fit the task: a scalar regression output need not use sigmoid, and a classification probability requires a consistent output and loss definition.

### Conventions, batch form and what each layer costs

The lesson uses the column convention: a dense layer maps $x\in\mathbb R^d$ to $z=Wx+b\in\mathbb R^h$ with $W\in\mathbb R^{h\times d}$. Row $j$ of $W$ holds the weights of unit $j$, so unit $j$ computes the affine function $w_j^\top x+b_j$, a hyperplane's signed distance up to scale. Libraries that store a batch as rows use the transpose: for a batch $X\in\mathbb R^{m\times d}$ the layer computes $Z=XW^\top+\mathbf 1b^\top$, where $\mathbf 1b^\top$ repeats the bias on every row ("broadcasting"). Mixing the two conventions is the most common shape bug, and it is silent when $d=h$. A layer has $hd+h$ parameters and needs about $2hd$ floating-point operations per example (one multiply and one add per weight), so a $784\to128\to10$ network costs roughly $2\cdot101{,}770\approx2\times10^5$ operations per image. For a network with widths $n_0,n_1,\dots,n_L$ the parameter count is $\sum_{l=1}^L(n_ln_{l-1}+n_l)$.

The four activations you will meet differ mainly in their derivatives, because training multiplies those derivatives together:

| activation | $\sigma(z)$ | $\sigma'(z)$ | $\sigma'(0.5)$ | range of $\sigma'$ |
|---|---|---|---|---|
| ReLU | $\max(0,z)$ | $\mathbb 1[z>0]$ | 1 | $\{0,1\}$ |
| sigmoid | $1/(1+e^{-z})$ | $\sigma(1-\sigma)$ | 0.2350 | $(0,\tfrac14]$ |
| tanh | $\tanh z$ | $1-\tanh^2z$ | 0.7864 | $(0,1]$ |
| softplus | $\ln(1+e^z)$ | sigmoid$(z)$ | 0.6225 | $(0,1)$ |

Tanh and sigmoid are the same function up to an affine change of variables, $\tanh z=2\,\mathrm{sigmoid}(2z)-1$ (check: $\frac{e^z-e^{-z}}{e^z+e^{-z}}=\frac{2}{1+e^{-2z}}-1$), so a network with one can be rewritten exactly as a network with the other by rescaling weights and biases (d2l.ai §5.1.4, Exercise 5). What differs is the conditioning during optimisation, not what can be represented.

**Example.** A torque predictor for a 6-joint arm takes 12 inputs (six angles and six velocities) through one hidden layer of 64 units to 6 torques. Find the number of parameters, the shape of $Z$ for a batch of 100 samples, the cost of one sample in floating-point operations, and the load of a 1 kHz control loop.

**Solution.** Layer 1 has $12\cdot64+64=832$ parameters (weights plus biases) and layer 2 has $64\cdot6+6=390$, so the total is $832+390=1222$. For a batch of 100 samples, $Z$ has one row per sample and one column per hidden unit: shape $(100,64)$. One sample costs about two operations (multiply and add) per weight, $2(12\cdot64+64\cdot6)=2(768+384)=2304$ floating-point operations. At 1 kHz that is $2304\cdot1000\approx2.3$ MFLOP per second.

### Why depth needs a nonlinearity, and what ReLU networks compute

For $L$ affine layers without activations, $x\mapsto W_L(\cdots(W_2(W_1x+b_1)+b_2)\cdots)+b_L$ is one affine map $Mx+m$ with $M=W_L\cdots W_1$.

**Proof.** Induction on $L$. For $L=1$ the map is $W_1x+b_1$, so $M=W_1$, $m=b_1$. Suppose the first $L-1$ layers equal $x\mapsto M'x+m'$. Layer $L$ then gives $W_L(M'x+m')+b_L=(W_LM')x+(W_Lm'+b_L)$, which is affine with $M=W_LM'$ and $m=W_Lm'+b_L$. No assumption on the shapes is used beyond the products being defined. $\blacksquare$

The proof also shows what depth *costs* when there is no nonlinearity. With all widths equal to $n$, the end result has $n^2+n$ free numbers but the factored form stores $L(n^2+n)$, and the factors are redundant: for any invertible $G$, replacing $(W_1,b_1,W_2)$ by $(GW_1,Gb_1,W_2G^{-1})$ leaves the function unchanged (substitute: $W_2G^{-1}(GW_1x+Gb_1)+b_2=W_2(W_1x+b_1)+b_2$). The extra parameters change how gradient descent moves, not which functions can be represented. Worse, the factored form can represent *fewer* functions: $\operatorname{rank}(M)\le\min_l\operatorname{rank}W_l\le\min_ln_l$ (the rank of a product is at most the rank of each factor), so a narrow layer is a bottleneck that no later layer can repair (d2l.ai §5.1.4, Exercise 1). Counterexample to "more parameters, more power": a linear $100\to10\to100$ network stores $(100\cdot10+10)+(10\cdot100+100)=2110$ numbers, while a general affine map $\mathbb R^{100}\to\mathbb R^{100}$ needs $100\cdot100+100=10{,}100$; the network can only produce matrices of rank at most $10$.

**Example.** A tactile skin gives 100 taxel readings. A linear autoencoder $100\to10\to100$ must return the 100 readings from 10 numbers. How many parameters does it have, and when can it reproduce the input exactly?

**Solution.** The parameters are $(100\cdot10+10)+(10\cdot100+100)=1010+1100=2110$. The overall map $M$ is a product through a 10-dimensional layer, so $M$ has rank at most 10. It therefore reproduces the input exactly only when the readings always lie in one 10-dimensional subspace; any reading with a component outside it is lost, however long it is trained.

With ReLU the network is no longer affine but is still highly structured: **an MLP using only ReLU hidden units computes a continuous piecewise linear (CPWL) function** (d2l.ai §5.1.4, Exercise 4).

**Proof.** Induction on depth, with the claim "every unit's output is a CPWL function of the input $x$". The input coordinates are CPWL (they are linear). Sums and affine combinations of CPWL functions are CPWL (the union of the two sets of break lines cuts the domain into finitely many pieces on each of which every term is affine). If $g$ is CPWL then so is $\max(0,g)$: on each linear piece of $g$ the function $\max(0,g)$ is either $0$ or $g$, it is continuous (a composition of continuous maps), and inside each linear piece of $g$ the zero set of $g$ is empty, the whole piece, or a single point (a hyperplane piece in higher dimensions), so the new break set is the old one plus finitely many such pieces. A layer is a vector of affine combinations followed by ReLU, so each layer preserves the property. $\blacksquare$

On every region where the on/off pattern of all hidden units is constant, the network is exactly one affine function. This is why the gradient of the output with respect to the input is piecewise constant, and why a Jacobian that must be smooth (the torque example of the exercises) calls for a smooth activation. The statement is false for other activations: $\sigma(z)=1/(1+e^{-z})$ is not piecewise linear on any interval, so sigmoid networks are not CPWL.

**Example.** A camera pixel value $p\in[0,255]$ must be clipped at $200$ using two ReLU units. Give a network and evaluate it at $p=150,230,255$.

**Solution.** Take $\max(0,p)-\max(0,p-200)$. For $p\le200$ the second unit is $0$ and the output equals $p$; for $p>200$ the two units differ by $p-(p-200)=200$. Then $150\mapsto150$, $230\mapsto230-30=200$ and $255\mapsto255-55=200$. The result has two linear pieces with one kink, from a network with no sigmoid or other smooth part.

### Representing functions: exact in one dimension, approximate in general

Let $f:[a,b]\to\mathbb R$ be continuous piecewise linear with kinks at $t_1<\dots<t_m$ and slope $s_j$ after kink $j$ ($s_0$ before the first). Then
$$f(x)=f(a)+s_0\max(0,x-a)+\sum_{j=1}^m c_j\,\max(0,x-t_j),\qquad c_j=s_j-s_{j-1}.$$

**Proof.** Both sides are continuous on $[a,b]$, agree at $x=a$ (every ReLU term vanishes there) and have the same slope on every interval: on $(t_j,t_{j+1})$ the right side has slope $s_0+\sum_{i\le j}c_i=s_j$ (the sum telescopes), because $\max(0,x-t_i)$ contributes slope $1$ only to the right of $t_i$, and $\max(0,x-a)=x-a$ on $[a,b]$. Two continuous piecewise linear functions with equal value at one point and equal slope on every interval are equal (piecewise linearity is needed: the Cantor function is continuous with derivative $0$ almost everywhere but not constant). $\blacksquare$

So on $[a,b]$ a one-hidden-layer ReLU network with $m+1$ units, hidden weights $1$, hidden biases $-a,-t_1,\dots,-t_m$, output weights $s_0,c_1,\dots,c_m$ and output bias $f(a)$ represents any CPWL function with $m$ kinks exactly (the display is claimed on $[a,b]$ only, where $\max(0,x-a)=x-a$). On all of $\mathbb R$, $m+1$ units still suffice: write $x-t_1=\max(0,x-t_1)-\max(0,t_1-x)$, which folds the linear part into the first breakpoint (the unit $\max(0,x-t_1)$ gets output weight $s_0+c_1$ and the extra unit $\max(0,t_1-x)$ gets $-s_0$). Conversely, a network with $n$ hidden units $\max(0,w_jx+b_j)$ has slope changes only where $w_jx+b_j=0$, so it has at most $n$ kinks. The count $m+1$ cannot always be improved. Replacing $\max(0,x-t_j)$ by $\max(0,t_j-x)+(x-t_j)$ for the breakpoints in a subset $S$ moves slope into the linear part, so $m$ units suffice when some subset of the slope changes sums to $-s_0$; a flat piece is one such case (take $S$ as the breakpoints to its left; that piece then needs hidden weight $-1$, as in the Coulomb-friction torque curve of the Intuition section). For slopes $(1,3,7)$ ($m=2$, $c=(2,4)$) no subset sums to $-1$, and this construction needs $3$ units. Likewise $|x|$ on $[-1,1]$ (one kink, slopes $\mp1$) cannot be made by a single unit $c\max(0,wx+b)+d$, whose slopes are $0$ and $cw$, so it needs two.

For a smooth function interpolate: if $f\in C^2$ and the knots are spaced $h$ apart, the standard interpolation estimate gives $|f(x)-\hat f(x)|\le\tfrac{h^2}{8}\max|f''|$ (proved in the answer to exercise 11 by applying Rolle's theorem twice to the error function). To reach accuracy $\epsilon$ one needs $h\le\sqrt{8\epsilon/\max|f''|}$ and hence $O(\epsilon^{-1/2})$ units in one dimension. This is the constructive content of the universal approximation theorem for ReLU networks (Goodfellow et al., *Deep Learning*, §6.4.1). The same section stresses what the theorem does *not* say: it gives no bound on the size needed in general (in the worst case it is exponential in the input dimension, since there are $2^{2^n}$ Boolean functions of $n$ bits), and it does not say that gradient descent finds the weights or that the fit generalises.

**Example.** A battery's state of charge (SoC, in %) is $0$ at $3.0$ V, $30\%$ at $3.5$ V and $100\%$ at $4.0$ V, interpolated linearly. Write it as a one-hidden-layer ReLU network on $[3.0,4.0]$ V, count its parameters, and evaluate it at $3.5$, $3.8$ and $4.0$ V.

**Solution.** The slopes are $s_0=(30-0)/(3.5-3.0)=60$ and $s_1=(100-30)/(4.0-3.5)=140$ %/V. The first piece is $60\max(0,V-3.0)$; at the kink $3.5$ V the slope grows by $c_1=s_1-s_0=80$, so with $m=1$ interior kink $\mathrm{SoC}(V)=60\max(0,V-3.0)+80\max(0,V-3.5)$. The parameter count is $2+2+2+1=7$ (two input weights, two biases, two output weights, one output bias). Evaluation: $60\cdot0.5=30\%$ at $3.5$ V, $60\cdot0.8+80\cdot0.3=48+24=72\%$ at $3.8$ V, and $60\cdot1.0+80\cdot0.5=100\%$ at $4.0$ V.

### Depth: folding and counting linear regions

Width and depth are not interchangeable. In one input dimension, a hidden layer of $n$ ReLU units produces at most $n+1$ linear pieces, because each unit contributes one kink. Now compose. The **tent map** $T(x)=2\max(0,x)-4\max(0,x-\tfrac12)$ equals $2x$ on $[0,\tfrac12]$ and $2-2x$ on $[\tfrac12,1]$ (check: $2x-4(x-\tfrac12)=2-2x$): it rises from 0 to 1 and falls back, so it sends $[0,1]$ onto $[0,1]$ with two linear pieces and costs two hidden units. Composing it $l$ times gives $T^{\circ l}$.

**Proof.** Claim: $T^{\circ l}$ has exactly $2^l$ linear pieces on $[0,1]$, each mapped affinely onto $[0,1]$. For $l=1$ this is the description above. Suppose it holds for $G=T^{\circ(l-1)}$. On one of its pieces $G$ is affine and onto $[0,1]$, so it takes the crease value $\tfrac12$ at exactly one interior point, which splits the piece into two parts: on one part $G$ covers $[0,\tfrac12]$, on the other $[\tfrac12,1]$. On each part $T$ is affine and maps that half of its domain onto $[0,1]$, so $T\circ G$ is affine and onto $[0,1]$ on each part. Every one of the $2^{l-1}$ pieces becomes two, giving $2^l$. $\blacksquare$

The deep network has $2l$ hidden units in $l$ layers and $2^l$ pieces. A single hidden layer needs one kink per slope change, so about $2^l$ units for the same function. Geometrically each unit folds the input space along a hyperplane, and composing folds multiplies the number of regions; Montufar et al. (2014), summarised in Goodfellow et al. §6.4.1, prove lower bounds showing that the maximal number of linear regions of a deep rectifier network grows exponentially in depth. For one hidden layer in $\mathbb R^d$ the count is bounded by the number of regions cut out by $n$ hyperplanes, $\sum_{j=0}^{d}\binom nj$, which is polynomial in $n$ for fixed $d$ (16 regions for $n=5$, $d=2$). Goodfellow et al. (eq. 6.42) write the count for deep networks as $O\big((n/d)^{d(l-1)}n^d\big)$ for $l$ layers of $n$ units. These are statements about *capacity*; whether the function you want has that compositional structure is an empirical question.

![The tent map T and its compositions. Three plots on [0, 1]: T has 2 linear pieces from 2 hidden units, T composed with itself twice has 4 pieces from 4 units, and three times has 8 pieces from 6 units. Each piece rises or falls across the full range from 0 to 1.](/lesson-figures/ML04-2.svg)

*Figure: each extra layer of two units folds every piece of the previous function in two, so pieces double while units grow by 2 (after Goodfellow et al., §6.4.1, and the sawtooth plots of Yarotsky 2017, Fig. 2a).*

The doubling needs each inner piece to *cover the crease*. Counterexample: the inner map $g(x)=0.4x$ is affine and sends $[0,1]$ onto $[0,0.4]$, which never reaches $\tfrac12$, so $T\circ g(x)=0.8x$ has one piece, not two. Depth multiplies pieces only when the layers are arranged to fold on top of each other.

**Example.** Take the tent map $T$ with $T(x)=2\max(0,x)-4\max(0,x-\tfrac12)$. Evaluate three folds at $x=0.3$, and compare the number of linear pieces and hidden units of $T^{\circ l}$ for $l=1,\dots,6$ with those of a single hidden layer.

**Solution.** Three folds at $x=0.3$: $T(0.3)=0.6$, $T(0.6)=1.2-0.4=0.8$, $T(0.8)=1.6-1.2=0.4$, so $T^{\circ3}(0.3)=0.4$. Counting slope changes of $T^{\circ l}$ on a fine grid for $l=1,\dots,6$ gives $2,4,8,16,32,64$ pieces from $2l=2,4,6,8,10,12$ hidden units. One hidden layer needs one kink per slope change: $63$ kinks plus the initial slope, i.e. $64$ units, for $64$ pieces, against $12$ units in the deep network.

### The sawtooth network for $x^2$ and its error bound

The folds give an unexpectedly small network for a *smooth* function. Let $g_s=T^{\circ s}$ (the "sawtooth": $2^s$ linear pieces, i.e. $2^{s-1}$ teeth of height $1$, with $g_s=0$ at the multiples of $2^{-(s-1)}$ and $g_s=1$ at the odd multiples of $2^{-s}$, by the proof above) and define
$$f_m(x)=x-\sum_{s=1}^m\frac{g_s(x)}{4^s},\qquad x\in[0,1].$$

**Proof.** Claim: $f_m$ is the piecewise linear interpolant of $x^2$ at the knots $k/2^m$, $k=0,\dots,2^m$, and $0\le f_m(x)-x^2\le4^{-(m+1)}$. (This is the construction of Yarotsky 2017, Proposition 2, §3.1: depth and number of weights $O(\ln1/\epsilon)$, error $2^{-2m-2}$ and $f_{m-1}-f_m=g_m/2^{2m}$; he credits the sawtooth structure of $g_s$ to Telgarsky 2015, Lemma 2.4. The counts of $3m$ units and $12m-2$ parameters below are this lesson's own.) For $m=0$, $f_0(x)=x$ interpolates $x^2$ at $0$ and $1$. Suppose the claim holds for $m-1$ and let $h=2^{-(m-1)}$. On each interval $[t,t+h]$ the interpolant $f_{m-1}$ is the chord, and the error of the chord of $x^2$ is $f_{m-1}(x)-x^2=(x-t)(t+h-x)$, which is $0$ at both ends and equal to $h^2/4=4^{-m}$ at the midpoint. The function $g_m/4^m$ is affine on each half-interval, $0$ at the knots $t$, $t+h$ and $4^{-m}$ at the midpoint. So $f_m=f_{m-1}-g_m/4^m$ is affine on each half, equals $x^2$ at $t$, $t+h$ and at the midpoint ($x^2+4^{-m}-4^{-m}$): it is the interpolant on the finer knots. The same chord formula with $h=2^{-m}$ gives $0\le f_m-x^2\le h^2/4=4^{-(m+1)}$, with equality at the midpoints. $\blacksquare$

The error therefore shrinks by a factor $4$ per added fold, i.e. two bits of accuracy per layer. As a network, state $(g_{s-1},f_{s-1})$ in layer $s$ needs three hidden units $\max(0,g_{s-1})$, $\max(0,g_{s-1}-\tfrac12)$, $\max(0,f_{s-1})$: then $g_s=2h_1-4h_2$ and $f_s=h_3-4^{-s}g_s$ are affine in the hidden outputs, and the ReLU on $f_{s-1}$ and $g_{s-1}$ is harmless because both are non-negative ($f_{s-1}\ge x^2\ge0$ and $g_{s-1}\in[0,1]$). This network has $3m$ hidden units and $12m-2$ parameters (first layer $3+3$, each further layer $3\cdot3+3$, output $3+1$), checked on an explicit network in Case 3. A shallow network on the same $2^m$ intervals needs $2^m$ units and $3\cdot2^m+1$ parameters.

| $m$ | max error $4^{-(m+1)}$ | shallow units / parameters | deep units / parameters |
|---|---|---|---|
| 2 | 0.015625 | 4 / 13 | 6 / 22 |
| 4 | 0.000977 | 16 / 49 | 12 / 46 |
| 6 | 0.0000610 | 64 / 193 | 18 / 70 |
| 10 | $2.4\times10^{-7}$ | 1024 / 3073 | 30 / 118 |

The deep network wins only asymptotically: at $m=2$ the shallow one is smaller. Three limits are worth stating. The bound is for the domain $[0,1]$: outside it $T$ is no longer a fold ($T(1.5)=-1$) and $f_2(1.5)=1.75$ while $1.5^2=2.25$. The weights are special; the theorem says nothing about whether gradient descent from a random start would find them, and the narrow, oscillating functions $g_s$ are notoriously hard to learn. And the saving is for one specific, very smooth function. For generic functions of $d$ variables with $s$ bounded derivatives the number of weights still grows like a power of $1/\epsilon$, namely $\epsilon^{-d/s}$ up to a logarithm (Yarotsky 2017, Theorem 1; the lower bound $\epsilon^{-d/(2s)}$ is Theorem 4a), so depth does not remove the dependence on the dimension.

### Initialisation and signal propagation

Initialisation decides whether the first gradient step has anything to work with (d2l.ai §5.4). Consider layer $l$ with fan-in $n$: $z_j=\sum_{i=1}^nw_{ji}a_i$ and $a'_j=\max(0,z_j)$, biases set to $0$. Let $q=\mathbb E[\|a\|^2]/n$ be the mean second moment of the incoming activations.

**Proof.** *Assumptions.* (A1) The weights $w_{ji}$ of this layer are drawn independently of each other and of $a$, with mean $0$, variance $\sigma_w^2$ and a symmetric distribution (Gaussian, or uniform on $[-c,c]$). (A2) The biases are $0$. *Forward second moment.* Condition on $a$. By (A1), $\mathbb E[w_{ji}w_{jk}]=\sigma_w^2\delta_{ik}$ (independence and mean $0$ for $i\ne k$), so
$$\mathbb E[z_j^2\mid a]=\sum_{i,k}\mathbb E[w_{ji}w_{jk}]\,a_ia_k=\sigma_w^2\|a\|^2,\qquad \mathbb E[z_j^2]=n\sigma_w^2\,q.$$
Because $\mathbb E[z_j]=0$ this is also $\operatorname{Var}(z_j)$. Note what was *not* used: the $a_i$ may be correlated and need not have zero mean. *The ReLU step.* Given $a$, $z_j$ is symmetric about $0$ (the weights are, by (A1)), so $\mathbb E[z_j^21[z_j>0]\mid a]=\mathbb E[z_j^21[z_j<0]\mid a]$, and these add up to $\mathbb E[z_j^2\mid a]$. Hence $\mathbb E[\max(0,z_j)^2]=\tfrac12\mathbb E[z_j^2]$. *Recursion.* With $k=n\sigma_w^2$, the second moment of the next layer is $q'=\tfrac k2\,q$, so after $l$ such layers $q_l=(k/2)^l\,q_0$. $\blacksquare$

The product is constant only for $k=2$, i.e. $\sigma_w^2=2/n$ (the "He" rule; He et al. 2015, §2.2, Eq. (10)). For a linear or identity layer there is no halving and $\sigma_w^2=1/n$ is right. Xavier initialisation, $\sigma_w^2=2/(n_{\text{in}}+n_{\text{out}})$, is a compromise between preserving forward variance ($1/n_{\text{in}}$) and backward variance ($1/n_{\text{out}}$) (d2l.ai §5.4.2.2). Initialising all weights to the same value is never acceptable: units in the same layer then compute identical functions and receive identical gradients forever (the symmetry problem of d2l.ai §5.4.1.3), so random initialisation is what breaks the tie.

*The failing cases, computed.* Width 256, batch 512, 30 ReLU layers, Gaussian weights, inputs $\mathcal N(0,1)$ ($q_0=1$): $k=1$ gives $q_{30}=5.9\times10^{-10}$ (prediction $2^{-30}=9.3\times10^{-10}$), $k=4$ gives $6.8\times10^{8}$ (prediction $2^{30}=1.07\times10^9$), and $k=2$ gives $0.63$. The He value is "$1$" only in expectation: each layer's factor is random with mean about $1$, so seeds 0 to 7 gave $q_{30}$ between $0.18$ and $4.4$. With half-precision floats the exponents matter: at $k=1$ the root-mean-square activation is $2^{-l/2}$ and reaches float16's smallest normal number ($2^{-14}\approx6.1\times10^{-5}$) at $l=28$, where precision starts to degrade (subnormal numbers continue down to about $6\times10^{-8}$, around $l=48$); at $k=4$ it is $2^{l/2}$ and reaches float16's largest value (65504) at $l=32$, but individual activations, larger than the RMS, overflow earlier. The recursion also fails when (A1) or (A2) fails: with a bias the pre-activation is not symmetric. For $z\sim\mathcal N(1,1)$, $\mathbb E[\max(0,z)^2]=(\mu^2+\sigma^2)\Phi(\mu/\sigma)+\mu\sigma\varphi(\mu/\sigma)=1.925$ ($\Phi$ and $\varphi$ are the standard normal distribution function and density; the formula follows by integrating $z^2$ against the Gaussian over $z>0$), not $\tfrac12\mathbb E[z^2]=1$.

**Example.** A 12-layer ReLU network of width 512 is initialised with $\sigma_w^2=1/n$ ($k=1$). By what factor does the second moment change between input and output, what is the output size in RMS relative to the input, and what changes with $\sigma_w^2=2/n$?

**Solution.** Each ReLU layer multiplies the second moment by $k/2$. With $k=1$ the factor per layer is $1/2$, so after 12 layers it is $2^{-12}=2.4\times10^{-4}$. The RMS is the square root, $2^{-6}=1/64$ of the input size before any training. With $\sigma_w^2=2/n$ ($k=2$) the factor per layer is $1$ and the input size is kept. The recursions describe the first step, not training: after training the weights are correlated with the activations and (A1) no longer holds.

### Four views: a ReLU layer cuts the input space

**Algebra.** A unit computes $a_j=\max(0,w_j^\top x+b_j)$. Collect the on/off pattern in $s\in\{0,1\}^h$ and set $D_s=\operatorname{diag}(s)$. Inside the region where the pattern is $s$ the layer is affine, $a=D_s(Wx+b)$, so a network with output weights $v$ computes $f(x)=v^\top D_s(Wx+b)=(W^\top D_sv)^\top x+v^\top D_sb$: gradient $W^\top D_sv$, offset $v^\top D_sb$.

**Geometry.** Each unit has a crease, the line $w_j^\top x+b_j=0$ in the input plane, with $w_j$ perpendicular to it. The graph $z=f(x_1,x_2)$ is a sheet made of flat polygons that meet along the creases. The figure in the Intuition section shows a layer acting on the plane (the half-plane behind each crease is flattened onto the crease), and the 3D block below shows the surface of the network of Case 1.

**Code.**
```python
import numpy as np
W = np.array([[1., -1.], [2., 0.]]); b = np.array([0., 1.]); v = np.array([2., -1.])
f = lambda x: v @ np.maximum(0, W @ x + b)

def local_plane(x):                       # pattern, gradient and offset of the flat piece at x
    s = (W @ x + b > 0).astype(float)     # on/off pattern in {0,1}^h
    return s, W.T @ (s * v), float(v @ (s * b))  # f(x') = grad @ x' + offset inside this cell

print(local_plane(np.array([1., 2.])), f(np.array([1., 2.])))   # (array([0., 1.]), array([-2.,  0.]), -1.0) -3.0
```

**Physical meaning.** A hidden unit is a threshold switch on a weighted sum of measurements: "contact if the weighted force exceeds a limit", "saturated if the command exceeds the actuator range". $w_j$ has the units of (unit output)/(unit input), $b_j$ the units of $z$, and the crease is the set of inputs at which the switch flips. The network is then a different linear law in each switch state.

**Example.** The code above defines a two-unit network with $W=\begin{pmatrix}1&-1\\2&0\end{pmatrix}$, $b=(0,1)$ and $v=(2,-1)$. Find the pre-activations, the value $f$ and the local plane at $x=(0,-1)$, and the local plane at $x=(1,2)$.

**Solution.** At $x=(0,-1)$: $Wx+b=(0+1,\,0)+(0,1)=(1,1)$, so $z=(1,1)$, both units are on and $f=2\cdot1-1\cdot1=1$. The local plane from the code has gradient $W^\top(s\odot v)=W^\top(2,-1)=(0,-2)$ and offset $v^\top(s\odot b)=-1$, so $f=-2x_2-1$, and $-2(-1)-1=1$ agrees. At $x=(1,2)$: $Wx+b=(-1,2)+(0,1)=(-1,3)$, only unit 2 is on, $s=(0,1)$, gradient $W^\top(0,-1)=(-2,0)$, offset $-1$, so the plane is $f=-2x_1-1$ (value $-3$, as printed by the code).

At the defaults the network of Case 1 has four flat pieces: $f=-2x_2-1$ where both units are on, $2(x_1-x_2)$ where only unit 1 is on, $-2x_1-1$ where only unit 2 is on and $0$ where both are off. The rose point is $x=(1,2)$, where $f=-3$; the third readout shows the same number.

### Four views: depth multiplies the regions

**Algebra.** $g_s=T\circ g_{s-1}$ with $T(t)=2\max(0,t)-4\max(0,t-\tfrac12)$, $g_0(x)=x$, and $f_m=x-\sum_{s\le m}4^{-s}g_s$. The pieces of $g_s$ number $2^s$ and $\max_{[0,1]}(f_m-x^2)=4^{-(m+1)}$.

**Geometry.** Each application of $T$ folds $[0,1]$ in half, so the graph of $g_s$ is a sawtooth with $2^s$ linear pieces ($2^{s-1}$ teeth) (figure above); $f_m$ is the chord polygon of the parabola on $2^m$ equal intervals, and the next fold lifts every midpoint onto the parabola.

**Code.**
```python
import numpy as np
T = lambda t: 2 * np.maximum(0, t) - 4 * np.maximum(0, t - 0.5)

def f_m(x, m):
    g, f = x, x.copy()
    for s in range(1, m + 1):
        g = T(g)              # one more fold: 2^s linear pieces
        f = f - g / 4**s      # each fold adds two bits of accuracy to x^2
    return f

x = np.linspace(0, 1, 100001)
print([round(float(np.max(f_m(x, m) - x**2)), 8) for m in (1, 2, 3, 4)])   # [0.0625, 0.015625, 0.00390625, 0.00097656]
```

**Physical meaning.** A fold reuses one computation on a smaller scale, like a successive-approximation converter that resolves one more bit per step: ten layers (30 units) give $4^{-11}=2^{-22}$ accuracy for squaring, about the precision of a 22-bit number, with 118 weights. In a robot this is the reason a deep policy can compute a very oscillatory function such as a high-frequency gait phase cheaply, but only if training finds the folds.

**Example.** For the sawtooth construction of $x^2$, take the point $x=0.6$. Compute $g_1,g_2,g_3$ and $f_1,f_2,f_3$, and compare the errors with the bounds $4^{-(m+1)}$.

**Solution.** The folds are $g_1=T(0.6)=0.8$, $g_2=T(0.8)=0.4$, $g_3=T(0.4)=0.8$. With $f_m=f_{m-1}-g_m/4^m$ and $f_0=x$: $f_1=0.6-0.8/4=0.4$, $f_2=0.4-0.4/16=0.375$, $f_3=0.375-0.8/64=0.3625$, against $x^2=0.36$. The errors $0.04$, $0.015$ and $0.0025$ stay below the bounds $4^{-2}=0.0625$, $4^{-3}=0.015625$ and $4^{-4}=0.0039$.

### Four views: the initialisation scale

**Algebra.** $q_l=\big(\tfrac{n\sigma_w^2}2\big)^lq_0$ for ReLU, so $\log_{10}q_l=l\log_{10}(k/2)+\log_{10}q_0$ with $k=n\sigma_w^2$.

**Geometry.** On a log scale the second moment is a straight line in the layer index with slope $\log_{10}(k/2)$: flat only for $k=2$, downhill for $k<2$, uphill for $k>2$ (the figure above and the second slider block).

**Code.**
```python
import numpy as np

def second_moment(k, n=256, batch=512, layers=30, seed=0):
    rng = np.random.default_rng(seed)
    a = rng.standard_normal((batch, n))
    for _ in range(layers):
        W = rng.standard_normal((n, n)) * np.sqrt(k / n)    # k = n * sigma_w^2
        a = np.maximum(0.0, a @ W.T)
    return np.mean(a**2)

print([f"{second_moment(k):.2e}" for k in (1, 2, 4)])        # ['5.88e-10', '6.32e-01', '6.78e+08']
```

**Physical meaning.** The second moment is the energy of the signal travelling through the layers, measured in squared units of the input (volts$^2$, metres$^2$...). A wrong scale makes that energy fall into the noise floor of the number format, or overflow it, before the loss can even be computed: float16 starts to lose precision from layer 28 at $k=1$ and overflows from about layer 32 at $k=4$, individual values earlier (computed above), and the backward signal follows the same law with $n_{\text{out}}$ in place of $n_{\text{in}}$.

**Example.** In the run above the second moment after 30 layers is $q_{30}=5.9\times10^{-10}$ for $k=1$ and $0.63$ for $k=2$. By what factor does it change, and how does that compare with the change in $\sigma_w$?

**Solution.** The ratio is $0.63/(5.9\times10^{-10})\approx1.07\times10^{9}$, a factor of about $10^{9}$. The standard deviation $\sigma_w$ differs only by $\sqrt2=1.41$ between the two cases. A small constant error per layer becomes an enormous one after many layers, since it is raised to the power of the depth.

### Where these results stop being true, and links to neighbouring topics

Each result above has a boundary. The collapse of stacked linear layers holds only if *every* layer is affine; a single saturated or clipped unit is enough to break it, and a network whose hidden units are all dead (ReLU with $z<0$ on every training input) behaves like a constant. Exact CPWL representation is a statement about one input dimension; in $d$ dimensions the regions are cells of hyperplane arrangements and the number of units needed to match a given function can grow quickly. The $4^{-(m+1)}$ bound holds on $[0,1]$ for $x^2$ only. Counting regions bounds *capacity*, not what training finds: gradient descent from a small random initialisation typically finds functions with far fewer effective pieces than the maximum, which is one reason deep networks can generalise despite their capacity (Zhang et al., d2l.ai §5.5, generalisation in deep learning). Finally, the second-moment recursion of the initialisation section needs fresh, symmetric, zero-mean weights independent of the incoming activations and zero biases; the incoming activations need not be independent or zero-mean, but the weights must be independent of them, zero-mean and symmetric. Skip connections add a second term, normalisation layers rescale, and trained weights correlate with the data, so the constants change.

**Example.** A unit $\max(0,2x-3)$ acts on a sensor input $x\in[0,1]$. What is its output and gradient over the data, and can training revive it?

**Solution.** For $x\in[0,1]$ the pre-activation is $z=2x-3\in[-3,-1]$, negative for every sample. The output is therefore $0$ everywhere and the gradient is $0$ as well, so no training step on those data can change its weights. Only the other units, the bias of the output layer, or a re-initialisation can bring it back.

Three links to the rest of CoreLab keep the picture honest. First, a network with a *linear* output layer and no hidden layer is exactly the linear regression of ML02, so the hidden layers can be read as learned features feeding that regression; comparing against the linear baseline is therefore a fair diagnostic. Second, the output layer and loss must be chosen together: a real-valued target (a torque in N$\cdot$m) wants a linear output with squared error and standardised targets, a probability wants a sigmoid or softmax output with cross-entropy, and a sigmoid output cannot represent a value outside $(0,1)$ whatever the hidden layers do. Third, everything here concerns the forward map; the derivatives of the loss with respect to $W$ and $b$ are the subject of the next lesson on backpropagation (ML05), and the activation derivatives in the table above are exactly the local factors that backpropagation multiplies, which is why the sigmoid's maximum slope of $\tfrac14$ matters for deep networks.

## Worked example

### Case 1: a two-layer ReLU forward pass

**Problem.** A network has two inputs, two hidden ReLU units and one linear output. The hidden layer has $W=\begin{pmatrix}1&-1\\2&0\end{pmatrix}$, $b=(0,1)$; the output layer has weights $v=(2,-1)$ and bias $0$. Compute the hidden pre-activations $z$, the activations $a$ and the output $\hat y$ for $x=(1,2)$, and count the parameters.

**Solution.**

1. *Shapes.* $W$ is $2\times2$ and $x$ has 2 entries, so $z=Wx+b$ has 2 entries (Theory, "Conventions").
2. *Pre-activations.* $z_1=1\cdot1+(-1)\cdot2+0=-1$ and $z_2=2\cdot1+0\cdot2+1=3$, so $z=(-1,3)$.
3. *Activation.* ReLU keeps positive entries: $a=(\max(0,-1),\max(0,3))=(0,3)$. Unit 1 is off, unit 2 is on.
4. *Output.* $\hat y=v^\top a+0=2\cdot0+(-1)\cdot3=-3$.
5. *Parameters.* The hidden layer has $2\cdot2+2=6$ (not 4: the biases count) and the output layer $2+1=3$, so $9$ in all.

**Check.** The on/off pattern is $s=(0,1)$, so the network is affine near $x$ with $f=(W^\top D_sv)^\top x+v^\top D_sb=(-2,0)\cdot x-1$, and $-2\cdot1-1=-3$ (Four views code). The 3D block above shows this point on the surface.

**Takeaway.** One forward pass is two matrix-vector products and one elementwise ReLU; the only nonlinear step decided that unit 1 contributes nothing at this input.

### Case 2: building a network for $x^2$ and checking the error bound

**Problem.** Approximate $f(x)=x^2$ on $[0,1]$ with a one-hidden-layer ReLU network by interpolation at the knots $0,\,0.25,\,0.5,\,0.75,\,1$ (so $h=0.25$). Find the weights, the parameter count, the value at $x=0.6$ and the largest error, and compare with the bound $\tfrac{h^2}{8}\max|f''|$.

**Solution.**

1. *Chord slopes.* Between knots $t_j$ and $t_{j+1}$ the slope is $s_j=(t_{j+1}^2-t_j^2)/h=t_j+t_{j+1}$, i.e. $0.25,\ 0.75,\ 1.25,\ 1.75$.
2. *Slope changes.* By the representation formula the output weights are $c_j=s_j-s_{j-1}$ and $s_0$ for the first unit: $c=(0.25,\ 0.5,\ 0.5,\ 0.5)$.
3. *Network.* Hidden units $\max(0,x),\ \max(0,x-0.25),\ \max(0,x-0.5),\ \max(0,x-0.75)$: hidden weights all $1$, hidden biases $0,-0.25,-0.5,-0.75$, output weights $c$, output bias $f(0)=0$.
4. *Parameters.* $4+4$ in the hidden layer, $4+1$ in the output layer: $13$ in all (the output bias is a parameter even though it equals $0$).
5. *Value at $x=0.6$.* Units 1 to 3 are on (0.6, 0.35, 0.1) and unit 4 is off: $0.25(0.6)+0.5(0.35)+0.5(0.1)=0.15+0.175+0.05=0.375$, against $0.36$, an error of $0.015$.
6. *Largest error.* On one interval the chord lies above the parabola by $(x-t)(t+h-x)$, largest at the midpoint, $h^2/4=0.015625$, and the bound $\tfrac{h^2}{8}\cdot2=\tfrac{0.0625}8\cdot2=0.015625$ is attained because $f''\equiv2$.

**Check.** A grid of $10^5$ points on $[0,1]$ gives a maximum of $f_{\text{net}}-x^2$ of $0.015625$ and a minimum of $0$, so the network is a slight overestimate everywhere ($x^2$ is convex, the chords lie above it). To halve the error ($\propto h^2$) the spacing must shrink by $\sqrt2$, i.e. $\sqrt2$ times as many units.

**Takeaway.** Any CPWL function is a weighted sum of ReLU ramps, and the weights are just slope changes; for a smooth function the error is controlled by the knot spacing.

### Case 3: the same function from a deep network

**Problem.** Build the function $f_2$ of Case 2 (the interpolant of $x^2$ with knots every $0.25$) with the sawtooth network $f_2=x-g_1/4-g_2/16$ and evaluate it at $x=0.6$; then add one more fold ($m=3$) and compare the error with the bound $4^{-(m+1)}$. Count units and parameters.

**Solution.**

1. *Layer 1.* The state is $(g_0,f_0)=(0.6,0.6)$. The hidden units are $\max(0,0.6)=0.6$, $\max(0,0.6-0.5)=0.1$ and $\max(0,0.6)=0.6$.
2. *Fold.* $g_1=2\cdot0.6-4\cdot0.1=0.8$ and $f_1=0.6-g_1/4=0.6-0.2=0.4$.
3. *Layer 2.* The hidden units are $\max(0,0.8)=0.8$, $\max(0,0.8-0.5)=0.3$ and $\max(0,f_1)=0.4$. Then $g_2=2\cdot0.8-4\cdot0.3=0.4$ and $f_2=0.4-g_2/16=0.4-0.025=0.375$, the same number as Case 2.
4. *One more fold.* $g_3=T(0.4)=0.8$ and $f_3=0.375-0.8/64=0.3625$, against $x^2=0.36$: error $0.0025\le4^{-4}=0.0039$.
5. *Size.* For $m=2$: $3m=6$ hidden units and $12m-2=22$ parameters (Theory, sawtooth subsection), against $4$ units and $13$ parameters in Case 2.

**Check.** Running the Four views code gives $f_2$ with maximum error $0.015625$ and $f_3$ with $0.00390625$ on a grid of $10^5$ points, and a direct forward pass through the explicit 3-units-per-layer weights agrees with $x-g_1/4-g_2/16$ to $10^{-16}$ at $x=0.6$.

**Takeaway.** Depth and width build the same piecewise linear function by different routes; the deep route costs more at 4 pieces but is cheaper from $m=4$ on, and each added fold gains a factor $4$ in accuracy.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

The core algorithm, written without any machine-learning library: He initialisation, the forward pass, the backward pass derived by hand (the chain rule through the linear output layer, the weights, and the 0/1 slope of each ReLU), and five tests. The tests compare against the lesson's worked example, a closed-form gradient, central finite differences on a random 3-layer network, the signal-propagation theory, and a small fit of $x^2$. Rows are samples, so $Z=AW^\top+b$ as in the batch form of the theory.

```python
import numpy as np


def he_init(sizes, rng):
    """Weights ~ N(0, 2/fan_in), biases 0. W[l] has shape (n_l, n_{l-1})."""
    return [(rng.standard_normal((n, m)) * np.sqrt(2.0 / m), np.zeros(n))
            for m, n in zip(sizes[:-1], sizes[1:])]


def forward(params, X):
    """X has shape (batch, d). ReLU on every layer except the last. Returns output and cache."""
    cache, A = [X], X
    for l, (W, b) in enumerate(params):
        Z = A @ W.T + b                       # (batch, n_l): the lesson's z = W x + b, row-wise
        A = Z if l == len(params) - 1 else np.maximum(0.0, Z)
        cache.append(Z)
        cache.append(A)
    return A, cache


def backward(params, cache, Y):
    """Gradients of L = (1/2m) * sum ||yhat - y||^2, written out layer by layer."""
    m = Y.shape[0]
    delta = (cache[-1] - Y) / m               # dL/dZ_last (the output layer is linear)
    grads = []
    for l in reversed(range(len(params))):
        A_prev = cache[2 * l]                 # input of layer l
        W, _ = params[l]
        grads.append((delta.T @ A_prev, delta.sum(axis=0)))   # dL/dW, dL/db
        if l > 0:
            Z_prev = cache[2 * l - 1]
            delta = (delta @ W) * (Z_prev > 0)  # chain rule through W, then ReLU's 0/1 slope
    return grads[::-1]


def loss(params, X, Y):
    return 0.5 * np.sum((forward(params, X)[0] - Y) ** 2) / X.shape[0]


# ---- tests -----------------------------------------------------------------
# 1. the lesson's worked example: z = (-1, 3), a = (0, 3), output -3
P = [(np.array([[1., -1.], [2., 0.]]), np.array([0., 1.])), (np.array([[2., -1.]]), np.array([0.]))]
x = np.array([[1., 2.]])
out, cache = forward(P, x)
assert np.allclose(cache[1], [[-1, 3]]) and np.allclose(cache[2], [[0, 3]]) and np.allclose(out, [[-3]])

# 2. closed-form gradient of that network for target y = 0: e = -3, delta = e*v*[z>0] = (0, 3)
(gW1, gb1), (gW2, gb2) = backward(P, cache, np.array([[0.]]))
assert np.allclose(gW1, [[0, 0], [3, 6]]) and np.allclose(gb1, [0, 3])
assert np.allclose(gW2, [[0, -9]]) and np.allclose(gb2, [-3])

# 3. central finite differences on a random 3-layer network (batch of 5)
rng = np.random.default_rng(1)
Q = he_init([3, 6, 4, 2], rng)
Q = [(W, b + 0.1 * rng.standard_normal(b.shape)) for W, b in Q]   # non-zero biases
X, Y = rng.standard_normal((5, 3)), rng.standard_normal((5, 2))
G = backward(Q, forward(Q, X)[1], Y)
worst = 0.0
for l, (W, b) in enumerate(Q):
    for arr, g in ((W, G[l][0]), (b, G[l][1])):
        for idx in np.ndindex(arr.shape):
            old = arr[idx]
            arr[idx] = old + 1e-6; lp = loss(Q, X, Y)
            arr[idx] = old - 1e-6; lm = loss(Q, X, Y)
            arr[idx] = old
            worst = max(worst, abs(g[idx] - (lp - lm) / 2e-6))
assert worst < 1e-8, worst

# 4. He initialisation (variance 2/fan_in) keeps the second moment near 1 over 30 layers;
#    the too-small scale 1/fan_in lets it vanish, as the theory predicts (2^-30 ~ 1e-9)
def second_moment_30(var_scale, seed=0):
    rng = np.random.default_rng(seed)
    deep = he_init([256] * 31, rng)
    A = rng.standard_normal((512, 256))
    for W, b in deep:
        A = np.maximum(0.0, A @ (W * np.sqrt(var_scale)).T + b)
    return np.mean(A ** 2)
q_he, q_small = second_moment_30(1.0), second_moment_30(0.5)
assert 0.3 < q_he < 3 and q_small < 1e-8, (q_he, q_small)

# 5. training: fitting y = x^2 on [0, 1] with 16 hidden units reaches a mean squared error below 1e-4
rng = np.random.default_rng(2)
Xt = np.linspace(0, 1, 64)[:, None]; Yt = Xt ** 2
net = he_init([1, 16, 1], rng)
for _ in range(20000):
    g = backward(net, forward(net, Xt)[1], Yt)
    net = [(W - 0.1 * gW, b - 0.1 * gb) for (W, b), (gW, gb) in zip(net, g)]
mse = 2 * loss(net, Xt, Yt)
assert mse < 1e-4, mse
print(f"finite-difference worst error {worst:.1e}; second moment after 30 layers {q_he:.3f} (He) and {q_small:.1e} (half scale); fit MSE {mse:.2e}")
print("all tests passed")
```

### What the library does differently

The same network in PyTorch (`nn.Linear`, `torch.relu`, `loss.backward()`), run in float64 on the random network of test 3, gives gradients that agree with the hand-written ones to $5.6\times10^{-17}$ and the same loss to all printed digits. The differences are elsewhere:

- *Automatic differentiation.* `backward()` records the operations of the forward pass and differentiates any composition; the hand-written `backward` above works for exactly one architecture and must be rewritten when the architecture changes. Finite differences remain the independent test, with a step near $10^{-6}$ in float64 but about $10^{-3}$ in float32.
- *Initialisation defaults.* `nn.Linear` does not use He: its weights are uniform on $\pm1/\sqrt{\text{fan-in}}$ (variance $1/(3\,\text{fan-in})$, i.e. $k=1/3$ in the notation of the theory) and its biases are uniform and non-zero, not $0$ (measured on a $256\to256$ layer: weight variance $0.001295$, against $1/(3\cdot256)=0.001302$). With ReLU this loses signal at every layer unless `nn.init.kaiming_normal_` is called or normalisation layers follow.
- *Fused and batched kernels.* A linear layer is one fused matrix-multiply-and-add running on optimised BLAS or GPU kernels, and the activation memory needed for the backward pass is managed by the framework; the NumPy version allocates a new array for every step.
- *Numerically stable losses.* Classification losses are computed from logits with the log-sum-exp trick (`F.cross_entropy`, `BCEWithLogitsLoss`) and never as "softmax, then log"; the squared error used here has no such issue.
- *Edge cases.* The slope of ReLU at exactly $z=0$ is a convention: PyTorch returns $0$, as `Z > 0` does above. Default dtype is float32, so the second-moment test above would show float32 rounding, and half precision hits the limits computed in the theory section.

## Failure modes

Dead ReLU units: if $z<0$ on every training input the unit outputs $0$ and receives zero gradient, so it never recovers. A wrong initial scale: with $k=n\sigma_w^2\neq2$ the second moment of the activations shrinks or grows like $(k/2)^l$ (about $10^{-10}$ after 30 layers at $k=1$). Shape conventions: $W$ stored as $(d,h)$ instead of $(h,d)$, or samples in rows versus columns, runs silently when $d=h$ and computes the wrong product. A sigmoid or ReLU output on a regression target outside its range (a temperature of $50$) cannot be fitted whatever the hidden layers do. Non-zero biases break the factor $\tfrac12$ of the variance recursion, and equal initial weights keep units identical forever. More layers are not automatically better, and a forward pass alone does not demonstrate learning.

## Alternatives and trade-offs

The linear regression of ML02 is the transparent baseline: if the network does not beat it on a held-out split, the hidden layers add nothing. ReLU networks give piecewise linear functions with a discontinuous Jacobian; softplus or tanh give smooth ones at the price of saturation and cost. Sigmoid or softmax outputs suit probabilities, a linear output suits real targets. Depth buys exponentially many pieces only for compositional structure (the sawtooth example), while width costs units linearly in the number of pieces; for small tabular data, trees or kernel methods may be simpler. Choose the architecture from the task and the evidence, not from the parameter count alone.
