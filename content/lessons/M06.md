## Why this matters

Describe sensitivity when inputs or outputs have several coordinates. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A gradient collects the sensitivities of one scalar output to many inputs. A Jacobian collects the sensitivities of many outputs to many inputs. The distinction prevents shape mistakes in backpropagation and tells you how a small joint change moves a robot endpoint.

![Level curves of x squared plus 2 y squared with the gradient and steepest descent arrows at (1,1), and a Jacobian drawn as a matrix with one row per output and one column per input.](/lesson-figures/M06.svg)

*The gradient is perpendicular to level curves; a Jacobian is the local linear map with one row per output.*

## Theory and derivation

For $f:\mathbb R^n\to\mathbb R$, define the column gradient $\nabla f=[\partial f/\partial x_1,\ldots,\partial f/\partial x_n]^T$. Locally, $f(x+\delta)\approx f(x)+\nabla f(x)^T\delta$. The directional derivative along unit $u$ is $\nabla f^Tu$; Cauchy–Schwarz makes $-\nabla f/\|\nabla f\|$ the steepest unit descent direction.

For $g:\mathbb R^n\to\mathbb R^m$, $J_{ij}=\partial g_i/\partial x_j$, hence $J$ is $m\times n$ and $g(x+\delta)\approx g(x)+J\delta$. If $h=f\circ g$ is scalar, then $\nabla_xh=J_g^T\nabla_g f$. The transpose is dictated by dimensions.

For $g(x,y)=(x^2+y,xy)$, differentiating each output gives $J=[[2x,1],[y,x]]$. This matrix depends on the evaluation point. A Jacobian is a local map, not a global replacement for the nonlinear function.

## Worked example

At (x,y)=(2,3), J=[[4,1],[3,2]]. A change δ=(0.01,−0.02) predicts Δg=(0.02,−0.01). Direct evaluation gives g(2.01,2.98)−g(2,3)=(0.0201,−0.0102); the remaining terms are second order.

Paste this below the starter code (same file) and run it. Every check is a plain `assert`; the first failure stops the run.

```python
import random
def close(a, b, t=1e-6): return all(abs(x - y) < t for x, y in zip(a, b))
assert close(fk((0, math.pi / 2)), (1, 1))
J = jacobian_analytic((0, math.pi / 2))
assert close(J[0], (-1, -1)) and close(J[1], (1, 0))
# Jacobian of a map R^3 -> R^2 must be 2 x 3: g(x) = (x0*x1, x1 + x2^2) at (1,2,3)
Jn = numeric_jacobian(lambda x: [x[0] * x[1], x[1] + x[2] ** 2], [1.0, 2.0, 3.0])
assert len(Jn) == 2 and all(len(r) == 3 for r in Jn)
assert close(Jn[0], (2, 1, 0), 1e-5) and close(Jn[1], (0, 1, 6), 1e-5)
# numeric and analytic Jacobians agree; J dq predicts the tip motion
random.seed(3)
for _ in range(50):
    q = [random.uniform(-3, 3), random.uniform(-3, 3)]
    Ja = jacobian_analytic(q); Jf = numeric_jacobian(lambda z: list(fk(z)), q)
    assert all(close(a, b, 1e-6) for a, b in zip(Ja, Jf))
    dq = (1e-5, -2e-5); p0, p1 = fk(q), fk((q[0] + dq[0], q[1] + dq[1]))
    pred = (Ja[0][0] * dq[0] + Ja[0][1] * dq[1], Ja[1][0] * dq[0] + Ja[1][1] * dq[1])
    assert close((p1[0] - p0[0], p1[1] - p0[1]), pred, 1e-9)

q = newton_ik((1.2, 0.8), (0.2, 1.0))

try: newton_ik((1, 1), (0, 0)); raise SystemExit("singular start accepted")
except ValueError: pass
print("IK solution q =", tuple(round(v, 4) for v in q), "-> tip", tuple(round(v, 6) for v in fk(q)))
```

## Failure modes

A partial derivative holds other independent inputs fixed; it does not freeze intermediate variables that depend on the differentiated input. State whether gradients are rows or columns and use that convention consistently.

## Alternatives and trade-offs

A full Jacobian is easy to inspect for small problems. Jacobian-vector and vector-Jacobian products avoid constructing a large matrix when only directional sensitivities or a scalar loss gradient are needed.

## Exercise answers

1. $f_x=2x+3y=8$, $f_y=3x+4y=11$. Linear prediction: $f(1,2)=1+6+8=15$, so $15+8(0.01)+11(-0.02)=14.86$. Exact $14.8603$. The omitted second-order terms are $\tfrac12(f_{xx}\delta_x^2+2f_{xy}\delta_x\delta_y+f_{yy}\delta_y^2)\approx0.0003$.
2. (a) $2\times3$; (b) $1\times10$ (the gradient transposed); (c) $6\times6$. Row $i$ holds the partial derivatives of output $i$ with respect to every input.
3. $p=(1+0,\ 0+1)=(1,1)$. $J=\begin{pmatrix}-\sin q_1-\sin(q_1+q_2)&-\sin(q_1+q_2)\\\cos q_1+\cos(q_1+q_2)&\cos(q_1+q_2)\end{pmatrix}=\begin{pmatrix}-1&-1\\1&0\end{pmatrix}$. $J\dot q=(-0.1-0.2,\ 0.1+0)=(-0.3,\ 0.1)$ m/s.
4. $\nabla f=(2,4)$. Along $(1,0)$: $2$. Steepest descent: $-(2,4)/\sqrt{20}=(-0.447,-0.894)$, slope $-\sqrt{20}=-4.472$. The gradient is perpendicular to level curves, which are ellipses here, so descent follows the steep axis and does not point at the minimum; with non-circular contours the gradient direction is not toward the minimiser.
5. It returns $n\times m$ instead of $m\times n$. If $m=n$ the shape is still square so the code runs and yields $J^T$: velocity predictions and Newton steps are wrong without any error. Fix: `J = [[0.0]*n for _ in range(m)]` and `J[i][j] = ...`.
6. At $(2,3)$: $u=7$, $v=6$, $\nabla f=(2u,1)=(14,1)$; $J_g=\begin{pmatrix}2x&1\\y&x\end{pmatrix}=\begin{pmatrix}4&1\\3&2\end{pmatrix}$. $J_g^T\nabla f=(4\cdot14+3\cdot1,\ 1\cdot14+2\cdot1)=(59,16)$. Direct: $h_x=2(x^2+y)(2x)+y=2\cdot7\cdot4+3=59$; $h_y=2(x^2+y)+x=14+2=16$.
7. $(J_3J_2)J_1$: $1\cdot50\cdot200=10^4$ then $1\cdot200\cdot1000=2\times10^5$: total $2.1\times10^5$. $J_3(J_2J_1)$: $50\cdot200\cdot1000=10^7$ then $1\cdot50\cdot1000=5\times10^4$: about $1.0\times10^7$, nearly 48 times more. Reverse mode multiplies from the scalar output backwards (the first order): with one output and many inputs it only ever carries row vectors.
8. $\nabla f^Tu=\|\nabla f\|\cos\theta\le\|\nabla f\|$ with equality iff $\theta=0$. Along a level curve $\gamma(t)$, $f(\gamma(t))$ is constant so $\nabla f^T\gamma'=0$: the gradient is perpendicular to every tangent direction.
9. $\det J=(-\sin q_1-\sin q_{12})\cos q_{12}+\sin q_{12}(\cos q_1+\cos q_{12})=\sin q_{12}\cos q_1-\sin q_1\cos q_{12}=\sin q_2$. At $q=(0,0)$: $J=\begin{pmatrix}0&0\\2&1\end{pmatrix}$, rank 1: the arm is fully extended along $x$ and the tip cannot move along $x$ (radially). Near $q_2=0$, $J^{-1}$ has entries of order $1/\sin q_2$, so tiny desired velocities become huge joint rates.
10. A good answer has the numeric Jacobian matching the analytic one to about $10^{-8}$, convergence to $\|p-p^*\|<10^{-8}$ in a few iterations (to $q\approx(-0.177,1.531)$ in the lab), and a clear error when $|\det J|$ is below a threshold instead of a division blow-up.
