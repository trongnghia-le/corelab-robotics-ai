## Why this matters

Describe sensitivity when inputs or outputs have several coordinates. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A gradient collects the sensitivities of one scalar output to many inputs. A Jacobian collects the sensitivities of many outputs to many inputs. The distinction prevents shape mistakes in backpropagation and tells you how a small joint change moves a robot endpoint.

## Theory and derivation

For $f:\mathbb R^n\to\mathbb R$, define the column gradient $\nabla f=[\partial f/\partial x_1,\ldots,\partial f/\partial x_n]^T$. Locally, $f(x+\delta)\approx f(x)+\nabla f(x)^T\delta$. The directional derivative along unit $u$ is $\nabla f^Tu$; Cauchy–Schwarz makes $-\nabla f/\|\nabla f\|$ the steepest unit descent direction.

For $g:\mathbb R^n\to\mathbb R^m$, $J_{ij}=\partial g_i/\partial x_j$, hence $J$ is $m\times n$ and $g(x+\delta)\approx g(x)+J\delta$. If $h=f\circ g$ is scalar, then $\nabla_xh=J_g^T\nabla_g f$. The transpose is dictated by dimensions.

For $g(x,y)=(x^2+y,xy)$, differentiating each output gives $J=[[2x,1],[y,x]]$. This matrix depends on the evaluation point. A Jacobian is a local map, not a global replacement for the nonlinear function.

## Worked example

At (x,y)=(2,3), J=[[4,1],[3,2]]. A change δ=(0.01,−0.02) predicts Δg=(0.02,−0.01). Direct evaluation gives g(2.01,2.98)−g(2,3)=(0.0201,−0.0102); the remaining terms are second order.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
import numpy as np
def g(x):
    return np.array([x[0]**2+x[1], x[0]*x[1]])
x=np.array([2.,3.]); u=np.array([.6,.8]); h=1e-5
J=np.array([[4.,1.],[3.,2.]])
assert np.allclose((g(x+h*u)-g(x-h*u))/(2*h), J@u)
```

## Failure modes

A partial derivative holds other independent inputs fixed; it does not freeze intermediate variables that depend on the differentiated input. State whether gradients are rows or columns and use that convention consistently.

## Alternatives and trade-offs

A full Jacobian is easy to inspect for small problems. Jacobian-vector and vector-Jacobian products avoid constructing a large matrix when only directional sensitivities or a scalar loss gradient are needed.
