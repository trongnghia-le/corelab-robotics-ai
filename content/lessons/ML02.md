## Why this matters

Connect matrix algebra, a loss, a gradient, and an evaluation split. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A linear model is small enough to inspect end to end. It can reveal mistakes in preprocessing, optimization, and evaluation that would be harder to isolate in a deep network. “Linear” refers to the parameters; hand-designed nonlinear features can still be used.

![Left: noisy points around a fitted line with residual bars. Right: residuals of a straight-line fit to curved data showing a U-shaped pattern that signals a missing feature.](/lesson-figures/ML02.svg)

*Fit by minimising squared residuals, then look at the residuals: patterns mean the model is missing structure.*

## Theory and derivation

For $N$ row-samples, $\hat y=Xw+b\mathbf1$. With $e=\hat y-y$, define $J=(1/2N)e^Te$. Applying the chain rule gives $\nabla_wJ=X^Te/N$ and $\partial J/\partial b=\sum_i e_i/N$. The factor $1/2$ cancels the derivative of the square.

A bias can be absorbed by appending a column of ones to $X$. Ordinary least squares minimizes the same objective using a factorization-based solver. Ridge regression adds $\lambda\|w\|^2/2$, whose gradient is $\lambda w$. This penalizes large coefficients but depends on feature scaling and typically excludes the bias.

A model can fit training data well but extrapolate badly. Check residuals against input, report held-out error, and compare with a training-mean baseline. A closed-form or least-squares solution is a useful independent reference for a gradient implementation.

## Worked example

With x=[0,1], y=[1,3], w=0, b=0, errors are [−1,−3]. For N=2, gradient w is (0×−1+1×−3)/2=−1.5 and gradient b=(−1−3)/2=−2. A step of 0.1 produces w=0.15 and b=0.2. The exact fitting line is y=2x+1.

### Tests
Paste this below the starter code (same file) and run it. Every check is a plain `assert`; the first failure stops the run.

```python
import random
def close(a, b, t=1e-6): return abs(a - b) < t
X = [[0], [1]]; y = [1, 3]
gw, gb = gradients(X, y, [0.0], 0.0); assert close(gw[0], -1.5) and close(gb, -2.0)             # lesson example
w, b = gd_fit(X, y, 0.1, 1); assert close(w[0], 0.15) and close(b, 0.2)
w, b = gd_fit(X, y, 0.3, 400); assert close(w[0], 2.0) and close(b, 1.0)                      # exact line y = 2x + 1
X3 = [[1], [2], [3]]; y3 = [2, 4, 5]
gw, gb = gradients(X3, y3, [0.0], 0.0); assert close(gw[0], -25 / 3) and close(gb, -11 / 3)
w, b = solve_normal(X3, y3); assert close(w[0], 1.5) and close(b, 2 / 3)
res = [t - p for t, p in zip(y3, predict(X3, w, b))]
assert close(sum(res), 0) and close(sum(r[0] * e for r, e in zip(X3, res)), 0)               # optimality conditions
# ridge example from the exercises
gw, gb = gradients([[0], [1]], [1, 3], [1.0], 0.0, 0.5); assert close(gw[0], -0.5) and close(gb, -1.5)
wr, br = solve_normal([[1], [2]], [2, 4], 0.0); assert close(wr[0], 2.0)
# GD agrees with the closed form on random data, ridge shrinks, finite-difference gradient check
random.seed(5)
Xr = [[random.uniform(-1, 1), random.uniform(-1, 1)] for _ in range(60)]
yr = [2 * a - b + 3 + random.gauss(0, 0.05) for a, b in Xr]
wg, bg = gd_fit(Xr, yr, 0.5, 3000); ws, bs = solve_normal(Xr, yr)
assert all(close(a, c, 1e-5) for a, c in zip(wg, ws)) and close(bg, bs, 1e-5) and abs(ws[0] - 2) < 0.1
wl, _ = solve_normal(Xr, yr, 1.0); assert sum(v * v for v in wl) < sum(v * v for v in ws)
J = lambda w_, b_, lam=0.3: sum((p - t) ** 2 for p, t in zip(predict(Xr, w_, b_), yr)) / (2 * len(yr)) + lam / 2 * sum(v * v for v in w_)
g, gb = gradients(Xr, yr, [0.4, -0.2], 0.1, 0.3); h = 1e-6
assert close(g[0], (J([0.4 + h, -0.2], 0.1) - J([0.4 - h, -0.2], 0.1)) / (2 * h), 1e-6) and close(gb, (J([0.4, -0.2], 0.1 + h) - J([0.4, -0.2], 0.1 - h)) / (2 * h), 1e-6)
# unscaled features need a tiny step; standardising fixes it
Xu = [[r[0], 1000 * r[1]] for r in Xr]
wu, _ = gd_fit(Xu, yr, 0.5, 50)
assert not all(abs(v) < 1e6 for v in wu)                                                      # diverged
Xs, mu, sd = standardize_columns(Xu); ws2, _ = gd_fit(Xs, yr, 0.5, 300)
assert all(abs(v) < 10 for v in ws2)
assert all(close(sum(r[j] for r in Xs), 0, 1e-9) for j in range(2))
try: standardize_columns([[1, 2], [1, 3]]); raise SystemExit("constant column accepted")
except ValueError: pass
print("GD w,b:", [round(v, 3) for v in wg], round(bg, 3), "| closed form:", [round(v, 3) for v in ws], round(bs, 3))
print("all tests passed")
```

## Failure modes

Updating w before computing the bias gradient can mix old and new parameter states if the error is recomputed mid-step. Compute all gradients from the same parameter snapshot.

## Alternatives and trade-offs

Direct least squares is attractive for small dense problems. Gradient methods scale to large or streaming data. Ridge adds a bias toward smaller weights and can improve conditioning, but it introduces a hyperparameter to select honestly.

## Exercise answers

1. $e=(0-2,0-4,0-5)=(-2,-4,-5)$. $\nabla_wJ=(1(-2)+2(-4)+3(-5))/3=-25/3=-8.333$; $\partial J/\partial b=(-11)/3=-3.667$. Step: $w=0.4167$, $b=0.1833$.
2. $\bar x=2$, $\bar y=11/3$; $S_{xy}=(-1)(2-\tfrac{11}3)+0+(1)(5-\tfrac{11}3)=\tfrac53+\tfrac43=3$, $S_{xx}=2$, so $w=1.5$, $b=\tfrac{11}3-3=0.6667$. Fitted values $2.167,3.667,5.167$; residuals $(-0.167,0.333,-0.167)$ (as $y-\hat y$), summing to 0 and with $\sum x_ie_i=-0.167+0.667-0.5=0$. Both are the first-order conditions $\partial J/\partial b=0$ and $\partial J/\partial w=0$.
3. $X:500\times8$, $w:8$, $e:500$, $\nabla_wJ:8$. Parameters: $8+1=9$. With the ones column, $X':500\times9$ and $w':9$.
4. Curvatures $\approx E[x_1^2]=1/3$ and $E[x_2^2]\approx3.3\times10^5$. Stability needs $\alpha<2/3.3\times10^5\approx6\times10^{-6}$. At that step the $x_1$ contraction is $1-\alpha/3\approx1-2\times10^{-6}$: it effectively never learns. Fix: standardise (or rescale) features, so both curvatures are order 1 and one $\alpha$ suits both.
5. $e=(-1,-2)$; $gw=(0\cdot(-1)+1\cdot(-2))/2+0.5\cdot1=-0.5$; $gb=-1.5$. Output `1.05 0.15`. The penalty $\frac\lambda2\|w\|^2$ shrinks weights; the bias is an offset, not a sensitivity, and shrinking it would bias predictions toward zero for no variance benefit.
6. The gradient is $N=1000$ times too large, so the effective step is $\alpha N=100$; the stability limit is of order $2/\lambda\sim2$, so training diverges. Fix: divide by $N$ (use the mean gradient) or use $\alpha\approx10^{-4}$ with the sum; the first keeps $\alpha$ independent of dataset size.
7. $\nabla J=X^T(Xw-y)/N+\lambda w=0\Rightarrow(X^TX/N+\lambda I)w=X^Ty/N$. With $X^TX=5$, $X^Ty=10$, $N=2$: OLS $w=2$. Ridge: $w=10/(5+1\cdot2)=1.4286$. The penalty pulls $w$ toward 0. $X^TX$ is positive semidefinite, so adding $\lambda NI$ makes all eigenvalues at least $\lambda N>0$.
8. Line: slope $4$, intercept $-2$; fitted $(-2,2,6,10,14)$; residuals $y-\hat y=(2,-1,-2,-1,2)$: a U shape, not noise. At $x=8$ the line predicts 30 but the truth is 64. Add the $x^2$ feature (exact fit), or restrict claims to the training range.
9. A good answer proposes features such as $d$, $d^2$ (or a piecewise/low-order polynomial) or a small neural net, a held-out set with distances beyond the training range (or a range-based split), a baseline (constant or linear), residual-versus-distance plots, and refuses to extrapolate beyond the measured range.
10. A good answer shows the closed-form and GD weights matching to $\sim10^{-6}$ after convergence, ridge shrinking $\|w\|$, GD needing a much smaller $\alpha$ on unscaled features, and residuals without pattern.
