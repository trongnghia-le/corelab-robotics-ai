## Why this matters

Connect matrix algebra, a loss, a gradient, and an evaluation split. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A linear model is small enough to inspect end to end. It can reveal mistakes in preprocessing, optimization, and evaluation that would be harder to isolate in a deep network. “Linear” refers to the parameters; hand-designed nonlinear features can still be used.

![Left: noisy points around a fitted line with residual bars. Right: residuals of a straight-line fit to curved data showing a U-shaped pattern that signals a missing feature.](/lesson-figures/ML02.svg)

*Fit by minimising squared residuals, then look at the residuals: patterns mean the model is missing structure.*

Picture a cloud of points and a rigid ruler. Fitting a line means laying the ruler through the cloud so that the vertical gaps (residuals) are, in total square, as small as possible. Squaring has a physical reading: imagine each point joined to the line by a spring; the energy of a spring is proportional to the square of its stretch, and the fitted line is the position where the springs balance. At balance the pulls cancel, which is exactly the statement that residuals sum to zero and are uncorrelated with the input.

Gradient descent is a blind hiker on the bowl-shaped surface $J(w)$. The hiker feels only the local slope. If the bowl is round, the slope points at the bottom and a few steps suffice. If the bowl is a long narrow valley, as happens when two features are on very different scales or nearly duplicate each other, the slope points mostly across the valley, the hiker zig-zags between the walls, and the step must be tiny to avoid being thrown up the other side, while the progress along the valley floor is painfully slow. A robot example: regress motor current on joint speed in rad/s (values near 1) and on encoder ticks (values near 1000). The ticks column dominates the curvature, so the largest safe step is set by ticks while the speed weight crawls.

**Predict before you compute.** Take data lying exactly on $y=2x+1$ and start gradient descent from $w=0,b=0$. Before any arithmetic, say in which direction each of $w$ and $b$ will move at the first step and whether the first step can overshoot the answer. Then check with the worked example below. A second prompt: if you double the penalty $\lambda$, do you expect the fitted slope to grow or shrink, and does the intercept move?

**The common wrong intuition** is that regularisation is only a trick to stop overfitting by "making the model simpler". It is more specific than that: ridge shrinks the weights most along the directions of the data that carry the least information (small singular values), it makes the optimisation problem better conditioned, and it is a Bayesian prior. A second wrong intuition is that a good fit means a correct model: a straight line through curved data can have a small average error and still leave a systematic U-shaped residual pattern, which is the signal to add a feature rather than to tune $\lambda$.

## Theory and derivation

For $N$ row-samples, $\hat y=Xw+b\mathbf1$. With $e=\hat y-y$, define $J=(1/2N)e^Te$. Applying the chain rule gives $\nabla_wJ=X^Te/N$ and $\partial J/\partial b=\sum_i e_i/N$. The factor $1/2$ cancels the derivative of the square.

A bias can be absorbed by appending a column of ones to $X$. Ordinary least squares minimizes the same objective using a factorization-based solver. Ridge regression adds $\lambda\|w\|^2/2$, whose gradient is $\lambda w$. This penalizes large coefficients but depends on feature scaling and typically excludes the bias.

A model can fit training data well but extrapolate badly. Check residuals against input, report held-out error, and compare with a training-mean baseline. A closed-form or least-squares solution is a useful independent reference for a gradient implementation.

### Ridge as a MAP estimate, and what it does along each singular direction

The lesson adds $\lambda\|w\|^2/2$ by decree. Mathematics for Machine Learning (MML, §9.2.3) derives it. Assume Gaussian noise, $y=Xw+\varepsilon$ with $\varepsilon\sim N(0,\sigma^2I)$, and a Gaussian prior $w\sim N(0,b^2I)$. The negative log-posterior is, up to a constant (MML eq. 9.28),
$$-\log p(w\mid X,y)=\frac1{2\sigma^2}\|y-Xw\|^2+\frac1{2b^2}\|w\|^2 .$$
Multiplying by $\sigma^2$ gives $\tfrac12\|y-Xw\|^2+\tfrac12\frac{\sigma^2}{b^2}\|w\|^2$, and setting the gradient to zero yields the **MAP estimate**
$$w_{\text{MAP}}=\Big(X^TX+\frac{\sigma^2}{b^2}I\Big)^{-1}X^Ty \qquad(\text{MML eq. 9.30}).$$
So ridge with the un-normalised penalty $\lambda_u=\sigma^2/b^2$ is exactly the MAP estimate under that prior: a larger noise variance or a tighter prior means stronger shrinkage. In the lesson's normalised objective $J=\frac1{2N}\|e\|^2+\frac\lambda2\|w\|^2$ the same estimate has $\lambda_u=N\lambda$, i.e. $\lambda=\sigma^2/(Nb^2)$: with more data the prior matters less, which is the Bayesian reading of why the penalty should shrink with $N$.

To see *what* the shrinkage does, write the thin SVD $X=U\,\mathrm{diag}(s_i)\,V^T$ (Mathematics for Machine Learning, §4.5). Since $X^TX+\lambda_uI=V\,\mathrm{diag}(s_i^2+\lambda_u)V^T$,
$$w_{\text{ridge}}=\sum_i \frac{s_i}{s_i^2+\lambda_u}\,(u_i^Ty)\,v_i=\sum_i \underbrace{\frac{s_i^2}{s_i^2+\lambda_u}}_{\text{filter factor }f_i}\;\frac{u_i^Ty}{s_i}\,v_i ,$$
while OLS is the same sum with $f_i=1$. Directions with $s_i^2\gg\lambda_u$ are almost untouched ($f_i\approx1$); directions with $s_i^2\ll\lambda_u$, which are the poorly determined ones that amplify noise through the factor $1/s_i$, are suppressed. The sum $\mathrm{df}(\lambda_u)=\sum_i f_i$ is a natural "effective number of parameters": it equals $p$ at $\lambda_u=0$ and falls to $0$ as $\lambda_u\to\infty$. As $\lambda_u\to0$ with $X$ rank-deficient, the terms with $s_i=0$ are dropped and the limit is the minimum-norm least-squares solution $X^{+}y$.

### Gradient descent on a quadratic: the step limit, the rate and the condition number

For least squares and ridge, $J(w)=\tfrac12w^THw-g^Tw+\text{const}$ with $H=X^TX/N+\lambda I$ symmetric positive definite and $g=X^Ty/N$, so the minimiser is $w^\star=H^{-1}g$ (consistent with MML §9.2). Gradient descent $w_{k+1}=w_k-\alpha(Hw_k-g)$ gives, for the error $e_k=w_k-w^\star$,
$$e_{k+1}=(I-\alpha H)\,e_k\quad\Longrightarrow\quad e_k=(I-\alpha H)^ke_0 .$$
In the eigenbasis of $H$ with eigenvalues $\mu=\lambda_{\min}\le\dots\le\lambda_{\max}=L$, component $j$ is multiplied by $(1-\alpha\lambda_j)$ at every step. Convergence for every starting point requires $|1-\alpha\lambda_j|<1$ for all $j$, that is $0<\alpha<2/L$: the stiffest direction sets the step-size limit (MML §7.1.1 notes that too large a step overshoots or diverges). The worst contraction factor is $\rho(\alpha)=\max\{|1-\alpha\mu|,|1-\alpha L|\}$. It is minimised where the two terms are equal in magnitude, $1-\alpha\mu=\alpha L-1$, i.e. $\alpha^\star=2/(L+\mu)$, giving
$$\rho^\star=\frac{L-\mu}{L+\mu}=\frac{\kappa-1}{\kappa+1},\qquad \kappa=\frac L\mu,$$
the **condition number** of the Hessian, which MML §7.1.1 identifies as what governs gradient descent. Reducing the error by a factor $\varepsilon$ needs $k\approx\ln(1/\varepsilon)/\ln(1/\rho^\star)\approx\frac\kappa2\ln\frac1\varepsilon$ iterations when $\kappa\gg1$. Two practical consequences for this lesson. Unscaled features inflate $L$ (so $\alpha$ must be small) while a flat direction keeps $\mu$ tiny, so $\kappa$ explodes; standardising features removes the first effect. Ridge adds $\lambda$ to every eigenvalue, so $\kappa_\lambda=(L+\lambda)/(\mu+\lambda)$: a regulariser is also a *preconditioner*, which is why it speeds up gradient descent on nearly collinear features as well as reducing variance.

### The normal equations and the geometry of least squares

Let $X\in\mathbb R^{N\times p}$ (bias absorbed as a column of ones), $y\in\mathbb R^N$ and $J(w)=\frac1{2N}\|y-Xw\|^2$. Expanding, $J=\frac1{2N}(y^Ty-2w^TX^Ty+w^TX^TXw)$, so $\nabla J=\frac1N(X^TXw-X^Ty)$ and setting it to zero gives the **normal equations** $X^TXw=X^Ty$. Equivalently $X^T(y-Xw)=0$: the residual vector is orthogonal to every column of $X$. Geometrically $Xw$ ranges over the column space of $X$, and the fitted vector $\hat y=X\hat w$ is the orthogonal projection of $y$ onto that subspace, which is why the residuals sum to zero when a ones-column is present. The Hessian is $X^TX/N\succeq0$, so every stationary point is a global minimiser; it is unique exactly when $X$ has full column rank ($N\ge p$ and no feature is a linear combination of others). When columns are dependent, $X^TXw=X^Ty$ has a whole affine set of solutions, and ridge selects the one of smallest norm in the limit (exercise 14). Forming $X^TX$ squares the condition number, so numerical libraries prefer QR or SVD of $X$ itself; this is the practical reason behind the lesson's advice to use a factorisation-based solver as the reference (MML §9.2.1 derives the same equations as maximum likelihood).

### Maximum likelihood, estimator variance and the $p/N$ price of parameters

Assume $y=Xw_0+\varepsilon$ with $\varepsilon\sim N(0,\sigma^2I)$ and $X$ fixed. The negative log-likelihood is $\frac1{2\sigma^2}\|y-Xw\|^2+\text{const}$, so maximum likelihood *is* least squares (MML §9.2.1). The estimator $\hat w=(X^TX)^{-1}X^Ty=w_0+(X^TX)^{-1}X^T\varepsilon$ is unbiased with covariance $\sigma^2(X^TX)^{-1}$: the variance along the $i$-th singular direction is $\sigma^2/s_i^2$, large exactly where the data barely constrain $w$. To find the expected errors, note that the hat matrix $H=X(X^TX)^{-1}X^T$ is a projection of rank $p$, so $E\|(I-H)\varepsilon\|^2=\sigma^2(N-p)$. Hence
$$E[\text{training MSE}]=\sigma^2\Big(1-\frac pN\Big),\qquad E[\text{test MSE on fresh noise, same }X]=\sigma^2\Big(1+\frac pN\Big),$$
the second because the prediction error splits into $\sigma^2$ (new noise) plus $E\|X(\hat w-w_0)\|^2/N=\sigma^2\operatorname{tr}(H)/N=\sigma^2p/N$. The optimism of the training error is therefore $2\sigma^2p/N$, growing with the number of parameters and shrinking with data. A Monte Carlo check with $N=20$, $p=5$, $\sigma=1$ gave $0.748$ and $1.250$ against the formulas $0.75$ and $1.25$. This explains the residual-based advice of the lesson: a training loss below the noise level is not a success but a symptom of fitting noise, and when $p$ approaches $N$ the training error goes to zero while the test error blows up.

### Bias and variance of ridge along each direction

With $X=U\operatorname{diag}(s)V^T$ and ridge parameter $\lambda_u$ (the un-normalised form), write the true weights in the singular basis, $\beta_i=v_i^Tw_0$. The ridge estimate has component $f_i\hat\beta_i^{\text{OLS}}$ with $f_i=s_i^2/(s_i^2+\lambda_u)$, so its mean is $f_i\beta_i$ and its variance is $f_i^2\sigma^2/s_i^2=\sigma^2s_i^2/(s_i^2+\lambda_u)^2$. Per direction,
$$\text{bias}_i^2=\Big(\frac{\lambda_u}{s_i^2+\lambda_u}\Big)^2\beta_i^2,\qquad \text{var}_i=\frac{\sigma^2s_i^2}{(s_i^2+\lambda_u)^2},$$
and the total squared estimation error is the sum over $i$ (this is the bias-variance decomposition of Bishop §3.2 specialised to the linear model). Raising $\lambda_u$ always lowers the variance and raises the bias; the total is minimised at an intermediate value, which for a single direction is $\lambda_u=\sigma^2/\beta_i^2$ (differentiate $\beta^2\lambda^2/(s^2+\lambda)^2+\sigma^2s^2/(s^2+\lambda)^2$ with respect to $\lambda$ and set to zero), matching the MAP reading $\lambda_u=\sigma^2/b^2$ with prior variance $b^2=\beta^2$. Because the optimum depends on unknown $\beta$, in practice $\lambda$ is chosen on validation data, never on the training loss, which always prefers $\lambda=0$.

### Conditioning, centring and feature scaling

Suppose each feature column is centred, $x_j\to x_j-\bar x_j$. Setting $\partial J/\partial b=0$ for $J=\frac1{2N}\sum(y_i-b-w^Tx_i)^2$ gives $b=\bar y-w^T\bar x$, so after centring the intercept is $\bar y$ and decouples from $w$; the remaining problem has Hessian $C=X_c^TX_c/N$, the sample covariance matrix. If, in addition, each column is divided by its standard deviation, $C$ becomes the correlation matrix, with unit diagonal. For two standardised features with correlation $\rho$ the eigenvalues are $1\pm\rho$, so $\kappa=(1+\rho)/(1-\rho)$: uncorrelated features give $\kappa=1$ and gradient descent with $\alpha=1$ converges in one step, while $\rho=0.99$ gives $\kappa=199$. Standardising therefore removes the dependence on units but cannot remove correlation between features; only a larger $\lambda$, a different basis (PCA, QR) or a second-order method can do that. Standardisation also matters for ridge: the penalty $\lambda\|w\|^2$ treats all weights alike, so a feature measured in millimetres (large values, small weight) is penalised far less than the same feature in kilometres. The statistics used for centring and scaling must be computed on the training data only and applied unchanged to validation and test data (the leakage rule of ML01).

### When linear regression fails

Least squares inherits four assumptions, and each failure has a recognisable symptom. (1) *Linearity in the chosen features*: a curved relationship leaves a structured residual pattern against the input (the lesson's U shape). The fix is a feature, not a larger $\lambda$. (2) *Extrapolation*: the fitted line carries no information outside the range of the data, and the leverage $H_{ii}=x_i^T(X^TX)^{-1}x_i$ grows for points far from the centre, so predictions there have large variance, $\sigma^2(1+x_*^T(X^TX)^{-1}x_*)$ for a new input $x_*$. (3) *Outliers*: squared loss grows quadratically, so one wild measurement can move the line; the mean-versus-median argument of ML01 (Bishop §1.5.5) shows that the absolute loss or a robust loss limits their influence, at the cost of losing the closed form. (4) *Constant noise variance*: if the noise standard deviation grows with the input, ordinary least squares is still unbiased but inefficient, and the weighted form of exercise 12 is the remedy. Finally, when there are more features than samples ($p>N$) the normal equations are singular and the fit interpolates the data exactly; the minimum-norm solution of exercise 14 or a ridge penalty is then needed, and the training error stops being informative.

### How the pieces connect

The linear model is the smallest place where three threads of the course meet. The evaluation protocol of ML01 decides whether a residual or a held-out loss can be believed, and the baseline there (the mean predictor) is the special case $p=1$ with no features. The optimisation theory above explains why the same objective can be solved in one linear solve or in thousands of gradient steps, which is the first example of the trade-off that returns for logistic regression and neural networks, where no closed form exists and conditioning governs training time. The probabilistic reading (likelihood for the data term, prior for the penalty) is the template for every later loss in the course: choose a noise model, and the loss follows. Keeping these links in mind turns the three formulas $X^TXw=X^Ty$, $(X^TX+\lambda I)w=X^Ty$ and $w\leftarrow w-\alpha\nabla J$ into one story rather than three recipes.

## Worked example

### Basic case

**Problem.** Data $x=[0,1]$, $y=[1,3]$, model $\hat y=wx+b$ with $J=\frac1{2N}\sum e_i^2$, $e=\hat y-y$. Starting from $w=0,b=0$, compute the errors, the gradients $\nabla_wJ$ and $\partial J/\partial b$, and one gradient-descent step with $\alpha=0.1$. Then find the exact fitting line.

**Solution.**

1. *Predictions and errors.* With $w=b=0$ every prediction is $0$, so $e=\hat y-y=[0-1,\,0-3]=[-1,-3]$.
2. *Gradient in $w$.* From the theory section, $\nabla_wJ=X^Te/N$ with $N=2$: $\dfrac{0\times(-1)+1\times(-3)}{2}=\dfrac{-3}{2}=-1.5$.
3. *Gradient in $b$.* $\partial J/\partial b=\sum_ie_i/N=\dfrac{-1-3}{2}=-2$.
4. *Step.* $w\leftarrow w-\alpha\nabla_wJ=0-0.1\times(-1.5)=0.15$ and $b\leftarrow b-\alpha\,\partial J/\partial b=0-0.1\times(-2)=0.2$. Both parameters move up, as the negative errors (predictions too low) require.
5. *Exact line.* The two points fix the line: $x=0$ gives $b=1$, then $x=1$ gives $w+b=3$, so $w=2$. The exact fitting line is $y=2x+1$, with $J=0$.

**Check.** The loss falls from $J=(1+9)/(2\cdot2)=2.5$ at $(0,0)$ to $\hat y=(0.2,\,0.35)$, $e=(-0.8,-2.65)$, $J=(0.64+7.0225)/4=1.9156$ after the step, so the step does not overshoot. The normal equations at $(w,b)=(2,1)$ give $e=[0,0]$, hence zero gradient, confirming $y=2x+1$ is the minimiser.

**Takeaway.** Negative errors push both parameters upward, and the gradient of $J$ is just the average of error times feature (and of the error alone for the bias); data on an exact line are recovered exactly by the minimiser.

### Harder case: ridge along singular directions, with a bias-variance table

**Problem.** Take $N=2$ observations with a perfectly orthogonal design $X=\begin{pmatrix}2&0\\0&0.1\end{pmatrix}$, so the singular values are $s=(2,0.1)$, and targets $y=(4,\,0.1)$. Suppose the truth is $w_0=(2,1)$ and the noise standard deviation is $\sigma=0.1$. Compute the OLS estimate and its variances, the ridge estimate for $\lambda_u=0.01$ with its effective number of parameters, a bias-variance table for $\lambda_u\in\{0,0.01,0.1\}$, and the condition numbers of $H=X^TX$ for gradient descent.

**Solution.**

1. *OLS.* $X^TX=\operatorname{diag}(4,0.01)$, so $\hat w=(X^TX)^{-1}X^Ty=(4/2,\,0.1/0.1)=(2,\,1)$.
2. *OLS variances.* The variance along direction $i$ is $\sigma^2/s_i^2=(0.01/4,\;0.01/0.01)=(0.0025,\,1.0)$: the first coefficient is pinned down, the second has a standard deviation of $1$, as large as the coefficient itself.
3. *Ridge filter factors, $\lambda_u=0.01$.* $f_i=s_i^2/(s_i^2+\lambda_u)$ gives $f=(4/4.01,\,0.01/0.02)=(0.9975,\,0.5)$. Each component of the OLS estimate is multiplied by $f_i$, so $\hat w=(0.9975\times2,\;0.5\times1)=(1.9950,\,0.5)$. The second coordinate is halved.
4. *Effective parameters.* $\mathrm{df}=\sum f_i=0.9975+0.5=1.4975$ instead of $2$.
5. *Bias and variance per direction.* Use $\text{bias}_i^2=\big(\frac{\lambda_u}{s_i^2+\lambda_u}\big)^2\beta_i^2$ and $\text{var}_i=\frac{\sigma^2s_i^2}{(s_i^2+\lambda_u)^2}$ with $\beta=(2,1)$ (the truth is already along the axes). For $\lambda_u=0.01$: bias$^2=(0.01/4.01)^2\cdot4+(0.01/0.02)^2\cdot1=0.00002+0.25\approx0.2500$; variance $=0.01\cdot4/4.01^2+0.01\cdot0.01/0.02^2=0.0025+0.25=0.2525$; total $0.5025$. For $\lambda_u=0.1$: bias$^2=(0.1/4.1)^2\cdot4+(0.1/0.11)^2=0.0024+0.8264=0.8288$; variance $=0.04/4.1^2+0.0001/0.11^2=0.0024+0.0083=0.0106$; total $0.8395$. For $\lambda_u=0$: bias$=0$, variance $=0.0025+1.0=1.0025$.

   | $\lambda_u$ | squared bias | variance | total squared error |
   |---|---|---|---|
   | 0 | 0 | 1.0025 | 1.0025 |
   | 0.01 | 0.2500 | 0.2525 | 0.5025 |
   | 0.1 | 0.8288 | 0.0106 | 0.8395 |

6. *Reading the table.* The best of the three is the middle one, and the gain comes entirely from the poorly determined direction (the 0.1 singular value), where the variance dropped from $1.0$ to $0.25$ for a bias of $0.25$.
7. *Conditioning.* Gradient descent on the same problem has $H=X^TX$ with eigenvalues $4$ and $0.01+\lambda_u$ for the small one, so $\kappa=4/0.01=400$ for $\lambda_u=0$, and $\kappa=4.01/0.02\approx200$ for $\lambda_u=0.01$ (exactly $200.5$).

**Check.** All numbers were recomputed in Python. Consistency: bias$^2$ + variance in the first row equals the OLS total $0.0025+1.0$; the per-direction optimum $\lambda_u=\sigma^2/\beta_i^2$ is $0.01$ for $\beta=1$, the direction that dominates the error, which is why $0.01$ beats both neighbours. Limiting case: $\lambda_u\to\infty$ would give bias$^2\to\|w_0\|^2=5$ and variance $0$.

**Takeaway.** Ridge shrinks only the poorly determined directions, trading a small bias for a large variance reduction, and as a side effect it also lowers the condition number from $400$ to about $200$.

```python
import numpy as np
import torch
from sklearn.linear_model import LinearRegression, Ridge

# 1. Exercise data: OLS line through (1,2),(2,4),(3,5)
X3 = np.array([[1.], [2.], [3.]]); y3 = np.array([2., 4., 5.])
ols = LinearRegression().fit(X3, y3)
assert np.isclose(ols.coef_[0], 1.5) and np.isclose(ols.intercept_, 2 / 3)

# 2. Ridge: sklearn minimises ||y - Xw||^2 + alpha ||w||^2 (no 1/N), intercept unpenalised.
#    Our J = 1/(2N) sum e^2 + lam/2 |w|^2 is the same objective with alpha = lam * N.
rng = np.random.default_rng(5)
X = rng.uniform(-1, 1, (60, 2)); y = 2 * X[:, 0] - X[:, 1] + 3 + rng.normal(0, 0.05, 60)
lam, N = 1.0, len(X)
rid = Ridge(alpha=lam * N).fit(X, y)
Xc = X - X.mean(0); yc = y - y.mean()
w_closed = np.linalg.solve(Xc.T @ Xc / N + lam * np.eye(2), Xc.T @ yc / N)   # centred data => bias decouples
assert np.allclose(rid.coef_, w_closed)
assert np.linalg.norm(rid.coef_) < np.linalg.norm(LinearRegression().fit(X, y).coef_)   # shrinkage

# 3. Autograd checks the hand-derived gradient (1/N mean, ridge on w only)
w = torch.tensor([0.4, -0.2], dtype=torch.float64, requires_grad=True)
b = torch.tensor(0.1, dtype=torch.float64, requires_grad=True)
Xt, yt = torch.tensor(X), torch.tensor(y)
J = ((Xt @ w + b - yt) ** 2).sum() / (2 * N) + 0.3 / 2 * (w ** 2).sum()
J.backward()
e = X @ w.detach().numpy() + 0.1 - y
assert np.allclose(w.grad.numpy(), X.T @ e / N + 0.3 * w.detach().numpy())
assert np.isclose(b.grad.item(), e.mean())

# 4. Scaling: the Hessian condition number explains why unscaled features diverge
Xu = X * np.array([1, 1000.0])
H = lambda A: A.T @ A / len(A)
assert np.linalg.cond(H(Xu)) > 1e5 and np.linalg.cond(H((Xu - Xu.mean(0)) / Xu.std(0))) < 10
print("library track ok")
```
