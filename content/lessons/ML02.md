## Vì sao học bài này?

Connect matrix algebra, a loss, a gradient, and an evaluation split. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

A linear model is small enough to inspect end to end. It can reveal mistakes in preprocessing, optimization, and evaluation that would be harder to isolate in a deep network. “Linear” refers to the parameters; hand-designed nonlinear features can still be used.

## Định nghĩa và suy luận · Theory & derivation

For $N$ row-samples, $\hat y=Xw+b\mathbf1$. With $e=\hat y-y$, define $J=(1/2N)e^Te$. Applying the chain rule gives $\nabla_wJ=X^Te/N$ and $\partial J/\partial b=\sum_i e_i/N$. The factor $1/2$ cancels the derivative of the square.

A bias can be absorbed by appending a column of ones to $X$. Ordinary least squares minimizes the same objective using a factorization-based solver. Ridge regression adds $\lambda\|w\|^2/2$, whose gradient is $\lambda w$. This penalizes large coefficients but depends on feature scaling and typically excludes the bias.

A model can fit training data well but extrapolate badly. Check residuals against input, report held-out error, and compare with a training-mean baseline. A closed-form or least-squares solution is a useful independent reference for a gradient implementation.

## Ví dụ có lời giải · Worked example

With x=[0,1], y=[1,3], w=0, b=0, errors are [−1,−3]. For N=2, gradient w is (0×−1+1×−3)/2=−1.5 and gradient b=(−1−3)/2=−2. A step of 0.1 produces w=0.15 and b=0.2. The exact fitting line is y=2x+1.

## Triển khai tham khảo · Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
import numpy as np
x=np.array([0.,1.]); y=np.array([1.,3.])
w=b=0.
e=w*x+b-y
w -= .1*np.mean(e*x)
b -= .1*np.mean(e)
assert np.allclose([w,b],[.15,.2])
```

## Hiểu lầm thường gặp · Failure modes

Updating w before computing the bias gradient can mix old and new parameter states if the error is recomputed mid-step. Compute all gradients from the same parameter snapshot.

## So sánh và lựa chọn · Alternatives

Direct least squares is attractive for small dense problems. Gradient methods scale to large or streaming data. Ridge adds a bias toward smaller weights and can improve conditioning, but it introduces a hyperparameter to select honestly.
