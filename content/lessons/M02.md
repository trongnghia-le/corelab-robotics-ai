## Why this matters

Represent direction and magnitude before reaching for an array library. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

An arrow tells you both how far and in which direction to move. A vector is the displacement, not the place where you draw the arrow. Coordinates describe that vector relative to a basis. Rewriting the basis changes the numbers, while the physical displacement can remain unchanged.

## Theory and derivation

In $\mathbb R^n$, addition and scaling act componentwise: $(u+v)_i=u_i+v_i$ and $(\alpha v)_i=\alpha v_i$. The dot product $u^Tv=\sum_i u_i v_i$ is a scalar. Expanding $\|u-v\|^2=(u-v)^T(u-v)$ gives $\|u\|^2+\|v\|^2-2u^Tv$. Compare with the cosine rule to obtain $u^Tv=\|u\|\|v\|\cos\theta$.

The Euclidean norm is $\|v\|_2=\sqrt{v^Tv}$. A unit direction is $\hat v=v/\|v\|$, defined only for $v\ne0$. Projecting $u$ onto a nonzero $v$ gives $\mathrm{proj}_v u=(u^Tv/v^Tv)v$. The residual is orthogonal to $v$: multiplying $u-\mathrm{proj}_v u$ by $v^T$ yields zero. This is a useful verification property, not just a formula to memorize.

## Worked example

Let u=(3,4), v=(1,0). Their dot product is 3 and ‖u‖=5. The projection of u onto v is (3,0); the residual (0,4) has zero dot product with v. The displacement (3,4) and point (3,4) have the same coordinates but different meanings: adding two positions is generally not a physical displacement.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
def dot(u, v):
    if len(u) != len(v):
        raise ValueError("dimension mismatch")
    return sum(a * b for a, b in zip(u, v))

assert dot([3, 4], [1, 0]) == 3
assert dot([1, 2], [-2, 1]) == 0
```

## Failure modes

A negative dot product is valid and indicates an obtuse angle. Normalize only after checking length; dividing a zero vector by zero does not reveal a direction. Equal array lengths do not guarantee both vectors use the same coordinate frame.

## Alternatives and trade-offs

The L1 norm sums absolute values and favors axis-aligned sparse solutions in some optimization settings; the L2 norm reflects ordinary Euclidean distance and is rotation invariant. Choose according to the geometry of the problem.
