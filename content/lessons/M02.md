## Why this matters

Represent direction and magnitude before reaching for an array library. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

An arrow tells you both how far and in which direction to move. A vector is the displacement, not the place where you draw the arrow. Coordinates describe that vector relative to a basis. Rewriting the basis changes the numbers, while the physical displacement can remain unchanged.

## Theory and derivation

In $\mathbb R^n$, addition and scaling act componentwise: $(u+v)_i=u_i+v_i$ and $(\alpha v)_i=\alpha v_i$. The dot product $u^Tv=\sum_i u_i v_i$ is a scalar. Expanding $\|u-v\|^2=(u-v)^T(u-v)$ gives $\|u\|^2+\|v\|^2-2u^Tv$. Compare with the cosine rule to obtain $u^Tv=\|u\|\|v\|\cos\theta$.

The Euclidean norm is $\|v\|_2=\sqrt{v^Tv}$. A unit direction is $\hat v=v/\|v\|$, defined only for $v\ne0$. Projecting $u$ onto a nonzero $v$ gives $\mathrm{proj}_v u=(u^Tv/v^Tv)v$. The residual is orthogonal to $v$: multiplying $u-\mathrm{proj}_v u$ by $v^T$ yields zero. This is a useful verification property, not just a formula to memorize.

## Worked example

Let u=(3,4), v=(1,0). Their dot product is 3 and ‖u‖=5. The projection of u onto v is (3,0); the residual (0,4) has zero dot product with v. The displacement (3,4) and point (3,4) have the same coordinates but different meanings: adding two positions is generally not a physical displacement.

1. **(Easy)** A mobile robot drives $(2,1)$ m, then $(-1,3)$ m. Find its net displacement, the net distance from the start, and the total distance driven. 4. **(Medium)** A wind vector $w=(4,3)$ knots acts on a vehicle heading along $h=(1,1)$. Decompose $w$ into a component along the heading and a component across it. Which one affects arrival time, and which one pushes the vehicle off course?

6. **(Medium)** **Predict the output.**

7. **(Hard)** **Cross-track error.** A drone must follow the line through the origin with direction $d=(3,1)$. It is at $p=(4,3)$. Compute its along-track position (as a multiple of $d$), the projected point, and the cross-track error. Verify the residual is orthogonal to $d$. *(Adapted from: Boyd and Vandenberghe, Introduction to Applied Linear Algebra, Ch. 3 and Ch. 5 on orthogonality)*
8. **(Hard)** **Proof.** Using the residual $r=u-tv$ with $t=u\cdot v/v\cdot v$, show $\|u\|^2=t^2\|v\|^2+\|r\|^2$ and conclude the Cauchy-Schwarz inequality $|u\cdot v|\le\|u\|\|v\|$.
9. **(Hard)** **Design.** You compare two sensor feature vectors $a=(1,2,3)$ and $b=(2,4,6)$ (the same pattern at twice the gain). Compute the Euclidean distance and the cosine similarity. For which tasks (matching a pattern versus detecting a gain change) would you use each?
10. **(Project)** Write `cross_track(p, a, b)` for a path segment from $a$ to $b$, returning along-track fraction and cross-track distance, clamped to the segment. Test on an L-shaped path (three waypoints), including a point beyond the end of a segment.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
def dot(u, v):
    if len(u) != len(v):
        raise ValueError("dimension mismatch")
    return sum(a * b for a, b in zip(u, v))

assert dot([3, 4], [1, 0]) == 3
assert dot([1, 2], [-2, 1]) == 0
```

### Tests
Paste this below the starter code (same file) and run it. Every check is a plain `assert`; the first failure stops the run.

```python
import random
def close(a, b, t=1e-9): return abs(a - b) < t
def raises(f, *a):
    try: f(*a)
    except ValueError: return True
    return False
# hand-computed
assert dot([1, 2, 3], [4, -5, 6]) == 12 and dot([1, 2], [-2, 1]) == 0
assert close(norm([3, 4]), 5.0)
assert all(close(a, b) for a, b in zip(normalize([3, 4]), [0.6, 0.8]))
assert close(math.degrees(angle([1, 2], [3, -1])), 81.869898, 1e-5)
assert project([4, 3], [1, 1]) == [3.5, 3.5]
t, d = cross_track([4, 3], [0, 0], [30, 10])         # infinite-line example, inside the segment
assert close(t, 0.15) and close(d, math.sqrt(2.5))
t, d = cross_track([-3, 4], [0, 0], [10, 0])         # before the start: clamps to a
assert t == 0.0 and close(d, 5.0)
t, d = cross_track([13, 4], [0, 0], [10, 0])         # beyond the end: clamps to b
assert t == 1.0 and close(d, 5.0)
# errors
assert raises(dot, [1, 2], [1, 2, 3]) and raises(normalize, [0, 0])
assert raises(project, [1, 1], [0, 0]) and raises(cross_track, [1, 1], [2, 2], [2, 2])
# invariants on random vectors: symmetry, orthogonal residual, Pythagoras, Cauchy-Schwarz
random.seed(1)
for _ in range(200):
    u = [random.uniform(-5, 5) for _ in range(3)]; v = [random.uniform(-5, 5) for _ in range(3)]
    assert close(dot(u, v), dot(v, u))
    pr = project(u, v); res = [a - b for a, b in zip(u, pr)]
    assert close(dot(res, v), 0.0, 1e-9)
    assert close(norm(u) ** 2, norm(pr) ** 2 + norm(res) ** 2, 1e-9)
    assert abs(dot(u, v)) <= norm(u) * norm(v) + 1e-12
print("angle(deg) =", round(math.degrees(angle([1, 2], [3, -1])), 3), "| cross-track =", round(cross_track([4, 3], [0, 0], [30, 10])[1], 4))
print("all tests passed")
```

### Library track
Redo the lab with NumPy (`pip install numpy` in a virtual environment): `@`/`np.dot`, `np.linalg.norm`, `np.clip` before `np.arccos`, and a vectorised check of the lab invariants (Cauchy-Schwarz, orthogonal residual) over 200 random vector pairs at once with `np.einsum`. It also adds the signed 2D lateral error from the extension challenge: the 2D cross product of the path direction with $p-a$, divided by the segment length, is positive when $p$ is to the left of travel.

```python
import numpy as np

u = np.array([1.0, 2.0, 3.0]); v = np.array([4.0, -5.0, 6.0])
assert np.dot(u, v) == 12 and np.isclose(np.linalg.norm([3, 4]), 5.0)

def angle(a, b):
    c = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
    return np.arccos(np.clip(c, -1.0, 1.0))        # clip, as in the lab
assert np.isclose(np.degrees(angle(np.array([1., 2.]), np.array([3., -1.]))), 81.869898, atol=1e-5)

def project(u, v): return (u @ v) / (v @ v) * v
assert np.allclose(project(np.array([4., 3.]), np.array([1., 1.])), [3.5, 3.5])

def cross_track(p, a, b):
    ab = b - a
    t = np.clip((p - a) @ ab / (ab @ ab), 0.0, 1.0)
    return t, np.linalg.norm(p - (a + t * ab))
t, d = cross_track(np.array([4., 3.]), np.array([0., 0.]), np.array([30., 10.]))
assert np.isclose(t, 0.15) and np.isclose(d, np.sqrt(2.5))

# Signed lateral error in 2D: z-component of path-direction x (p - a); positive = left of travel
def signed_lateral(p, a, b):
    ab, ap = b - a, p - a
    return (ab[0] * ap[1] - ab[1] * ap[0]) / np.linalg.norm(ab)
assert np.isclose(signed_lateral(np.array([4., 3.]), np.array([0., 0.]), np.array([30., 10.])), 1.5811, atol=1e-4)

# Batch: random vectors, check the invariants of the lab in one vectorised shot
rng = np.random.default_rng(1)
U = rng.uniform(-5, 5, (200, 3)); V = rng.uniform(-5, 5, (200, 3))
dots = np.einsum("ij,ij->i", U, V)
assert np.all(np.abs(dots) <= np.linalg.norm(U, axis=1) * np.linalg.norm(V, axis=1) + 1e-12)   # Cauchy-Schwarz
P = (dots / np.einsum("ij,ij->i", V, V))[:, None] * V
assert np.allclose(np.einsum("ij,ij->i", U - P, V), 0.0)                                       # orthogonal residual
print("library track ok")
```

Expected output: `library track ok`. Every assert compares the NumPy result with a hand-computed value from the lab tests.

## Failure modes

A negative dot product is valid and indicates an obtuse angle. Normalize only after checking length; dividing a zero vector by zero does not reveal a direction. Equal array lengths do not guarantee both vectors use the same coordinate frame.

## Alternatives and trade-offs

The L1 norm sums absolute values and favors axis-aligned sparse solutions in some optimization settings; the L2 norm reflects ordinary Euclidean distance and is rotation invariant. Choose according to the geometry of the problem.

## Exercise answers

1. Net displacement $(1,4)$, distance $\sqrt{17}\approx4.123$ m. Total driven $\sqrt5+\sqrt{10}\approx2.236+3.162=5.398$ m. The triangle inequality $\|u+v\|\le\|u\|+\|v\|$ holds with equality only if the two moves are in the same direction; here they turn.
2. Speed $\sqrt{9+16}=5$ m/s; heading $(0.6,0.8)$. The vectors $(3,4)$ and $(-4,3)$ are perpendicular (dot $=-12+12=0$), so the product is exactly zero: orthogonal directions.
3. $a\cdot b=3-2=1$; $\|a\|\|b\|=\sqrt5\sqrt{10}=\sqrt{50}$; $\cos\theta=1/\sqrt{50}\approx0.1414$, $\theta\approx81.9^\circ$. Positive dot means acute (cosine positive since norms are positive), so yes, the sign alone settles acute versus obtuse.
4. $w\cdot h=7$, $h\cdot h=2$, so the along-heading component is $3.5\,h=(3.5,3.5)$, magnitude $7/\sqrt2\approx4.95$ kn (a tailwind: it changes speed over ground, hence arrival time). The across component is $(0.5,-0.5)$, magnitude $\approx0.707$ kn: it pushes the vehicle sideways.
5. It returns $\sum x_i^2$, missing the square root. $(3,4)$ returns 25, not 5. It is accidentally right for $(1,0)$ or $(0,1)$ (unit vectors). Property test: `norm(c*v) == abs(c)*norm(v)` fails for $c=2$ (gives 4x instead of 2x).
6. $4-10+18=12$; $-2+2=0$; the third call silently ignores the extra element (`zip` truncates) and returns $1+4=5$. Output `12 0 5`. Fix: check `len(u) == len(v)` and raise `ValueError`.
7. $p\cdot d=12+3=15$, $d\cdot d=10$, $t=1.5$; projected point $(4.5,1.5)$; residual $(-0.5,1.5)$, cross-track error $\sqrt{2.5}\approx1.581$. Check: $(-0.5)(3)+(1.5)(1)=0$.
8. $r\cdot v=u\cdot v-t\,v\cdot v=0$. Then $\|u\|^2=\|tv+r\|^2=t^2\|v\|^2+2t\,v\cdot r+\|r\|^2=t^2\|v\|^2+\|r\|^2\ge t^2\|v\|^2=(u\cdot v)^2/\|v\|^2$. Multiply by $\|v\|^2$ and take square roots.
9. Distance $\|a-b\|=\|(1,2,3)\|=\sqrt{14}\approx3.742$; cosine $=28/(\sqrt{14}\sqrt{56})=1$. Cosine similarity ignores gain, so use it to match a pattern regardless of scale; use Euclidean distance (or compare norms) when gain or magnitude itself matters.
10. A good answer clamps $t=\mathrm{clip}(\,(p-a)\cdot(b-a)/\|b-a\|^2,0,1)$, returns $t$ and $\|p-(a+t(b-a))\|$, rejects $a=b$, and tests: a point mid-segment, one before $a$ (t=0, distance to $a$), one beyond $b$ (t=1), and the corner of the L where two segments are equidistant.
