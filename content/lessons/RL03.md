## Why this matters

Every reinforcement learning method has to answer one question, in some form: how good is it to be here, or to do this here? A robot arm in the middle of a pick-and-place has not yet earned its reward; the plan only makes sense because we can assign value to intermediate situations. Value functions are the quantity that planners compute, that Q-learning estimates, and that actor-critic methods use to judge actions (the advantage). Getting them wrong is silent: a mistaken value looks like a plausible number. So the skill taught here is to compute values exactly for a small model, check them with an identity, and see how they change decisions. The same calculation is the ground truth against which later estimates (dynamic programming, Monte Carlo, temporal difference) are checked.

## Intuition

Reward is what you get now. **Return** is the discounted sum of rewards from now on: $G_t=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots$. A policy $\pi$ and random transitions make $G_t$ random, so we ask for its expectation.

- **State value** $V^\pi(s)$: expected return starting in $s$ and following $\pi$.
- **Action value** $Q^\pi(s,a)$: expected return starting in $s$, taking $a$ first, then following $\pi$.
- **Advantage** $A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$: how much better $a$ is than the policy's average in $s$.

Think of $V$ as the grade of a position and $Q$ as the grade after committing to one move. The advantage is the difference between that move and what you would typically do. Because $V$ is the policy-weighted average of $Q$, the policy-weighted average of the advantage is exactly zero: a move can only be better than average if another is worse.

Immediate reward and value can disagree. A cheap reward now may lead to a dead end; a zero reward now may step toward a place with a high stream of rewards. In the example below the action with the *larger* immediate payoff at one state is not the one with the larger value.

## Theory and derivation

### Definitions

For a finite MDP with transition probabilities $p(s',r\mid s,a)$ and discount $\gamma\in[0,1)$:
$$V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s],\qquad Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].$$
The value of a terminal state is 0 by convention; any final reward is paid on the transition into it.

### Bellman expectation equations

Split the return into the first reward and the rest: $G_t=r_t+\gamma G_{t+1}$. Taking expectations conditioned on $s$ (and the first action) gives
$$V^\pi(s)=\sum_a\pi(a|s)\,Q^\pi(s,a),\qquad Q^\pi(s,a)=\sum_{s',r}p(s',r|s,a)\,\big[r+\gamma V^\pi(s')\big].$$
Substituting one into the other:
$$V^\pi(s)=\sum_a\pi(a|s)\sum_{s',r}p(s',r|s,a)\big[r+\gamma V^\pi(s')\big].$$
For $n$ non-terminal states this is $n$ linear equations in $n$ unknowns, $(I-\gamma P_\pi)V=r_\pi$, with a unique solution for $\gamma<1$ because $\gamma P_\pi$ has spectral radius below 1. Hence $V^\pi=(I-\gamma P_\pi)^{-1}r_\pi$.

### Advantage

$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$ satisfies $\sum_a\pi(a|s)A^\pi(s,a)=0$. It is the quantity policy-gradient methods weight actions by (see Spinning Up); subtracting the baseline $V^\pi(s)$ lowers variance without bias.

### Greedy improvement

For a policy $\pi$, define $\pi'(s)=\arg\max_aQ^\pi(s,a)$. The policy improvement theorem says $V^{\pi'}(s)\ge V^\pi(s)$ for all $s$. Sketch: $Q^\pi(s,\pi'(s))\ge V^\pi(s)$; unroll one step at a time and use $V^\pi(s)\le Q^\pi(s,\pi'(s))=\mathbb E[r+\gamma V^\pi(s')]\le\mathbb E[r+\gamma Q^\pi(s',\pi'(s'))]\le\cdots\le V^{\pi'}(s)$. Note the advantage is measured against the current policy, so the best action under $Q^\pi$ need not be the best action under the optimal $Q^*$ (see the worked example).

## Worked example

The MDP of the figure, $\gamma=0.9$, uniform random policy. Unknowns $V_A,V_B$ (terminal $T$ has value 0).

**State B.** Stay: reward 2, stay in B. Go: with 0.9 reward 10 and reach $T$; with 0.1 reward 0 and stay in B.
$$V_B=0.5\,[2+0.9V_B]+0.5\,[0.9\cdot10+0.1\cdot0.9V_B]=1+0.45V_B+4.5+0.045V_B=5.5+0.495V_B,$$
so $V_B=5.5/0.505=10.8911$.

**State A.** Stay: reward 1, stay in A. Go: with 0.8 reach B, with 0.2 stay in A, reward 0.
$$V_A=0.5\,[1+0.9V_A]+0.5\,[0.8\cdot0.9V_B+0.2\cdot0.9V_A]=0.5+0.45V_A+0.36V_B+0.09V_A,$$
so $0.46V_A=0.5+0.36\cdot10.8911=4.4208$ and $V_A=9.6104$.

**Action values.**
$Q(A,\text{stay})=1+0.9\cdot9.6104=9.6494$; $Q(A,\text{go})=0.72\cdot10.8911+0.18\cdot9.6104=7.8416+1.7299=9.5715$.
$Q(B,\text{stay})=2+0.9\cdot10.8911=11.8020$; $Q(B,\text{go})=9+0.09\cdot10.8911=9.9802$.

**Check.** $0.5\cdot9.6494+0.5\cdot9.5715=9.6104=V_A$ and $0.5\cdot11.8020+0.5\cdot9.9802=10.8911=V_B$.

**Advantages.** At A: $+0.039$ (stay), $-0.039$ (go). At B: $+0.911$ and $-0.911$.

**Improvement.** Greedy with respect to $Q^{\pi}$: stay in A and stay in B. That policy loops forever: $V_A=1/(1-0.9)=10$, $V_B=2/(1-0.9)=20$, both larger than before. Greedy again with respect to the new $Q$ gives go in A (reach B, then stay): $V_A=14.4/0.82=17.56$. Always staying at A looked best under the uniform policy ($A^\pi=+0.039$) but is not optimal: the advantage is relative to the policy being evaluated.

## Reference implementation

The MDP is a dictionary; the linear system is solved by hand-written Gaussian elimination so everything is stdlib.

```python
# MDP: dict (state, action) -> list of (prob, next_state, reward); the terminal state has value 0.
MDP = {
    ("A", "stay"): [(1.0, "A", 1.0)],
    ("A", "go"):   [(0.8, "B", 0.0), (0.2, "A", 0.0)],
    ("B", "stay"): [(1.0, "B", 2.0)],
    ("B", "go"):   [(0.9, "T", 10.0), (0.1, "B", 0.0)],
}
STATES = ["A", "B"]          # non-terminal states ("T" is terminal)
ACTIONS = ["stay", "go"]

def solve(M, b):
    """Solve M x = b by Gaussian elimination with partial pivoting."""
    n = len(b)
    A = [row[:] + [b[i]] for i, row in enumerate(M)]
    for c in range(n):
        p = max(range(c, n), key=lambda r: abs(A[r][c]))
        A[c], A[p] = A[p], A[c]
        for r in range(c + 1, n):
            f = A[r][c]/A[c][c]
            A[r] = [x - f*y for x, y in zip(A[r], A[c])]
    x = [0.0]*n
    for i in reversed(range(n)):
        x[i] = (A[i][n] - sum(A[i][j]*x[j] for j in range(i + 1, n)))/A[i][i]
    return x

def evaluate(mdp, pi, gamma):
    """V^pi from the linear system (I - gamma P_pi) V = r_pi.  pi[s][a] = probability."""
    idx = {s: i for i, s in enumerate(STATES)}
    n = len(STATES)
    M = [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
    b = [0.0]*n
    for s in STATES:
        for a, pa in pi[s].items():
            for p, s2, r in mdp[(s, a)]:
                b[idx[s]] += pa*p*r
                if s2 in idx:
                    M[idx[s]][idx[s2]] -= gamma*pa*p
    return dict(zip(STATES, solve(M, b)))

def q_from_v(mdp, V, gamma):
    """Q(s,a) = sum_{s'} p (r + gamma V(s')) with V(terminal) = 0."""
    return {(s, a): sum(p*(r + gamma*V.get(s2, 0.0)) for p, s2, r in mdp[(s, a)])
            for s in STATES for a in ACTIONS}

def advantage(Q, V):
    return {(s, a): q - V[s] for (s, a), q in Q.items()}

if __name__ == "__main__":
    gamma = 0.9
    uniform = {s: {"stay": 0.5, "go": 0.5} for s in STATES}
    V = evaluate(MDP, uniform, gamma)
    Q = q_from_v(MDP, V, gamma)
    Adv = advantage(Q, V)
    print("V:", {s: round(v, 4) for s, v in V.items()})
    print("Q:", {k: round(v, 4) for k, v in Q.items()})
    print("A:", {k: round(v, 4) for k, v in Adv.items()})
    # Bellman consistency: V(s) = sum_a pi(a|s) Q(s,a), so the policy-weighted advantage is 0
    for s in STATES:
        assert abs(sum(uniform[s][a]*Q[(s, a)] for a in ACTIONS) - V[s]) < 1e-12
        assert abs(sum(uniform[s][a]*Adv[(s, a)] for a in ACTIONS)) < 1e-12
    assert abs(V["B"] - 5.5/0.505) < 1e-9
    print("self-test passed")
```

### Library track

Redo the evaluation with NumPy (`np.linalg.solve` on $(I-\gamma P_\pi)V=r_\pi$) and then on a standard Gymnasium environment: `FrozenLake-v1` exposes its transition model as `env.unwrapped.P[s][a] = [(prob, next_state, reward, done), ...]`, the same shape as `MDP` above. The code evaluates the uniform policy exactly, checks $V=\sum_a\pi Q$ and the zero-mean advantage, applies one greedy improvement, and compares $V$ at the start state with a Monte Carlo average of simulated returns. Put the reference code above this block (it uses `MDP`, `STATES`, `evaluate`). Needs `numpy` and `gymnasium`.

```python
import numpy as np
import gymnasium as gym

# --- 1. the lesson's MDP with NumPy: V = (I - gamma P_pi)^-1 r_pi, compared with the stdlib solver ---
gamma = 0.9
P = np.array([[0.5*1.0 + 0.5*0.2, 0.5*0.8],      # A: stay -> A; go -> B w.p. 0.8, A w.p. 0.2
              [0.0, 0.5*1.0 + 0.5*0.1]])         # B: stay -> B; go -> T w.p. 0.9 (leaves), B w.p. 0.1
r = np.array([0.5*1.0, 0.5*2.0 + 0.5*9.0])       # expected immediate reward per state under the uniform policy
V = np.linalg.solve(np.eye(2) - gamma * P, r)
ref = evaluate(MDP, {s: {"stay": 0.5, "go": 0.5} for s in STATES}, gamma)
assert np.allclose(V, [ref["A"], ref["B"]]) and abs(V[1] - 5.5/0.505) < 1e-12
assert max(abs(np.linalg.eigvals(gamma * P))) < 1                   # spectral radius below 1: unique solution

# --- 2. Gymnasium FrozenLake: its transition model env.unwrapped.P has the same (prob, next, reward, done) shape ---
env = gym.make("FrozenLake-v1", is_slippery=True)
model, nS, nA = env.unwrapped.P, env.observation_space.n, env.action_space.n
def evaluate_gym(pi, gamma):
    Pm, rv = np.zeros((nS, nS)), np.zeros(nS)
    for s in range(nS):
        for a in range(nA):
            for p, s2, rew, done in model[s][a]:
                rv[s] += pi[s, a] * p * rew
                if not done:                       # terminal states (holes, goal) keep value 0
                    Pm[s, s2] += pi[s, a] * p * gamma
    return np.linalg.solve(np.eye(nS) - Pm, rv)
uniform = np.full((nS, nA), 1 / nA)
Vg = evaluate_gym(uniform, 0.99)
Qg = np.array([[sum(p * (rew + 0.99 * (0 if done else Vg[s2])) for p, s2, rew, done in model[s][a]) for a in range(nA)] for s in range(nS)])
assert np.allclose((uniform * Qg).sum(1), Vg)                       # V = sum_a pi Q
assert np.allclose((uniform * (Qg - Vg[:, None])).sum(1), 0)        # weighted advantage is 0
greedy = np.eye(nA)[Qg.argmax(1)]
Vg2 = evaluate_gym(greedy, 0.99)
assert (Vg2 >= Vg - 1e-12).all()                                    # policy improvement theorem
print("FrozenLake start state: V uniform %.4f -> after one greedy step %.4f" % (Vg[0], Vg2[0]))
# Monte Carlo check of V(start) under the uniform policy
rng = np.random.default_rng(0); rets = []
for ep in range(4000):
    s, _ = env.reset(seed=int(rng.integers(1 << 30))); G, disc, done = 0.0, 1.0, False
    while not done:
        s, rew, term, trunc, _ = env.step(int(rng.integers(nA))); G += disc * rew; disc *= 0.99; done = term or trunc
    rets.append(G)
print("Monte Carlo V(start) = %.4f +- %.4f" % (np.mean(rets), 2 * np.std(rets) / np.sqrt(len(rets))))
assert abs(np.mean(rets) - Vg[0]) < 0.01
print("library track passed")
```

## Verification

- Bellman consistency: $V(s)=\sum_a\pi(a|s)Q(s,a)$ to $10^{-9}$.
- Advantage identity: $\sum_a\pi(a|s)A(s,a)=0$.
- Compare with the closed form on a one-state loop: value $=r/(1-\gamma)$.
- Probabilities of every $(s,a)$ must sum to 1; the terminal value must be 0; a $\gamma$ limit check ($\gamma=0$ gives $V=$ expected immediate reward).

## Failure modes

| Mistake | Wrong value or symptom |
|---|---|
| Using $\max_aQ$ for $V^\pi$ (Exercise 5) | $V_B=11.80$ instead of $10.89$; this is a control value, not policy evaluation |
| Forgetting the terminal value is 0 | Terminal bootstraps garbage and inflates values |
| Taking $\gamma=1$ with a policy that never terminates | Linear system is singular or returns are infinite |
| Using the advantage under $\pi$ as the optimal action | Picks "stay" at A, which is not optimal ($Q^*$ prefers go) |
| Mixing reward on arrival and reward on departure | Values off by a shifted reward term |
| Not normalising transition probabilities | Values scale wrongly; check sums |

## Alternatives and trade-offs

- **Linear solve**: exact for small tabular MDPs; cost $O(n^3)$.
- **Iterative evaluation (RL04)**: scales to larger tabular MDPs and is the template for dynamic programming.
- **Monte Carlo and TD (RL05)**: estimate the same values from samples without a model.
- **Function approximation**: needed when states are continuous (robot joint angles); values become learned and the exact checks above become approximate.
- **$V$ versus $Q$**: with a model, $V$ suffices to act (one-step lookahead); without a model, $Q$ is needed.

## Transfer and retention

The Bellman equations here are the fixed-point conditions that RL04 solves iteratively, RL05 estimates from samples, and RL06 turns into control (Q-learning, SARSA). The advantage is the signal used by actor-critic and PPO-style methods in robot learning. Retrieval prompts: Write $V$ in terms of $Q$. Why does the weighted advantage vanish? Why can the greedy action under $Q^\pi$ differ from the optimal action?

## Exercise answers

1. $V=0.25\cdot4+0.75\cdot8=7$. Advantages: $4-7=-3$ and $8-7=+1$. Weighted: $0.25\cdot(-3)+0.75\cdot1=0$.
2. $G_0=1+0.9\cdot0+0.81\cdot5=5.05$. With $\gamma=0$: $G_0=1$, only the immediate reward.
3. $V=2/(1-0.95)=40$. As $\gamma\to1$ the value grows without bound ($2/(1-\gamma)$) because the reward stream does not end.
4. $A$ removes the part of the value that is common to all actions in the state, leaving the effect of the choice. With $Q=(100,102)$ and $\pi=(0.5,0.5)$, $V=101$ and $A=(-1,+1)$. Weighting the gradient by $A$ rather than by $Q\approx100$ gives much lower variance.
5. It returns $11.802$ for B. The correct $V_B=0.5\cdot11.802+0.5\cdot9.980=10.891$. The function computes $\max_aQ$, which is the value of the greedy (one-step improved) action, not the value of the uniform policy.
6. Staying forever in B is worth $2/(1-\gamma)$. Going: with probability 0.9 you get 10 and stop, otherwise you retry, so $V_{go}=9+0.1\gamma V_{go}$ at the best continuation, i.e. $V_{go}=9/(1-0.1\gamma)$. Stay is better when $2(1-0.1\gamma)>9(1-\gamma)$, i.e. $8.8\gamma>7$, $\gamma>0.7955$. A larger $\gamma$ favours the endless stream: stay.
7. $G_t=r_t+\gamma G_{t+1}$. Conditioning on $S_t=s$: $\mathbb E[r_t|s]=\sum_a\pi\sum p\,r$ and $\mathbb E[G_{t+1}|s,a,s']=V^\pi(s')$. The second step uses the Markov property: given $s'$, the future return does not depend on how $s'$ was reached.
8. $V^\pi(s)\le Q^\pi(s,\pi'(s))=\mathbb E_{\pi'}[r_t+\gamma V^\pi(S_{t+1})\mid S_t=s]\le\mathbb E_{\pi'}[r_t+\gamma Q^\pi(S_{t+1},\pi'(S_{t+1}))]=\mathbb E_{\pi'}[r_t+\gamma r_{t+1}+\gamma^2V^\pi(S_{t+2})]\le\cdots\le\mathbb E_{\pi'}[G_t]=V^{\pi'}(s)$.
9. $V^*(B)=20$ (stay), $V^*(A)=17.561$. $Q^*(A,\text{stay})=1+0.9\cdot17.561=16.805$; $Q^*(A,\text{go})=0.72\cdot20+0.18\cdot17.561=17.561$. So $Q^*$ prefers go at A, while $Q^\pi$ for the uniform policy preferred stay (9.649 vs 9.572). The advantage is relative to the current policy, so it tells you the direction of improvement, not the optimum; iterating (policy iteration) is needed.
10. A good answer gives a transition table with probabilities summing to 1, a terminal convention (dead has value 0), exact $V$ for both policies via a linear solve, $Q=\sum p[r+\gamma V]$, advantages, and the check $V=\sum\pi Q$.
