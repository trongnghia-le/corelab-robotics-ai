## Why this matters

Separate data, targets, objectives, and evaluation assumptions. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

Machine learning is an experimental claim: a model fitted on observed data should perform on a declared future distribution. Choosing the prediction target and evaluation split is part of the algorithm. A sophisticated network cannot rescue an invalid test.

![A pipeline diagram: all data split into train, validation and test; the scaler and model are fit on train, choices are made on validation, test is used once at the end, and a crossed-out leakage path from test to training.](/lesson-figures/ML01.svg)

*Evaluation is only honest if no test information reaches fitting or selection.*

## Theory and derivation

For supervised data $D=\{(x_i,y_i)\}_{i=1}^N$, a predictor $f_\theta(x)$ is fitted by minimizing empirical risk $\hat R(\theta)=N^{-1}\sum_i\ell(f_\theta(x_i),y_i)$. The future risk $R(\theta)=E_{(x,y)\sim P}[\ell(f_\theta(x),y)]$ depends on the deployment distribution $P$, which training data only approximates.

Training data fits parameters; validation data selects models and hyperparameters; the test set estimates final performance after those choices are fixed. If normalization, feature selection, or duplicate samples use test information, the reported test result is biased. Fit preprocessing on training data and reuse its parameters unchanged.

Choose a baseline before a complex model. For squared error with a constant predictor $c$, differentiate $N^{-1}\sum_i(c-y_i)^2$ to get $2(c-\bar y)$, so the optimal training constant is the training mean. Baselines turn “the loss is small” into a meaningful comparison.

## Worked example

If a dataset has 95 nondefective and 5 defective items, always predicting nondefective gives 95% accuracy and zero defect recall. The metric should reflect the cost of missed defects. If images from one physical part appear in both train and test, a random image split can leak part identity.

## Exercises

1. **(Easy)** A quality-control model sees 1,000 parts of which 20 are defective. (a) A model that always says "good" has what accuracy and recall? (b) Another catches 15 defects but raises 30 false alarms: give its confusion matrix, accuracy, precision and recall. Which metric would you report to the plant manager and why? *(Adapted from: Zhang et al., Dive into Deep Learning, the evaluation sections on classification metrics)*
2. **(Easy)** Training targets (battery runtime in hours) are $2,4,9,5$. What is the best constant predictor under squared error, and its training MSE? On test targets $3,7$ what is the baseline's MSE? What does a learned model's test MSE of $5$ tell you?
3. **(Medium)** **Leakage by scaling.** Train features are $0,2,4$ and one test feature is $100$. Compute the $z$-score of $x=4$ when the scaler is fit on the training set only, and when it is fit on all four values. Which is right, and what would the second one do to a reported test score? *(Adapted from: scikit-learn User Guide, Common pitfalls: data leakage)*
4. **(Medium)** **Split design.** You have 5,000 frames from each of 10 robots and want to know how well a model works on a new robot. Why does a random frame split give an optimistic estimate? Propose a split and a cross-validation scheme and say what to report.
5. **(Medium)** **Predict the output.**

6. **(Medium)** **Find the flaw.**

   Explain why the printed number is optimistic. If 20 configurations each have true accuracy $0.80$ and a test estimate with standard deviation $0.04$, what is the expected best score (the expected maximum of 20 standard normals is about $1.87$)?
7. **(Hard)** Show that the constant minimising $\frac1N\sum(c-y_i)^2$ is the mean. For targets $1,2,10$ compare the mean and the median as constants under squared error and absolute error. Which baseline is more honest when outliers exist?
8. **(Hard)** A test set of 200 labelled robot runs gives accuracy $0.90$. Compute the standard error and an approximate 95% interval. How many test samples would you need for a half-width of $0.02$? What assumption (independence) might fail for frames of the same run?
9. **(Hard)** **Design.** Formulate "predict remaining battery time for a delivery robot" as a supervised problem: inputs, target, loss, baseline, metric, split, and two ways deployment could differ from the data. *(Adapted from: Stanford CS229 lecture notes, introduction to supervised learning and generalisation)*

```python
def close(a, b, t=1e-9): return abs(a - b) < t
c = mean_baseline([1, 2, 3]); assert c == 2 and close(mse(c, [2, 4]), 2.0)
assert close(mse(mean_baseline([2, 4, 9, 5]), [2, 4, 9, 5]), 6.5) and close(mse(5.0, [3, 7]), 4.0)
# imbalanced classification: accuracy hides a useless model

sc = fit_scaler([0, 2, 4]); assert close(sc[0], 2) and close(sc[1], math.sqrt(8 / 3))

leak = apply_scaler(fit_scaler([0, 2, 4, 100]), [4])[0]; assert close(leak, -0.52992543, 1e-6)
z = apply_scaler(sc, [0, 2, 4]); assert close(sum(z), 0, 1e-9) and close(sum(v * v for v in z) / 3, 1, 1e-9)   # property
try: fit_scaler([3, 3, 3]); raise SystemExit("constant feature accepted")
except ValueError: pass
# grouped split: no group on both sides, and every sample used exactly once
groups = ["a", "a", "b", "b", "b", "c"]
tr, te = group_split(groups, {"b"})
assert te == [2, 3, 4] and tr == [0, 1, 5]
assert not ({groups[i] for i in tr} & {groups[i] for i in te}) and sorted(tr + te) == list(range(6))
try: group_split(groups, {"z"}); raise SystemExit("unknown group accepted")
```

### Library track
Redo the lab with scikit-learn (`pip install numpy scipy scikit-learn` in a virtual environment): `DummyRegressor` as the baseline, `sklearn.metrics` for the confusion matrix and precision/recall, `StandardScaler` fitted on training data only, and a leakage demo in which a one-hot group id wins a random `KFold` but fails `GroupKFold`. The numbers in the asserts are the ones from your hand-written lab.

```python
import numpy as np
from sklearn.dummy import DummyRegressor
from sklearn.metrics import accuracy_score, confusion_matrix, precision_score, recall_score
from sklearn.model_selection import GroupKFold, cross_val_score
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

# 1. Baseline and metrics
base = DummyRegressor(strategy="mean").fit(np.zeros((3, 1)), [1, 2, 3])
assert base.predict([[0]])[0] == 2 and np.isclose(np.mean((base.predict(np.zeros((2, 1))) - [2, 4]) ** 2), 2.0)
yt = np.array([1] * 20 + [0] * 980); yp = np.array([1] * 15 + [0] * 5 + [1] * 30 + [0] * 950)
assert confusion_matrix(yt, yp).ravel().tolist() == [950, 30, 5, 15]            # tn, fp, fn, tp
assert np.isclose(accuracy_score(yt, yp), 0.965) and np.isclose(precision_score(yt, yp), 1 / 3)
assert np.isclose(recall_score(yt, yp), 0.75)
y95 = np.array([0] * 95 + [1] * 5)
assert recall_score(y95, np.zeros(100), zero_division=0) == 0.0

# 2. Scaler fitted on train only
sc = StandardScaler().fit([[0], [2], [4]])
assert np.isclose(sc.transform([[4]])[0, 0], 1.224744871391589)
assert np.isclose(StandardScaler().fit([[0], [2], [4], [100]]).transform([[4]])[0, 0], -0.52992543, atol=1e-6)

# 3. Leakage demo: a one-hot group id predicts y by memorising per-group offsets
from sklearn.model_selection import KFold
from sklearn.preprocessing import OneHotEncoder
rng = np.random.default_rng(0)
groups = np.repeat(np.arange(10), 50)
y = rng.normal(0, 5, 10)[groups] + rng.normal(0, 0.5, 500)    # per-group offset plus noise
X = groups.reshape(-1, 1)
model = make_pipeline(OneHotEncoder(handle_unknown="ignore"), LinearRegression())
r2_random = cross_val_score(model, X, y, cv=KFold(5, shuffle=True, random_state=0)).mean()
r2_group = cross_val_score(model, X, y, cv=GroupKFold(5), groups=groups).mean()
assert r2_random > 0.9 and r2_group < 0.1                     # honest grouped score exposes the memorisation
for tr, te in GroupKFold(5).split(X, y, groups):
    assert set(groups[tr]).isdisjoint(groups[te])
print("random-split R^2 > 0.9:", r2_random > 0.9, "| grouped R^2 < 0.1:", r2_group < 0.1)
```

Expected output: `random-split R^2 > 0.9: True | grouped R^2 < 0.1: True`. In a real project put the scaler inside the `Pipeline` so that cross-validation refits it on every training fold; that is what makes leakage by scaling impossible.

## Failure modes

A high test score does not prove a causal mechanism. Random splits are not appropriate for every time series or correlated collection. Accuracy alone can hide class imbalance.

## Alternatives and trade-offs

Regression predicts continuous targets; classification predicts discrete categories; unsupervised learning analyzes structure without the same labeled target. Choose the formulation from the decision being supported.

## Exercise answers

1. (a) Accuracy $980/1000=98\%$; recall $0$ (no defect caught). (b) TP$=15$, FN$=5$, FP$=30$, TN$=950$; accuracy $965/1000=96.5\%$, precision $15/45=0.333$, recall $15/20=0.75$. Report recall together with precision (and the cost of each error type): accuracy is dominated by the common class and rewards the useless always-good model.
2. Mean $=5$; training MSE $=(9+1+16+0)/4=6.5$ (the variance). On test $\{3,7\}$: $(4+4)/2=4$. A learned test MSE of $5$ is worse than the baseline's $4$: the model has not earned its complexity.
3. Train-only: mean 2, population std $1.633$, $z=(4-2)/1.633=1.225$. All data: mean 26.5, std 42.46, $z=-0.530$. The first is correct. Fitting on all values lets the test point shape the transform, so a reported test score is biased (here the huge outlier inflates the standard deviation and squashes all the training features towards zero).
4. Frames from the same robot are highly correlated and share its hardware quirks, so a random split puts near-duplicates in train and test and measures memorisation. Split by robot (e.g. train on 7, validate on 1-2, test on 1-2), and use leave-one-robot-out or grouped $k$-fold; report the mean and the spread across held-out robots, and the worst robot.
5. `0.95 0.0`. Accuracy looks good, but recall is zero: the model never detects the rare class. A safety review should care about recall (and the cost of misses).
6. The test set is used to choose the learning rate, so it is part of model selection and the best of several noisy estimates is reported (winner's curse). Expected best: $0.80+1.87\times0.04\approx0.875$, even though every configuration is truly $0.80$. Fix: choose on a validation set and evaluate the chosen model on the test set once.
7. $\frac{d}{dc}\frac1N\sum(c-y_i)^2=\frac2N\sum(c-y_i)=2(c-\bar y)=0\Rightarrow c=\bar y$. For $1,2,10$: mean $4.33$, median $2$. Absolute errors: median $(1+0+8)/3=3.0$, mean $3.78$. Squared errors: mean $(11.1+5.44+32.1)/3\approx16.2$, median $(1+0+64)/3\approx21.7$. The mean is optimal for squared loss but chases outliers; report both baselines when outliers exist.
8. $SE=\sqrt{0.9\cdot0.1/200}=0.0212$; interval $0.90\pm1.96\cdot0.0212=0.90\pm0.042$. For $\pm0.02$: $n=1.96^2\cdot0.09/0.02^2\approx865$. Frames of one run are not independent, so the effective sample size is closer to the number of runs, and the interval is wider than this formula suggests.
9. A good answer states inputs (current, voltage, load, speed, temperature, route profile), the target (remaining minutes), a loss (absolute error, since a 10-minute error costs the same linearly), a baseline (mean or a physics-based discharge rate), metrics (MAE and the underestimate/overestimate asymmetry), a split by robot and by time, and shift risks (ageing batteries, new routes or temperatures).
10. A good answer shows the leak inflating the score (the grouped split gives noticeably lower and honest numbers), and a check function such as `assert set(train_groups).isdisjoint(test_groups)`.
