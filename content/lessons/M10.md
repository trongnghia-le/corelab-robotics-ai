## Vì sao học bài này?

Derive an update, then check whether it actually reduces the objective. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

Optimization changes parameters to make an objective smaller. A gradient points toward the steepest local increase, so descending takes its negative. The useful question is not whether an optimizer ran, but whether the objective, gradients, and convergence checks support the result.

## Định nghĩa và suy luận · Theory & derivation

For differentiable $J$, the first-order model is $J(\theta+\delta)\approx J(\theta)+\nabla J(\theta)^T\delta$. Choosing $\delta=-\alpha\nabla J$ gives predicted change $-\alpha\|\nabla J\|^2\le0$. Thus $\theta_{k+1}=\theta_k-\alpha\nabla J(\theta_k)$ for $\alpha>0$.

For $J(\theta)=(\theta-3)^2$, $\nabla J=2(\theta-3)$. Let $e_k=\theta_k-3$. Then $e_{k+1}=(1-2\alpha)e_k$. Convergence requires $|1-2\alpha|<1$, or $0<\alpha<1$. A direction can be locally correct while a long step overshoots.

A stationary point has zero gradient but need not be a minimum: $J(x)=-x^2$ has a stationary maximum at zero. Report objective traces, stopping criteria, and initialization. Tiny updates caused by a tiny learning rate do not prove convergence.

## Ví dụ có lời giải · Worked example

Start θ=0 and α=0.1. The gradient is −6, so θ₁=0.6 and J falls from 9 to 5.76. At α=1.1, θ₁=6.6 and J=12.96: the loss increases. On this quadratic α=0.5 reaches the solution in one step, but this special value does not generalize to arbitrary losses.

## Triển khai tham khảo · Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
theta=0.0
trace=[]
for _ in range(100):
    trace.append((theta-3)**2)
    theta -= .1*2*(theta-3)
assert trace[-1] < trace[0]
assert abs(theta-3) < 1e-6
```

## Hiểu lầm thường gặp · Failure modes

A decreasing training loss does not prove generalization. A zero gradient can indicate a saddle or maximum. Mixing a summed loss with a gradient of the mean silently changes the effective learning rate.

## So sánh và lựa chọn · Alternatives

Full-batch descent gives deterministic gradients. Stochastic descent is cheaper per update but noisy. Momentum accelerates some directions, while adaptive methods rescale updates; none removes the need to inspect the objective and evaluation protocol.
