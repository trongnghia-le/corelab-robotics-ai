## Why this matters

Derive an update, then check whether it actually reduces the objective. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

Optimization changes parameters to make an objective smaller. A gradient points toward the steepest local increase, so descending takes its negative. The useful question is not whether an optimizer ran, but whether the objective, gradients, and convergence checks support the result.

![Left: a parabola with gradient descent iterates for a small step and the first overshoot for a large step. Right: the per-step error factor as a function of step size, below one only for step sizes between zero and one.](/lesson-figures/M10.svg)

*A step size is stable only if every error component shrinks; too large a step overshoots the valley and diverges.*

## Theory and derivation

For differentiable $J$, the first-order model is $J(\theta+\delta)\approx J(\theta)+\nabla J(\theta)^T\delta$. Choosing $\delta=-\alpha\nabla J$ gives predicted change $-\alpha\|\nabla J\|^2\le0$. Thus $\theta_{k+1}=\theta_k-\alpha\nabla J(\theta_k)$ for $\alpha>0$.

For $J(\theta)=(\theta-3)^2$, $\nabla J=2(\theta-3)$. Let $e_k=\theta_k-3$. Then $e_{k+1}=(1-2\alpha)e_k$. Convergence requires $|1-2\alpha|<1$, or $0<\alpha<1$. A direction can be locally correct while a long step overshoots.

A stationary point has zero gradient but need not be a minimum: $J(x)=-x^2$ has a stationary maximum at zero. Report objective traces, stopping criteria, and initialization. Tiny updates caused by a tiny learning rate do not prove convergence.

## Worked example

Start θ=0 and α=0.1. The gradient is −6, so θ₁=0.6 and J falls from 9 to 5.76. At α=1.1, θ₁=6.6 and J=12.96: the loss increases. On this quadratic α=0.5 reaches the solution in one step, but this special value does not generalize to arbitrary losses.

### Library track
Redo the lab with SciPy and PyTorch (`pip install numpy scipy torch` in a virtual environment): `scipy.optimize.minimize` (BFGS) and `check_grad` for the gradient check, and `torch.optim.SGD` on the ill-conditioned quadratic, whose step counts must match your formulas (87 at the optimal step, 135 at $\alpha=0.05$, no convergence at $0.1$). PyTorch's momentum rule is $v\leftarrow\beta v+g,\ \theta\leftarrow\theta-\alpha v$, which differs from the lab's extension by a rescaling of $\alpha$.

```python
import numpy as np
import torch
from scipy.optimize import minimize

lam = np.array([1.0, 25.0])
J = lambda th: 0.5 * np.sum(lam * th ** 2)
g = lambda th: lam * th

# 1. SciPy: BFGS and plain gradient descent reach the same minimiser (the origin)
res = minimize(J, [1.0, 1.0], jac=g, method="BFGS")
assert res.success and np.allclose(res.x, 0, atol=1e-5)

# 2. Gradient check with scipy.optimize.check_grad (2-norm of the difference)
from scipy.optimize import check_grad
assert check_grad(J, g, np.array([0.7, -0.3])) < 1e-6
assert check_grad(J, lambda th: lam * th * [1, 24 / 25], np.array([0.7, -0.3])) > 0.1   # wrong gradient caught

# 3. PyTorch: SGD on the same quadratic; compare the step count with the formula
def steps(alpha, momentum=0.0, tol=1e-3, cap=5000):
    th = torch.tensor([1.0, 1.0], dtype=torch.float64, requires_grad=True)
    opt = torch.optim.SGD([th], lr=alpha, momentum=momentum)
    L = torch.tensor(lam)
    for i in range(cap):
        if th.abs().max() < tol: return i
        opt.zero_grad(); (0.5 * (L * th ** 2).sum()).backward(); opt.step()
    return None
a_opt = 2 / 26
assert steps(0.1) is None                       # alpha > 2/25 diverges
assert steps(0.05) == 135 and steps(a_opt) == 87
fast = steps(0.05, momentum=0.8)
assert fast is not None and fast < 87           # momentum beats the best plain step here
print("plain:", steps(a_opt), "momentum:", fast)
```

## Failure modes

A decreasing training loss does not prove generalization. A zero gradient can indicate a saddle or maximum. Mixing a summed loss with a gradient of the mean silently changes the effective learning rate.

## Alternatives and trade-offs

Full-batch descent gives deterministic gradients. Stochastic descent is cheaper per update but noisy. Momentum accelerates some directions, while adaptive methods rescale updates; none removes the need to inspect the objective and evaluation protocol.

## Exercise answers

1. $\nabla J=2(\theta-3)$. $\theta_1=1-0.25(-4)=2$, $\theta_2=2-0.25(-2)=2.5$. Losses $4,\ 1,\ 0.25$: strictly decreasing, and steps shrink (1, 0.5) because the gradient shrinks near the minimum.
2. $\ln(10^{-3})/\ln(0.8)=30.96$, so 31 steps. $\alpha=0.5$ makes the factor $0$ and solves it in one step, but only because the curvature is exactly 2; with unknown or varying curvature that value is unknown or wrong.
3. $\nabla J(0)=-2\bar r=-0.7$; optimum $b^*=\bar r=0.35$. $b_1=0-0.25(-0.7)=0.175$; $\nabla J(b_1)=-2(0.35-0.175)=-0.35$, $b_2=0.175+0.0875=0.2625$. Error factor $1-2\alpha=0.5$ (errors $0.35,0.175,0.0875$).
4. Gradient $=(\theta_1,25\theta_2)$: factors $1-\alpha$ and $1-25\alpha$. Stability needs $\alpha<2/25=0.08$. At $\alpha=0.05$: $0.95$ and $-0.25$. The slow coordinate $\theta_1$ needs $\ln(10^{-3})/\ln(0.95)=134.7\to135$ steps; the other converges quickly (oscillating). The ratio 25 is the condition number $\kappa=\lambda_{\max}/\lambda_{\min}$: the step size is bounded by the stiffest direction while progress is limited by the flattest one.
5. Factor $1-2.2=-1.2$: output `[0.0, 6.6, -1.32, 8.184]`. The loss grows $9\to12.96\to18.7\to\dots$. The gradient gives only a local first-order guarantee for small steps; a long step overshoots the valley.
6. This is gradient ascent. $\theta_1=0+0.1(-6)=-0.6$, $J=(-3.6)^2=12.96>9$. The loss trace rises on the first step. Fix: `theta -= alpha * grad`.
7. $J'=3x^2-3=0\Rightarrow x=\pm1$; $J''=6x$: $x=1$ is a local minimum ($J=-2$), $x=-1$ a local maximum ($J=2$). From $x_0=-1$ the gradient is exactly 0: it never moves though it is a maximum. From $-1.01$: $J'=0.06>0$, so $x$ decreases and runs off to $-\infty$ (the function is unbounded below). From $0.5$: $J'=-2.25<0$ so $x$ increases to the local minimum $x=1$.
8. Quadratic $\frac12\lambda\theta^2$ gives $\theta\leftarrow(1-\alpha\lambda)\theta$. Equalise $|1-\alpha\lambda_1|=|1-\alpha\lambda_2|$ with opposite signs: $1-\alpha\lambda_1=\alpha\lambda_2-1\Rightarrow\alpha=2/(\lambda_1+\lambda_2)$. For $(1,25)$: $\alpha=2/26=0.0769$; rate $24/26=0.923$; steps $\ln(10^{-3})/\ln(0.923)=86.3\to87$.
9. Start with a large $\alpha$, multiply by the shrink factor until the Armijo inequality holds. At $\theta=0$, $g=-6$, $J=9$: $\alpha=2$ gives $\theta'=12$, $J=81$ (reject); $\alpha=1$ gives $\theta'=6$, $J=9>9-10^{-4}\cdot36$ (reject); $\alpha=0.5$ gives $\theta'=3$, $J=0$ (accept): two halvings, step 0.5. Also log $\|g\|$ against a tolerance (and the relative decrease of $J$) as stopping criteria.
10. A good answer shows a U-shaped curve of steps versus $\alpha$ with best value near $2/26\approx0.077$ (about 170 steps to a $10^{-6}$ tolerance, since $\ln10^{-6}/\ln(24/26)\approx173$), growth for $\alpha>0.08$, and the discussion that the conditioning, not the step size alone, limits speed.
