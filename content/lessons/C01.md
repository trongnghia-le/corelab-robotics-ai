## Why this matters

Close the loop on a simple model and reason about gain and disturbance. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A feedback controller measures what happened and changes input based on the discrepancy from a target. This can correct disturbances, but it also creates a dynamical system whose stability must be checked. A larger gain is not automatically a better controller.

## Theory and derivation

Consider $\dot x=u+d$ with constant reference $r$, disturbance $d$, and error $e=r-x$. Proportional feedback $u=ke$ gives $\dot e=-ke-d$. With $d=0$, the solution is $e(t)=e(0)e^{-kt}$, stable for $k>0$. For constant $d$, equilibrium satisfies $e_*=-d/k$, so proportional control does not generally remove steady-state error.

Integral action introduces $\dot z=e$ and $u=k_pe+k_iz$, which can reject constant disturbances when the closed-loop system is stable. Saturated actuators can accumulate integral state, causing windup; the controller must account for input limits. A derivative term responds to error rate but can amplify noisy measurements.

With sampled proportional control and Euler plant update, $e_{n+1}=(1-hk)e_n$ for $d=0$. Thus $0<hk<2$ is required in this ideal discrete model. Delays, unmodeled dynamics, and noise impose additional limits in real systems.

## Worked example

For ẋ=u, r=1, x₀=0, k=2, the initial control is 2 and continuous error after one second is e⁻²≈0.1353. If d=0.2, the equilibrium error is −0.1, meaning x settles at 1.1. The sign is consistent: the positive disturbance needs a negative control to balance it.

### Library track
Redo the lab with SciPy (install NumPy and SciPy locally, for example in a virtual environment). Integrate the continuous loop with `scipy.integrate.solve_ivp` and compare it with your Euler simulation and the closed form, check the sampled pole against $hk<2$, and use `scipy.signal.step` for the PI loop. The asserts are the checks; the Euler `simulate_p` with a small `h` should agree with the `solve_ivp` trajectory to about $h$.

```python
import numpy as np
from scipy.integrate import solve_ivp
from scipy import signal

k, d, r = 2.0, 0.2, 1.0
# 1. ODE solver vs closed form x(t) = (r + d/k)(1 - e^{-kt}) for x(0) = 0
sol = solve_ivp(lambda t, x: k * (r - x) + d, (0, 5), [0.0], rtol=1e-9, atol=1e-12,
                t_eval=np.linspace(0, 5, 11))
assert np.allclose(sol.y[0], (r + d / k) * (1 - np.exp(-k * sol.t)), atol=1e-7)
print("P settles at", round(sol.y[0, -1], 4), "(theory", r + d / k, ")")

# 2. Sampled loop: the pole of e_{n+1} = (1 - h k) e_n leaves the unit circle at h k = 2
for h in (0.1, 0.5, 1.0, 1.2):
    pole = 1 - h * k
    assert (abs(pole) < 1) == (h * k < 2)

# 3. PI error dynamics s^2 + kp s + ki = 0 (kp=2, ki=1): double root at -1
kp, ki = 2.0, 1.0
assert np.allclose(np.roots([1, kp, ki]), -1.0, atol=1e-6)

# 4. Reference step through PI: x/r = (kp s + ki)/(s^2 + kp s + ki); z(0)=0
t, y = signal.step(signal.lti([kp, ki], [1, kp, ki]), T=np.linspace(0, 10, 2001))
print("final", round(y[-1], 4), "peak", round(y.max(), 4))
assert abs(y[-1] - 1) < 1e-3 and 1.13 < y.max() < 1.14   # overshoot from the PI zero
```

Expected: `P settles at 1.1 (theory 1.1 )` and `final 1.0 peak 1.1353`. Note the last line: the roots are critically damped, yet a unit reference step still overshoots by about 13.5% because the PI controller adds a zero.

## Failure modes

Small tracking error does not establish robust stability. A controller tested without delay may fail with delay. Error sign conventions must match the control law; reversing one sign creates positive feedback.

## Alternatives and trade-offs

Open-loop feedforward anticipates a known model; feedback corrects mismatch. Proportional control is simple, integral action removes some steady errors, and derivative action can add damping but is noise-sensitive. Compare them using the same plant and limits.

## Exercise answers

1. $e_*=-d/k=-0.5/5=-0.1$: the plant ends $0.1$ above the reference (the controller must push $u=-d$, which needs negative error). Doubling $k$ halves it ($-0.05$). Large $k$ is limited by actuator saturation, sampling ($hk<2$), delays and noise amplification.
2. $u=4(2-0.5)=6$. The actuator saturates, so the plant receives $5$. The controller is more aggressive than the hardware allows, which is where windup begins once an integrator is added.
3. $\tau=1/k=2$ s. $e(2)=3e^{-1}\approx1.10$ cm. Below 5% when $e^{-0.5t}<0.05$, $t>\ln(20)/0.5\approx5.99$ s, about $3\tau$.
4. Stable for $k<2/h=40$. For $k=30$: $1-1.5=-0.5$, the error flips sign every step and halves: stable but oscillating. Continuous simulation has no such sign flip (the factor is $e^{-hk}>0$); sampling, delay and computation time create it on a real robot.
5. With $k=10$: factor 0, so $x$ reaches $1$ in one step: `1.0`. With $k=25$: factor $-1.5$, so $x=2.5,\,-1.25,\,4.375$. Output: `1.0 4.375`. The error magnitude grows by 1.5 per step: unstable.
6. The error sign is reversed: $e=x-r$ gives $\dot e=+ke$, positive feedback, $e(t)=e_0e^{kt}$. Fix: `e = r - x`.
7. $\dot e=-\dot x=-(u+d)=-k_pe-k_iz-d$. At equilibrium $\dot z=e=0$ and $\dot e=0$, so $k_iz_*=-d$, $z_*=-d/k_i$: the integrator holds exactly the disturbance cancellation. Differentiating: $\ddot e=-k_p\dot e-k_ie$ (since $\dot d=0$). Roots of $s^2+2s+1$: $s=-1$ double (critically damped: no oscillation). For a disturbance step starting at rest, $e(t)=-dt\,e^{-t}$ never changes sign, so there is no overshoot. A reference step with $z(0)=0$ is different: $e(t)=(1-t)e^{-t}$ crosses zero at $t=1$, so $x$ overshoots by about $e^{-2}\approx13.5\%$ because the integral term adds a zero to the response.
8. While $u$ saturates, the error stays large, so $z$ keeps integrating. When the output reaches the target, $z$ is huge and keeps $u$ saturated in the wrong direction (overshoot). Fixes: clamp or conditionally stop integrating while saturated (simple, may be slow to recover); back-calculation (feed saturation difference to the integrator; more tuning). Log $z$, unsaturated and saturated $u$: windup shows $z$ growing while $u$ is pinned.
9. Fixed point: $e=(1-hk)e-hd\Rightarrow hk\,e=-hd\Rightarrow e_*=-d/k$, independent of $h$. Subtracting $e_*$: $e_{n+1}-e_*=(1-hk)(e_n-e_*)$, hence the closed form. A faster sample rate changes how quickly (and whether) you converge, not where: only integral action (or feedforward of $d$) changes the equilibrium.
10. A good answer reports: P leaves $-d/k$; PI reaches 0 after the disturbance step with some transient; anti-windup shows markedly smaller overshoot under saturation (in the lab: about 0.10 versus 4.07 for the 5-unit step). It names unmodelled effects still to test: delay, noise, quantisation, real actuator limits and rate limits.
