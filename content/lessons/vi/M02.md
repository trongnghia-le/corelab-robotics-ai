## Vì sao điều này quan trọng

Biểu diễn hướng và độ lớn trước khi dùng đến một thư viện mảng. Bài học này phát triển phép tính cốt lõi trước khi yêu cầu bạn áp dụng nó vào một bối cảnh mới. Hãy làm bài chẩn đoán trước nếu bạn nghĩ mình đã biết rồi; việc từng dùng công cụ không phải là bằng chứng của sự hiểu.

## Trực giác

Một mũi tên cho bạn biết cả đi bao xa lẫn đi theo hướng nào. Vector là độ dịch chuyển (displacement), không phải nơi bạn vẽ mũi tên. Tọa độ mô tả vector đó so với một cơ sở (basis). Viết lại cơ sở làm đổi các con số, trong khi độ dịch chuyển vật lý có thể không đổi.

## Lý thuyết và suy dẫn

Trong $\mathbb R^n$, phép cộng và nhân vô hướng tác động theo từng thành phần: $(u+v)_i=u_i+v_i$ và $(\alpha v)_i=\alpha v_i$. Tích vô hướng $u^Tv=\sum_i u_i v_i$ là một số vô hướng. Khai triển $\|u-v\|^2=(u-v)^T(u-v)$ cho ra $\|u\|^2+\|v\|^2-2u^Tv$. So với định lý cosin ta được $u^Tv=\|u\|\|v\|\cos\theta$.

Chuẩn Euclid là $\|v\|_2=\sqrt{v^Tv}$. Vector hướng đơn vị là $\hat v=v/\|v\|$, chỉ xác định khi $v\ne0$. Chiếu $u$ lên một $v$ khác không cho $\mathrm{proj}_v u=(u^Tv/v^Tv)v$. Phần dư vuông góc với $v$: nhân $u-\mathrm{proj}_v u$ với $v^T$ cho kết quả bằng không. Đây là một tính chất kiểm chứng hữu ích, không chỉ là công thức để học thuộc.

## Ví dụ có lời giải

Cho u=(3,4), v=(1,0). Tích vô hướng của chúng là 3 và ‖u‖=5. Hình chiếu của u lên v là (3,0); phần dư (0,4) có tích vô hướng bằng không với v. Độ dịch chuyển (3,4) và điểm (3,4) có cùng tọa độ nhưng ý nghĩa khác nhau: cộng hai vị trí nói chung không phải là một độ dịch chuyển vật lý.

def dot(u, v):
    if len(u) != len(v):
        raise ValueError("dimension mismatch")
    return sum(a * b for a, b in zip(u, v))

assert dot([1, 2], [-2, 1]) == 0

### Kiểm thử
Dán đoạn này bên dưới code khởi đầu (cùng một file) rồi chạy. Mọi kiểm tra đều là `assert` thuần; lần thất bại đầu tiên sẽ dừng chương trình.

```python
import random
def close(a, b, t=1e-9): return abs(a - b) < t
def raises(f, *a):
    try: f(*a)
    except ValueError: return True
    return False
# hand-computed
assert dot([1, 2, 3], [4, -5, 6]) == 12 and dot([1, 2], [-2, 1]) == 0
assert close(norm([3, 4]), 5.0)
assert all(close(a, b) for a, b in zip(normalize([3, 4]), [0.6, 0.8]))
assert close(math.degrees(angle([1, 2], [3, -1])), 81.869898, 1e-5)
assert project([4, 3], [1, 1]) == [3.5, 3.5]
t, d = cross_track([4, 3], [0, 0], [30, 10])         # infinite-line example, inside the segment
assert close(t, 0.15) and close(d, math.sqrt(2.5))
t, d = cross_track([-3, 4], [0, 0], [10, 0])         # before the start: clamps to a
assert t == 0.0 and close(d, 5.0)
t, d = cross_track([13, 4], [0, 0], [10, 0])         # beyond the end: clamps to b
assert t == 1.0 and close(d, 5.0)
# errors
assert raises(dot, [1, 2], [1, 2, 3]) and raises(normalize, [0, 0])
assert raises(project, [1, 1], [0, 0]) and raises(cross_track, [1, 1], [2, 2], [2, 2])
# invariants on random vectors: symmetry, orthogonal residual, Pythagoras, Cauchy-Schwarz
random.seed(1)
for _ in range(200):
    u = [random.uniform(-5, 5) for _ in range(3)]; v = [random.uniform(-5, 5) for _ in range(3)]
    assert close(dot(u, v), dot(v, u))
    pr = project(u, v); res = [a - b for a, b in zip(u, pr)]
    assert close(dot(res, v), 0.0, 1e-9)
    assert close(norm(u) ** 2, norm(pr) ** 2 + norm(res) ** 2, 1e-9)
    assert abs(dot(u, v)) <= norm(u) * norm(v) + 1e-12
print("angle(deg) =", round(math.degrees(angle([1, 2], [3, -1])), 3), "| cross-track =", round(cross_track([4, 3], [0, 0], [30, 10])[1], 4))
print("all tests passed")
```

### Thực hành với thư viện
Làm lại bài lab bằng NumPy (`pip install numpy` trong một môi trường ảo): `@`/`np.dot`, `np.linalg.norm`, `np.clip` trước `np.arccos`, và một kiểm tra vector hóa các bất biến của lab (Cauchy-Schwarz, phần dư vuông góc) trên 200 cặp vector ngẫu nhiên cùng lúc bằng `np.einsum`. Nó cũng thêm sai số ngang có dấu 2D từ thử thách mở rộng: tích có hướng 2D của hướng đường với $p-a$, chia cho độ dài đoạn, dương khi $p$ ở bên trái hướng di chuyển.

```python
import numpy as np

u = np.array([1.0, 2.0, 3.0]); v = np.array([4.0, -5.0, 6.0])
assert np.dot(u, v) == 12 and np.isclose(np.linalg.norm([3, 4]), 5.0)

def angle(a, b):
    c = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
    return np.arccos(np.clip(c, -1.0, 1.0))        # clip, as in the lab
assert np.isclose(np.degrees(angle(np.array([1., 2.]), np.array([3., -1.]))), 81.869898, atol=1e-5)

def project(u, v): return (u @ v) / (v @ v) * v
assert np.allclose(project(np.array([4., 3.]), np.array([1., 1.])), [3.5, 3.5])

def cross_track(p, a, b):
    ab = b - a
    t = np.clip((p - a) @ ab / (ab @ ab), 0.0, 1.0)
    return t, np.linalg.norm(p - (a + t * ab))
t, d = cross_track(np.array([4., 3.]), np.array([0., 0.]), np.array([30., 10.]))
assert np.isclose(t, 0.15) and np.isclose(d, np.sqrt(2.5))

# Signed lateral error in 2D: z-component of path-direction x (p - a); positive = left of travel
def signed_lateral(p, a, b):
    ab, ap = b - a, p - a
    return (ab[0] * ap[1] - ab[1] * ap[0]) / np.linalg.norm(ab)
assert np.isclose(signed_lateral(np.array([4., 3.]), np.array([0., 0.]), np.array([30., 10.])), 1.5811, atol=1e-4)

# Batch: random vectors, check the invariants of the lab in one vectorised shot
rng = np.random.default_rng(1)
U = rng.uniform(-5, 5, (200, 3)); V = rng.uniform(-5, 5, (200, 3))
dots = np.einsum("ij,ij->i", U, V)
assert np.all(np.abs(dots) <= np.linalg.norm(U, axis=1) * np.linalg.norm(V, axis=1) + 1e-12)   # Cauchy-Schwarz
P = (dots / np.einsum("ij,ij->i", V, V))[:, None] * V
assert np.allclose(np.einsum("ij,ij->i", U - P, V), 0.0)                                       # orthogonal residual
print("library track ok")
```

## Đáp án bài tập

1. Độ dịch chuyển ròng $(1,4)$, khoảng cách $\sqrt{17}\approx4.123$ m. Tổng quãng đường $\sqrt5+\sqrt{10}\approx2.236+3.162=5.398$ m. Bất đẳng thức tam giác $\|u+v\|\le\|u\|+\|v\|$ chỉ đạt dấu bằng khi hai chuyển động cùng hướng; ở đây chúng rẽ hướng.
2. Tốc độ $\sqrt{9+16}=5$ m/s; hướng $(0.6,0.8)$. Các vector $(3,4)$ và $(-4,3)$ vuông góc (dot $=-12+12=0$), nên tích đúng bằng không: các hướng trực giao.
3. $a\cdot b=3-2=1$; $\|a\|\|b\|=\sqrt5\sqrt{10}=\sqrt{50}$; $\cos\theta=1/\sqrt{50}\approx0.1414$, $\theta\approx81.9^\circ$. Tích vô hướng dương nghĩa là nhọn (cosin dương vì các chuẩn dương), nên đúng, chỉ riêng dấu đã quyết định nhọn hay tù.
4. $w\cdot h=7$, $h\cdot h=2$, nên thành phần dọc hướng đi là $3.5\,h=(3.5,3.5)$, độ lớn $7/\sqrt2\approx4.95$ kn (gió xuôi: nó đổi tốc độ so với mặt đất, do đó đổi thời gian đến). Thành phần ngang là $(0.5,-0.5)$, độ lớn $\approx0.707$ kn: nó đẩy phương tiện sang một bên.
5. Nó trả về $\sum x_i^2$, thiếu căn bậc hai. $(3,4)$ trả về 25, không phải 5. Nó đúng tình cờ với $(1,0)$ hoặc $(0,1)$ (vector đơn vị). Property test: `norm(c*v) == abs(c)*norm(v)` thất bại với $c=2$ (cho 4 lần thay vì 2 lần).
6. $4-10+18=12$; $-2+2=0$; lời gọi thứ ba im lặng bỏ qua phần tử thừa (`zip` cắt cụt) và trả về $1+4=5$. Đầu ra `12 0 5`. Sửa: kiểm tra `len(u) == len(v)` và ném `ValueError`.
7. $p\cdot d=12+3=15$, $d\cdot d=10$, $t=1.5$; điểm chiếu $(4.5,1.5)$; phần dư $(-0.5,1.5)$, sai số ngang $\sqrt{2.5}\approx1.581$. Kiểm tra: $(-0.5)(3)+(1.5)(1)=0$.
8. $r\cdot v=u\cdot v-t\,v\cdot v=0$. Khi đó $\|u\|^2=\|tv+r\|^2=t^2\|v\|^2+2t\,v\cdot r+\|r\|^2=t^2\|v\|^2+\|r\|^2\ge t^2\|v\|^2=(u\cdot v)^2/\|v\|^2$. Nhân với $\|v\|^2$ và lấy căn bậc hai.
9. Khoảng cách $\|a-b\|=\|(1,2,3)\|=\sqrt{14}\approx3.742$; cosin $=28/(\sqrt{14}\sqrt{56})=1$. Độ tương tự cosin bỏ qua gain, nên dùng nó để khớp mẫu bất kể tỉ lệ; dùng khoảng cách Euclid (hoặc so sánh các chuẩn) khi bản thân gain hay độ lớn quan trọng.
10. Một câu trả lời tốt kẹp $t=\mathrm{clip}(\,(p-a)\cdot(b-a)/\|b-a\|^2,0,1)$, trả về $t$ và $\|p-(a+t(b-a))\|$, từ chối $a=b$, và kiểm thử: một điểm giữa đoạn, một điểm trước $a$ (t=0, khoảng cách tới $a$), một điểm vượt quá $b$ (t=1), và góc của chữ L nơi hai đoạn cách đều.
