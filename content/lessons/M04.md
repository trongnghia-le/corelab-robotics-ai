## Why this matters

Understand what a linear solver can and cannot recover. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A linear system asks whether a target can be assembled from available directions. Redundant directions do not create new capabilities. In robot estimation, a sensor can constrain some directions while leaving others ambiguous; a solver cannot manufacture information about the missing directions.

Think of the columns of $A$ as the control levers of a machine and the vector $b$ as the position you want to reach. Each lever pushes in one fixed direction, and the unknown $x$ says how hard to push each. Two levers that push in different directions can reach every point in the plane; two levers that push in the same direction reach only a line, no matter how hard you pull. A system that asks for a point off that line is not "hard", it is impossible, and a more powerful computer does not change it. The opposite surprise happens when you have more levers than directions you need: several combinations of pushes reach the same target, so the answer is a whole family and the question becomes which member to choose.

A robot example. Two joint encoders of a planar arm are wired so that they both report the sum $q_1+q_2$ (a wiring mistake). Whatever you do, the two readings are the same number, so the equations are $q_1+q_2=75$ and $q_1+q_2=75$ again: two equations, but only one piece of information. You can recover the sum, never the pair. If one reading drifts by 0.5 degrees, the equations contradict each other, and the only honest answer is a compromise (least squares) together with a warning that the data disagree.

**Predict before you compute.** For the equations $x+y=3$ and $x-y=1$, how many solutions are there? Change the second to $2x+2y=6$, and then to $2x+2y=7$. Before reading the figure, say for each version whether you expect one solution, none or infinitely many, and which property of the coefficient columns decides it.

**The common wrong intuition.** "Two equations and two unknowns always have one solution", or "more equations than unknowns means no solution". Neither is true. What matters is not the count of equations but the number of *independent* ones, that is the rank. Three equations can be redundant (and consistent) while two equations can already contradict each other. The second trap is to read a tiny residual as success: a solver that returns a small $\|Ax-b\|$ has found a point near the column space, which says nothing about whether the unknowns were determined by the data.

## Theory and derivation

The span of columns of $A$ is every vector $Ax$. Columns are independent if $Ac=0$ implies $c=0$. Rank counts independent column directions. A system $Ax=b$ has a solution exactly when $b$ lies in that column space; a solution is unique when the nullspace is trivial.

Elimination replaces equations by equivalent combinations. For $x+y=3$ and $x-y=1$, subtract the second equation from the first to get $2y=2$, hence $y=1$ and $x=2$. If the second equation were $2x+2y=6$, it would add no constraint: infinitely many solutions remain.

For inconsistent measurements, minimize $J(x)=\frac12\|Ax-b\|^2$. Differentiating yields $A^T(Ax-b)=0$: the residual is perpendicular to the column space. This gives normal equations $A^TAx=A^Tb$. Deriving them clarifies the geometry; numerically, QR or SVD avoids the condition-number squaring caused by explicitly forming $A^TA$. Here the condition number is $\kappa(A)=\sigma_1/\sigma_n$, the ratio of the largest to the smallest singular value (defined with the SVD in the rank view below), and $u=2^{-53}\approx1.1\times10^{-16}$ denotes the unit round-off of double precision.

### Independence, dimension and basis

Vectors $a_1,\dots,a_k$ are **linearly independent** if $\beta_1a_1+\dots+\beta_ka_k=0$ only for $\beta_1=\dots=\beta_k=0$; otherwise one of them is a combination of the others (Boyd and Vandenberghe, *Introduction to Applied Linear Algebra* (VMLS), §5.1). Independence is exactly what makes a representation unique. If $x=\sum\beta_ja_j=\sum\gamma_ja_j$ then $\sum(\beta_j-\gamma_j)a_j=0$, so independence forces $\beta_j=\gamma_j$ for all $j$. Applied to the columns of $A$, this is the statement "the solution of $Ax=b$ is unique if and only if the columns are independent": two different solutions would differ by a nonzero vector in the nullspace.

How many independent directions can there be? The **independence-dimension inequality** says that if $n$-vectors $a_1,\dots,a_k$ are independent then $k\le n$; any $n+1$ vectors in $\mathbb R^n$ are dependent (VMLS §5.2, with an induction proof there). Consequently $n$ independent $n$-vectors form a **basis**: any $b$ can be written as a combination of them, because the $n+1$ vectors $a_1,\dots,a_n,b$ must be dependent, and the coefficient of $b$ in the dependency cannot be zero (otherwise the $a_j$ would be dependent), so $b$ can be solved for. Combined with uniqueness, every $b$ has exactly one set of coordinates in a basis. For a non-square $A$ the same reasoning applies inside the column space: its **dimension** is the largest number of independent columns, which we call the **rank**, and a set of independent columns spanning the column space is a basis of it. The three standard shapes follow at once. A tall matrix ($m>n$) cannot have more than $n$ independent columns, so its columns can never fill $\mathbb R^m$: $Ax=b$ is solvable only for special $b$. A wide matrix ($m<n$) has more than $m$ columns in $\mathbb R^m$, so its columns are dependent, the nullspace is nontrivial, and solutions are never unique. Only a square matrix with independent columns gives exactly one solution for every $b$.

**Example.** A planar sensor rig has three candidate directions $a_1=(1,0,1)$, $a_2=(0,1,1)$ and $a_3=(1,1,2)$ in a 3-D measurement space. What are the rank and the span of the three vectors, can the targets $(1,1,2)$ and $(1,1,3)$ be reached, and when would a fourth direction help?

**Solution.** Since $a_3=a_1+a_2$, the combination $1\cdot a_1+1\cdot a_2-1\cdot a_3=0$ is a nontrivial dependency, so the rank is 2 and the three vectors span only a plane through the origin. Every combination is $c_1a_1+c_2a_2+c_3a_3=(c_1+c_3,\ c_2+c_3,\ c_1+c_2+2c_3)$, whose third entry is the sum of the first two. The target $(1,1,2)$ satisfies $1+1=2$ (it is $a_3$ itself, with $c=(0,0,1)$), so it is reachable. The target $(1,1,3)$ has $1+1=2\ne3$, so it has no solution, however the coefficients are chosen. A fourth direction helps only if it leaves the plane, for instance $(0,0,1)$ ($0+0=0\ne1$), which raises the rank to 3.

### Elimination, pivots and the set of all solutions

Gaussian elimination solves $Ax=b$ by adding multiples of one equation to another and swapping equations. Each such step is reversible (undo it by subtracting the same multiple), so the new system has exactly the same solutions as the old one (MIT 18.06SC, lectures on solving $Ax=0$ and $Ax=b$). The goal is a staircase (echelon) form in which each nonzero row starts further right than the row above; the first nonzero entry of each row is a **pivot**, and the columns that contain pivots are the **pivot columns**. A system in this form is solved from the bottom by back substitution (VMLS §11.3): the last pivot variable is found first, then each earlier one by substitution, and the process needs about $n^2$ flops for an $n\times n$ triangular system.

Three facts follow, all because row operations multiply $A$ on the left by an invertible matrix $E$, so $Ac=0$ if and only if $(EA)c=0$: linear relations among the columns are unchanged by elimination. First, the pivot columns are independent (in the echelon form that is visible) and every other column is a combination of them, so **rank equals the number of pivots** $r$. Second, the remaining $n-r$ columns correspond to **free variables**: you may choose them arbitrarily and solve for the pivot variables. Setting one free variable to 1 and the others to 0 gives a *special solution* of $Ax=0$; these $n-r$ vectors are independent and span the nullspace, so $\dim\operatorname{null}(A)=n-r$ (the rank-nullity relation). Third, the complete solution of a consistent system is
$$x=x_p+t_1s_1+\dots+t_{n-r}s_{n-r},$$
a particular solution $x_p$ plus any combination of special solutions; if $Ax_p=b$ and $Ax=b$ then $A(x-x_p)=0$, which proves that nothing else can occur.

Consistency shows up in the zero rows. If after elimination a row reads $0=c$ with $c\ne0$, the system is inconsistent: $b$ is outside the column space. Together this gives a complete classification by the rank $r$ of an $m\times n$ matrix: $r=n=m$, one solution for every $b$; $r=n<m$, at most one solution (and none for most $b$); $r=m<n$, a solution for every $b$ and infinitely many of them; $r<m$ and $r<n$, usually none, and infinitely many if one exists. The last two cases are those that the least-squares and minimum-norm constructions below resolve. In floating point the exact pivot test needs a tolerance, so a robust solver reads the rank from singular values, as discussed at the end of this section.

**Example.** Solve $x+2y+z=6$, $2x+4y+3z=13$. Give the complete solution and the solution of smallest norm.

**Solution.** Subtracting twice row 1 from row 2 gives $z=13-12=1$. The pivots are in columns 1 and 3, so $r=2$ and $y$ is free. Row 1 gives $x=6-2y-z=5-2y$. With $y=t$ the complete solution is $(5-2t,\,t,\,1)$: the particular solution $(5,0,1)$ plus $t$ times the special solution $(-2,1,0)$. Check with $t=2$: $x=1$, so $(1,2,1)$ gives $1+4+1=6$ and $2+8+3=13$. The smallest norm minimises $\|x\|^2=(5-2t)^2+t^2+1$, whose derivative $-4(5-2t)+2t=10t-20$ vanishes at $t=2$, so the solution of smallest norm is $(1,2,1)$.

### Rank and nullity from the definitions

For an $m\times n$ matrix $A$ define the **column space** $\operatorname{col}(A)=\{Ax:x\in\mathbb R^n\}\subseteq\mathbb R^m$ and the **null space** $\operatorname{null}(A)=\{x\in\mathbb R^n:Ax=0\}$. Both are subspaces (each contains $0$ and is closed under addition and scaling), because $A(x+y)=Ax+Ay$ and $A(cx)=c\,Ax$. Linearity is the only property of $A$ used below. The **rank** is $r=\dim\operatorname{col}(A)$ and the **nullity** is $\dim\operatorname{null}(A)$. The elimination argument above counted pivots; the theorem below derives the same count without any pivots, which also shows that the number of pivots cannot depend on the order in which you eliminate (Axler, *Linear Algebra Done Right*, 3rd ed., Theorem 3.22, the "fundamental theorem of linear maps").

**Theorem (rank-nullity).** For every $m\times n$ matrix $A$, $\operatorname{rank}(A)+\dim\operatorname{null}(A)=n$.

**Proof.** Let $k=\dim\operatorname{null}(A)$ and let $v_1,\dots,v_k$ be a basis of $\operatorname{null}(A)$ (an empty list if $k=0$). A list of independent vectors in $\mathbb R^n$ can be extended to a basis of $\mathbb R^n$: keep adding a vector outside the span of those already chosen; each addition keeps the list independent, and by the independence-dimension inequality the process stops after at most $n$ vectors, when the span is all of $\mathbb R^n$. So there are $w_1,\dots,w_{n-k}$ such that $v_1,\dots,v_k,w_1,\dots,w_{n-k}$ is a basis of $\mathbb R^n$. We show that $Aw_1,\dots,Aw_{n-k}$ is a basis of $\operatorname{col}(A)$; then $r=n-k$.
*They span.* Any $x\in\mathbb R^n$ is $x=\sum_i\alpha_iv_i+\sum_j\beta_jw_j$. Applying $A$ and using $Av_i=0$ gives $Ax=\sum_j\beta_j\,Aw_j$. So every vector of $\operatorname{col}(A)$ is a combination of the $Aw_j$.
*They are independent.* Suppose $\sum_j\beta_jAw_j=0$. Then $A\big(\sum_j\beta_jw_j\big)=0$, so $\sum_j\beta_jw_j$ lies in $\operatorname{null}(A)$ and equals $\sum_i\alpha_iv_i$ for some $\alpha_i$. Hence $\sum_i\alpha_iv_i-\sum_j\beta_jw_j=0$ is a vanishing combination of a basis of $\mathbb R^n$, so every coefficient is zero; in particular every $\beta_j=0$. $\square$

*Where it stops being true.* The proof used linearity twice (that $A$ of a sum is the sum of the $A$'s, and that the kernel is a subspace). For a nonlinear map the solution set of $f(x)=0$ need not be a subspace at all: for $f(x,y)=x^2+y^2-1$ it is the unit circle, which does not contain the sum of two of its points, and no formula "dimension of the input = kernel + image" follows from this argument. In floating point the *computed* rank also changes with the tolerance (see the second worked case), so the theorem is a statement about exact arithmetic.

**Example.** A mixing matrix maps four hidden quantities to three sensor readings, $A=\begin{pmatrix}1&2&0&1\\0&0&1&3\\1&2&1&4\end{pmatrix}$. Find the rank, the nullity and two independent null vectors, and say how many combinations of the four unknowns are visible in the data.

**Solution.** Row 3 equals row 1 plus row 2, and rows 1 and 2 are independent (row 2 has a nonzero entry where row 1 has a zero), so $r=2$ and the nullity is $4-2=2$. Two independent null vectors are $v_1=(-2,1,0,0)$ and $v_2=(-1,0,-3,1)$: $Av_1=(-2+2,\,0,\,-2+2)=(0,0,0)$ and $Av_2=(-1+1,\,-3+3,\,-1-3+4)=(0,0,0)$. Four unknowns, but only two independent combinations of them are visible in the data.

### The solution set is a particular solution plus the null space

**Theorem.** Suppose $Ax_p=b$. Then $\{x:Ax=b\}=\{x_p+z:\ z\in\operatorname{null}(A)\}$. The set is empty exactly when $b\notin\operatorname{col}(A)$, it has exactly one point exactly when $\operatorname{null}(A)=\{0\}$, and otherwise it is a translate of a subspace of dimension $n-r$.

**Proof.** ($\supseteq$) If $z\in\operatorname{null}(A)$ then $A(x_p+z)=Ax_p+Az=b+0=b$. ($\subseteq$) If $Ax=b$, put $z=x-x_p$; then $Az=Ax-Ax_p=b-b=0$, so $z\in\operatorname{null}(A)$ and $x=x_p+z$. The set is nonempty iff some $x$ has $Ax=b$, which is the definition of $b\in\operatorname{col}(A)$. If $\operatorname{null}(A)=\{0\}$ the description has the single point $x_p$; if some $z\ne0$ lies in the null space, then $x_p$ and $x_p+z$ are two different solutions. Finally the map $z\mapsto x_p+z$ is a translation, so the solution set has the dimension of $\operatorname{null}(A)$, which is $n-r$ by rank-nullity. $\square$

*Where it stops being true.* The solution set is not a subspace when $b\ne0$ (it does not contain $0$), so one cannot add two solutions of $Ax=b$ and stay inside it; differences of solutions, not sums, lie in the null space. And the proof is linear through and through: for $x^2=4$ the solutions are $2$ and $-2$, but the "null set" of $x^2=0$ is just $\{0\}$, so "particular plus null" would miss $-2$.

**Example.** Take the mixing matrix above and the readings $b=(3,4,7)$. Find the complete solution of $Ax=b$, test it for one choice of the parameters, and decide whether $b=(3,4,8)$ can be explained.

**Solution.** Setting the free variables $x_2=x_4=0$ gives the particular solution $x_p=(3,0,4,0)$ (the rows give $x_1=3$, $x_3=4$, and row 3 reads $3+4=7$). Adding the null space, the complete solution is $x=(3,0,4,0)+s(-2,1,0,0)+t(-1,0,-3,1)=(3-2s-t,\ s,\ 4-3t,\ t)$. With $s=1$, $t=2$ this is $(-1,1,-2,2)$ and indeed $-1+2+0+2=3$, $0+0-2+6=4$, $-1+2-2+8=7$. For the readings $b=(3,4,8)$ no solution exists, because $8\ne3+4$ and $b$ must satisfy the same relation as the rows (row 3 = row 1 + row 2).

### Four views: Ax = b as a combination of columns

**Algebra.** Write $A=[a_1\ a_2\ \cdots\ a_n]$ by columns. Then $Ax=x_1a_1+x_2a_2+\dots+x_na_n$: the unknowns are the coefficients of a combination, and "$Ax=b$ is solvable" means "$b$ is in the span of the columns". Reading the same product by rows, $\tilde a_i^{\,T}x=b_i$ says that $x$ lies on $m$ hyperplanes at once. The two readings are the same arithmetic; the column reading is the one that explains rank, because it asks which targets can be assembled at all.

**Geometry.** With two independent columns in $\mathbb R^3$ all combinations fill a plane through the origin (the grey sheet in the 3D block further down). A target $b$ is either on the sheet, with exactly one pair of coefficients, or off it, with none. Three independent columns fill the whole space; two parallel columns fill only a line (the first figure of this lesson).

**Code.**
```python
import numpy as np
A = np.array([[-0.3, -0.3], [0.4, 0.0]]); x = np.array([0.5, -1.0])
by_rows = A @ x                                  # row reading: dot products
by_cols = x[0] * A[:, 0] + x[1] * A[:, 1]        # column reading: a combination of columns
assert np.allclose(by_rows, by_cols)
```

**Physical meaning.** For a robot arm the Jacobian $J$ maps joint rates $\dot q$ (rad/s) to tip velocity $v$ (m/s), $v=J\dot q$. Column $j$ is the tip velocity produced by one unit of rate of joint $j$, so its entries are in metres. "Can the tip move with velocity $v$?" is exactly "is $v$ in the span of the columns of $J$?".

**Example.** A planar two-link arm with $l_1=0.4$ m, $l_2=0.3$ m at $q=(0^\circ,90^\circ)$ has $J=\begin{pmatrix}-0.3&-0.3\\0.4&0\end{pmatrix}$ m. Find the tip velocity for the joint rates $\dot q=(0.5,-1)$ rad/s, and say whether every tip velocity can be commanded at this pose.

**Solution.** The tip velocity is $v=J\dot q$, a combination of the columns: $0.5\,(-0.3,0.4)-1\,(-0.3,0)=(-0.15+0.3,\ 0.20)=(0.15,\,0.20)$ m/s. Conversely, $\det J=(-0.3)(0)-(-0.3)(0.4)=0.12\ne0$, so the two columns span the plane and every tip velocity has exactly one joint-rate command.

### Four views: rank and the null space

**Algebra.** The rank $r$ is the number of independent columns, the null space has dimension $n-r$ (previous theorem) and its basis is the list of special solutions. The row space and the null space are orthogonal: $Ax=0$ says that every row of $A$ has zero dot product with $x$, hence so does every combination of rows. Together, $\mathbb R^n=\operatorname{row}(A)\oplus\operatorname{null}(A)$ with dimensions $r$ and $n-r$.

**Geometry.** Think of $A$ as a map from $\mathbb R^n$ to $\mathbb R^m$. The null space is the set of inputs that the map squashes onto the origin; every line parallel to it is squashed onto a single output point, which is why a consistent system has a whole translate of the null space as solutions. The image is $\operatorname{col}(A)$, of dimension $r$: the map keeps $r$ directions and loses $n-r$ (compare the line of solutions in the first figure).

The singular value decomposition (SVD) writes $A=U\Sigma V^T$ with $U^TU=I$, $V^TV=I$ and $\Sigma$ diagonal with entries $\sigma_1\ge\sigma_2\ge\dots\ge0$, the singular values; the number of nonzero ones is the rank, and the columns of $V$ that belong to zero singular values span the null space.

**Code.**
```python
import numpy as np
A = np.array([[0.0, 0.0], [0.7, 0.3]])
U, s, Vt = np.linalg.svd(A)
r = int(np.sum(s > 1e-12 * s[0]))      # rank = number of nonzero singular values
null_basis = Vt[r:].T                   # right singular vectors of the zero singular values
col_basis = U[:, :r]                    # left singular vectors of the nonzero ones
assert np.allclose(A @ null_basis, 0)
```

**Physical meaning.** A kinematic singularity is a rank drop of the Jacobian. With the arm stretched out, $q=(0,0)$ and the same link lengths, $J=\begin{pmatrix}0&0\\0.7&0.3\end{pmatrix}$ m has rank 1. The null space is spanned by $(3,-7)$ rad/s: that pair of joint rates produces no tip motion at first order ($0.7\cdot3+0.3\cdot(-7)=0$). The column space is the $y$ axis: whatever the joint rates, the tip cannot move along the arm, a direction that is lost.

**Example.** At the stretched pose $q=(0,0)$ with $J=\begin{pmatrix}0&0\\0.7&0.3\end{pmatrix}$ m, ask for the tip velocity $v=(0.1,0.2)$ m/s. Is there a solution, and what are the minimum-norm least-squares joint rates and the velocity they produce?

**Solution.** Row 1 reads $0=0.1$, so there is no solution. The minimum-norm least-squares rates are $\dot q=\dfrac{0.2}{0.7^2+0.3^2}(0.7,0.3)=\dfrac{0.2}{0.58}(0.7,0.3)=(0.241,\,0.103)$ rad/s, which gives $v=J\dot q=(0,\ 0.7\cdot0.241+0.3\cdot0.103)=(0,\,0.2)$ m/s: the $y$ component is achieved and the $x$ component of $0.1$ m/s is the residual that no solver can remove.

### Cost of solving: factor once, solve many times

Solving a general square system $Ax=b$ through the QR factorisation costs about $2n^3$ flops for the factorisation, $2n^2$ for $Q^Tb$ and $n^2$ for back substitution (VMLS §11.3, Algorithm 11.2), so about $2n^3$ in total and dominated by the factorisation. The practical consequence is **factorisation caching**: when you must solve $k$ systems with the same $A$ and different right-hand sides, factor once and repeat only the cheap steps, for a total of $2n^3+3kn^2$ instead of $2kn^3$ (§11.3). This is why a robot controller that applies the same calibration matrix to a stream of measurements should keep the factors, not call a fresh solve each time, and why forming $A^{-1}$ explicitly buys nothing.

**Example.** Solve a system with $n=1000$ unknowns for $k=100$ right-hand sides. Compare the flop count of repeating the full solve with factoring once, and with a single back substitution.

**Solution.** Repeating the full solve costs $2kn^3=2\times100\times10^9=2\times10^{11}$ flops. Factoring once and then solving for each right-hand side costs $2n^3+3kn^2=2\times10^9+3\times10^8=2.3\times10^9$ flops, about $2\times10^{11}/2.3\times10^9\approx87$ times less. A single back substitution is only $n^2=10^6$ flops, about $2\times10^9/10^6=2000$ times cheaper than the factorisation ($2n^3=2\times10^9$).

### Least squares without calculus, and when the minimiser is unique

The gradient argument above shows that a minimiser must satisfy the normal equations. Two facts make the statement complete (Boyd and Vandenberghe, *Introduction to Applied Linear Algebra* (VMLS), §11.5 and §12.2).

**Lemma 1 (Gram matrix).** $A^TA$ is invertible if and only if the columns of $A$ are independent. **Proof.** If the columns are independent and $A^TAx=0$, then $0=x^TA^TAx=\|Ax\|^2$, so $Ax=0$ and hence $x=0$. Conversely, if $Ac=0$ for some $c\ne0$, then $A^TAc=0$, so $A^TA$ is singular. $\square$

**Lemma 2 (Pythagoras).** Let $\hat x$ satisfy $A^TA\hat x=A^Tb$. Then for every $x$,
$$\|Ax-b\|^2=\|A(x-\hat x)\|^2+\|A\hat x-b\|^2 .$$
**Proof.** Write $Ax-b=A(x-\hat x)+(A\hat x-b)$ and expand. The cross term is $2(x-\hat x)^TA^T(A\hat x-b)=2(x-\hat x)^T(A^TA\hat x-A^Tb)=0$. $\square$

Lemma 2 needs no calculus and no independence assumption. It says three things at once. First, $\hat x$ is a global minimiser. Second, every minimiser has the same residual, because equality requires $A(x-\hat x)=0$. Third, the set of all minimisers is exactly $\hat x+\operatorname{null}(A)$: it is a single point when the columns are independent (Lemma 1 then gives the formula $\hat x=(A^TA)^{-1}A^Tb$) and a whole affine family otherwise. Normal equations are always solvable, because $\operatorname{null}(A^TA)=\operatorname{null}(A)$ by the computation in Lemma 1, so $\operatorname{rank}(A^TA)=\operatorname{rank}(A)=\operatorname{rank}(A^T)$ and $\operatorname{range}(A^TA)=\operatorname{range}(A^T)\ni A^Tb$.

Apply this to the worked example, $A=\begin{pmatrix}1&1\\2&2\end{pmatrix}$ and $b=(3,7)$. The system is inconsistent, yet $A^TA=\begin{pmatrix}5&5\\5&5\end{pmatrix}$, $A^Tb=(17,17)$, and every $x$ with $x_1+x_2=3.4$ solves the normal equations. All of them give the residual $b-Ax=(-0.4,\,0.2)$. Least squares removes the contradiction but cannot choose a point on the family: that information is not in the data.

*Figure: least squares projects $b$ onto the column space; the leftover residual is perpendicular to every column, which is the normal equation $A^T(Ax-b)=0$ drawn.*

**Example.** Two thermometers read the same room at $20.1\,^\circ$C and $19.7\,^\circ$C. With $A=\begin{pmatrix}1\\1\end{pmatrix}$ and $b=(20.1,19.7)$, find the least-squares estimate from the normal equation, check that the residual is perpendicular to $A$, and compare with the estimate $20.0$.

**Solution.** The normal equation $A^TAx=A^Tb$ is $2x=39.8$, so $\hat x=19.9\,^\circ$C, the mean. The residual $b-A\hat x=(0.2,-0.2)$ is perpendicular to $A=(1,1)$ since $0.2-0.2=0$. Lemma 2 says any other estimate has a larger sum of squares: for $20.0$ it is $0.1^2+0.3^2=0.10$ against $0.2^2+0.2^2=0.08$ at $\hat x$.

### Orthogonal projection: why the residual is perpendicular

Let $W=\operatorname{col}(A)$. The **orthogonal complement** is $W^\perp=\{r\in\mathbb R^m: r^Tw=0\ \text{for all }w\in W\}$. Since $W$ is spanned by the columns, $r\in W^\perp$ iff $a_j^Tr=0$ for every column, that is $A^Tr=0$; so $W^\perp=\operatorname{null}(A^T)$.

**Theorem.** For every $b\in\mathbb R^m$ there is exactly one decomposition $b=p+r$ with $p\in W$ and $r\in W^\perp$. The vector $p$ is the unique point of $W$ closest to $b$, and $p=A\hat x$ for any solution $\hat x$ of the normal equations $A^TA\hat x=A^Tb$. If the columns of $A$ are independent then $p=Pb$ with $P=A(A^TA)^{-1}A^T$, and $P^2=P=P^T$.

**Proof.** *Existence.* The normal equations are always solvable (the Gram-matrix discussion above showed $A^Tb\in\operatorname{range}(A^TA)$). Let $\hat x$ solve them, $p=A\hat x\in W$ and $r=b-p$. Then $A^Tr=A^Tb-A^TA\hat x=0$, so $r\in W^\perp$. *Uniqueness.* If $p+r=p'+r'$ are two such decompositions then $p-p'=r'-r$ lies in $W$ and in $W^\perp$; a vector orthogonal to itself has $\|\cdot\|^2=0$, so $p=p'$ and $r=r'$. *Closest point.* For any $w\in W$ the vector $p-w$ is in $W$, hence orthogonal to $r$, and $\|b-w\|^2=\|r+(p-w)\|^2=\|r\|^2+\|p-w\|^2\ge\|r\|^2$ with equality iff $w=p$. *Projector.* With independent columns, $\hat x=(A^TA)^{-1}A^Tb$ gives $p=Pb$. $P$ is symmetric because $(A^TA)^{-1}$ is, and $P^2=A(A^TA)^{-1}(A^TA)(A^TA)^{-1}A^T=P$: projecting a point already in $W$ changes nothing. $\square$ (This is the orthogonality principle of Boyd and Vandenberghe, VMLS §12.2, Figure 12.2; the projection matrix is treated in MIT 18.06SC, *Projection matrices and least squares*.)

*Where it stops being true.* "Perpendicular" is relative to the dot product. If the readings have different noise levels and you minimise the weighted cost $(Ax-b)^T\Omega(Ax-b)$ with $\Omega=\mathrm{diag}(1,9)$, the minimiser changes and the ordinary residual is no longer perpendicular to the columns; only the weighted one is ($A^T\Omega(Ax-b)=0$). For $A=(1,1)^T$ and $b=(1,3)$ the ordinary fit is $\hat x=2$ with residual $(-1,1)$, whereas the weighted fit is $\hat x=2.8$ with residual $(-1.8,0.2)$, for which $a^Tr=-1.6\ne0$ but $a^T\Omega r=-1.8+9\cdot0.2=0$. The decomposition survives when the columns are dependent ($p$ is still unique), but the formula for $P$ then needs the pseudo-inverse.

**Example.** With $A=\begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix}$ and $b=(1,4,2)$, find $\hat x$, the projection $p=A\hat x$ and the residual $r=b-p$, and check orthogonality and the Pythagorean identity.

**Solution.** The normal equations use $A^TA=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ and $A^Tb=(1+4,\ 4+2)=(5,6)$. Solving $\begin{pmatrix}2&1\\1&2\end{pmatrix}\hat x=(5,6)$ (determinant 3) gives $\hat x=\tfrac13(2\cdot5-6,\ -5+2\cdot6)=(4/3,\,7/3)$. Then $p=A\hat x=(4/3,\,11/3,\,7/3)$ and $r=b-p=(-1/3,\,1/3,\,-1/3)$. Check: $r\cdot(1,1,0)=-1/3+1/3=0$, $r\cdot(0,1,1)=1/3-1/3=0$, and $\|b\|^2=21=\|p\|^2+\|r\|^2=20.6667+0.3333$.

### Four views: least squares as projection

**Algebra.** For independent columns, $\hat x=(A^TA)^{-1}A^Tb$, the fitted vector is $p=A\hat x=Pb$, the residual is $r=b-p=(I-P)b$, and Pythagoras gives $\|b\|^2=\|p\|^2+\|r\|^2$. The cost of the best fit is therefore $\|r\|^2=\|b\|^2-\|p\|^2$.

**Geometry.** In $\mathbb R^3$ with two columns, $W$ is a plane through the origin, $b$ is a point off it, $p$ is the foot of the perpendicular and $r$ is the perpendicular segment, parallel to the normal of the plane. Drag $b$ in the block below and watch $r$ stay perpendicular to both columns, and the readouts $r\cdot a_1$ and $r\cdot a_2$ stay at zero.

**Code.**
```python
import numpy as np
A = np.array([[1.0, 0.0], [1.0, 1.0], [0.0, 1.0]]); b = np.array([1.0, 4.0, 2.0])
P = A @ np.linalg.inv(A.T @ A) @ A.T        # projector onto col(A)
p, r = P @ b, b - P @ b
assert np.allclose(P @ P, P) and np.allclose(A.T @ r, 0)
assert np.isclose(b @ b, p @ p + r @ r)     # Pythagoras
```

**Physical meaning.** The residual is the part of the data that no choice of the model parameters can explain: noise, or an effect missing from the model. Orthogonality is the statement that nothing explainable is left in it. If some part of $r$ were still correlated with a column, a small change of the parameters would absorb that part and lower the cost. Units: $p$ and $r$ have the units of the measurements $b$; the parameters $\hat x$ have units of measurement per unit of the column.

**Example.** A motor test records speed (rpm) at $2,4,6$ V: $410,\,790,\,1230$ rpm. Fit the model speed $=kV$ by least squares, and give the fitted speeds, the residual and an orthogonality check.

**Solution.** The matrix is the single column $A=(2,4,6)^T$ V and $b=(410,790,1230)$ rpm, so $A^Tb=820+3160+7380=11360$ and $A^TA=4+16+36=56$, giving $\hat k=11360/56=202.86$ rpm/V. The fitted speeds are $\hat kA=(405.7,\,811.4,\,1217.1)$ rpm and the residual is $b-\hat kA=(4.29,\,-21.43,\,12.86)$ rpm. Orthogonality to the voltage column: $2\cdot4.29-4\cdot21.43+6\cdot12.86=8.58-85.72+77.16=0.02\approx0$ (rounding).

### Right inverses, minimum norm and the pseudo-inverse

When $A$ is wide ($m<n$) with independent rows, $Ax=b$ is solvable for every $b$ and the solution set is $x_p+\operatorname{null}(A)$ for any particular solution $x_p$. A right inverse is $A^T(AA^T)^{-1}$ (VMLS §11.5). The vector
$$x^\star=A^T(AA^T)^{-1}b$$
solves the system and has the smallest norm of all solutions. **Proof.** $Ax^\star=b$ is immediate. Every other solution is $x=x^\star+z$ with $Az=0$. Since $x^\star=A^Tw$ with $w=(AA^T)^{-1}b$, we get $x^{\star T}z=w^TAz=0$, so $\|x\|^2=\|x^\star\|^2+\|z\|^2\ge\|x^\star\|^2$. $\square$ (VMLS §16.1.1 and §16.3 present the same vector as the solution of the least-norm problem.)

**Example.** A single wiring-error sensor reports $q_1+q_2=75$. Find the minimum-norm solution and say what it tells about the information in the data.

**Solution.** Here $A=(1\;1)$ and the minimum-norm solution is $x^\star=A^T(AA^T)^{-1}\cdot75=(37.5,\,37.5)$, while every pair $(37.5+t,\,37.5-t)$ is equally consistent. The minimum-norm answer is a *choice* (it encodes a preference for small joint values), not a measurement. This is the precise sense in which "a solver cannot manufacture information about the missing directions".

For a general matrix of rank $r$ write the SVD $A=U\Sigma V^T$ with singular values $\sigma_1\ge\dots\ge\sigma_r>0$. Then $(A^TA+\lambda I)^{-1}A^T=V\,\mathrm{diag}\!\big(\sigma_i/(\sigma_i^2+\lambda)\big)U^T$, with entries $0$ where $\sigma_i=0$, and letting $\lambda\to0$ defines the pseudo-inverse $A^\dagger=V\,\mathrm{diag}(1/\sigma_i\ \text{or}\ 0)\,U^T$ (this limit is the definition used in VMLS Exercise 15.11). For every $b$, $A^\dagger b$ is the minimum-norm least-squares solution. **Proof.** With $y=V^Tx$ and $c=U^Tb$, the normal equations read $\sigma_i^2y_i=\sigma_ic_i$, so $y_i=c_i/\sigma_i$ whenever $\sigma_i>0$ and $y_i$ is free otherwise. Since $\|x\|=\|y\|$, the minimum norm sets every free $y_i$ to $0$, which is $A^\dagger b$. $\square$ For the example above this gives $A^\dagger=\tfrac1{10}\begin{pmatrix}1&2\\1&2\end{pmatrix}$ and $A^\dagger b=(1.7,\,1.7)$.

Conditioning follows from the same SVD. The singular values of $A^TA$ are $\sigma_i^2$, so for full column rank $\kappa(A^TA)=\sigma_1^2/\sigma_n^2=\kappa(A)^2$. This is the exact statement behind "normal equations square the condition number" (exercise 14 makes it bite).

### A second worked case: rank that depends on a parameter

Take $A(\alpha)=\begin{pmatrix}1&1&0\\0&1&1\\1&2&\alpha\end{pmatrix}$ and $b=(b_1,b_2,b_3)$. Subtracting rows 1 and 2 from row 3 leaves the equation $(\alpha-1)z=b_3-b_1-b_2$.

- If $\alpha\ne1$ the rank is 3 and the solution is unique, $z=(b_3-b_1-b_2)/(\alpha-1)$, then $y=b_2-z$, $x=b_1-y$.
- If $\alpha=1$ the rank is 2, the nullspace is spanned by $(1,-1,1)$, and the system is solvable iff $b_3=b_1+b_2$. For $b=(2,3,5)$ the solutions are $(t-1,\,3-t,\,t)$ and the minimum-norm one is $t=4/3$. For $b=(2,3,5.01)$ there is no solution.
- Near the boundary the answer is violently sensitive. With $\alpha=1.001$ the data $b=(2,3,5)$ give $(-1,3,0)$, but changing $b_3$ by only $0.01$ gives $(9,-7,10)$: the factor $1/(\alpha-1)=1000$ turns a 0.01 measurement error into a change of 10 in $z$.

Rank is therefore not a property you can read off with a yes/no test in floating point: a matrix that is "rank 3 with a tiny singular value" behaves like a rank-2 matrix with an amplifier attached. Inspect singular values, not only the pivot count.

![Plot of the smallest singular value of A(alpha) for alpha from 0 to 2: it falls to zero at alpha=1, equals 0.0003 at alpha=1.001, and is 0.333 at alpha=0.](/lesson-figures/M04-3.svg)

*Figure: the smallest singular value of $A(\alpha)$ touches zero at $\alpha=1$, where the rank drops from 3 to 2; near that point the matrix is almost rank 2 and amplifies errors by about $1/\sigma_{\min}$.*

**Example.** Compute the smallest singular value of $A(\alpha)$ for $\alpha=0,\,0.9,\,0.99,\,1,\,1.001$, and use it to bound the amplification of a measurement error $\epsilon$ at $\alpha=1.001$.

**Solution.** With NumPy the smallest singular value is 0.333 at $\alpha=0$, 0.034 at $\alpha=0.9$, 0.0033 at $\alpha=0.99$, exactly 0 at $\alpha=1$ and 0.00033 at $\alpha=1.001$. A measurement error $\epsilon$ is amplified by at most about $1/\sigma_{\min}=1/0.00033\approx3000$ at $\alpha=1.001$, so $\epsilon=0.01$ may move the solution by tens of units. This is consistent with the factor 1000 found above for $z$.

### Summary: where each result stops being true

| Result | What it needs | Where it fails | Computed instance |
|---|---|---|---|
| Rank-nullity, $r+\dim\operatorname{null}=n$ | linearity of $A$ | nonlinear maps; floating-point rank with a bad tolerance | $x^2+y^2-1=0$ is a circle, not a subspace |
| Solutions $=x_p+\operatorname{null}(A)$ | linearity, $b\in\operatorname{col}(A)$ | $b$ off the column space; nonlinear equations | $x^2=4$ has the solutions $\pm2$ but $x^2=0$ has only $0$ |
| Unique least-squares minimiser | independent columns | dependent columns: a whole family | $x_1+x_2=3.4$ for $A=\begin{pmatrix}1&1\\2&2\end{pmatrix}$ |
| Residual $\perp$ columns | ordinary dot product | weighted cost | $\hat x=2$ ordinary, $2.8$ with weights $(1,9)$ |
| Normal equations in floating point | $\kappa(A)^2\ll1/u$ | ill-conditioned columns | Vandermonde fit below: error $10^{-6}$ against $4\times10^{-11}$ for QR |

## Worked example

### Case 1: identical columns, rank 1

**Problem.** Let $A=\begin{pmatrix}1&1\\2&2\end{pmatrix}$. (a) Find its rank and nullspace. (b) Solve $Ax=(3,6)$. (c) Solve $Ax=(3,7)$ if possible, and otherwise find the least-squares answer.

**Solution.**
1. *Rank.* Both columns equal $(1,2)$, so $1\cdot a_1-1\cdot a_2=0$ is a nontrivial dependency (Independence, dimension and basis). Elimination: row 2 minus twice row 1 gives $(0,0)$, so there is one pivot and $r=1$.
2. *Nullspace.* Free variable $x_2=t$; the pivot equation $x_1+x_2=0$ gives $x_1=-t$. The special solution is $(-1,1)$, so $\operatorname{null}(A)=\{t(-1,1)\}$, of dimension $n-r=1$.
3. *Case $b=(3,6)$.* Row 1 reads $x_1+x_2=3$ and row 2 reads $2x_1+2x_2=6$, the same equation. A particular solution is $(3,0)$, so the complete solution is $(3,0)+t(-1,1)$, which contains $(2,1)$ for $t=1$. Infinitely many solutions, because $b=3\,(1,2)$ lies in the column space.
4. *Case $b=(3,7)$.* Row 1 says $x_1+x_2=3$ and row 2 says $x_1+x_2=3.5$: a contradiction, $0=1$ after subtracting twice row 1 from row 2. $b$ is not on the line through $(1,2)$, so there is no solution.
5. *Least squares for $b=(3,7)$.* The normal equations (Theory) are $A^TAx=A^Tb$ with $A^TA=\begin{pmatrix}5&5\\5&5\end{pmatrix}$ and $A^Tb=(17,17)$, so $x_1+x_2=3.4$. Any such $x$ gives $Ax=3.4\,(1,2)=(3.4,6.8)$ and the residual $b-Ax=(-0.4,0.2)$ with norm $0.447$.

**Check.** The residual is perpendicular to the column $(1,2)$: $-0.4\cdot1+0.2\cdot2=0$. The minimum-norm choice is $x_1=x_2=1.7$ (pseudo-inverse), with $Ax=(3.4,6.8)$, the same projection.

**Takeaway.** Rank 1 means one equation's worth of information; whether the system has infinitely many solutions or none depends only on whether $b$ is on the column line, and no solver setting changes that.

### Case 2: fitting a line to three measurements

**Problem.** A sensor reading $y$ is taken at times $t=0,1,2$ s with $y=(1,\,2,\,2.5)$ V. Fit $y\approx a+ct$ by least squares and report the residual.

**Solution.**
1. *Model.* The unknowns are $x=(a,c)$ and the equations $a+ct_i=y_i$ give $A=\begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix}$, $b=(1,2,2.5)$. The columns are independent, rank 2, but three equations in two unknowns are inconsistent: no line passes through all points.
2. *Normal equations.* $A^TA=\begin{pmatrix}3&3\\3&5\end{pmatrix}$ and $A^Tb=(1+2+2.5,\;0+2+5)=(5.5,\,7)$.
3. *Solve.* The inverse of a $2\times2$ matrix $\begin{pmatrix}p&q\\s&t\end{pmatrix}$ is $\frac1{pt-qs}\begin{pmatrix}t&-q\\-s&p\end{pmatrix}$. The determinant is $3\cdot5-3\cdot3=6$. By this formula $a=(5\cdot5.5-3\cdot7)/6=6.5/6=1.0833$ V and $c=(3\cdot7-3\cdot5.5)/6=4.5/6=0.75$ V/s.
4. *Residual.* The fitted values are $a+ct=1.0833,\;1.8333,\;2.5833$, so $b-A\hat x=(-0.0833,\,0.1667,\,-0.0833)$ with norm $0.2041$ V.

**Check.** $A^T(b-A\hat x)=(-0.0833+0.1667-0.0833,\;0+0.1667-0.1667)=(0,0)$ to rounding error: the residual is perpendicular to both columns, as the normal equation demands. Python's `numpy.linalg.lstsq` returns the same $(1.0833,\,0.75)$.

**Takeaway.** Least squares replaces an impossible system by the closest possible one, and the perpendicular residual is both the check and the measure of how well the model explains the data.

### From scratch: reduced row echelon form, rank, null space, least squares

The block below builds the lesson's three algorithms with plain arrays and loops, and no library call for the core step: Gauss-Jordan elimination with partial pivoting to the reduced row echelon form (`rref`), from which `rank`, `null_basis` (the special solutions of the theory) and `solve_general` (a particular solution plus the null space) follow; Householder QR with back substitution for least squares; and the normal equations through the same elimination. NumPy appears only for array storage and, in the tests, as the referee. Predict first which of the two least-squares methods will be less accurate on the last test, then run it.

```python
import numpy as np


def rref(A, tol=1e-10):
    """Reduced row echelon form by Gauss-Jordan elimination with partial pivoting.
    Returns (R, pivots): R is the echelon matrix, pivots the list of pivot columns."""
    R = np.array(A, dtype=float)
    m, n = R.shape
    scale = max(1.0, float(np.abs(R).max()))
    pivots, row = [], 0
    for col in range(n):
        if row == m:
            break
        p = row + int(np.argmax(np.abs(R[row:, col])))   # largest entry: partial pivoting
        if abs(R[p, col]) <= tol * scale:                  # no usable pivot in this column
            R[row:, col] = 0.0
            continue
        R[[row, p]] = R[[p, row]]                          # row swap
        R[row] /= R[row, col]                              # pivot becomes 1
        for i in range(m):
            if i != row:
                R[i] -= R[i, col] * R[row]                 # clear the column above and below
        pivots.append(col)
        row += 1
    return R, pivots


def rank(A, tol=1e-10):
    return len(rref(A, tol)[1])


def null_basis(A, tol=1e-10):
    """Special solutions: one free variable set to 1, the others 0 (columns of the result)."""
    R, piv = rref(A, tol)
    n = R.shape[1]
    free = [j for j in range(n) if j not in piv]
    N = np.zeros((n, len(free)))
    for k, f in enumerate(free):
        N[f, k] = 1.0
        for i, pc in enumerate(piv):
            N[pc, k] = -R[i, f]
    return N


def solve_general(A, b, tol=1e-10):
    """All solutions of A x = b: returns (x_p, N) with x = x_p + N t, or None if inconsistent."""
    A = np.array(A, dtype=float)
    R, piv = rref(np.column_stack([A, b]), tol)
    n = A.shape[1]
    if n in piv:                                           # a row reads 0 = c with c != 0
        return None
    xp = np.zeros(n)
    for i, pc in enumerate(piv):
        xp[pc] = R[i, n]
    return xp, null_basis(A, tol)


def back_substitute(R, y):
    n = len(y)
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (y[i] - R[i, i + 1:] @ x[i + 1:]) / R[i, i]
    return x


def householder_qr(A):
    """Full QR, A = Q R, built from reflections H = I - 2 v v^T (no library call)."""
    R = np.array(A, dtype=float)
    m, n = R.shape
    Q = np.eye(m)
    for k in range(min(n, m - 1)):
        x = R[k:, k]
        s = float(np.sqrt(x @ x))
        if s == 0.0:
            continue
        v = x.copy()
        v[0] += s if x[0] >= 0 else -s                     # sign chosen to avoid cancellation
        v /= np.sqrt(v @ v)
        R[k:, :] -= 2.0 * np.outer(v, v @ R[k:, :])
        Q[:, k:] -= 2.0 * np.outer(Q[:, k:] @ v, v)
    return Q, np.triu(R)


def lstsq_qr(A, b):
    A = np.array(A, dtype=float)
    n = A.shape[1]
    Q, R = householder_qr(A)
    if min(abs(R[i, i]) for i in range(n)) < 1e-12 * abs(R[0, 0]):
        raise ValueError("columns are (numerically) dependent: use the SVD / minimum norm")
    return back_substitute(R[:n, :n], (Q.T @ b)[:n])


def lstsq_normal(A, b):
    A = np.array(A, dtype=float)
    G, rhs = A.T @ A, A.T @ b
    R, piv = rref(np.column_stack([G, rhs]))
    if len(piv) < A.shape[1] or A.shape[1] in piv:
        raise ValueError("A^T A is singular")
    return R[:, -1]


# ---------------- tests against NumPy and against closed forms ----------------
rng = np.random.default_rng(4)
for _ in range(40):
    m, n, r = int(rng.integers(3, 8)), int(rng.integers(3, 8)), int(rng.integers(1, 3))
    A = rng.standard_normal((m, r)) @ rng.standard_normal((r, n))      # rank r by construction
    assert rank(A) == np.linalg.matrix_rank(A) == r
    N = null_basis(A)
    assert N.shape[1] == n - r and np.allclose(A @ N, 0, atol=1e-9)    # rank-nullity and A N = 0
    V2 = np.linalg.svd(A)[2][r:].T                                     # NumPy's null-space basis
    assert np.allclose(N @ np.linalg.pinv(N), V2 @ V2.T, atol=1e-8)   # same subspace
    b = A @ rng.standard_normal(n)
    xp, N2 = solve_general(A, b)
    assert np.allclose(A @ (xp + N2 @ rng.standard_normal(N2.shape[1])), b)   # particular + null
    assert solve_general(A, b + rng.standard_normal(m)) is None or r == m

for _ in range(40):
    A, b = rng.standard_normal((9, 3)), rng.standard_normal(9)
    ref = np.linalg.lstsq(A, b, rcond=None)[0]
    for x in (lstsq_qr(A, b), lstsq_normal(A, b)):
        assert np.allclose(x, ref) and np.allclose(A.T @ (A @ x - b), 0, atol=1e-9)
Q, R = householder_qr(rng.standard_normal((6, 3)))
assert np.allclose(Q.T @ Q, np.eye(6)) and np.allclose(np.tril(R, -1), 0)

A = np.array([[1., 2., 0., 1.], [0., 0., 1., 3.], [1., 2., 1., 4.]])  # the 3x4 matrix of the lesson
print("rank", rank(A), "| null basis columns", (null_basis(A).T.round(3) + 0.0).tolist())
assert solve_general(A, [3., 4., 8.]) is None                          # b3 != b1 + b2: inconsistent

# Conditioning: a degree-7 polynomial fit on 12 points; exact answer is all ones.
t = np.linspace(0, 1, 12)
V = np.vander(t, 8, increasing=True)
b = V @ np.ones(8)
for name, f in [("normal eq.", lstsq_normal), ("Householder QR", lstsq_qr)]:
    print(f"{name:15s} error {np.linalg.norm(f(V, b) - 1):.1e}")
print(f"cond(V) = {np.linalg.cond(V):.1e}, cond(V^T V) = {np.linalg.cond(V.T @ V):.1e}")
print("all tests passed")
```

Expected output (the asserts run on seeded random matrices; the last test is the conditioning experiment; the normal-equation error is about 1e-6, and its exact digits depend on your BLAS):

**What the library does differently.** `np.linalg.matrix_rank` and `np.linalg.lstsq` use the SVD, not elimination: they decide rank from singular values against a tolerance scaled by the largest one (about $\max(m,n)\,\varepsilon_{\text{mach}}\,\sigma_1$), which is more reliable than a pivot test because a pivot can be tiny by accident of the elimination order while the matrix is well conditioned, or not tiny although the matrix is nearly singular. `lstsq` returns the minimum-norm solution for rank-deficient problems, whereas the code above refuses them. `np.linalg.solve` calls LAPACK's LU with partial pivoting in blocked, cache-friendly form, which is far faster than the Python loops here, and `np.linalg.qr` uses the same Householder reflections through LAPACK, which keeps them in compact form and builds $Q$ only on request. On conditioning: the last test fits a degree-7 polynomial to 12 points, where $\kappa(V)=1.2\times10^5$ and $\kappa(V^TV)=1.5\times10^{10}$. The normal equations lose about ten digits (error $10^{-6}$), Householder QR about five (error $4\times10^{-11}$), as $\kappa(A^TA)=\kappa(A)^2$ predicts. Pick QR for well-posed fits, the SVD when rank is in doubt.

8. $\kappa(A^TA)=\kappa(A)^2\approx1.6\times10^5$ (computed: 161 610). Roughly twice as many digits are lost, about 5 digits instead of 2.6; in double precision that is harmless here but becomes a problem for $\kappa\gtrsim10^8$. QR or SVD works with $A$ directly and keeps $\kappa(A)$.
9. $J=\tfrac12(Ax-b)^T(Ax-b)$; $\nabla J=A^T(Ax-b)=0$ gives the normal equations. $A^TA$ is invertible iff the columns of $A$ are independent (trivial nullspace). Geometrically the closest point $Ax$ in the column space to $b$ is the projection: the error $b-Ax$ is perpendicular to every column, i.e. $A^T(b-Ax)=0$.
10. A good answer shows: row swap used when a pivot is smaller than a tolerance, an explicit `ValueError` for singular systems, rank 2 for the fit matrix, $(a,b)=(7/6,3/2)$, and the orthogonality check on random data with a tolerance like $10^{-9}$.

11. (a) With $n=1$ the normal equation is $a^Ta\,\hat x=a^Tb$, so $\hat x=a^Tb/\|a\|^2$ and $\|a\hat x-b\|^2=\|b\|^2-(a^Tb)^2/\|a\|^2$ (expand and substitute). Since $a^Tb=\|a\|\|b\|\cos\theta$, this equals $\|b\|^2(1-\cos^2\theta)=\|b\|^2\sin^2\theta$. For $a=(1,2,2)$, $b=(3,0,4)$: $a^Tb=11$, $\|a\|^2=9$, $\hat x=11/9=1.2222$, $\cos\theta=11/15$, $\sin^2\theta=104/225$ and the squared error is $25\cdot104/225=104/9=11.5556$ (checked directly: $\|\hat xa-b\|^2=11.5556$).
(b) $(Ax)^Tb-(Ax)^T(A\hat x)=x^T(A^Tb-A^TA\hat x)=0$ by the normal equations. With $x=\hat x$ this gives $(A\hat x)^Tb=\|A\hat x\|^2$, so $\cos\angle(A\hat x,b)=\|A\hat x\|/\|b\|$. For any $x$ with $Ax\ne0$: $\cos\angle(Ax,b)=\dfrac{(Ax)^T(A\hat x)}{\|Ax\|\|b\|}=\dfrac{\|A\hat x\|}{\|b\|}\cos\angle(Ax,A\hat x)\le\dfrac{\|A\hat x\|}{\|b\|}=\cos\angle(A\hat x,b)$, with equality exactly when $Ax$ is a positive multiple of $A\hat x$ (so any $\alpha\hat x$, $\alpha>0$, is also optimal). A larger cosine is a smaller angle.
(c) $\hat x=(7/6,3/2)$, $\|A\hat x\|^2=155/6=25.8333$, $\|b\|^2=26$, so $\cos\angle=\sqrt{155/156}=0.99679$ (angle $4.59^\circ$) and the squared residual is $26-25.8333=1/6$, matching exercise 7. For $x=(0,2)$, $Ax=(0,2,4)$ and the cosine is $22/(\sqrt{20}\sqrt{26})=0.96476$, a larger angle.
12. (a) Expand both products: $A^T(AA^T+\lambda I)=A^TAA^T+\lambda A^T=(A^TA+\lambda I)A^T$. Both $A^TA+\lambda I$ and $AA^T+\lambda I$ are symmetric positive definite for $\lambda>0$ (for any $z\ne0$, $z^T(A^TA+\lambda I)z=\|Az\|^2+\lambda\|z\|^2>0$), hence invertible. Multiply the identity on the left by $(A^TA+\lambda I)^{-1}$ and on the right by $(AA^T+\lambda I)^{-1}$ to obtain $(A^TA+\lambda I)^{-1}A^T=A^T(AA^T+\lambda I)^{-1}$.
(b) Write $A=uv^T$ with $u=(1,3)$, $v=(1,-1)$, so $A^TA=\|u\|^2vv^T=10\,vv^T$ and $A^T=vu^T$. Because $10\,vv^Tv=20v$, we have $(A^TA+\lambda I)^{-1}v=v/(20+\lambda)$, hence $(A^TA+\lambda I)^{-1}A^T=\dfrac1{20+\lambda}\begin{pmatrix}1&3\\-1&-3\end{pmatrix}$ (at $\lambda=1$ the entries are $0.0476$ and $0.1429$, as a numerical check confirms). The limit is $A^\dagger=\tfrac1{20}\begin{pmatrix}1&3\\-1&-3\end{pmatrix}$. Then $A^\dagger(2,6)=(1,-1)$, which satisfies $Ax=(2,6)$ exactly, and $A^\dagger(2,7)=(1.15,-1.15)$ with $Ax=(2.3,6.9)$ and residual $(-0.3,0.1)$, perpendicular to the column $(1,3)$ ($-0.3+0.3=0$). In both cases the answer is the point of the solution family $x_1-x_2=\text{const}$ that is closest to the origin. The direction $(1,1)$ is invisible to $A$, so the data cannot say how to shift both components together; the zero weight on that direction is a convention of the regulariser.
13. (a) Put $x=y+d$. The constraint becomes $Ad=b-Ay$ and the objective is $\|d\|^2$, a least-norm problem. By the minimum-norm result in the theory, $d=A^T(AA^T)^{-1}(b-Ay)$, so $x=y+A^T(AA^T)^{-1}(b-Ay)$ (this is the orthogonal projection of $y$ onto the solution set).
(b) $A=(1\;1)$, $AA^T=2$, $b-Ay=62-80=-18$, so $d=(1,1)\cdot(-18/2)=(-9,-9)$ and $x=(21,41)$ with cost $162$.
(c) Substitute $d=W^{-1/2}d'$. The problem becomes: minimise $\|d'\|^2$ subject to $(AW^{-1/2})d'=r$, with $r=b-Ay$. Its minimiser is $d'=(AW^{-1/2})^T(AW^{-1}A^T)^{-1}r$, so $d=W^{-1}A^T(AW^{-1}A^T)^{-1}r$. Here $W^{-1}A^T=(1,\,0.25)^T$, $AW^{-1}A^T=1.25$, $r=-18$, so $d=(1,0.25)\cdot(-14.4)=(-14.4,-3.6)$ and $x=(15.6,46.4)$. Weighted costs: $(15.6,46.4)$ gives $14.4^2+4\cdot3.6^2=259.2$, while the equal split $(21,41)$ gives $81+4\cdot81=405$. The expensive joint moves 3.6 degrees and the cheap one 14.4 degrees. Both satisfy $q_1+q_2=62$; they differ only in which unobserved direction $(1,-1)$ is used.
14. (a) With $A=U\Sigma V^T$, $A^TA=V\Sigma^2V^T$, so the singular values of $A^TA$ are $\sigma_i^2$ and $\kappa(A^TA)=\sigma_1^2/\sigma_n^2=\kappa(A)^2$. For $A_\varepsilon$, $A^TA=\begin{pmatrix}1+\varepsilon^2&1\\1&1+\varepsilon^2\end{pmatrix}$ has eigenvalues $2+\varepsilon^2$ and $\varepsilon^2$, so $\kappa(A_\varepsilon)=\sqrt{2+\varepsilon^2}/\varepsilon\approx\sqrt2/\varepsilon$ ($1.414\times10^8$ at $\varepsilon=10^{-8}$) and $\kappa(A^TA)\approx2/\varepsilon^2=2\times10^{16}$, beyond $1/u\approx9\times10^{15}$.
(b) $\mathrm{fl}(1+\varepsilon^2)=1$ iff $\varepsilon^2\le2^{-53}$ (a tie rounds to even, which is 1), i.e. $\varepsilon\le2^{-26.5}=1.0537\times10^{-8}$. Then the computed Gram matrix is $\begin{pmatrix}1&1\\1&1\end{pmatrix}$, exactly singular.
(c) Computed with NumPy: at $\varepsilon=10^{-8}$, `solve` raises `LinAlgError: Singular matrix` while `lstsq` returns $(1,2)$ with error $9\times10^{-16}$. At $\varepsilon=1.2\times10^{-8}$, $\varepsilon^2=1.44\times10^{-16}>2^{-53}$, so $1+\varepsilon^2$ rounds up to $1+2^{-52}$, the Gram matrix has computed determinant $4.4\times10^{-16}\ne0$, and `solve` returns $(0,3)$ without any warning (error $1.414$), while `lstsq` still returns $(1,2)$ with error $4.6\times10^{-16}$. The second case is more dangerous because the failure is silent: a loud error is a bug report, a wrong but plausible answer is a crashed robot. QR/SVD work on $A$ itself, whose condition number is $1.2\times10^8$, so their worst-case error bound is about $u\kappa\approx10^{-8}$ instead of a total loss of accuracy.
