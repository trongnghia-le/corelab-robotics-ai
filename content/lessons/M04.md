## Why this matters

Understand what a linear solver can and cannot recover. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

A linear system asks whether a target can be assembled from available directions. Redundant directions do not create new capabilities. In robot estimation, a sensor can constrain some directions while leaving others ambiguous; a solver cannot manufacture information about the missing directions.

![Left: two independent lines meet at one solution. Right: parallel lines with no solution when the rows are dependent but the right-hand sides disagree.](/lesson-figures/M04.svg)

*Rank decides whether a linear system has one, none, or infinitely many solutions.*

## Theory and derivation

The span of columns of $A$ is every vector $Ax$. Columns are independent if $Ac=0$ implies $c=0$. Rank counts independent column directions. A system $Ax=b$ has a solution exactly when $b$ lies in that column space; a solution is unique when the nullspace is trivial.

Elimination replaces equations by equivalent combinations. For $x+y=3$ and $x-y=1$, subtract the second equation from the first to get $2y=2$, hence $y=1$ and $x=2$. If the second equation were $2x+2y=6$, it would add no constraint: infinitely many solutions remain.

For inconsistent measurements, minimize $J(x)=\frac12\|Ax-b\|^2$. Differentiating yields $A^T(Ax-b)=0$: the residual is perpendicular to the column space. This gives normal equations $A^TAx=A^Tb$. Deriving them clarifies the geometry; numerically, QR or SVD avoids the condition-number squaring caused by explicitly forming $A^TA$.

## Worked example

For A=[[1,1],[2,2]], both columns are identical, so rank=1. The equation Ax=(3,6) admits x=(3,0), (2,1), and many others. Ax=(3,7) is inconsistent because the second output must be twice the first. No optimizer setting changes that structural fact.

Compute $\kappa(A)$ and $\kappa(A^TA)$ for $A=[[1,1],[1,1.01]]$ using the singular values from a $2\times2$ eigenvalue formula, and show experimentally that the normal-equation solution loses about twice as many digits as solving a QR-style (Gram-Schmidt) version.

### Library track
Redo the lab with NumPy (`pip install numpy` in a virtual environment) and compare it with your pure-Python solver: `np.linalg.solve` (which pivots for you), `np.linalg.matrix_rank` and the SVD nullspace, the line fit three ways (normal equations, `lstsq`, QR), and the condition numbers from exercise 8.

```python
import numpy as np

# Square solve and the row-swap case
assert np.allclose(np.linalg.solve([[1, 1], [1, -1]], [3, 1]), [2, 1])
assert np.allclose(np.linalg.solve([[0, 1], [1, 1]], [2, 3]), [1, 2])            # LAPACK pivots for you
assert np.allclose(np.linalg.solve([[1, 1, 1], [0, 2, 5], [2, 5, -1]], [6, -4, 27]), [5, 3, -2])
try:
    np.linalg.solve([[1., 1.], [2., 2.]], [3., 6.])
except np.linalg.LinAlgError:
    print("singular system rejected")

# Rank (SVD-based, with a tolerance) and the nullspace from the SVD
M = np.array([[1., 2., 3.], [2., 4., 6.], [1., 0., 1.]])
assert np.linalg.matrix_rank(M) == 2
_, s, Vt = np.linalg.svd(M)
null = Vt[-1]                                         # right singular vector of the zero singular value
assert np.allclose(M @ null, 0, atol=1e-12) and s[-1] < 1e-12

# Line fit y = a + b x three ways: normal equations, lstsq (SVD), QR
A = np.array([[1., 0.], [1., 1.], [1., 2.]]); y = np.array([1., 3., 4.])
x_ne = np.linalg.solve(A.T @ A, A.T @ y)
x_ls = np.linalg.lstsq(A, y, rcond=None)[0]
Q, R = np.linalg.qr(A); x_qr = np.linalg.solve(R, Q.T @ y)
assert np.allclose(x_ne, [7 / 6, 1.5]) and np.allclose(x_ls, x_ne) and np.allclose(x_qr, x_ne)
assert np.allclose(A.T @ (A @ x_ls - y), 0)           # residual orthogonal to the columns
print("fit", np.round(x_ls, 4), "residual", np.round(A @ x_ls - y, 4))

# Conditioning: kappa(A^T A) = kappa(A)^2
B = np.array([[1, 1], [1, 1.01]])
k1, k2 = np.linalg.cond(B), np.linalg.cond(B.T @ B)
assert abs(k1 - 402) < 1 and np.isclose(k2, k1 ** 2, rtol=1e-3)
print("cond(A) =", round(k1), " cond(A^T A) =", round(k2))
```

Expected output: `singular system rejected`, `fit [1.1667 1.5   ] residual [ 0.1667 -0.3333  0.1667]`, then `cond(A) = 402  cond(A^T A) = 161610`. All three line-fit methods agree here because $A$ is well conditioned; the normal equations are the first to degrade as $\kappa(A)$ grows.

## Failure modes

A low residual does not prove a unique solution. A rectangular matrix is not automatically full rank. Floating-point rank depends on scale and tolerance, so inspect singular values before interpreting a borderline case.

## Alternatives and trade-offs

Elimination is transparent for hand calculations; QR handles well-conditioned least squares; SVD exposes weak or missing directions and supports regularization. These are different numerical tools for the same geometry.

## Exercise answers

1. Adding: $2q_1=90$, so $q_1=45$; then $q_2=75-45=30$. Check: $45+30=75$, $45-30=15$. If the second sensor repeated $q_1+q_2$ the equations would be identical (rank 1): only the sum is known, infinitely many pairs fit.
2. First matrix: column 2 is twice column 1, rank 1; outputs are all multiples of $(1,2)$: a line. Second: columns $e_1,e_2$ are independent, rank 2; outputs fill the whole plane.
3. Row 2 is twice row 1, so the matrix has rank 1. Nullspace: $\theta=t(1,-1)$ gives zero for both sensors (and $y_2$ must equal $2y_1$ exactly). Add a measurement such as $y_3=\theta_1-\theta_2$ (or $\theta_1$ alone) so the stacked matrix has rank 2.
4. Row ops: $R_3\leftarrow R_3-2R_1$: $3y-3z=15$, i.e. $y-z=5$. Then from $2y+5z=-4$: $2(z+5)+5z=-4\Rightarrow7z=-14$, $z=-2$; $y=3$; $x=6-3+2=5$. Solution $(5,3,-2)$. Check: $5+3-2=6$; $6-10=-4$; $10+15+2=27$.
5. First: $\det=-2$, result $(2.0,1.0)$. Second: $\det=0$, `ZeroDivisionError`. A robust solver checks for a (near) zero determinant or pivot and reports a singular system; here $2\cdot3=6$, so the equations are dependent and there are infinitely many solutions, not a division error.
6. The first pivot is $0$: dividing by it fails. Partial pivoting swaps rows: $(1,1\mid3)$, $(0,1\mid2)$, giving $y=2$, $x=1$. A pivot of $10^{-20}$ produces multipliers of $10^{20}$ that swamp the other entries in floating point (information is lost), giving large errors even though it is nonzero.
7. $A^TA=\begin{pmatrix}3&3\\3&5\end{pmatrix}$, $A^Ty=(8,11)$. Subtract the equations: $2b=3$, $b=1.5$, $a=8/3-1.5=7/6\approx1.1667$. Fitted values $(1.1667,2.6667,4.1667)$; residual $b-Ax=(-0.1667,0.3333,-0.1667)$ (the lab's `residual` returns $Ax-b$, the negative; its norm is the same). Check: sum of residuals $=0$ (orthogonal to the ones column) and $0\cdot(-0.1667)+1\cdot0.3333+2\cdot(-0.1667)=0$ (orthogonal to the $x$ column).
8. $\kappa(A^TA)=\kappa(A)^2\approx1.6\times10^5$ (computed: 161 610). Roughly twice as many digits are lost, about 5 digits instead of 2.6; in double precision that is harmless here but becomes a problem for $\kappa\gtrsim10^8$. QR or SVD works with $A$ directly and keeps $\kappa(A)$.
9. $J=\tfrac12(Ax-b)^T(Ax-b)$; $\nabla J=A^T(Ax-b)=0$ gives the normal equations. $A^TA$ is invertible iff the columns of $A$ are independent (trivial nullspace). Geometrically the closest point $Ax$ in the column space to $b$ is the projection: the error $b-Ax$ is perpendicular to every column, i.e. $A^T(b-Ax)=0$.
10. A good answer shows: row swap used when a pivot is smaller than a tolerance, an explicit `ValueError` for singular systems, rank 2 for the fit matrix, $(a,b)=(7/6,3/2)$, and the orthogonality check on random data with a tolerance like $10^{-9}$.
