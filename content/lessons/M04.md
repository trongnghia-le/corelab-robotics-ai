## Vì sao học bài này?

Understand what a linear solver can and cannot recover. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

A linear system asks whether a target can be assembled from available directions. Redundant directions do not create new capabilities. In robot estimation, a sensor can constrain some directions while leaving others ambiguous; a solver cannot manufacture information about the missing directions.

## Định nghĩa và suy luận · Theory & derivation

The span of columns of $A$ is every vector $Ax$. Columns are independent if $Ac=0$ implies $c=0$. Rank counts independent column directions. A system $Ax=b$ has a solution exactly when $b$ lies in that column space; a solution is unique when the nullspace is trivial.

Elimination replaces equations by equivalent combinations. For $x+y=3$ and $x-y=1$, subtract the second equation from the first to get $2y=2$, hence $y=1$ and $x=2$. If the second equation were $2x+2y=6$, it would add no constraint: infinitely many solutions remain.

For inconsistent measurements, minimize $J(x)=\frac12\|Ax-b\|^2$. Differentiating yields $A^T(Ax-b)=0$: the residual is perpendicular to the column space. This gives normal equations $A^TAx=A^Tb$. Deriving them clarifies the geometry; numerically, QR or SVD avoids the condition-number squaring caused by explicitly forming $A^TA$.

## Ví dụ có lời giải · Worked example

For A=[[1,1],[2,2]], both columns are identical, so rank=1. The equation Ax=(3,6) admits x=(3,0), (2,1), and many others. Ax=(3,7) is inconsistent because the second output must be twice the first. No optimizer setting changes that structural fact.

## Triển khai tham khảo · Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
import numpy as np
A = np.array([[1., 1.], [2., 2.]])
b = np.array([3., 7.])
x, residuals, rank, singular_values = np.linalg.lstsq(A, b, rcond=None)
assert rank == 1
assert np.allclose(A.T @ (A @ x - b), 0)
```

## Hiểu lầm thường gặp · Failure modes

A low residual does not prove a unique solution. A rectangular matrix is not automatically full rank. Floating-point rank depends on scale and tolerance, so inspect singular values before interpreting a borderline case.

## So sánh và lựa chọn · Alternatives

Elimination is transparent for hand calculations; QR handles well-conditioned least squares; SVD exposes weak or missing directions and supports regularization. These are different numerical tools for the same geometry.
