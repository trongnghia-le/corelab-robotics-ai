## Vì sao học bài này?

Make array dimensions explicit before vectorizing computations. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

A batch of vectors is a table whose axes have meaning. NumPy can repeat compatible singleton dimensions without physically copying data, but it cannot know whether a dimension means sample, feature, or camera. Shape reasoning is therefore part of mathematical correctness.

## Định nghĩa và suy luận · Theory & derivation

An array of $N$ samples with $D$ features has shape $(N,D)$ under the row-sample convention. Broadcasting compares dimensions from the right: a pair is compatible if equal or either is 1; missing leading dimensions behave as 1. Thus $(N,D)-(D,)$ centers features, while $(N,D)-(N,)$ usually fails or, when $N=D$, can silently mean the wrong thing.

Feature means use `X.mean(axis=0)`, which reduces the sample axis and gives shape `(D,)`. Per-row means use `axis=1, keepdims=True`, preserving shape `(N,1)` for subtraction. `A*B` multiplies elementwise; `A@B` contracts matrix dimensions.

For row normalization, compute $r_i=\sqrt{\sum_jX_{ij}^2}$ and $Y_{ij}=X_{ij}/r_i$. Specify how to handle zero rows. A view can share storage with its parent; modifying a slice may mutate the source. Use `.copy()` when independent ownership is required.

## Ví dụ có lời giải · Worked example

X=[[1,2,3],[4,5,6]] has shape (2,3). Its feature mean is [2.5,3.5,4.5], so centering yields two rows [−1.5,−1.5,−1.5] and [1.5,1.5,1.5]. Row means [2,5] require shape (2,1); a plain (2,) cannot broadcast against (2,3).

## Triển khai tham khảo · Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
import numpy as np
X=np.array([[1.,2.,3.],[4.,5.,6.]])
centered=X-X.mean(axis=0,keepdims=True)
assert centered.shape == X.shape
assert np.allclose(centered.mean(axis=0),0)
row_centered=X-X.mean(axis=1,keepdims=True)
```

## Hiểu lầm thường gặp · Failure modes

A shape-compatible result can be conceptually wrong. Square batches conceal axis swaps, so prefer non-square test examples. Integer arrays can truncate assignments of floating-point results.

## So sánh và lựa chọn · Alternatives

Loops are useful reference implementations. Broadcasting is fast and compact but can allocate huge intermediates. Matrix products exploit optimized kernels; verify shapes and memory cost before replacing a clear implementation.
