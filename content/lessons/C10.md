## Why this matters

Linear tools (C04, C05) describe behaviour near an equilibrium. Robots leave that neighbourhood: a pendulum swings through 90 degrees, a manipulator's inertia changes with its pose, an actuator saturates. Nonlinear control gives two things: a way to *prove* stability and estimate how large the guaranteed region is (Lyapunov), and a way to *design* a controller that cancels known nonlinearity (feedback linearisation, the idea behind computed torque). Both depend on the model being right, and both have regions where they stop working.

## Intuition

Think of a bowl. A marble in a smooth bowl loses energy to friction and ends at the bottom. You can prove that without solving the motion: the height (energy) only decreases, and it is zero only at the bottom. A **Lyapunov function** $V(x)$ is a generalised energy: positive away from the equilibrium, zero at it. If its value strictly decreases along every trajectory, the state must end at the equilibrium. If the bowl has a rim (a boundary beyond which $V$ stops decreasing), the proof holds only inside it: that is the basin of attraction.

*Figure: left, $\dot V=-x^2(1-x)$ is negative for $|x|<1$ and positive beyond, so the guaranteed basin is $|x|<1$; right, the inner loop cancels the nonlinearity and the outer loop shapes a linear response, but an actuator limit shrinks the basin.*

## Theory and derivation

### Lyapunov's direct method

Let $x^*=0$ be an equilibrium of $\dot x=f(x)$. If there is a continuously differentiable $V$ with $V(0)=0$, $V(x)>0$ for $x\neq0$ near $0$, and
$$\dot V(x)=\nabla V(x)^\top f(x)<0\quad(x\neq0),$$
then $0$ is asymptotically stable. If $\dot V\le0$ you only get stability (the state stays near). If $V$ is also radially unbounded ($V\to\infty$ as $\|x\|\to\infty$) and $\dot V<0$ everywhere, stability is global. Otherwise, any sublevel set $\Omega_c=\{V\le c\}$ on which $\dot V<0$ (and which is bounded) is **invariant** and inside the basin: take the largest such $c$.

### Linearisation can fail

Near $0$, $\dot x\approx Ax$ with $A=\partial f/\partial x$. If all eigenvalues have negative real part the equilibrium is locally stable; if one has positive real part it is unstable. If the eigenvalues are on the imaginary axis the test is silent: $\dot x=-x^3$ (stable) and $\dot x=+x^3$ (unstable) have the same linearisation $\dot x=0$. Lyapunov handles both: $V=\tfrac12x^2$ gives $\dot V=\mp x^4$.

### Semi-definite derivative and LaSalle

For a damped pendulum $\ddot\theta=-\tfrac gl\sin\theta-b\dot\theta$, the energy $V=\tfrac12\omega^2+\tfrac gl(1-\cos\theta)$ has
$$\dot V=-b\,\omega^2\le0.$$
It is zero whenever $\omega=0$, so the strict test fails on the line $\omega=0$. **LaSalle's invariance principle**: trajectories converge to the largest invariant set inside $\{\dot V=0\}$. If $\omega\equiv0$ then $\dot\omega=-\tfrac gl\sin\theta=0$, so $\theta=0$ (for $|\theta|<\pi$). Hence the state converges to the bottom.

### Feedback linearisation

For the inverted pendulum (angle from upright) $\ddot\theta=\tfrac gl\sin\theta-b\dot\theta+a$, where $a$ is the torque divided by $ml^2$, choose
$$a=-\tfrac gl\sin\theta+b\dot\theta+v,\qquad v=-k_1\theta-k_2\dot\theta.$$
The closed loop is the linear system $\ddot\theta=-k_1\theta-k_2\dot\theta$ with poles from $s^2+k_2s+k_1$, for **every** $\theta$, if the model is exact and $a$ can be produced. Two caveats follow immediately:

- **Torque limit.** Holding $\theta$ needs $|a|\ge\tfrac gl|\sin\theta|$ just to cancel gravity. With $|a|\le a_{\max}<g/l$, starting at rest from $\theta_0$ with $\sin\theta_0>a_{\max}/(g/l)$ cannot be recovered.
- **Model error.** If the true gravity term is $(1+\epsilon)\tfrac gl\sin\theta$, the loop becomes $\ddot\theta=\epsilon\tfrac gl\sin\theta+v$: stable near $0$ iff $k_1>\epsilon g/l$.

Feedback linearisation is *exact only on paper*; also note that it cancels even helpful nonlinearities, which wastes effort.

## Worked example

System $\dot x=-x+x^2$, candidate $V=\tfrac12x^2$ ($V>0$ for $x\ne0$).

1. $\dot V=x\dot x=x(-x+x^2)=-x^2+x^3=-x^2(1-x)$.
2. Signs: for $x<1$ (and $x\neq0$), $1-x>0$ so $\dot V<0$. At $x=1$, $\dot V=0$. For $x>1$, $\dot V>0$.
3. Sublevel set: $V\le c$ is $|x|\le\sqrt{2c}$. The largest set on which $\dot V<0$ needs $\sqrt{2c}<1$, i.e. $c<\tfrac12$: the guaranteed basin is $|x|<1$.
4. Is it tight? $x=1$ is itself an equilibrium of the dynamics ($-1+1=0$), so it is exact. Exact solution: with $u=1/x$, $\dot u=u-1$, so $x(t)=\dfrac{1}{1+(1/x_0-1)e^{t}}$. For $x_0>1$ the denominator vanishes at $t^*=\ln\dfrac{x_0}{x_0-1}$: $x_0=1.01$ blows up at $t^*=\ln101=4.62$ s; $x_0=1.1$ at $\ln11=2.40$ s; $x_0=0.9$ decays to 0.
5. The Jacobian at 0 is $-1$: stable, consistent. At $x=1$ it is $-1+2=+1$: unstable.

## Reference implementation

A sign check of $\dot V$ for the worked example and a simulation that confirms the basin edge.

```python
# Lyapunov sign check for x' = -x + x^2 with V = x^2/2:  Vdot = -x^2 (1 - x).
f = lambda x: -x + x * x
Vdot = lambda x: x * f(x)
for x in (-2.0, -0.5, 0.5, 0.99, 1.0, 1.5):
    print(f"x={x:5}: Vdot={Vdot(x):8.4f}")
assert all(Vdot(x) < 0 for x in (-2.0, -0.5, 0.5, 0.99))     # decreasing inside |x| < 1
assert Vdot(1.0) == 0 and Vdot(1.5) > 0                       # not decreasing at or beyond x = 1

def settle(x0, dt=1e-3, T=20.0):
    x = x0
    for _ in range(int(T / dt)):
        x += dt * f(x)
        if abs(x) > 1e6: return None
    return x
assert abs(settle(0.9)) < 1e-6 and settle(1.05) is None       # the sign change marks the basin edge
print("start 0.9 -> converges; start 1.05 -> escapes")
```

## Independent practice

### Goal

Build a small nonlinear-analysis toolkit (RK4 integrator, Lyapunov derivative, grid check, feedback-linearising law) and use it to find where a Lyapunov proof stops, where a controller loses its guarantee, and whether simulations agree.

### Setup

Python 3, standard library only. Save starter and tests as `nonlin_lab.py`.

### Tasks

1. Implement `rk4_step` and `simulate` (with an escape bound) and check $x'=-x$.
2. Implement `vdot` and `violations`; reproduce the sign table of the worked example.
3. Confirm the blow-up time $\ln(x_0/(x_0-1))$ from simulation.
4. Apply `violations` to the damped pendulum and explain why only $\omega=0$ points fail.
5. Implement `fl_accel` and verify it gives $\ddot\theta=-k_1\theta-k_2\omega$.
6. Add the torque limit and find the starts that converge.

import math

def rk4_step(f, x, dt):

def simulate(f, x0, dt, N, bound=1e6):
    """Integrate with rk4_step for N steps; stop early (and return what you have)
    as soon as max |component| exceeds bound. Returns the list of states including x0."""
    raise NotImplementedError

def vdot(grad_v, f, x):
    """Derivative of V along trajectories: the dot product grad V(x) . f(x)."""
    raise NotImplementedError

def violations(grad_v, f, points, tol=1e-12):
    """Return the sample points (skipping any point where all |components| < 1e-12,
    i.e. the origin) at which vdot >= -tol, i.e. V is NOT strictly decreasing."""
    raise NotImplementedError

def fl_accel(theta, omega, g_l, b, k1, k2):

    theta'' = g_l*sin(theta) - b*omega + a. Choose a = -g_l*sin(theta) + b*omega + v
    with v = -k1*theta - k2*omega so that theta'' = v."""

### Tests

Paste below the starter code.

```python

# ---- tests ----
# 1. RK4 accuracy on x' = -x:  x(1) = e^-1
xs = simulate(lambda x: [-x[0]], [1.0], 0.01, 100)
assert abs(xs[-1][0] - math.exp(-1)) < 1e-9 and len(xs) == 101

# 2. scalar example x' = -x + x^2 with V = x^2/2 (grad V = x): Vdot = -x^2 (1 - x)
f1 = lambda x: [-x[0] + x[0] ** 2]
g1 = lambda x: [x[0]]
assert abs(vdot(g1, f1, [0.5]) - (-0.125)) < 1e-12 and abs(vdot(g1, f1, [2.0]) - 4.0) < 1e-12
pts = [[i / 10.0] for i in range(-20, 21)]
bad = violations(g1, f1, pts)
assert sorted(p[0] for p in bad) == [1.0 + i / 10.0 for i in range(0, 11)]    # exactly x >= 1
assert [0.0] not in bad                                                        # origin skipped
# 3. basin of attraction: exact blow-up time ln(x0/(x0-1)) for x0 > 1
assert abs(simulate(f1, [0.9], 0.01, 3000)[-1][0]) < 1e-6
esc = simulate(f1, [1.01], 0.01, 3000)
assert len(esc) < 3001 and abs(esc[-1][0]) > 1e6
assert abs((len(esc) - 1) * 0.01 - math.log(101)) < 0.05

# 4. damped hanging pendulum: V = w^2/2 + g(1 - cos th), Vdot = -b w^2 (only negative SEMI-definite)
g_l, b = 9.81, 0.5
fp = lambda x: [x[1], -g_l * math.sin(x[0]) - b * x[1]]
gp = lambda x: [g_l * math.sin(x[0]), x[1]]
assert abs(vdot(gp, fp, [0.7, 2.0]) - (-b * 4.0)) < 1e-12
grid = [[a / 4.0, w / 4.0] for a in range(-12, 13) for w in range(-8, 9)]
bad = violations(gp, fp, grid)
assert bad and all(abs(p[1]) < 1e-12 for p in bad)        # only the points with w = 0 fail strictness
E0 = [0.5 * x[1] ** 2 + g_l * (1 - math.cos(x[0])) for x in simulate(fp, [2.5, 0.0], 0.001, 8000)]
assert all(E0[i + 1] <= E0[i] + 1e-9 for i in range(len(E0) - 1))   # energy never increases

# 5. feedback linearisation of the inverted pendulum: theta'' = g sin(theta) - b w + a
k1, k2 = 25.0, 10.0
for th, w in [(0.3, -0.2), (1.0, 0.5), (-0.7, 1.5)]:
    a = fl_accel(th, w, g_l, b, k1, k2)
    assert abs((g_l * math.sin(th) - b * w + a) - (-k1 * th - k2 * w)) < 1e-12
def closed(amax):
    def F(x):
        a = max(-amax, min(amax, fl_accel(x[0], x[1], g_l, b, k1, k2)))
        return [x[1], g_l * math.sin(x[0]) - b * x[1] + a]
    return F
ok = lambda th, amax: max(abs(c) for c in simulate(closed(amax), [th, 0.0], 0.001, 8000, bound=50)[-1]) < 1e-3
assert ok(0.5, 1e9) and ok(1.2, 1e9)             # unlimited torque: global within the sampled range
assert ok(0.5, 8.0) and not ok(1.2, 8.0)         # torque limit 8 < g: only a basin remains
print("blow-up time from x0 = 1.01: %.2f s (theory ln(101) = %.2f)" % ((len(esc) - 1) * 0.01, math.log(101)))
print("grid points where Vdot is not strictly negative (pendulum): %d, all with w = 0" % len(bad))
print("torque limit 8: converges from 0.5 rad = %s, from 1.2 rad = %s" % (ok(0.5, 8.0), ok(1.2, 8.0)))
print("all tests passed")
```

### Extension challenge

Add a model error of $+10\%$ to the gravity term in the simulation and sweep $k_1$ to find the smallest value for which the small-angle response still converges. Compare with the prediction $k_1>0.1\,g/l$.

## Verification

Verify a Lyapunov claim three ways: analytically (sign of $\dot V$ by algebra), numerically on a fine grid including the boundary, and by simulating trajectories from inside and outside the claimed region. A grid check is evidence, not proof, and says nothing outside the grid. Test feedback linearisation by confirming the exact closed-loop acceleration at random states, then stress it: torque limit, model error, noise.

## Failure modes

- **Concluding global stability from local samples** (exercise 5).
- **Treating $\dot V\le0$ as asymptotic stability** without LaSalle.
- **Positive-definite $V$ that is not radially unbounded:** a decreasing $V$ can still allow escape.
- **Ignoring saturation:** feedback linearisation demands large torque near horizontal; clipping can remove all stability beyond about 55 degrees in the lab case.
- **Model mismatch:** a 10% gravity error leaves a residual $0.1\,\tfrac gl\sin\theta$.
- **Cancelling helpful dynamics:** inverting a stabilising nonlinearity (hanging pendulum) wastes torque and amplifies sensor noise.

## Alternatives and trade-offs

Linearise and use LQR (C05) when staying near an equilibrium: simple, guaranteed locally, with an LQR-derived $V=x^\top Px$ giving a basin estimate. Feedback linearisation/computed torque: global on paper, needs an accurate model and torque headroom. Energy shaping and passivity-based control exploit the physics instead of cancelling it. Sliding-mode and adaptive control tolerate model error at a price. MPC (C11) handles constraints directly. Sum-of-squares programming can search for $V$ automatically.

## Exercise answers

1. Both have $A=0$; marginal eigenvalues carry no information. With $V=\tfrac12x^2$: $\dot V=-x^4<0$ for $\dot x=-x^3$ (asymptotically stable, though not exponentially) and $\dot V=+x^4>0$ for $\dot x=x^3$ (unstable).
2. $\dot V=-x^2(1-x)$: at $0.5$: $-0.25\cdot0.5=-0.125$; at $1$: $0$; at $2$: $-4(1-2)=+4$. Decreasing inside $|x|<1$, not at or beyond 1: the guaranteed basin is $|x|<1$.
3. (a) $\dot V=2x_1(-x_1+x_2)+2x_2(-x_1-x_2)=-2x_1^2-2x_2^2$: negative definite, asymptotically stable. (b) $\dot V=2x_1x_2+2x_2(-x_1-x_2)=-2x_2^2\le0$: semi-definite. On $\{x_2=0\}$ staying there requires $\dot x_2=-x_1=0$, so the only invariant set is the origin: asymptotically stable by LaSalle.
4. $\dot V=-0.5\cdot4=-2.0$. When $\omega=0$ and $\theta\ne0$ the energy is momentarily not decreasing, but the pendulum is not at rest there ($\dot\omega\ne0$), so it immediately leaves the set; LaSalle then gives convergence to the bottom.
5. Samples in $[-0.9,0.9]$ lie inside the region where the sign holds, so they cannot reveal the failure at $x\ge1$ where $\dot V\ge0$ and trajectories diverge. A valid argument is the algebraic factorisation $\dot V=-x^2(1-x)$ (negative for $x<1$, positive for $x>1$) giving a local, not global, result; also test the boundary and beyond.
6. $x_0=0.99$ converges to 0; $x_0=1.01$ diverges, blowing up at $t^*=\ln(1.01/0.01)=\ln101=4.62$ s (the lab measures 4.63 s with the step size).
7. $s^2+k_2s+k_1=(s+4)(s+5)=s^2+9s+20$: $k_1=20,\ k_2=9$, $a=-9.81\sin\theta+b\dot\theta-20\theta-9\dot\theta$. With 10% more gravity the residual is $0.981\sin\theta\approx0.981\theta$, so $k_{1,\text{eff}}=20-0.981=19.02$ and the poles solve $s^2+9s+19.02$: $s=-4.5\pm\sqrt{20.25-19.02}=-4.5\pm1.11$, i.e. $-3.39$ and $-5.61$. Still stable.
8. To hold $\theta_0$ you need $a\ge\tfrac gl\sin\theta_0$, so $\sin\theta_0\le8/9.81$, $\theta_0\le0.9536$ rad (54.6 degrees). At the boundary the torque needed to cancel gravity already equals the limit, so no extra torque remains for $v$, and no choice of $k_1,k_2$ helps. The lab bisection finds 0.9536.
9. A good answer notes that (i) needs an accurate model and large torques near horizontal; (ii) uses the physics (energy pumping needs little torque) and hands over inside the LQR basin, which can be estimated from $V=x^\top Px$; (iii) works only near upright. Checks: Lyapunov sign test on a grid, simulation with mass/length errors, torque saturation, delay and noise. Typically pick (ii) for a limited-torque arm.
10. (a) The grid flags exactly $x\in\{1.0,1.1,\dots,2.0\}$. (b) All starts below 1 converge, all above diverge. (c) The bisection gives 0.9536 rad, matching $\arcsin(8/9.81)=0.9536$.
