## Why this matters

If you know exactly how a system behaves, you do not need to learn by trial and error: you can compute the best behaviour. A warehouse routing problem with a known map, a charging-station scheduler, or a discretised model of a simple robot are all small enough that dynamic programming (DP) gives the exact optimal policy in milliseconds. DP is also the template for everything that follows in reinforcement learning. Monte Carlo and temporal-difference methods (RL05) are DP backups with sampled instead of exact expectations; Q-learning (RL06) is value iteration from samples. The practical lessons are the same too: how to stop, what the error is, and what an update order changes.

## Intuition

Values satisfy a self-consistency condition: the value of a state equals the immediate reward plus the discounted value of where you land, averaged over the policy and the model (RL03). DP turns that condition into an algorithm by treating it as an update rule. Start with any table, apply the rule to every state, and repeat. Each sweep uses information one step further into the future, so the table improves from the end of the episode backwards; the discount makes distant future matter less, so the process converges.

Three algorithms follow.

- **Policy evaluation**: apply the *expectation* backup for a fixed policy to get $V^\pi$.
- **Policy improvement**: act greedily with respect to $Q^\pi$ to get a better policy.
- **Value iteration**: apply the *optimality* backup (max over actions) to go straight to $V^*$.

## Theory and derivation

### Iterative policy evaluation

For a fixed policy $\pi$ define the backup
$$(T^\pi V)(s)=\sum_a\pi(a|s)\sum_{s',r}p(s',r|s,a)\big[r+\gamma V(s')\big].$$
The true $V^\pi$ is its fixed point, $V^\pi=T^\pi V^\pi$. **Synchronous** evaluation computes the whole new table from the old one: $V_{k+1}=T^\pi V_k$. An **in-place** (Gauss-Seidel) sweep overwrites entries immediately so later states see new values; it has the same fixed point and usually converges in fewer sweeps.

### Contraction and convergence

For the max norm $\|V\|_\infty=\max_s|V(s)|$,
$$\|T^\pi V-T^\pi W\|_\infty\le\gamma\|V-W\|_\infty .$$
Proof: for each $s$, $|T^\pi V(s)-T^\pi W(s)|=\gamma\big|\sum_a\pi\sum p\,(V(s')-W(s'))\big|\le\gamma\max_{s'}|V(s')-W(s')|$ because the weights $\pi\cdot p$ are non-negative and sum to at most 1. Banach's fixed-point theorem then gives a unique fixed point and $\|V_k-V^\pi\|_\infty\le\gamma^k\|V_0-V^\pi\|_\infty$.

The optimality backup $(T^*V)(s)=\max_a\sum p[r+\gamma V(s')]$ is also a $\gamma$-contraction, because $|\max_af(a)-\max_ag(a)|\le\max_a|f(a)-g(a)|$.

### Policy improvement and policy iteration

Given $V^\pi$, the greedy policy $\pi'(s)=\arg\max_aQ^\pi(s,a)$ satisfies $V^{\pi'}\ge V^\pi$ (RL03). **Policy iteration** alternates evaluation and improvement. A finite MDP has finitely many deterministic policies and each round strictly improves the policy until it is optimal, so the loop terminates; in practice it needs very few rounds.

### Value iteration and stopping

Value iteration repeats $V_{k+1}=T^*V_k$. The **Bellman optimality residual** $\|T^*V-V\|_\infty$ measures how far $V$ is from a fixed point. Using the contraction, if one sweep changes $V$ by less than $\theta$ then
$$\|V_{k+1}-V^*\|_\infty\le\frac{\gamma}{1-\gamma}\theta .$$
A smaller $\theta$ is needed as $\gamma\to1$: at $\gamma=0.99$ the factor is 99. The greedy policy with respect to the final $V$ is optimal once the values are accurate enough to separate the best action from the others.

### Cost

One sweep costs $O(|S|\,|A|\,b)$ with $b$ successors per pair. That is trivial for 5 states and impossible for a continuous robot state discretised to $10^{12}$ cells: DP needs a model and suffers the curse of dimensionality, which is what sampling methods and function approximation address.

## Worked example

### Value iteration on the slippery corridor

**Problem.** The corridor MDP has states $0,\dots,4$. State 0 (pit) and state 4 (goal) are terminal with $V=0$; entering the pit pays $-10$ and entering the goal pays $+10$, and every other move pays $-1$. Actions are left and right; the chosen move slips (goes the other way) with probability $0.2$; $\gamma=0.9$. Value iteration uses the synchronous backup $V_{k+1}(s)=\max_a\sum_{s'}p(s'\mid s,a)\,[r+\gamma V_k(s')]$ from $V_0=0$, and the residual is $\max_s|V_{k+1}(s)-V_k(s)|$. Find: (a) $V_1$ and its residual; (b) $V_2$, its residual and the ratio of the two residuals; (c) the converged $V^*$ (stop when the residual is below $\theta=10^{-10}$), the optimal policy, and a check of $V^*(2)$ from $Q$; (d) the error guarantee for $\theta=10^{-3}$ against the real error, and how many sweeps in-place (Gauss-Seidel) updates need.

**Solution.**

1. First sweep, state 1. Right reaches state 2 with probability $0.8$ (reward $-1$, $V_0=0$) and slips to the pit with probability $0.2$ (reward $-10$): $Q(1,\text{right})=0.8(-1)+0.2(-10)=-0.8-2=-2.8$. Left is the mirror image: $Q(1,\text{left})=0.8(-10)+0.2(-1)=-8.2$. The max is $-2.8$.
2. First sweep, states 2 and 3. State 2: both neighbours are non-terminal with $V_0=0$, so both actions give $0.8(-1)+0.2(-1)=-1$. State 3: $Q(3,\text{right})=0.8\cdot10+0.2(-1)=7.8$ and $Q(3,\text{left})=0.8(-1)+0.2\cdot10=1.2$. The max is $7.8$.
3. Result of (a): $V_1=(-2.8,\,-1,\,7.8)$ for states $(1,2,3)$. Residual $=\max(2.8,\,1,\,7.8)=7.8$.
4. Second sweep, state 1, right: the move succeeds to state 2 where $V_1(2)=-1$, and slips to the pit: $0.8\,(-1+0.9\cdot(-1))+0.2(-10)=0.8(-1.9)-2=-1.52-2=-3.52$.
5. Second sweep, state 2, right: success goes to state 3 ($V_1=7.8$), slip goes to state 1 ($V_1=-2.8$): $0.8(-1+0.9\cdot7.8)+0.2(-1+0.9\cdot(-2.8))=0.8\cdot6.02+0.2\cdot(-3.52)=4.816-0.704=4.112$.
6. Second sweep, state 3, right: success is the goal (reward $10$, no future), slip goes to state 2 ($V_1=-1$): $0.8\cdot10+0.2(-1+0.9\cdot(-1))=8-0.38=7.62$.
7. Result of (b): $V_2=(-3.52,\,4.112,\,7.62)$. Changes: $|-3.52+2.8|=0.72$, $|4.112+1|=5.112$, $|7.62-7.8|=0.18$, so the residual is $5.112$ and the ratio is $5.112/7.8=0.655\le\gamma=0.9$, as the contraction requires.
8. Convergence, (c): repeating the sweep until the residual drops below $10^{-10}$ takes 40 sweeps and gives $V^*=(1.1965,\,5.5508,\,8.7991)$. In every state the right action has the larger $Q$, so the optimal policy is "right" everywhere.
9. Check of $V^*(2)$ from $Q$: $Q(2,\text{right})=0.8(-1+0.9\cdot8.7991)+0.2(-1+0.9\cdot1.1965)=0.8\cdot6.9192+0.2\cdot0.0769\approx5.5508$ (the rounded inputs give $5.5507$; the unrounded table gives $5.5508$), equal to $V^*(2)$. The other action gives $Q(2,\text{left})=1.4454$, which is lower.
10. Stopping bound, (d): when the residual is below $\theta$, $\|V_{k+1}-V^*\|_\infty\le\gamma\theta/(1-\gamma)$. With $\theta=10^{-3}$: $0.9\cdot10^{-3}/0.1=0.009$. Running to that threshold stops after 16 sweeps with real error $3.7\cdot10^{-4}<0.001$, well inside the guarantee (the bound is worst-case).
11. In-place (Gauss-Seidel) sweeps, which reuse the new value of a state within the same sweep, reach the same table ($10^{-10}$ threshold) in 22 sweeps instead of 40.

**Check.** A residual ratio $0.655<0.9$ matches the contraction factor. The greedy values satisfy the Bellman optimality equation (step 9: $Q(2,\text{right})$ reproduces $V^*(2)$). Independent run: a direct Python implementation of the sweep reproduces $V_1$, $V_2$, 40 sweeps, $V^*$, 16 sweeps for $\theta=10^{-3}$ with error $3.7\cdot10^{-4}$, and 22 Gauss-Seidel sweeps.

**Takeaway.** Each sweep shrinks the residual by at most the factor $\gamma$, so the first two residuals (7.8, then 5.112) already show the contraction, and $\gamma\theta/(1-\gamma)$ turns a small residual into a guaranteed error bound.

## Reference implementation

The MDP is a dictionary of `(prob, next_state, reward)` lists; terminal states have value 0 and are absent from the value table.

```python
GAMMA = 0.9
ACTIONS = ["left", "right"]
TERMINALS = {0, 4}

def corridor(slip=0.2):
    """States 0..4 in a row. 0 is a pit (reward -10 on entry), 4 is the goal (reward +10 on entry).
    Every other step costs -1. An action moves as intended with prob 1-slip and the other way with prob slip."""
    P = {}
    for s in (1, 2, 3):
        for a in ACTIONS:
            d = -1 if a == "left" else 1
            outs = []
            for step, p in ((d, 1 - slip), (-d, slip)):
                s2 = s + step
                r = 10.0 if s2 == 4 else -10.0 if s2 == 0 else -1.0
                outs.append((p, s2, r))
            P[(s, a)] = outs
    return P

STATES = [1, 2, 3]

def q_value(P, V, s, a, gamma=GAMMA):
    return sum(p*(r + gamma*V.get(s2, 0.0)) for p, s2, r in P[(s, a)])

def policy_evaluation(P, pi, gamma=GAMMA, theta=1e-10):
    """Synchronous sweeps: V_{k+1}(s) = sum_a pi(a|s) Q_k(s,a) computed from the OLD table only."""
    V = {s: 0.0 for s in STATES}
    sweeps = 0
    while True:
        new = {s: sum(pi[s].get(a, 0.0)*q_value(P, V, s, a, gamma) for a in ACTIONS) for s in STATES}
        delta = max(abs(new[s] - V[s]) for s in STATES)
        V = new
        sweeps += 1
        if delta < theta:
            return V, sweeps

def greedy(P, V, gamma=GAMMA):
    """Deterministic greedy policy, ties to the first action in ACTIONS."""
    out = {}
    for s in STATES:
        best = max(ACTIONS, key=lambda a: (round(q_value(P, V, s, a, gamma), 12), -ACTIONS.index(a)))
        out[s] = {best: 1.0}
    return out

def policy_iteration(P, gamma=GAMMA):
    pi = {s: {"left": 0.5, "right": 0.5} for s in STATES}
    rounds = 0
    while True:
        V, _ = policy_evaluation(P, pi, gamma)
        new = greedy(P, V, gamma)
        rounds += 1
        if new == pi:
            return pi, V, rounds
        pi = new

def value_iteration(P, gamma=GAMMA, theta=1e-10):
    """Returns (V, list of residuals max|V_{k+1}-V_k| per sweep)."""
    V = {s: 0.0 for s in STATES}
    residuals = []
    while True:
        new = {s: max(q_value(P, V, s, a, gamma) for a in ACTIONS) for s in STATES}
        res = max(abs(new[s] - V[s]) for s in STATES)
        residuals.append(res)
        V = new
        if res < theta:
            return V, residuals

if __name__ == "__main__":
    P = corridor()
    for (s, a), outs in P.items():
        assert abs(sum(p for p, _, _ in outs) - 1) < 1e-12
    V1 = {s: max(q_value(P, {}, s, a) for a in ACTIONS) for s in STATES}
    print("first VI sweep:", {s: round(v, 3) for s, v in V1.items()})
    Vs, res = value_iteration(P)
    print("V*:", {s: round(v, 4) for s, v in Vs.items()}, "sweeps:", len(res))
    print("residual ratios:", [round(res[i+1]/res[i], 3) for i in range(4)])
    pi, Vp, rounds = policy_iteration(P)
    print("policy:", {s: list(pi[s])[0] for s in STATES}, "rounds:", rounds)
    assert all(abs(Vs[s] - Vp[s]) < 1e-8 for s in STATES)
    assert all(abs(Vs[s] - max(q_value(P, Vs, s, a) for a in ACTIONS)) < 1e-8 for s in STATES)
    assert all(res[i+1] <= GAMMA*res[i] + 1e-12 for i in range(len(res) - 1))   # contraction
    print("self-test passed")
```

### Library track

Redo value iteration with NumPy arrays (`T[a, s, s']`, `R[a, s]`, one matrix product per sweep) and check it against the stdlib `value_iteration` and the contraction ratio; then run the same algorithm on Gymnasium's `FrozenLake-v1` transition model (`env.unwrapped.P`) and execute the greedy policy in the real environment. Put the reference code above this block. Needs `numpy` and `gymnasium`.

```python
import numpy as np
import gymnasium as gym

# --- 1. vectorised value iteration on arrays: P[a, s, s'] and R[a, s] (expected reward) ---
def to_arrays(P, states=(1, 2, 3)):
    idx = {s: i for i, s in enumerate(states)}
    n = len(states)
    T = np.zeros((len(ACTIONS), n, n)); R = np.zeros((len(ACTIONS), n))
    for ai, a in enumerate(ACTIONS):
        for s in states:
            for p, s2, r in P[(s, a)]:
                R[ai, idx[s]] += p * r
                if s2 in idx: T[ai, idx[s], idx[s2]] += p     # terminals are dropped: value 0
    return T, R
def vi_numpy(T, R, gamma, theta=1e-10):
    V = np.zeros(T.shape[1]); res = []
    while True:
        Vn = (R + gamma * T @ V).max(0)
        res.append(np.abs(Vn - V).max()); V = Vn
        if res[-1] < theta: return V, res
T, R = to_arrays(corridor())
V, res = vi_numpy(T, R, 0.9)
Vref, resref = value_iteration(corridor())
assert np.allclose(V, [Vref[1], Vref[2], Vref[3]], atol=1e-8) and len(res) == len(resref) == 40
assert all(res[i + 1] <= 0.9 * res[i] + 1e-12 for i in range(len(res) - 1))       # contraction
gam = 0.99
_, r99 = vi_numpy(T, R, gam, 1e-8); _, r5 = vi_numpy(T, R, 0.5, 1e-8)
print("sweeps for theta=1e-8: gamma 0.5 -> %d, 0.9 -> %d, 0.99 -> %d" % (len(r5), len(vi_numpy(T, R, 0.9, 1e-8)[1]), len(r99)))

# --- 2. Gymnasium FrozenLake (4x4, slippery): value iteration on env.unwrapped.P, then run the policy.
#        gamma = 1 is fine here because every episode ends; V*(start) is then the best success probability ---
env = gym.make("FrozenLake-v1", is_slippery=True)
model, nS, nA = env.unwrapped.P, env.observation_space.n, env.action_space.n
def q_all(V, gamma):
    return np.array([[sum(p * (r + gamma * (0 if d else V[s2])) for p, s2, r, d in model[s][a]) for a in range(nA)] for s in range(nS)])
V = np.zeros(nS)
for k in range(10000):
    Vn = q_all(V, 1.0).max(1)
    if np.abs(Vn - V).max() < 1e-10: break
    V = Vn
policy = q_all(V, 1.0).argmax(1)
print("FrozenLake: %d sweeps, V*(start) = %.4f" % (k + 1, V[0]))
env = gym.make("FrozenLake-v1", is_slippery=True, max_episode_steps=10_000)   # the default 100-step limit would cut some runs short
wins, rng = 0, np.random.default_rng(1)
for ep in range(2000):
    s, _ = env.reset(seed=int(rng.integers(1 << 30))); done = False
    while not done:
        s, r, term, trunc, _ = env.step(int(policy[s])); done = term or trunc
    wins += r
print("greedy policy success rate: %.3f (V*(start) with gamma=1 is %.3f)" % (wins / 2000, V[0]))
assert abs(wins / 2000 - V[0]) < 0.04            # with gamma = 1 the value is the success probability (episodic task)
print("library track passed")
```

## Verification

- Probabilities of each state-action pair must sum to 1 (assert it).
- At the end, recompute $T^*V$ once more: its residual should be below $\theta$.
- Compare value iteration and policy iteration on the same MDP; the values must agree to the tolerance.
- Hand-check one backup (as in the worked example) before trusting the loop.
- Check the residual ratios stay at or below $\gamma$.

## Failure modes

| Mistake | Wrong value or symptom |
|---|---|
| Residual computed after overwriting (Exercise 5) | Stops after one sweep with $V=(-2.8,-1.504,7.529)$ |
| Forgetting terminal value 0 | Terminal rewards bootstrap and the table drifts |
| Stopping at $\theta$ without the factor $\gamma/(1-\gamma)$ | Error much larger than $\theta$ when $\gamma$ is near 1 |
| Reading the greedy policy from unconverged values | Wrong action in near-ties |
| Mixing synchronous and in-place updates inside one sweep | Different sweep counts, harder to debug |
| Using $\max$ in evaluation of a stochastic policy | Evaluates the greedy policy, not $\pi$ |

## Alternatives and trade-offs

- **Policy iteration** needs few rounds but each evaluation is a full solve; good for small MDPs.
- **Value iteration** is simple, one backup per sweep, slower in sweeps near $\gamma\to1$.
- **Modified policy iteration** runs only a few evaluation sweeps between improvements and sits between the two.
- **Asynchronous and prioritised DP** updates states selectively; same fixed point, fewer backups.
- **Linear solve** for evaluation: exact, $O(n^3)$, fine below a few thousand states.
- **Sampling-based methods (RL05, RL06)** when the model is unknown or the state space is huge.

## Transfer and retention

DP gives the ground truth for checking sample-based estimators in RL05 and RL06 on the same tables. The contraction argument reappears in convergence proofs of Q-learning. In robotics, DP underlies grid-based planners (value iteration on occupancy grids) and the Bellman error losses used in deep RL. Retrieval prompts: State the contraction inequality. What does a residual of $10^{-3}$ guarantee at $\gamma=0.9$? When does policy iteration stop?

## Exercise answers

1. Synchronous means every $V_{k+1}(s)$ uses only $V_k$. Overwriting entries as you go makes later states use some new and some old values; that is the in-place (Gauss-Seidel) scheme, which also converges to the same fixed point but is a different algorithm with a different order dependence and sweep count.
2. With no slip the best path is deterministic: $V(3)=10$, $V(2)=-1+0.9\cdot10=8$, $V(1)=-1+0.9\cdot8=6.2$.
3. $0.99\cdot10^{-6}/0.01=9.9\times10^{-5}$; for $\gamma=0.9$: $0.9\cdot10^{-6}/0.1=9\times10^{-6}$.
4. Fourteen non-terminal cells, two terminal corners, $V_0=0$, repeat the expectation backup with reward $-1$ per step (and no discount in the textbook version). Converged values are most negative far from the terminals (more expected steps to terminate) and close to $0$ next to them; the value is minus the expected number of steps to reach a corner.
5. `V[s]-V[s]` is always 0 because $V[s]$ was just overwritten, so `delta` is 0 and the loop returns after the first sweep with $V=(-2.8,-1.504,7.529)$ (in-place values), far from $V^*$. Fix: compute `new`, compare with the old `V[s]`, then store.
6. $\gamma^k\cdot8.8<10^{-3}$ gives $k>\ln(1.136\times10^{-4})/\ln0.9=86.2$, so 87 sweeps. The real run needs about 40: the bound is worst case over all MDPs, while here the policy is "right" and rewards propagate through few steps.
7. Converged uniform-policy values are $(-6.60,-2.44,3.40)$. They are a lower bound on $V^*=(1.20,5.55,8.80)$ because $V^*\ge V^\pi$ for every policy.
8. Information about the goal reaches one state further in each sweep via the bootstrapped $V(s')$; after $k$ sweeps states within $k$ steps (that have a chance of reaching it) know about the reward, so sweeps look like a front moving backward from the goal.
9. Let $a^*$ maximise $f$. Then $\max f-\max g\le f(a^*)-g(a^*)\le\max|f-g|$; swap roles for the other direction. Apply with $f(a)=\sum p[r+\gamma V(s')]$ and $g$ the same with $W$: the difference is $\gamma\sum p[V(s')-W(s')]$, bounded by $\gamma\|V-W\|_\infty$.
10. A good answer states the model with probabilities summing to 1, shows the residual curve with ratios at most $\gamma$, a table of sweeps for each $\gamma$ with synchronous and in-place counts, agreement with policy iteration, and a rejection check such as residual not decreasing.
