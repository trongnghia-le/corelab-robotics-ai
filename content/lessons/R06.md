## Why this matters

Robots need velocity maps to track paths and understand singularities. A forward map gives position; differentiating it tells you how a small configuration change affects position. The Jacobian connects a geometric model to differential control without needing a full dynamics model.

## Intuition and definitions

For a two-link planar arm, x=l₁ cos(q₁)+l₂ cos(q₁+q₂) and y=l₁ sin(q₁)+l₂ sin(q₁+q₂). Differentiate each coordinate with respect to each joint. With s₁₂=sin(q₁+q₂), c₁₂=cos(q₁+q₂), the first row is [−l₁ sin(q₁)−l₂s₁₂, −l₂s₁₂], and the second is [l₁ cos(q₁)+l₂c₁₂, l₂c₁₂]. Then $\dot p=J(q)\dot q$. A column is endpoint velocity produced by unit motion of one joint with all other joint rates zero.

![Planar 2R arm showing the tip velocity contributed by each joint as the two Jacobian columns](/lesson-figures/R06.svg)

*Figure: each Jacobian column is the tip velocity per unit joint rate, perpendicular to the line from that joint to the tip.*

## Reasoning and assumptions

The determinant is $\det J=l_1l_2\sin q_2$. At q₂=0 or π, the planar endpoint Jacobian loses rank. The arm cannot create arbitrary instantaneous endpoint velocity there. This does not mean the joints stop moving or that forward kinematics becomes undefined. It means task motion directions become constrained.

## Worked example

For l₁=l₂=1, q₁=0, q₂=π/2, J=[[-1,-1],[1,0]]. With joint rates (1,0), endpoint velocity is (−1,1). With rates (0,1), it is (−1,0). The determinant is 1, so both local planar directions are available. At q₁=q₂=0, J=[[0,0],[2,1]] and instantaneous x velocity is zero for every joint-rate choice.

## Implementation and verification

Use a central directional difference: evaluate [f(q+h u)−f(q−h u)]/(2h), then compare with J(q)u. Check nonzero q values, unequal lengths, and random unit directions. Test several h values to see truncation and rounding effects. This independently checks differentiation and matrix ordering.

## Misconceptions and alternatives

An inverse Jacobian can amplify noise near a singularity. A pseudoinverse provides a least-squares velocity solution; damped least squares trades exact task tracking for bounded joint rates. Neither automatically respects joint limits or collision constraints. Always inspect singular values and the resulting rates.

## Independent practice and transfer

### Goal

Implement the planar-arm Jacobian for any number of revolute joints, verify it against finite differences, and use it in a resolved-rate controller. Observe singularity behaviour directly: rates that blow up with a plain inverse and stay bounded with damped least squares.

### Setup

Python 3 and NumPy (`pip install numpy`). Save the starter code and tests in one file, `jacobian_lab.py`, and run `python3 jacobian_lab.py`.

### Tasks

1. Implement `fk(q, l)` and the analytic `jacobian(q, l)` for $n$ joints ($2\times n$).
2. Implement `numeric_jacobian(q, l, h)` with central differences and compare.
3. Implement `manipulability(J)` $=\sqrt{\det(JJ^T)}$.
4. Implement `joint_rates(J, v, lam)`: plain solve for `lam == 0` and damped least squares $J^T(JJ^T+\lambda^2I)^{-1}v$ otherwise.
5. Implement `track(q0, l, v, dt, steps, lam)`: Euler-integrate joint rates for a constant tip velocity and return the final tip and joints.
6. Move the arm toward a straight-arm pose and compare the largest joint rate with and without damping.

### Tests

```python
l2 = np.array([1.0, 1.0])
# hand-computed (lesson worked example)
J = jacobian(np.array([0.0, np.pi / 2]), l2)
assert np.allclose(J, [[-1, -1], [1, 0]])
assert np.allclose(J @ [1, 0], [-1, 1]) and np.allclose(J @ [0, 1], [-1, 0])
assert np.allclose(jacobian(np.array([0.0, 0.0]), l2), [[0, 0], [2, 1]])    # singular
assert abs(manipulability(J) - 1.0) < 1e-12
assert abs(manipulability(jacobian(np.array([0.0, 0.0]), l2))) < 1e-12
assert np.allclose(joint_rates(J, [0, 0.1]), [0.1, -0.1])

# property: analytic equals finite difference for random arms (2R and 3R)
rng = np.random.default_rng(2)
for n in (2, 3, 4):
    for _ in range(25):
        q = rng.uniform(-3, 3, n); l = rng.uniform(0.2, 1.0, n)
        assert np.allclose(jacobian(q, l), numeric_jacobian(q, l), atol=1e-7)
q3 = np.array([0.3, 0.6, 0.9]); l3 = np.ones(3)
J3 = jacobian(q3, l3)
assert J3.shape == (2, 3) and np.allclose(J3 @ np.linalg.svd(J3)[2][-1], 0, atol=1e-12)

# det formula for the 2R arm: l1 l2 sin(q2)
for _ in range(20):
    q = rng.uniform(-3, 3, 2); l = rng.uniform(0.2, 1.0, 2)
    assert abs(np.linalg.det(jacobian(q, l)) - l[0] * l[1] * np.sin(q[1])) < 1e-12

# edge: near a singularity the plain inverse needs far larger rates than damping
Js = jacobian(np.array([0.0, 0.05]), l2)
plain = np.linalg.norm(joint_rates(Js, [0.1, 0.0]))
damped = np.linalg.norm(joint_rates(Js, [0.1, 0.0], lam=0.1))
assert plain > 4.0 and damped < 0.25 and plain > 15 * damped

# tracking: tip moves by v*T = 0.1 m along x (Euler error of order dt)
l_t = np.array([0.5, 0.5]); q0 = np.array([0.3, 1.2])
start = fk(q0, l_t)
tip, q_end = track(q0, l_t, [0.1, 0.0], 0.01, 100)
assert np.linalg.norm(tip - (start + [0.1, 0.0])) < 5e-3
print("plain %.2f rad/s, damped %.2f rad/s; tracking error %.1e m" %
      (plain, damped, np.linalg.norm(tip - (start + [0.1, 0.0]))))
print("all tests passed")
```

Add a null-space term to the 3R arm so that the tip tracks a line while the elbow is pulled toward a preferred posture, using $\dot q=J^+v+(I-J^+J)k(q_\mathrm{pref}-q)$. Verify that the tip velocity is unchanged by the secondary task.

## Exercise answers

1. $\phi=q_1+q_2=180^\circ$. Row 1: $-l_1\sin q_1-l_2\sin\phi=-1-0=-1$ and $-l_2\sin\phi=0$. Row 2: $l_1\cos q_1+l_2\cos\phi=0-1=-1$ and $l_2\cos\phi=-1$. So $J=\begin{bmatrix}-1&0\\-1&-1\end{bmatrix}$, $\det J=(-1)(-1)-0=1=\sin90^\circ$. Yes.
2. $\dot p=J\dot q=(-1)(0.5)+0\cdot(-0.2),\ (-1)(0.5)+(-1)(-0.2))=(-0.5,-0.3)$ m/s. Column 1 is the tip velocity per unit $\dot q_1$ (the tip circling the base: perpendicular to the line from base to tip); column 2 is the tip velocity per unit $\dot q_2$ (the tip circling the elbow).
3. $\det J=l_1l_2\sin q_2=0$ at $q_2=0$ (arm fully stretched) and $q_2=\pm\pi$ (folded back). Both columns become parallel: every joint rate moves the tip perpendicular to the arm, so the velocity component along the arm cannot be produced. (The boundary of the workspace, where the tip also cannot move outward.)
4. $\det J=0.5\cdot0.3\sin20^\circ=0.0513$ m². At $90^\circ$: $0.15$. Ratio $0.34$: at $20^\circ$ the arm is near-singular, so the set of velocities it can produce per unit joint rate is only a third as large in area and strongly elongated.
5. $J=\begin{bmatrix}-1&-1\\1&0\end{bmatrix}$. Solve $-\dot q_1-\dot q_2=0,\ \dot q_1=0.1$: $\dot q=(0.1,-0.1)$ rad/s; check $J\dot q=(-0.1+0.1,\,0.1)=(0,0.1)$. In a control loop $J^{-1}$ amplifies noise and demands very large rates near a singularity; use the pseudoinverse with damping, check the condition number or $\det J$ first.
6. The second column uses $q_2$ where it should use $q_1+q_2$: $-l_2\sin(q_1+q_2)$ and $l_2\cos(q_1+q_2)$. At $q_1=0$ the two are identical, so the first test passes. Detect it with a non-zero $q_1$ and by comparing against a central finite-difference Jacobian.
7. $J^T=\begin{bmatrix}-1&1\\-1&0\end{bmatrix}$, so $\tau=J^TF=(-10,\,0)$ N m. The tip is at $(1,1)$. About the base the moment is $xF_y-yF_x=1\cdot(-10)=-10$ N m, so joint 1 carries $-10$ N m. About the elbow at $(1,0)$ the force acts along the second link (vertical), so it has no moment arm: joint 2 carries $0$.
8. $J=\begin{bmatrix}-0.04998&-0.04998\\1.99875&0.99875\end{bmatrix}$. For $(0,0.1)$: $\|\dot q\|=0.14$ rad/s, fine. For $(0.1,0)$ (along the arm): $\dot q=(2.0,-4.0)$, $\|\dot q\|=4.47$ rad/s - 30 times larger, and growing as $1/\sin q_2$. DLS ($\lambda=0.1$): $J^T(JJ^T+\lambda^2I)^{-1}v$ gives $\|\dot q\|=0.21$ rad/s, but the tip velocity is no longer exactly $(0.1,0)$ (it is much smaller): you traded tracking accuracy for bounded joint rates.
9. $q_2=90^\circ$: $\sigma=(1.618,0.618)$, $\det=1.0$. $30^\circ$: $(2.163,0.231)$, $\det=0.5$. $5^\circ$: $(2.234,0.039)$, $\det=0.087$. The unit-joint-rate velocity ellipse has semi-axes $\sigma_1,\sigma_2$ so its area is $\pi\sigma_1\sigma_2=\pi|\det J|$. For equal speed in all directions, choose the pose with the most circular ellipse - here $q_2=90^\circ$ (ratio 2.6) is best of those listed.
10. Error falls like $h^2$ (truncation) until round-off ($\sim\varepsilon/h$) takes over. Measured max errors: $10^{-1}$: $1.1\times10^{-3}$; $10^{-3}$: $1.1\times10^{-7}$; $10^{-5}$: $1.2\times10^{-11}$; $10^{-9}$: $5\times10^{-8}$; $10^{-13}$: $9\times10^{-4}$. Use $h\approx10^{-5}$ to $10^{-6}$ and tolerance about $10^{-8}$.
11. Null-space direction (smallest right singular vector): $\dot q_0\approx(0.314,-0.714,0.626)$; $J\dot q_0\approx10^{-16}$. A controller adds $(I-J^+J)\dot q_\mathrm{secondary}$ to the primary command to move the elbows (avoid obstacles/joint limits, improve manipulability) without moving the tip.
12. Good answers: plain inverse produces rate spikes growing like $1/\sin q_2$ and may overshoot/jitter near the singularity; DLS keeps rates bounded but slows the tip along the lost direction, so final error grows with $\lambda$. Choose $\lambda$ small away from the singularity (e.g. scaled by $\det J$) and larger near it; report numbers for at least two $\lambda$ values.
