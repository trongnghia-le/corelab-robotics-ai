## Vì sao học bài này?

Predict a trajectory from a law of change and an initial condition. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

A differential equation says how a state changes, rather than directly giving the state at every time. An initial condition selects one trajectory from a family. In simulation, we approximate that trajectory with discrete steps, so the integrator becomes part of the experiment.

## Định nghĩa và suy luận · Theory & derivation

For $\dot x=-kx$ with $k>0$, separate variables for $x\ne0$: $dx/x=-k\,dt$. Integrating gives $\ln|x|=-kt+c$, and applying $x(0)=x_0$ yields $x(t)=x_0e^{-kt}$. The zero initial condition is also a solution and should not be lost when dividing by $x$.

Euler integration follows the local tangent: $x_{n+1}=x_n+h f(t_n,x_n)$. For decay this becomes $x_{n+1}=(1-hk)x_n$. The numerical trajectory decays only if $|1-hk|<1$, giving $0<hk<2$. A physically stable differential equation can therefore produce an unstable numerical simulation.

Position and velocity can be stacked into a state: with $\ddot q=a$, write $\dot q=v$ and $\dot v=a$. Update all derivatives from the same old state for explicit Euler. Mixing new and old states creates a different integrator; document that choice.

## Ví dụ có lời giải · Worked example

For k=2, x₀=1, h=0.1, Euler predicts x₁=0.8; the exact state is e⁻⁰·²≈0.81873. With h=1.1, the multiplier is −1.2, so magnitudes grow while signs alternate. The equation itself has not changed; the discretization failed.

## Hiểu lầm thường gặp · Failure modes

A derivative has different units from its state. Smaller steps improve some errors but cost computation. Passing one endpoint test does not verify the whole trajectory or stability for different parameters.

## So sánh và lựa chọn · Alternatives

Euler is transparent but first-order accurate. Runge–Kutta methods can be more accurate on smooth nonstiff systems; stiff systems may require implicit methods with additional solve cost.
