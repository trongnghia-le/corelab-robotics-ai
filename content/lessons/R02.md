## Vì sao học bài này?

Describe configuration before attempting kinematics. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

A mechanism constrains possible motion. Links are bodies, joints permit particular relative motions, and configuration coordinates describe the remaining freedom. An end-effector position is a task variable; it may not uniquely determine all joint coordinates.

## Định nghĩa và suy luận · Theory & derivation

A planar revolute joint contributes an angle coordinate and a prismatic joint contributes a displacement coordinate in a simple independent open chain. An $n$-joint serial revolute arm has $q=(q_1,\ldots,q_n)$ locally, though angles wrap and joint limits restrict the valid set.

A planar rigid body has three degrees of freedom: two translations and one orientation. A spatial rigid body has six. Constraints remove freedoms only when independent; naive joint counting can fail in closed loops or special configurations. Use a constraint Jacobian when independence is uncertain.

Forward kinematics is a map $x=f(q)$ from configuration to a chosen task. Its output dimension need not equal the configuration dimension. A 3-joint planar arm may use three variables to control a 2D endpoint, leaving redundancy for posture. At singular configurations, instantaneous task motion can lose a direction even though the joints still move.

## Ví dụ có lời giải · Worked example

A planar two-revolute arm uses q=(θ₁,θ₂). Its endpoint has coordinates (x,y), but the arm’s elbow arrangement can produce multiple q values for one reachable endpoint. A sliding joint instead changes length along an axis, so its coordinate has metres rather than radians.

## Triển khai tham khảo · Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
import math
q=[math.pi/2,0.]
limits=[(-math.pi,math.pi),(-1.,1.)]
valid=all(lo <= value <= hi for value,(lo,hi) in zip(q,limits))
assert valid
```

## Hiểu lầm thường gặp · Failure modes

A coordinate count is not a universal closed-loop mobility formula. A robot with more joints than task coordinates may be redundant rather than more capable in every direction. Actuated and unactuated degrees of freedom must be distinguished.

## So sánh và lựa chọn · Alternatives

Serial chains offer straightforward composition and large workspaces. Parallel mechanisms can provide stiffness but introduce coupled constraints and more difficult singularities. Choose based on task, load, and workspace.
