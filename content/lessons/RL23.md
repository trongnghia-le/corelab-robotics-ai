## Why this matters

A mobile manipulator that is rewarded only when a cup ends up in the sink will, with random action noise, essentially never see a reward. Exploration must be directed: go to places not yet seen, try actions whose outcome is uncertain, run experiments. Intrinsic motivation turns that into an auxiliary reward. The danger is that a robot is also happy to stare at anything unpredictable, such as a flickering monitor or a person walking behind the camera. This lesson gives you the tools to measure that.

This builds on RL06 (value learning with exploration, epsilon-greedy and bandits) and on ML08 (probabilistic models and uncertainty).

## Intuition

In a corridor with a reward at the far end, undirected noise behaves like a random walk and wastes most steps near where it has already been. A counter that rewards visiting *rarely seen* places pushes the agent outward. But what if the agent sees a screen that shows fresh random pixels every time it looks? Every observation is new, so the counter never decays and the agent stays.

## Theory and derivation

### Why undirected exploration is slow

Epsilon-greedy and Gaussian noise are memoryless: they do not know where they have been. In a corridor with $N$ states and a goal at the end, a random walk takes on the order of $N^2$ steps to reach the goal, rather than $N$. Counting how much of the state space has been visited fixes this.

### Count-based and optimistic bonuses

Keep a visit count $n(s)$ and add an intrinsic reward
$$r^{\text{int}}_t=\frac{\beta}{\sqrt{n(s_{t+1})}},$$
which falls as a state becomes familiar. The bandit analogue is UCB1: choose $\arg\max_a\ \bar Q(a)+c\sqrt{\ln t/N(a)}$, an optimism bonus based on the number of times each action has been tried. For large state spaces exact counts are useless, so methods use pseudo-counts from density models, or a proxy such as the prediction error of a fixed random network on the state (RND): a state that the learned predictor has seen often has low error, so the bonus decays with familiarity.

### Prediction-error curiosity and the noisy TV

Curiosity methods (ICM) reward the agent for how badly a learned forward model predicts the next feature $\phi(s')$: $r^{\text{int}}=\lVert\hat\phi(s'|s,a)-\phi(s')\rVert^2$. If part of the world is inherently random (the noisy TV), the error never goes down however much data the model sees: the stochasticity is *aleatoric*, the reducible lack of knowledge is *epistemic*. A prediction-error bonus cannot tell them apart, and pays forever for noise.

### Information gain

The principled quantity is how much an observation reduces uncertainty about the *unknown parameters*. For a hypothesis $\theta$ with prior $p(\theta)$ and an observation $o$,
$$\mathrm{IG}=H(\theta)-\mathbb E_o\,H(\theta\mid o)=I(\theta;o)=\mathbb E_o\,\mathrm{KL}\big(p(\theta|o)\,\|\,p(\theta)\big)\ \ge0 .$$
Pure noise that is independent of $\theta$ gives posterior $=$ prior, so $\mathrm{IG}=0$: the noisy TV is worthless. Information gain is optimal exploration for a Bayesian but expensive to compute; Thompson sampling and ensemble disagreement (variance across models, which reflects epistemic uncertainty only) are practical approximations.

### Combining with task return

The agent optimises $r^{\text{ext}}+\beta_t r^{\text{int}}$ with $\beta_t$ decaying, or keeps separate value heads for the two. Report both curves: the extrinsic return (did it solve the task?) and the coverage or novelty statistic (what did exploration actually do?).

## Worked example

**Part A, count bonus.** $\beta=0.5$. Visit counts 1, 4, 25 give bonuses $0.5,\ 0.25,\ 0.1$. A key sequence $a,a,b,a$ with $\beta=1$ gives $1,\ 1/\sqrt2=0.707,\ 1,\ 1/\sqrt3=0.577$.

**Part B, distraction.** Over $T=100$ steps with $\beta=0.5$: staying in one real state gives total bonus $0.5\sum_{n=1}^{100}n^{-1/2}=0.5(18.59)=9.29$. A noisy TV where every observation is new gives $100\cdot0.5=50$: more than five times as much, available for ever. An agent that maximises total reward including bonuses prefers the TV unless the extrinsic reward is larger.

**Part C, information gain.** Two hypotheses: the coin has $P(\text{heads})=0.2$ or $0.8$, prior $0.5/0.5$.
1. $H(\text{prior})=1$ bit.
2. $P(\text{heads})=0.5(0.2)+0.5(0.8)=0.5$. The posterior after heads is $(0.5\cdot0.2,\ 0.5\cdot0.8)/0.5=(0.2,0.8)$, entropy $-0.2\log_20.2-0.8\log_20.8=0.7219$ bits. By symmetry the posterior after tails has the same entropy.
3. Expected posterior entropy $=0.7219$.
4. $\mathrm{IG}=1-0.7219=0.2781$ bits.
With a prior $0.9/0.1$ the same flip yields only $0.1048$ bits: there is less left to learn. A coin whose two hypotheses both have $P(\text{heads})=0.5$ yields $0$, like the TV.

**Part D, speed.** For the 12-state corridor with actions left, right, stay (probability 1/3 each, walls reflect), the expected time for the random walk to reach the goal from state 0 is exactly $1.5\,N(N+1)=198$ steps for $N=11$. The count-based explorer needs 11.

## Reference implementation

A corridor with a noisy TV, a count-based explorer using true states and one using raw observations, the random-walk baseline, and the exact information gain of a coin flip.

```python
import math, random
from collections import defaultdict

N, GOAL, TV = 12, 11, 0          # corridor 0..11; extrinsic reward only at the goal; a noisy "TV" sits at state 0

def move(s, a):
    """a: 0 = left, 1 = right, 2 = watch TV (state unchanged)."""
    return s if a == 2 else min(max(s + (1 if a == 1 else -1), 0), N - 1)

def observe(s, a, rng):
    """What the agent sees after the step: the TV shows fresh random noise when watched."""
    return (s, rng.randrange(10**9)) if (a == 2 and s == TV) else (s, 0)

def count_bonus(n, beta=0.5):
    """Count-based novelty bonus beta / sqrt(n), n >= 1 = number of visits including this one."""
    if n < 1:
        raise ValueError("count must be at least 1")
    return beta / math.sqrt(n)

def info_gain_bits(prior, p_heads):
    """Expected information gain (bits) of one coin flip. Hypotheses h have prior[h] and
    P(heads | h) = p_heads[h]: prior entropy minus expected posterior entropy."""
    def H(ps):
        return -sum(p * math.log2(p) for p in ps if p > 0)
    gain = H(prior)
    for heads in (True, False):
        like = [(p_heads[h] if heads else 1 - p_heads[h]) for h in range(len(prior))]
        joint = [prior[h] * like[h] for h in range(len(prior))]
        z = sum(joint)
        if z > 0:
            gain -= z * H([j / z for j in joint])
    return gain

def novelty_seeker(key_mode, max_steps=500, seed=0):
    """Greedy count-based explorer: always take the action whose predicted next key has the
    smallest visit count (ties: watch, right, left). key_mode 'state' counts states, 'obs' counts
    raw observations, so watching the TV always produces a never-seen key.
    Returns (steps until the goal, or None, number of TV steps)."""
    rng = random.Random(seed); counts = defaultdict(int); s = 0; tv = 0
    counts[0 if key_mode == "state" else (0, 0)] += 1
    def predicted_key(s, a):
        s2 = move(s, a)
        if key_mode == "state":
            return s2
        return ("fresh", s2) if (a == 2 and s2 == TV) else (s2, 0)
    for t in range(1, max_steps + 1):
        a = min((2, 1, 0), key=lambda a: counts[predicted_key(s, a)] if predicted_key(s, a) in counts else 0)
        s2 = move(s, a); obs = observe(s2, a, rng)
        counts[s2 if key_mode == "state" else obs] += 1
        tv += (a == 2); s = s2
        if s == GOAL:
            return t, tv
    return None, tv

def random_walk_time(seed, max_steps=500):
    rng = random.Random(seed); s = 0
    for t in range(1, max_steps + 1):
        s = move(s, rng.randrange(3))
        if s == GOAL:
            return t
    return max_steps

if __name__ == "__main__":
    print("state-count explorer:", novelty_seeker("state"))
    print("obs-count explorer  :", novelty_seeker("obs"))
    rw = [random_walk_time(s) for s in range(50)]
    print("random walk: mean steps to goal %.0f (cap 500), %d of 50 runs hit the cap" % (sum(rw) / 50, sum(t == 500 for t in rw)))
    print("bonus after 1, 4, 100 visits:", [round(count_bonus(n), 3) for n in (1, 4, 100)])
    print("info gain, prior (0.5, 0.5), coins 0.2 / 0.8: %.4f bits" % info_gain_bits([0.5, 0.5], [0.2, 0.8]))
    assert novelty_seeker("state")[0] == 11 and novelty_seeker("obs")[0] is None
    assert count_bonus(4) == 0.25 and abs(info_gain_bits([0.5, 0.5], [0.2, 0.8]) - 0.2781) < 1e-4
    print("self-test passed")
```

Expected: the state explorer reaches the goal in 11 steps; the observation explorer never does (500 steps, all of them TV); the random walk averages about 200 steps.

### Extension challenge

Replace the two-coin hypothesis space by a Beta prior over $\theta$ and compute the expected information gain of a flip numerically on a grid. Check that it decreases as the posterior narrows.

### Library track

Redo the information-gain and exploration parts with NumPy (`pip install numpy`). Save your stdlib solution as `lab23.py` (starter with stubs implemented, without tests). The script computes the expected information gain of a coin flip on a grid of $\theta$ values (the extension challenge), checks it against `info_gain_bits`, and compares UCB, epsilon-greedy and uniform random on a 10-armed Bernoulli bandit over 200 seeds (UCB uses $c=0.5$ here; with $c=2$ it over-explores on this 1000-pull horizon).

```python
import numpy as np
from lab23 import info_gain_bits, bonus_sequence

def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -(p * np.log2(p)).sum()

# 1. expected information gain of one flip over a grid of theta values (Beta prior = weights on the grid)
theta = np.linspace(0.001, 0.999, 999)

def ig_grid(weights):
    w = weights / weights.sum()
    gain = entropy(w)
    for like in (theta, 1 - theta):             # heads, tails
        joint = w * like; z = joint.sum()
        gain -= z * entropy(joint / z)
    return gain

two = [0.2, 0.8]
w2 = np.zeros_like(theta); w2[[np.argmin(abs(theta - t)) for t in two]] = 0.5
assert abs(ig_grid(w2) - info_gain_bits([0.5, 0.5], two)) < 1e-3     # grid agrees with the 2-coin result

def beta_w(a, b):
    return theta ** (a - 1) * (1 - theta) ** (b - 1)
g = [ig_grid(beta_w(a, a)) for a in (1, 2, 5, 20, 100)]               # narrower posteriors around 0.5
print("IG vs posterior width:", np.round(g, 4))
assert all(x > y for x, y in zip(g, g[1:]))

# 2. UCB1 vs epsilon-greedy on a 10-armed Bernoulli bandit, 200 seeds at once
def bandit(method, seeds=200, T=1000, rng_seed=0):
    rng = np.random.default_rng(rng_seed)
    mu = rng.uniform(0.1, 0.9, (seeds, 10)); best = mu.max(axis=1)
    n = np.ones((seeds, 10)); q = (rng.random((seeds, 10)) < mu).astype(float)   # pull each arm once
    idx = np.arange(seeds); regret = np.zeros(seeds)
    for t in range(10, T):
        if method == "ucb":
            a = (q + 0.5 * np.sqrt(np.log(t) / n)).argmax(axis=1)
        elif method == "random":
            a = rng.integers(0, 10, seeds)
        else:
            a = np.where(rng.random(seeds) < 0.1, rng.integers(0, 10, seeds), q.argmax(axis=1))
        r = (rng.random(seeds) < mu[idx, a]).astype(float)
        n[idx, a] += 1; q[idx, a] += (r - q[idx, a]) / n[idx, a]
        regret += best - mu[idx, a]
    return regret.mean()

ucb, eg, rnd = bandit("ucb"), bandit("egreedy"), bandit("random")
print("mean regret after 1000 pulls: UCB %.1f, eps-greedy %.1f, uniform random %.1f" % (ucb, eg, rnd))
assert ucb < rnd / 3 and eg < rnd / 3     # both directed methods are far better than undirected noise
# 3. the noisy-TV total bonus with NumPy: 100 distinct observations vs 100 repeats
assert abs(sum(bonus_sequence(list(range(100)))) - 50) < 1e-9
```

Expected: information gain 0.278 for the two-coin prior falling to 0.158, 0.069, 0.018 and 0.004 bits as a symmetric Beta posterior around 0.5 narrows, and mean regret of about 34 (UCB), 53 (epsilon-greedy) and 324 (uniform random). The gap to random is the value of directed exploration; the UCB-versus-epsilon-greedy order depends on $c$ and the horizon.

## Failure modes

- **Noisy TV**: raw-observation novelty gave a total bonus of 50 over 100 steps versus 9.3 for a real state, and the agent stayed at the TV.
- **Bonus larger than task reward** makes the agent ignore the goal; decay $\beta$.
- **Non-decaying novelty** from hashing high-dimensional observations (every frame unique).
- **Detachment**: the agent forgets promising regions that are no longer novel.
- **Confusing aleatoric and epistemic uncertainty**: reward only reducible uncertainty.
- **Reporting only intrinsic reward** instead of task return, hiding that nothing was solved.

## Alternatives and trade-offs

| Method | Strength | Weakness |
| --- | --- | --- |
| Epsilon-greedy, action noise | Trivial | Memoryless; $O(N^2)$ in a corridor |
| UCB / optimism | Strong guarantees in bandits | Needs counts; hard in large spaces |
| Count / pseudo-count | Simple, directed | Needs a good state abstraction |

For a small discrete task use counts or optimism; for pixels use RND with feature compression and always check a noise-injection test.

9. With $E_N=0$, for $1\le s\le N-1$: $E_s=1+\tfrac13(E_{s-1}+E_s+E_{s+1})$; at $s=0$: $E_0=1+\tfrac13(2E_0+E_1)$ (left and stay both remain at 0).
