## Why this matters

A robot that can predict what will happen if it acts can try actions in its head before trying them on hardware. A world model is that predictor, learned from experience. It supports planning (search over imagined futures), cheap policy training (imagined rollouts instead of real ones), and data-efficient learning when hardware time is the bottleneck.

The catch is that a model is only as useful as its errors are harmless. Models are trained on prediction loss, but they are used for decisions. This lesson teaches the structure of a world model, how its errors grow, how planning with it works, and how to test whether a better predictor really gives better control.

## Intuition

Raw observations (images) are large and mostly irrelevant for deciding what to do. A world model compresses an observation $o_t$ into a small latent state $z_t$, then learns how that latent changes under an action $a_t$:
$$z_t=e_\phi(o_t),\qquad \hat z_{t+1}=f_\theta(z_t,a_t),\qquad \hat o_{t+1}=d_\psi(\hat z_{t+1})\ \text{(optional)}.$$

![A world model pipeline: observation is encoded to a latent z, the latent is rolled forward under candidate actions, and a planner picks the sequence with the best predicted outcome; a second panel shows error growing with the rollout step.](/lesson-figures/E08.svg)

*Left: encode, roll forward in latent space, score, execute the first action and replan. Right: a model with 5% error in its dynamics gain drifts further from the truth every step.*

Two ideas matter most. First, **predictions are used repeatedly**: a plan of $H$ steps feeds each prediction into the next, so small errors multiply. Second, **a model is judged by decisions, not by pixels**: a model can match everything that is easy to predict (the robot's static background, its own momentum) and still have the wrong answer to the only question the planner asks: "what changes if I choose action A instead of B?"

## Theory and derivation

### Learning the dynamics

Given transitions $(z_t,a_t,z_{t+1})$ from a dataset, supervised learning minimises
$$\mathcal L_{\text{dyn}}(\theta)=\frac1N\sum_t\|f_\theta(z_t,a_t)-z_{t+1}\|^2 .$$
When the latent comes from an encoder trained jointly, three variants exist: reconstruction (decode $z$ back to $o$, as in the original World Models and Dreamer), latent consistency (match the encoder's own next-step latent, avoiding pixel decoding), and reward prediction (make the latent contain what matters for the task). Stochastic models (the RSSM in PlaNet and Dreamer) add a random component so the model can represent environment noise instead of blurring it.

### Linear example and compounding

For $x_{t+1}=Ax_t+Bu_t$ with a fitted $\hat A=A+\delta$ and zero actions, the open-loop prediction error after $k$ steps from $x_0$ is
$$\hat x_k-x_k=(\hat A^k-A^k)x_0 .$$
Even a small $\delta$ grows because $\hat A^k-A^k=\sum_{j=0}^{k-1}\hat A^{\,j}\delta A^{k-1-j}$. With $A=0.9$, $\hat A=0.95$ and $x_0=1$ the error after 10 steps is $0.95^{10}-0.9^{10}=0.599-0.349=0.250$, even though the one-step error at $x=1$ is only $0.05$. If $|\hat A|>1$ the error diverges exponentially.

### Planning with a model

Given a cost $c(x,a)$ and a model, choose actions by minimising predicted cost. A simple method is **random shooting**: sample $N$ action sequences of length $H$, predict each, and keep the best. The **cross-entropy method (CEM)** refits a Gaussian to the best fraction and repeats $I$ iterations. Compute per replan: $N\cdot H\cdot I$ model evaluations.

**Model predictive control (MPC):** execute only the first action (or a few), observe the real next state, and replan. Because every plan starts from a real observation, model error cannot accumulate beyond the planning horizon, which is why MPC tolerates imperfect models.

### Prediction quality versus control usefulness

Planning cares about the **action-effect**, $\partial f/\partial a$ (here $B$), and about *differences* between candidates. A model that predicts the part of $x'$ independent of $a$ perfectly but ignores $a$ has small one-step error whenever actions have small variance, yet it predicts every candidate sequence identically and so cannot rank them. Explained variance of the next state measures how well the model reproduces the data; it does not measure how well the model ranks actions. The right test is **decision quality**: use the model to plan, execute in the real system (or a held-out simulator), and measure real cost.

### Dyna-style use

A model can also generate synthetic transitions to train a policy or value function (Dyna, Dreamer). The same caveat applies: the policy learns to exploit model errors where the model is optimistic, so short imagined rollouts branching from real states are safer than long ones.

## Worked example

True system: $x'=0.9x+0.5a$. Four logged transitions $(x,a,x')$:
$(1,0,0.9)$, $(0,0.2,0.1)$, $(-1,0.1,-0.85)$, $(0.5,-0.2,0.35)$.

**Action-conditioned fit.** The data satisfy $x'=0.9x+0.5a$ exactly (for example $0.9\cdot0.5+0.5\cdot(-0.2)=0.35$), so least squares returns $\hat A=0.9,\hat B=0.5$ and MSE $\approx0$.

**Action-ignoring fit** $x'=\hat Ax$: $\hat A=\sum xx'/\sum x^2=(0.9+0+0.85+0.175)/(1+0+1+0.25)=1.925/2.25=0.8556$. Residuals: $0.9-0.8556=0.0444$, $0.1-0=0.1$, $-0.85+0.8556=0.0056$, $0.35-0.4278=-0.0778$. One-step MSE $=(0.00198+0.01+0.00003+0.00605)/4=0.00451$. The variance of $x'$ is $0.4006$, so the model explains $1-0.0045/0.4006=98.9\%$ of the variance. By the usual score it looks excellent.

**Planning test.** Start at $x_0=0$, goal $x=1$, candidates $[-1,-1],[0,0],[1,1],[1,0]$. True final states: $-0.95,\ 0,\ 0.95,\ 0.45$. The action-conditioned model picks $[1,1]$ (index 2, error 0.05). The action-ignoring model predicts $0$ for every candidate, so all tie and the first candidate wins: $[-1,-1]$, with true final error $|-0.95-1|=1.95$. A 98.9%-explained model chooses the worst action.

**Compounding.** With $\hat A=0.95$ instead of 0.9 and $x_0=1$, zero actions: the prediction after 10 steps is 0.599 versus the true 0.349, an error of 0.250 (72% of the true value).

## Reference implementation

```python
import random

def fit(data, use_action=True):
    sxx = sum(x*x for x, a, y in data); sxa = sum(x*a for x, a, y in data)
    saa = sum(a*a for x, a, y in data)
    sxy = sum(x*y for x, a, y in data); say = sum(a*y for x, a, y in data)
    if not use_action:
        return sxy / sxx, 0.0
    det = sxx*saa - sxa*sxa
    return (sxy*saa - say*sxa)/det, (say*sxx - sxa*sxy)/det

def roll(m, x, acts):
    A, B = m
    for a in acts:
        x = A*x + B*a
    return x

def one_step_mse(m, data):
    return sum((m[0]*x + m[1]*a - y)**2 for x, a, y in data)/len(data)

def explained_variance(m, data):
    ys = [y for _, _, y in data]; mu = sum(ys)/len(ys)
    return 1 - one_step_mse(m, data)/(sum((y-mu)**2 for y in ys)/len(ys))

def plan_error(m, true, x0, goal, n=200, h=3, rng=None):
    """Random shooting with model m; return |true final state - goal|."""
    best, best_seq = None, None
    for _ in range(n):
        seq = [rng.uniform(-1, 1) for _ in range(h)]
        e = abs(roll(m, x0, seq) - goal)
        if best is None or e < best:
            best, best_seq = e, seq
    return abs(roll(true, x0, best_seq) - goal)

if __name__ == "__main__":
    rng = random.Random(0); true = (0.9, 0.5)
    data = []
    for _ in range(200):
        x, a = rng.uniform(-1, 1), rng.uniform(-0.2, 0.2)
        data.append((x, a, true[0]*x + true[1]*a + rng.gauss(0, 0.02)))
    m_act, m_noact = fit(data), fit(data, False)
    for name, m in (("action-conditioned", m_act), ("action-ignoring", m_noact)):
        errs = [plan_error(m, true, 0.0, rng.uniform(-1, 1)*1.0, rng=rng) for _ in range(100)]
        print(f"{name:20s} 1-step MSE {one_step_mse(m, data):.5f}  "
              f"explained var {explained_variance(m, data):.3f}  real planning error {sum(errs)/100:.3f}")
    # --- self-test ---
    assert abs(m_act[0] - 0.9) < 0.05 and abs(m_act[1] - 0.5) < 0.1
    assert explained_variance(m_noact, data) > 0.9
    assert abs(roll((0.95, 0), 1.0, [0]*10) - 0.95**10) < 1e-12
    print("self-test passed")
```

On a typical run both models explain over 90% of the variance, while the action-conditioned planner reaches goals with a much smaller real error than the action-ignoring one (which picks an arbitrary sequence).

### Library track

Redo the fit and the planning comparison with NumPy: `np.linalg.lstsq` replaces the hand-written normal equations, and the random-shooting planner is vectorised over candidates. The script checks the fitted parameters against the lab values, shows that the action-ignoring model plans no better than random choice, and runs one-step MPC with a 30% wrong $\hat B$.

```python
import numpy as np

# 1) The normal equations of the lab versus numpy.linalg.lstsq.
d = np.array([(1, 0, 0.9), (0, 0.2, 0.1), (-1, 0.1, -0.85), (0.5, -0.2, 0.35)], float)
X, y = d[:, :2], d[:, 2]
(A_hat, B_hat), *_ = np.linalg.lstsq(X, y, rcond=None)
print("action-conditioned", round(A_hat, 6), round(B_hat, 6))
assert np.allclose([A_hat, B_hat], [0.9, 0.5])
A0 = np.linalg.lstsq(X[:, :1], y, rcond=None)[0][0]
mse0 = np.mean((A0 * X[:, 0] - y) ** 2)
print("action-ignoring A", round(A0, 4), "MSE", round(mse0, 5))
assert abs(A0 - 1.925 / 2.25) < 1e-12 and abs(mse0 - 0.00451389) < 1e-7

# 2) Vectorised random shooting: 100 start/goal pairs, 200 candidates of length 3.
rng = np.random.default_rng(0)
def rollout(A, B, x0, seqs):                      # seqs: (n, h) -> final state (n,)
    x = np.full(len(seqs), x0)
    for k in range(seqs.shape[1]):
        x = A * x + B * seqs[:, k]
    return x
def real_error(model, x0, goal):
    seqs = rng.uniform(-1, 1, (200, 3))
    best = seqs[np.argmin(np.abs(rollout(*model, x0, seqs) - goal))]   # first index wins ties
    return abs(rollout(0.9, 0.5, x0, best[None])[0] - goal)
goals = rng.uniform(-1, 1, 100)
e_act = np.mean([real_error((0.9, 0.5), 0.0, g) for g in goals])
e_noact = np.mean([real_error((A0, 0.0), 0.0, g) for g in goals])
e_rand = np.mean([abs(rollout(0.9, 0.5, 0.0, rng.uniform(-1, 1, (1, 3)))[0] - g) for g in goals])
print(f"real error: action-aware {e_act:.3f}  action-ignoring {e_noact:.3f}  random {e_rand:.3f}")
assert e_act < 0.05 < 0.3 < e_noact and abs(e_noact - e_rand) < 0.25   # ignoring actions is no better than chance

# 3) One-step MPC with a 30% wrong B: it ends within about 3% of the goal (a small steady-state offset).
Bh, x = 0.35, 0.0
for _ in range(8):
    a = (1.0 - 0.9 * x) / Bh                      # one-step MPC with the wrong model
    x = 0.9 * x + 0.5 * a                         # real system
print("closed-loop final x", round(x, 4))
assert abs(x - 1.0) < 0.05
print("library track passed")
```

Expected: `action-conditioned 0.9 0.5`, action-ignoring MSE `0.00451`, real planning error about 0.01 for the action-aware model versus about 0.6 for the action-ignoring and random choices, closed-loop final state about 1.03, then `library track passed`.

## Verification

- **Check the baseline.** Random action selection gives a real final error you can compute; a model that does not beat it is not useful for planning, whatever its MSE.
- **Evaluate on-policy.** Test prediction on states and actions the planner will actually choose, not on the random data you trained on.
- **Separate errors.** Measure $A$-error and $B$-error individually: $B$ governs ranking of actions.
- **Check horizons.** Plot prediction error versus rollout step; the horizon where error exceeds the effect size of actions is the longest horizon worth planning over.
- **Close the loop.** Compare open-loop execution with MPC using the same model. A large gap means the model is usable only with feedback.

## Failure modes

| Mistake | What you observe |
|---|---|
| Judging by one-step MSE | action-ignoring model scores 98.9% explained variance yet picks the worst action |
| Training only on random-action data | good model near random behaviour, wrong near planned trajectories |
| Long open-loop plans | error 0.250 after 10 steps from a 0.05 parameter error |
| Planner exploiting model errors | predicted cost excellent, real cost bad; the planner finds regions where the model is wrong in its favour |
| Pixel loss dominating the latent | latent keeps background detail and discards the small object that matters |
| Ignoring stochasticity | deterministic model blurs two outcomes into an impossible average |

## Alternatives and trade-offs

- **Model-free RL or imitation**: no model errors to exploit, but needs more real data (compare E07).
- **Physics-based models (system identification)**: few parameters, interpretable, strong extrapolation, but limited to what you can write down.
- **Learned latent models**: scale to images, but need diverse data and careful evaluation.
- **Reconstruction versus reconstruction-free latents**: decoders give diagnostics you can look at but spend capacity on irrelevant pixels; consistency-based latents are cheaper but harder to debug.
- **Open-loop plan versus MPC**: MPC costs repeated computation but is far more robust to model error.

## Exercise answers

1. V compresses each frame into a small latent code; M predicts the next latent (and often the reward) given the latent and action; C maps the latent (and M's state) to actions. The controller can be tiny because V and M already extracted a compact, predictive state, so C faces a low-dimensional problem. A good answer names all three and the compression argument.
2. $15\times0.02=0.30$. Linear growth is optimistic because errors in $f$ feed back through the dynamics: with gain above 1 they grow geometrically and errors can also correlate.
3. $k=1$: $|0.85-0.8|\cdot2=0.1000$. $k=5$: $2(0.85^5-0.8^5)=2(0.4437-0.3277)=0.2320$. $k=10$: $2(0.1969-0.1074)=0.1790$. Second part: $(1.05^{10}-0.95^{10})/0.95^{10}=(1.6289-0.5987)/0.5987=1.7206$, i.e. 172% relative error. Unstable estimates amplify.
4. The model remembers the old next state and never experiences the closed door, so its imagined transitions are wrong; the planning updates are made from the stale model. Fix: Dyna-Q+ style exploration bonuses, ignoring old model entries after time, or re-querying the real environment when predicted and real transitions disagree.
5. $300\cdot15\cdot4=18{,}000$ evaluations per plan, 180,000 per second at 10 Hz. Four iterations at 4 ms per batch is 16 ms per replan, far below the 100 ms budget, so yes if one 4 ms pass covers all 300 samples for the whole 15-step plan. But a rollout is sequential: if each 4 ms pass is one time step, an iteration costs $15\times4=60$ ms and four iterations cost 240 ms, which misses the 100 ms budget. A strong answer notes this sequential-horizon trap and suggests fewer iterations or a smaller $H$.
6. True model: $x_1=0.5$, $x_2=0.95$, $x_3=0.855+0.5=1.355$. The action-ignoring model stays at 0. Output: `1.355 0.0`. The second model has the dynamics right and the action effect missing.

8. The 50-step policy exploits errors more because errors compound and the policy can steer toward regions where the model is optimistic. Measure real return versus imagined return for both; the gap grows with imagination length.
9. Let $g(k)=(\hat A^k-A^k)x_0$. It is 0 at $k=0$ and tends to 0 as $k\to\infty$ since both terms vanish, and it is positive in between, so it has a maximum. Continuous form: $g'(k)=0\Rightarrow\hat A^k\ln\hat A=A^k\ln A\Rightarrow k^*=\ln(\ln A/\ln\hat A)/\ln(\hat A/A)$. For 0.9 and 0.95: $\ln A=-0.10536,\ \ln\hat A=-0.05129$, ratio 2.0541, $\ln=0.7199$; $\ln(0.95/0.9)=0.05407$; $k^*\approx13.3$.
10. A good answer reports a table with both models, the random baseline (mean final error of a random sequence), the number of seeds, and a falsifier such as "if the action-ignoring model's real planning error is within noise of the action-conditioned one, explained variance is not misleading here".
