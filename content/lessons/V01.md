## Why this matters

An image is a sampled measurement, not a perfect copy of a scene. Before using a detector, understand what the array stores: axis order, coordinate origin, channel meaning, dtype, and intensity scale. An array with the right shape can still represent the wrong colors or geometry.

## Intuition and definitions

A grayscale image often has shape (H,W), while a color image often has (H,W,C). Row index usually increases downward and column index rightward; this differs from a conventional upward Cartesian y axis. A pixel coordinate (u,v) normally means column u, row v, so indexing is image[v,u]. Declare whether pixel centers are integer positions.

## Reasoning and assumptions

An 8-bit channel has $2^8=256$ representable values, conventionally 0 through 255. Dividing by 255 maps this range into [0,1], but does not undo nonlinear camera response or guarantee linear light. RGB and BGR channel orders contain the same number of entries with different meanings. Converting to grayscale uses a declared weighting and color-space convention.

## Worked example

For a two-row, three-column RGB image, shape is (2,3,3). Pixel (u=2,v=1) is the last column of the second row, indexed [1,2]. A pure red RGB pixel [255,0,0] interpreted as BGR becomes blue. A uint8 subtraction can wrap rather than represent a negative difference; cast to a suitable floating type before arithmetic.

## Implementation and verification

Create a tiny synthetic image in NumPy with one red, one green, and one blue marker. Predict their indices, normalized intensities, and channel means. Check a non-square shape so row/column swaps are visible. Compute a difference after converting to float and compare with unsigned arithmetic in a controlled example.

## Misconceptions and alternatives

Resizing changes sampling. Nearest-neighbor preserves discrete labels but can look blocky for photographs; bilinear interpolation blends nearby intensities and is generally unsuitable for category IDs in a segmentation mask. Downsampling without appropriate low-pass filtering can alias fine patterns into incorrect larger patterns.

## Independent practice and transfer

Build an image inspection script that prints shape, dtype, min, max, and per-channel means. Test RGB-to-BGR conversion by explicit indexing and a round trip. Use synthetic images before downloading data, and record color convention and normalization parameters in the experiment configuration. Explain how camera exposure or lighting shift affects intensity without changing object identity.
