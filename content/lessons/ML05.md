## Why this matters

Derive gradients through a computational graph and check them numerically. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

Backpropagation is the chain rule applied in reverse order through a recorded computation. Each intermediate receives a sensitivity from the output. When one quantity affects the loss through several paths, those contributions add.

## Theory and derivation

Let $z=wx+b$, $a=\sigma(z)$, and $L=\frac12(a-y)^2$. Start with $\bar L=1$ and propagate $\bar a=a-y$, $\bar z=(a-y)\sigma'(z)$, $\bar w=\bar z x$, $\bar b=\bar z$, and $\bar x=\bar z w$. Bars denote derivatives of the scalar loss with respect to an intermediate.

For sigmoid, differentiate $a=(1+e^{-z})^{-1}$ to get $\sigma'(z)=a(1-a)$. For a vector affine layer, reverse mode computes vector-Jacobian products rather than materializing the entire network Jacobian. If a parameter is reused, sum its derivative contributions from every use.

A central-difference check compares analytical $g_i$ with $[L(\theta+he_i)-L(\theta-he_i)]/(2h)$. Use tiny models, double precision, and inputs away from nonsmooth activation boundaries. Do not update parameters until all derivatives for that step have been computed.

## Worked example

Use identity activation, x=2, w=3, b=1, y=5. The prediction is 7, residual 2, and loss 2. Backprop gives dL/dw=2×2=4, dL/db=2, and dL/dx=2×3=6. For L=w²+w², the two paths each contribute 2w, totaling 4w.

```python
def loss(w, x=2., b=1., y=5.):
    return .5*(w*x+b-y)**2
w=3.; h=1e-5
analytic=(w*2+1-5)*2
numeric=(loss(w+h)-loss(w-h))/(2*h)
assert abs(analytic-numeric) < 1e-6
```

The model is $z=w_1x+b_1$, $h=\sigma(z)$, $\hat y=w_2h+b_2$, $L=\tfrac12(\hat y-y)^2$.

### Tests

```python
# 1. hand-computed case
p0 = {"w1": 0.0, "b1": 0.0, "w2": 2.0, "b2": 0.0}
L, g = loss_and_grads(p0, 1.0, 3.0)
assert abs(L - 2.0) < 1e-12
for k, v in {"w2": -1.0, "b2": -2.0, "w1": -1.0, "b1": -1.0}.items():
    assert abs(g[k] - v) < 1e-12, (k, g[k], v)

# 2. edge case: saturated sigmoid passes (almost) no gradient to w1, b1
sat = {"w1": 30.0, "b1": 0.0, "w2": 1.0, "b2": 0.0}
_, gs = loss_and_grads(sat, 1.0, 0.0)
assert abs(gs["w1"]) < 1e-9 and abs(gs["b1"]) < 1e-9 and abs(gs["w2"] - 1.0) < 1e-9

# 3. property: analytic gradient equals finite differences, and p is not mutated
for p, x, y in [({"w1": 0.8, "b1": -0.3, "w2": -1.2, "b2": 0.4}, 1.5, 0.7),
                ({"w1": -2.0, "b1": 1.0, "w2": 0.5, "b2": -0.1}, -0.5, 1.0),
                ({"w1": 0.1, "b1": 0.1, "w2": 3.0, "b2": 2.0}, 2.0, -1.0)]:
    before = dict(p)
    _, ga = loss_and_grads(p, x, y)
    gn = numeric_grad(p, x, y)
    assert p == before
    for k in p:
        assert abs(ga[k] - gn[k]) < 1e-8, (k, ga[k], gn[k])

# 4. training reduces the loss
data = [(-1.0, 0.2), (0.0, 0.5), (1.0, 0.8)]
start = {"w1": 0.5, "b1": 0.0, "w2": 1.0, "b2": 0.0}
total = lambda q: sum(loss_and_grads(q, x, y)[0] for x, y in data)
trained = train(start, data, 0.5, 2000)
assert start == {"w1": 0.5, "b1": 0.0, "w2": 1.0, "b2": 0.0}
assert total(trained) < 0.01 * total(start)
print("loss before %.4f, after %.2e" % (total(start), total(trained)))
```

## Failure modes

The backward pass must use the forward values from the same parameter state. Setting a gradient instead of adding it loses contributions for shared nodes. Numerical checking at ReLU zero can be ambiguous because no unique derivative exists there.

## Alternatives and trade-offs

Forward-mode differentiation is efficient for few input directions; reverse mode is efficient for one scalar loss with many parameters. Finite differences are easy to implement but expensive and approximate, so use them as a small-case oracle.

## Exercise answers

1. The loss is one number and the parameters are many. A reverse sweep produces one vector-Jacobian product per layer and yields the derivative of that single scalar with respect to every parameter in one pass; a forward sweep would need one pass per parameter. The forward pass must store (or be able to recompute) the intermediate values, such as $a$ and $z$, because the local derivatives depend on them.
2. $a=2(-1)+0.5=-1.5$; residual $a-y=-2.5$; $L=\tfrac12(6.25)=3.125$. $\partial L/\partial w=(a-y)x=(-2.5)(-1)=2.5$; $\partial L/\partial b=-2.5$; $\partial L/\partial x=(a-y)w=-5$.
3. (a) $\sigma'=a(1-a)=0.75\cdot0.25=0.1875$. (b) Maximum $0.25$ at $z=0$ ($a=0.5$). (c) $\sigma(5)=0.99331$, so $\sigma'(5)=0.99331\cdot0.00669\approx0.00665$: the neuron is saturated, so almost no gradient flows through it and its weights learn very slowly.
4. $z=0.5\cdot1-0.5=0$, $a=0.5$. $\bar a=a-y=-0.5$; $\bar z=\bar a\,a(1-a)=-0.5\cdot0.25=-0.125$; $\bar w=\bar z x=-0.125$; $\bar b=\bar z=-0.125$. (Also $\bar x=\bar z w=-0.0625$.)
5. Prints `12.000000999999205`, i.e. about 12.000001. The function is $w^3$ with true derivative $3w^2=12$. The central difference is $12+h^2f'''/6=12+10^{-6}\cdot6/6=12.000001$, so the gap is truncation error, not a bug.
6. The assignment `g = ...` overwrites the contribution of earlier samples (and it would equally overwrite contributions from several uses of a shared parameter). It must be `g += ...`. Wrong: only the last term, $(2-3)\cdot2=-2$. Correct: $(1-2)\cdot1+(2-3)\cdot2=-3$.
7. $f=w\cdot u$ with $u=wx$. Path 1 (through the left factor): $\partial f/\partial w|_u=u=wx$. Path 2 (through $u$): $w\cdot x$. Sum $=2wx$. At $w=3,x=2$: $12$. Check: $f=w^2x$, $f'=2wx=12$.
8. Forward: $z=3$, $a=3$ (ReLU active since $z>0$), $\hat y=-6$, $L=\tfrac12(-7)^2=24.5$. Backward: $\bar{\hat y}=-7$; $\bar w_2=\bar{\hat y}\,a=-21$; $\bar a=\bar{\hat y}\,w_2=14$; $\bar z=14\cdot1=14$ (ReLU slope 1); $\bar w_1=\bar z x=28$; $\bar x=\bar z w_1=21$.
9. $f(w\pm h)=f\pm hf'+\tfrac{h^2}{2}f''\pm\tfrac{h^3}{6}f'''+\dots$. Subtract: $f(w+h)-f(w-h)=2hf'+\tfrac{h^3}{3}f'''+O(h^5)$; divide by $2h$ to get the stated result. The forward difference $[f(w+h)-f(w)]/h=f'+\tfrac h2f''+\dots$ has an $O(h)$ error. For $f=w^3$: $f'''=6$, so error $=h^2=10^{-6}$, matching exercise 5.
10. Total error $\approx c_1h^2+\varepsilon/h$. Minimising: $2c_1h=\varepsilon/h^2$, so $h\sim(\varepsilon/2c_1)^{1/3}\approx10^{-5}$ to $10^{-6}$, with a best error near $10^{-10}$. At $h=10^{-12}$ the noise term is $\approx10^{-16}/10^{-12}=10^{-4}$, larger than the signal you want to check, so correct gradients appear wrong.
11. (a) $2\times10^6$ forward passes $\approx2\times10^6$ units. (b) $1+2=3$ units. Backprop is about $7\times10^5$ times cheaper. Finite differences remain the right oracle on a tiny model (a handful of parameters, double precision) to test a hand-written backward pass, or when the function is a black box with no available derivative.
12. A good answer has: `Value(data, parents, local_grads)`; each operation records parents and local derivatives (`*`: $\partial/\partial a=b$, $\partial/\partial b=a$); `backward()` builds a topological order with a visited set, sets the output `grad=1`, then walks the order in reverse doing `parent.grad += local * node.grad`. For $f=ab+a$: $\partial f/\partial a=b+1=4$ (two paths summed) and $\partial f/\partial b=a=2$. The neuron must match exercise 4 ($\bar w=-0.125$). Common bug: zeroing or overwriting `grad` instead of accumulating.
