## Vì sao học bài này?

Derive gradients through a computational graph and check them numerically. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Trực giác · Intuition

Backpropagation is the chain rule applied in reverse order through a recorded computation. Each intermediate receives a sensitivity from the output. When one quantity affects the loss through several paths, those contributions add.

## Định nghĩa và suy luận · Theory & derivation

Let $z=wx+b$, $a=\sigma(z)$, and $L=\frac12(a-y)^2$. Start with $\bar L=1$ and propagate $\bar a=a-y$, $\bar z=(a-y)\sigma'(z)$, $\bar w=\bar z x$, $\bar b=\bar z$, and $\bar x=\bar z w$. Bars denote derivatives of the scalar loss with respect to an intermediate.

For sigmoid, differentiate $a=(1+e^{-z})^{-1}$ to get $\sigma'(z)=a(1-a)$. For a vector affine layer, reverse mode computes vector-Jacobian products rather than materializing the entire network Jacobian. If a parameter is reused, sum its derivative contributions from every use.

A central-difference check compares analytical $g_i$ with $[L(\theta+he_i)-L(\theta-he_i)]/(2h)$. Use tiny models, double precision, and inputs away from nonsmooth activation boundaries. Do not update parameters until all derivatives for that step have been computed.

## Ví dụ có lời giải · Worked example

Use identity activation, x=2, w=3, b=1, y=5. The prediction is 7, residual 2, and loss 2. Backprop gives dL/dw=2×2=4, dL/db=2, and dL/dx=2×3=6. For L=w²+w², the two paths each contribute 2w, totaling 4w.

## Triển khai tham khảo · Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
def loss(w, x=2., b=1., y=5.):
    return .5*(w*x+b-y)**2
w=3.; h=1e-5
analytic=(w*2+1-5)*2
numeric=(loss(w+h)-loss(w-h))/(2*h)
assert abs(analytic-numeric) < 1e-6
```

## Hiểu lầm thường gặp · Failure modes

The backward pass must use the forward values from the same parameter state. Setting a gradient instead of adding it loses contributions for shared nodes. Numerical checking at ReLU zero can be ambiguous because no unique derivative exists there.

## So sánh và lựa chọn · Alternatives

Forward-mode differentiation is efficient for few input directions; reverse mode is efficient for one scalar loss with many parameters. Finite differences are easy to implement but expensive and approximate, so use them as a small-case oracle.
