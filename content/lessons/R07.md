## Why this matters

Relate torque to acceleration while keeping model terms physically meaningful. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

Kinematics tells you where a robot is. Dynamics tells you how forces and torques change its motion. Even a simple one-joint model exposes sign conventions, units, damping, and numerical integration choices that matter in larger robots.

![A pendulum with angle, gravity and torque, and a plot of energy over time for three integrators](/lesson-figures/R07.svg)

*Figure: the pendulum model and the energy drift of explicit Euler, symplectic Euler and RK4 (q0 = 1 rad, dt = 0.01 s).*

## Theory and derivation

A common manipulator form is $M(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau+J(q)^TF_{ext}$, with signs depending on the declared external-force convention. The mass matrix maps acceleration to torque; it is symmetric positive definite for independent unconstrained coordinates of an ordinary rigid mechanism.

For a point mass $m$ at distance $l$ from a pivot, measure $q$ from downward vertical. Kinetic energy is $K=ml^2\dot q^2/2$ and potential is $V=mgl(1-\cos q)$. Applying $d(\partial L/\partial\dot q)/dt-\partial L/\partial q=\tau$ to $L=K-V$ yields $ml^2\ddot q+mgl\sin q=\tau$. Add viscous damping $b\dot q$ on the left.

Energy satisfies $\dot E=\tau\dot q-b\dot q^2$, so without torque and damping it should be conserved in the ideal continuous model. A numerical method may drift; step-size experiments distinguish integration error from an incorrect dynamics equation.

## Worked example

At q=0, gravity torque is zero. With m=l=1, q̇=0, and τ=2, acceleration is 2 rad/s². At q=π/2, no damping, and τ=0, acceleration is −g/l, restoring motion toward downward vertical. The negative sign follows the chosen potential.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
from math import sin
def acceleration(q,qd,tau,m=1.,l=1.,g=9.81,b=.1):
    return (tau-b*qd-m*g*l*sin(q))/(m*l*l)
assert acceleration(0,0,2) == 2
```

### Tests

```python
# hand-computed (lesson worked example)
assert pend_acc(0.0, 0.0, 2.0) == 2.0
assert abs(pend_acc(math.pi / 2, 0.0, 0.0) + 9.81) < 1e-12           # restoring, -g/l
assert abs(pend_acc(math.radians(30), 0.0, 0.0, 0.5, 0.4, 9.81) + 12.2625) < 1e-9

# integrator energy behaviour (q0 = 1 rad, 10 s, dt = 0.01)
d_eu = max_energy_drift(step_euler, 1.0, 0.0, 0.01, 10.0)
d_sy = max_energy_drift(step_symplectic, 1.0, 0.0, 0.01, 10.0)
d_rk = max_energy_drift(step_rk4, 1.0, 0.0, 0.01, 10.0)

# 2R toolkit: hand values and structure
M0 = mass_matrix_2r(0.0, 1, 1, 0.5, 0.5)
```

### Library track

Compare your fixed-step RK4 with SciPy's adaptive integrators, then use the solver's event detection to measure a large-amplitude period. Install with `pip install numpy scipy`, put this file next to `dynamics_lab.py` (importing it runs your tests first) and run it.

```python
import numpy as np
from scipy.integrate import solve_ivp
from dynamics_lab import pend_acc, energy, max_energy_drift, step_rk4, mass_matrix_2r

# 1. Adaptive integrators from SciPy vs your fixed-step RK4 (frictionless pendulum, q0 = 1 rad, 10 s)
f = lambda t, y: [y[1], pend_acc(y[0], y[1], 0.0)]
E0 = energy(1.0, 0.0)
for method, kw in (("RK45", dict(rtol=1e-3, atol=1e-6)), ("RK45", dict(rtol=1e-9, atol=1e-12)),
                   ("DOP853", dict(rtol=1e-10, atol=1e-12))):
    sol = solve_ivp(f, (0, 10), [1.0, 0.0], method=method, **kw)
    drift = max(abs(energy(q, qd) - E0) for q, qd in sol.y.T)
    print("%-7s rtol=%.0e: %4d steps, max energy drift %.1e J" % (method, kw["rtol"], sol.t.size - 1, drift))
print("your rk4 (dt=0.01): 1000 steps, drift %.1e J" % max_energy_drift(step_rk4, 1.0, 0.0, 0.01, 10.0))
assert drift < 1e-8

# 2. Period of a large swing from the same solver (compare with 1.1803 x T0 for a 90 degree release)
ev = lambda t, y: y[0]
ev.terminal, ev.direction = True, -1                              # first downward crossing of q = 0
sol = solve_ivp(f, (0, 5), [np.pi / 2, 0.0], events=ev, rtol=1e-10, atol=1e-12)
T = 4 * sol.t_events[0][0]
T0 = 2 * np.pi * np.sqrt(1 / 9.81)
print("period ratio %.4f (exact 1.1803)" % (T / T0))
assert abs(T / T0 - 1.1803) < 1e-3

# 3. Mass matrix eigenvalues over the workspace of the 2R arm
for q2 in np.linspace(-np.pi, np.pi, 13):
    M = np.array(mass_matrix_2r(q2, 1, 1, 0.5, 0.5))
    assert np.allclose(M, M.T) and np.linalg.eigvalsh(M).min() > 0
print("library track passed")
```

Expected: low-tolerance `RK45` loses about 0.08 J of energy while `DOP853` at `rtol=1e-10` stays near $10^{-10}$ J, the period ratio prints `1.1803`, and `library track passed`.

## Failure modes

The Coriolis matrix is convention-dependent; the physically meaningful velocity-force product must match the chosen formulation. A torque limit, contact, or joint constraint can invalidate a free-motion model.

## Alternatives and trade-offs

Analytical equations clarify small mechanisms. Rigid-body dynamics libraries scale to many links but still need correct inertial parameters and frame conventions. A learned model can capture residuals but should be tested outside the training trajectory.

## Exercise answers

1. $\ddot q=-\frac{g}{l}\sin q=-\frac{9.81}{0.4}\cdot0.5=-12.26$ rad/s². The mass cancels. The sign is negative (toward $q=0$): restoring.
2. $ml^2=2\cdot0.25=0.5$ kg m². Holding torque at horizontal: $mgl=2\cdot9.81\cdot0.5=9.81$ N m (kg m²/s² = N m).
3. $\tau\dot q$ is the power the motor delivers to the joint, $b\dot q^2$ is the power dissipated by damping. If the motor opposes the motion ($\tau\dot q<0$) with no damping, the energy decreases at rate $|\tau\dot q|$: the motor acts as a brake.
4. For small $q$, $\sin q\approx q$ so $\ddot q=-(g/l)q$, i.e. a harmonic oscillator with $\omega=\sqrt{g/l}$ and $T_0=2\pi\sqrt{l/g}=2\pi\sqrt{0.25/9.81}=1.003$ s. At 90° the period is $1.1803\cdot1.003=1.184$ s. The true restoring torque $mgl\sin q$ is smaller than the linear $mglq$ for large $q$, so the pendulum accelerates less and takes longer.
5. The sign of the gravity term is flipped (`+ m*g*l*sin(q)`), so the 'restoring' torque is repelling and the downward position becomes unstable (it has built the upright equilibrium at $q=0$). An energy check against $E=\tfrac12ml^2\dot q^2+mgl(1-\cos q)$ would show kinetic energy growing while the computed potential energy also grows: energy is not conserved. A hand test, $a(0.1)<0$ for a pendulum hanging down, catches it immediately.
6. Explicit Euler gains energy systematically (about +5.1 J, doubling the energy over 10 s); symplectic Euler stays bounded with an oscillating error of about 0.07 J; RK4 is the most accurate (about $5\times10^{-8}$ J). Explicit Euler's amplification factor per step has modulus greater than 1 for oscillators.
7. Joint torque $\tau=mgl=2\cdot9.81\cdot0.4=7.85$ N m. Motor torque $=7.85/(50\cdot0.8)=0.196$ N m. The gearbox multiplies torque so the motor holds with 50 times less torque (at the cost of reflected inertia $N^2$ and friction), so the maximum achievable acceleration is limited by the motor torque times $N$ divided by the total inertia (link + $N^2\times$ rotor inertia).
8. $q_2=0$: $M_{11}=2\cdot0.25+0.25+2\cdot0.25=1.25$, $M_{12}=0.25+0.25=0.5$, $M_{22}=0.25$; $\det=0.3125-0.25=0.0625>0$. $q_2=90^\circ$: $M_{11}=0.75$, $M_{12}=0.25$, $M_{22}=0.25$; $\det=0.1875-0.0625=0.125>0$. Both are positive definite, but joint 1's effective inertia drops from 1.25 to 0.75. A controller tuned for one fixed inertia would be too sluggish when the arm is stretched (large inertia, the same torque gives less acceleration) and too aggressive, possibly oscillatory, when folded (small inertia); computed-torque control uses $M(q)$.
9. $K=\tfrac12ml^2\dot q^2$, $V=mgl(1-\cos q)$. $\frac{d}{dt}\frac{\partial L}{\partial\dot q}=ml^2\ddot q$, $\frac{\partial L}{\partial q}=-mgl\sin q$, so $ml^2\ddot q+mgl\sin q=\tau$. $E=K+V$: $\dot E=ml^2\dot q\ddot q+mgl\sin q\,\dot q=\dot q(\tau-b\dot q)$ when damping $b\dot q$ is added. For the 2R arm: $g_1=(m_1+m_2)gl_1\cos q_1+m_2gl_2\cos(q_1+q_2)=2\cdot9.81\cdot0.5+9.81\cdot0.5=14.715$ N m, $g_2=m_2gl_2\cos(q_1+q_2)=4.905$ N m.
10. Let $q=\pi+\epsilon$: $\sin q=-\sin\epsilon\approx-\epsilon$, so $\ddot\epsilon=+(g/l)\epsilon$, growth rate $\sqrt{g/l}=3.13$ s⁻¹ (exponential $e^{3.13t}$). Factor 10: $t=\ln10/3.13=0.74$ s. The controller must react in a small fraction of that, e.g. 50-100 Hz or faster, which sets a minimum loop rate.
11. (a) Stiff, damped system: use an implicit or small-step method, or RK4 with a step below the stiffness limit; explicit Euler becomes unstable beyond $\Delta t\approx2/\lambda_{max}$. (b) Long energy-conserving run: RK4 with small step or a symplectic (geometric) integrator, which keeps the energy bounded for all time. (c) Real-time: cheap per step; semi-implicit Euler with a small step, accepting small energy error. Explain the cost: RK4 needs 4 force evaluations per step.
12. A good answer: steady state at $q_{ss}$ where $k_p(q^*-q_{ss})=mgl\sin q_{ss}$; error $\approx mgl\sin q^*/(k_p+mgl\cos q^*)$, shrinking as $k_p$ grows but never vanishing. With $\tau_g=mgl\sin q$ added (a feedforward of the gravity torque) the steady-state error is zero. The energy balance check holds to integration accuracy for RK4.
