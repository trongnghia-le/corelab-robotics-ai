## Why this matters

Relate torque to acceleration while keeping model terms physically meaningful. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

Kinematics tells you where a robot is. Dynamics tells you how forces and torques change its motion. Even a simple one-joint model exposes sign conventions, units, damping, and numerical integration choices that matter in larger robots.

## Theory and derivation

A common manipulator form is $M(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau+J(q)^TF_{ext}$, with signs depending on the declared external-force convention. The mass matrix maps acceleration to torque; it is symmetric positive definite for independent unconstrained coordinates of an ordinary rigid mechanism.

For a point mass $m$ at distance $l$ from a pivot, measure $q$ from downward vertical. Kinetic energy is $K=ml^2\dot q^2/2$ and potential is $V=mgl(1-\cos q)$. Applying $d(\partial L/\partial\dot q)/dt-\partial L/\partial q=\tau$ to $L=K-V$ yields $ml^2\ddot q+mgl\sin q=\tau$. Add viscous damping $b\dot q$ on the left.

Energy satisfies $\dot E=\tau\dot q-b\dot q^2$, so without torque and damping it should be conserved in the ideal continuous model. A numerical method may drift; step-size experiments distinguish integration error from an incorrect dynamics equation.

## Worked example

At q=0, gravity torque is zero. With m=l=1, q̇=0, and τ=2, acceleration is 2 rad/s². At q=π/2, no damping, and τ=0, acceleration is −g/l, restoring motion toward downward vertical. The negative sign follows the chosen potential.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
from math import sin
def acceleration(q,qd,tau,m=1.,l=1.,g=9.81,b=.1):
    return (tau-b*qd-m*g*l*sin(q))/(m*l*l)
assert acceleration(0,0,2) == 2
```

## Failure modes

The Coriolis matrix is convention-dependent; the physically meaningful velocity-force product must match the chosen formulation. A torque limit, contact, or joint constraint can invalidate a free-motion model.

## Alternatives and trade-offs

Analytical equations clarify small mechanisms. Rigid-body dynamics libraries scale to many links but still need correct inertial parameters and frame conventions. A learned model can capture residuals but should be tested outside the training trajectory.
