## Why this matters

Build a free-body model before writing a dynamics equation. This lesson develops the core calculation before asking you to apply it in a new setting. Start with the diagnostic if you think you already know it; prior tool use is not evidence of understanding.

## Intuition

Mechanics turns a physical system into a model with chosen boundaries. A free-body diagram identifies forces acting on that system; it does not include both halves of an action-reaction pair as forces on the same body. Coordinate and sign conventions come before equations.

## Theory and derivation

In an inertial frame, $\sum F=ma$ for constant mass. Velocity is $v=\dot x$ and acceleration $a=\dot v$. For a horizontal mass pulled by force $u$ with viscous drag $cv$, $m\dot v=u-cv$. With $u=0$, drag dissipates energy rather than creating it.

Kinetic energy is $K=mv^2/2$. Differentiate to get $\dot K=mv\dot v=v(u-cv)=uv-cv^2$. This independently checks the damping sign. Under constant acceleration, integrating $\dot v=a$ gives $v=v_0+at$, then integrating $\dot x=v$ gives $x=x_0+v_0t+at^2/2$.

The model neglects deformation, actuator dynamics, and many friction effects. State these assumptions explicitly. In SI units, force is kg·m/s² and energy is kg·m²/s²; adding incompatible terms is a modeling error even when code runs.

## Worked example

A 2 kg cart experiences +6 N drive and −2 N drag. Net force is +4 N, so acceleration is +2 m/s². Starting from rest, after 3 s under constant acceleration its velocity is 6 m/s and displacement 9 m. Its kinetic energy is 36 J.

## Reference implementation

Read the contract first. Predict the output before running the code locally. This reference is for studying; a submission copied from it is assisted practice, not independent evidence.

```python
m=2.; drive=6.; drag=2.
a=(drive-drag)/m
t=3.; v=a*t; x=.5*a*t*t
assert (a,v,x) == (2.,6.,9.)
```

## Failure modes

A large velocity does not require a large net force; acceleration does. A normal force and gravity can cancel vertically while horizontal motion continues. A model valid at low speed may fail when drag changes regime.

## Alternatives and trade-offs

Point-mass models isolate translation. Rigid-body models add rotational inertia. Flexible models describe deformation but require more parameters and data; begin with the least complex model that explains the measurements.
